cron 을 어떻게 거나

리눅스·맥이면 crontab -e 로 열고 위의 '크론 한 줄' 을 그대로 붙입니다.

crontab -e        # 편집
crontab -l        # 지금 걸린 것 보기

n8n 을 쓰신다면 Schedule Trigger → Execute Command 두 노드면 됩니다. 6번 n8n 워크플로우 생성기로 뼈대를 만들 수 있습니다.

시각은 되도록 새벽으로 두세요. 유튜브 API 쿼터는 태평양 시간 자정에 초기화되고, 낮에 돌리면 손으로 돌린 것과 겹쳐 쿼터를 두 번 씁니다.
