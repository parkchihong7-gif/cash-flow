# 집 컴퓨터에서 쓰기

바탕화면에 두 개의 바로가기를 만들어 두시면 됩니다.

| 눌러야 할 때 | 파일 | 무엇을 하나 |
|---|---|---|
| **집에 돌아오셨을 때** | `집컴퓨터_최신화.bat` | 밖에서 고친 것을 받아 오고 화면을 다시 만듭니다 |
| **실제로 쓰실 때** | `대시보드_열기.bat` | 대시보드를 띄웁니다 (창을 닫으면 닫힘) |

## 왜 최신화가 따로 필요한가

Claude 는 **저장소**에 고칩니다. 어느 컴퓨터에서 부르시든, 어느 IP 에서
들어오시든 결과는 저장소 한 곳에 쌓입니다. 집 컴퓨터는 그걸 **받아 와야**
최신이 됩니다. 자동으로 흘러 들어오지 않습니다.

    밖에서 (휴대폰·회사·어디든)
      Claude 에게 시킴 → 저장소에 쌓임
                            ↓
    집에 와서  집컴퓨터_최신화.bat 한 번  → 내 컴퓨터가 최신이 됨

## 고객 자료는 안 건드립니다

`data\dashboard.db` 에 고객·접속키·실행 기록이 들어 있습니다. 이 파일은
**저장소에 올라가지 않고** 이 컴퓨터에만 있습니다. 최신화해도 그대로입니다.

> 백업은 이 파일 하나만 복사해 두시면 됩니다.

## 내 컴퓨터에서 고친 게 있으면 멈춥니다

최신화 스크립트는 덮어쓰기 전에 확인합니다. 고친 것이 있으면 목록을 보여
주고 멈춥니다 — 모르는 새에 작업이 사라지는 일을 만들지 않습니다.

## 파이썬이 없으시면

[python.org](https://www.python.org/downloads/) 에서 받으실 때
**"Add Python to PATH"** 를 꼭 체크하세요. 안 하시면 위 파일들이 파이썬을
못 찾습니다.
