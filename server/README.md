# 무료 키 서버 — 구글 앱스 스크립트

16종 + 공인중개사 + maim 이 **한 서버를 같이 씁니다.** 돈이 들지 않습니다.

**사장님이 손으로 만드실 것은 없습니다.** 구글 시트도, 비밀번호도, 설정값도
서버가 알아서 만들어 알려 드립니다. 사장님은 **관리자 화면에서 키만
발급**하시면 됩니다.

---

# 설치 — 세 단계

## 1. 붙여넣기

[script.google.com](https://script.google.com) → **새 프로젝트**

편집기에 있는 것을 전부 지우고, **`server/keyserver.bundle.gs`** 를 통째로
복사해 붙여 넣습니다. 파일은 **하나뿐**입니다 — 서버와 관리자 화면이 그 안에
같이 들어 있습니다.

### ⚠ 복사가 자꾸 잘립니다 — 이 방법으로 하세요

**브라우저 화면에서 `Ctrl+A` 로는 안 됩니다.** 브라우저는 긴 글을 화면에
보이는 만큼만 그려 두어서, 스크롤한 데까지만 복사됩니다. 그래서 150줄,
250줄 하는 식으로 제각각 잘립니다.

**파일로 내려받아 메모장에서 복사하세요.** 메모장은 안 보이는 부분까지
전부 복사합니다.

1. 아래 링크를 **마우스 오른쪽 클릭 → 다른 이름으로 링크 저장**
   [keyserver.bundle.gs 내려받기](https://raw.githubusercontent.com/parkchihong7-gif/cash-flow/claude/new-session-9lqy1t/server/keyserver.bundle.gs)
2. 내려받은 파일을 **오른쪽 클릭 → 연결 프로그램 → 메모장**
3. 메모장에서 `Ctrl+A` → `Ctrl+C`
4. 앱스 스크립트 편집기에서 `Ctrl+A` (있는 것 전부 선택) → `Ctrl+V`

### 붙여 넣은 뒤 꼭 확인

편집기에서 `Ctrl+End` 를 눌러 **맨 아래로** 가세요. 두 가지를 보십시오.

| 보실 것 | 맞는 값 |
|---|---|
| 마지막 줄 번호 | **1257** |
| 마지막 줄 내용 | `// ⛳ 여기가 마지막 줄입니다...` |

줄 번호가 1257 보다 작으면 잘린 것입니다. 그대로 저장하면 이 오류가 납니다.

```
구문 오류: SyntaxError: Unexpected end of input
```

**이 오류는 코드가 잘못된 것이 아니라 파일이 중간에 끊겼다는 뜻입니다.**
위의 복사 방법으로 다시 해 주세요.

저장(`Ctrl+S`)합니다.

## 2. `처음설정` 실행

편집기 위쪽 함수 고르는 칸에서 **`처음설정`** 을 고르고 **[실행]** 을 누릅니다.

처음 한 번은 권한을 묻습니다. 사장님이 직접 만든 스크립트라 "확인되지 않은
앱" 이라고 뜨는데, **고급 → (프로젝트 이름)(으)로 이동 → 허용** 하시면 됩니다.

아래 실행 기록에 이렇게 나옵니다.

```
════════════════════════════════════════════════
  설치가 끝났습니다.

  관리자 비밀번호 :  7KQM-3XTB-9PWD-HRJ4

  장부 시트 : https://docs.google.com/spreadsheets/d/.../edit

  다음 할 일
   1. 오른쪽 위 [배포] → [새 배포] → 유형 **웹 앱**
   2. 다음 사용자로 실행: **나**
      액세스 권한이 있는 사용자: **모든 사용자**
   3. 나오는 주소를 열면 **관리자 화면**이 바로 뜹니다.
════════════════════════════════════════════════
```

**이 비밀번호를 적어 두세요.** 구글 시트는 이때 자동으로 만들어집니다 —
사장님 드라이브에 `접속키 장부 (지우지 마세요)` 라는 이름으로 생깁니다.

## 3. 배포

오른쪽 위 **[배포] → [새 배포] → 유형: 웹 앱**

| | |
|---|---|
| 다음 사용자로 실행 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** |

> "모든 사용자" 가 불안해 보이지만, **들어오려면 키나 비밀번호가 있어야**
> 합니다. 이 값을 "나" 로 두면 고객이 키를 넣어도 구글 로그인 화면이 떠서
> 아무도 못 들어옵니다.

나온 주소를 **브라우저로 열면 관리자 화면이 바로 뜹니다.** 주소를 어디에
적어 넣으실 필요가 없습니다 — 그 주소가 곧 서버입니다.

2번에서 받은 비밀번호를 넣으시면 끝입니다.

# 쓰는 법 — 키 발급

관리자 화면에서:

1. 프로그램을 고릅니다 (16종 + 공인중개사 + maim)
2. **무슨 키**: 판매(산 분이 관리자가 됨) / 고객용(쓰는 화면만)
3. 이름·이메일을 넣고 **[발급하고 보내기]**

**1차키 1개 + 2차키 3개(PC·노트북·휴대폰)** 가 만들어지고, 그 자리에서
이메일이 나갑니다. 화면에도 키가 그대로 보여서 복사해 쓰실 수 있습니다.

그 밖에: 발급한 키 목록, 정지·풀기·지우기, 프로그램 하나만 초기화.

---

# 키 체계

| | |
|---|---|
| **1차키** | 사람 한 명당 하나. 동시 접속 수를 세지 않습니다 |
| **2차키** | 1차키 아래 PC·노트북·휴대폰 셋. **기기당 한 세션** |
| **판매 키** | 산 분이 그 프로그램의 관리자가 되어, 자기 고객에게 키를 줍니다 |
| **고객용 키** | 쓰는 화면만 열립니다 |

같은 2차키로 다른 기기에서 들어오면 **먼저 있던 기기가 잠깁니다.**
키를 빌려줘도 기기 수만큼만 쓸 수 있게 한 것입니다.

---

# 대시보드에서 발급해도 시트에 올라가게

관리자 화면과 대시보드, 두 군데서 발급하시면 장부가 갈라집니다.
**대시보드 한 곳에서만** 발급하시고 싶으시면 `.env` 에 두 줄을 넣으세요.

```
KEYSERVER_URL=https://script.google.com/macros/s/.../exec
KEYSERVER_PASSWORD=2번에서_받은_비밀번호
```

그러면 대시보드의 발급 버튼이 이렇게 움직입니다.

1. **시트에 먼저 넣습니다.**
2. 들어간 뒤에야 대시보드 목록에 같은 코드로 적습니다.

순서가 이래야 합니다. 반대로 하면 시트에 못 들어간 키를 고객에게 보내게
되고, 고객은 그 자리에서 "키가 틀렸다" 는 말을 듣습니다. 이 순서면 최악이라도
시트에만 있고 대시보드에 안 보이는 키가 생기는데, 그건 고객에게 해가 없습니다.

인터넷이 끊겼거나 비밀번호가 틀리면 **아무것도 안 만들어집니다.**

# 다시 배포할 때 — 꼭 보세요

코드를 고친 뒤에는 **[배포] → [배포 관리] → 연필(수정) → 버전: 새 버전 → [배포]**
로 하십시오.

**[새 배포]** 를 누르면 **주소가 바뀝니다.** 이미 고객에게 알려 준 주소가
죽어서, 판 키가 전부 안 먹는 것처럼 보이게 됩니다.

# 한도

구글이 하루에 허용하는 양이 있습니다. 개인 Gmail 계정은 메일 발송이 가장
빡빡합니다(하루 100통 안팎). 정확한 수는 계정 종류와 시점에 따라 달라지므로
[구글 문서](https://developers.google.com/apps-script/guides/services/quotas)
를 보세요.

한도를 넘어 메일이 안 나가도 **키는 이미 만들어져 있습니다.** 화면이 그 키를
보여 주니 복사해서 직접 보내시면 됩니다. 그렇게 되도록 일부러 만들었습니다 —
메일이 막혔다고 고객에게 줄 키까지 사라지면 안 되니까요.

# 무엇이 막혀 있나

| | |
|---|---|
| 비밀번호 없이 목록 보기 | 막힘 |
| `처음설정` 을 웹 주소로 부르기 | 막힘 (비밀번호를 갈아 버릴 수 있음) |
| `처음설정` 을 두 번 눌러 비밀번호가 바뀌기 | 막힘 (알려 드린 것이 죽음) |
| 산 사람이 관리자키를 찍어 내기 | 막힘 (재판매 방지) |
| 학원 A 가 학원 B 의 고객 보기·정지·삭제 | 막힘 |
| 한 프로그램 키로 다른 프로그램 문 열기 | 막힘 |
| 같은 2차키로 다른 기기에서 들어오기 | 열리고, **먼저 있던 기기가 잠김** |
| 1차키를 정지하면 (시트에서 손으로 해도) | 딸린 2차키 세션까지 끊김 |
| 키를 찍어 보기 | 10분에 10번까지 |
| 목록에 남의 세션 표가 딸려 나오기 | 막힘 |
| 서버가 터졌을 때 시트 id 가 새기 | 막힘 |
| 초기화 | `confirm=초기화` 라고 적어야 움직임 |

전부 시험으로 지키고 있습니다. 일부러 뚫어 보고 시험이 잡는지도 확인했습니다.

# 되살리기

장부가 구글 시트라, 백업이 따로 필요 없습니다. 시트를 열어
**파일 → 사본 만들기** 를 눌러 두시면 그것이 그대로 백업입니다.

시트에서 값을 직접 고치셔도 서버가 그 값을 그대로 따릅니다
(예: `status` 칸을 `suspended` 로 바꾸면 그 키가 그 자리에서 막힙니다).

# 고쳤을 때 — 올리기 전에

`keyserver.gs` 나 `web/admin.html` 을 고치셨으면 **반드시 다시 묶으세요.**
안 묶으면 구글에는 옛 판이 올라갑니다.

```bash
python -m tools.build_keyserver          # 한 장으로 다시 묶기
node --test server/tests/keyserver.test.js   # 서버 규약 60개
pytest tests/test_keyserver_web.py           # 서버 + 화면 + 묶음 최신 여부
```

시험이 **올릴 파일 그대로**를 돌립니다. 다시 만든 사본이 아닙니다.

관리자 화면을 눈으로 보시려면:

```bash
node server/tests/serve.js 8790
# http://127.0.0.1:8790/admin.html  (비밀번호: 주인비밀번호7)
```

# 파일이 왜 둘인가

| 파일 | 무엇 |
|---|---|
| `server/keyserver.gs` | 서버 원본. **고치는 곳은 여기** |
| `web/admin.html` | 관리자 화면 원본. 고치는 곳은 여기 |
| `server/keyserver.bundle.gs` | 위 둘을 묶은 것. **구글에 붙여 넣는 것은 이것** |

묶음은 만들어진 파일입니다. 손으로 고치지 마세요.
