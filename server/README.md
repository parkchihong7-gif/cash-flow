# 무료 키 서버 — 구글 앱스 스크립트

16종 + 공인중개사 + maim 이 **한 서버를 같이 씁니다.** 돈이 들지 않습니다.

```
GitHub Pages          구글 앱스 스크립트          구글 시트 + Gmail
 (화면 · 무료)    →     (서버 · 무료)       →      (장부 · 발송 · 무료)
```

공인중개사 기출문제 프로그램이 이미 이 방식으로 돌고 있습니다. 그 규약을
그대로 지키면서 **프로그램 구분**과 **이중 판매**를 더한 것이 이 폴더입니다.

| | 여기 |
|---|---|
| 돈 | 안 듭니다 |
| 항상 켜져 있나 | 예 — 고객이 아무 때나 키로 들어옵니다 |
| 집 컴퓨터가 꺼져 있어도 | 됩니다 |
| 발급·이메일 발송 | 됩니다 |
| 무거운 실행(문서·리포트 만들기) | 안 됩니다 → 집 컴퓨터에서 하십니다 |

---

## 1. 장부로 쓸 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 빈 시트를 하나 만듭니다.
2. 이름을 `접속키 장부` 쯤으로 바꿉니다.
3. 주소창의 `/d/` 와 `/edit` 사이 글자가 **시트 id** 입니다. 적어 두세요.

```
https://docs.google.com/spreadsheets/d/  1AbC...xyz  /edit
                                         ↑ 이 부분
```

칸은 만들지 않으셔도 됩니다. 서버가 처음 돌 때 알아서 만듭니다.

## 2. 스크립트 붙이기

1. 그 시트에서 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 열린 편집기의 내용을 전부 지우고, `server/keyserver.gs` 를 **통째로
   복사해 붙여** 넣습니다.
3. 저장합니다.

## 3. 설정값 넣기

편집기 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성** 에서 넣습니다.
**코드에 적지 마세요.** 저장소는 공개라 그대로 새어 나갑니다.

| 이름 | 값 | 꼭 필요한가 |
|---|---|---|
| `ADMIN_PASSWORD` | 사장님만 아는 비밀번호 | **필수** |
| `SIGNING_SECRET` | 아무 긴 글자 (예: 무작위 40자) | **필수** |
| `SHEET_ID` | 1번에서 적어 둔 시트 id | 권장 |
| `DEFAULT_PROGRAM` | `exam` — 프로그램을 안 보내는 옛 화면이 쓸 이름 | 권장 |
| `MAIL_FROM_NAME` | 메일에 보일 보내는 사람 이름 | 선택 |

> `ADMIN_PASSWORD` 를 안 넣으면 **아무도 못 들어옵니다.** 빈 값을 비밀번호로
> 치면 주소만 아는 사람이 고객 명단을 전부 가져가기 때문에, 그렇게 만들어
> 두었습니다.

## 4. 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 유형은 **웹 앱**.
3. 두 값을 이렇게 둡니다.

   | | |
   |---|---|
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   "모든 사용자" 가 불안해 보이지만, **들어오려면 키나 비밀번호가 있어야**
   합니다. 이 값을 "나" 로 두면 고객이 키를 넣어도 구글 로그인 화면이 떠서
   아무도 못 들어옵니다.

4. 처음에는 권한을 묻습니다. "고급 → 안전하지 않은 페이지로 이동" 을 눌러
   허용하십시오. 사장님이 직접 만든 스크립트라 그렇게 뜹니다.
5. 나오는 주소를 적어 둡니다. `.../exec` 으로 끝납니다.

```
https://script.google.com/macros/s/AKfycb.../exec
```

## 5. 잘 되는지 보기

주소 뒤에 `?action=ping` 을 붙여 브라우저로 열어 보세요.

```json
{"ok":true,"at":"2026-09-19T23:53:32"}
```

이렇게 나오면 살아 있는 것입니다.

## 6. 관리자 화면 열기

`web/admin.html` 을 브라우저로 열고(또는 GitHub Pages 에 올려서 열고),
4번에서 받은 주소와 `ADMIN_PASSWORD` 를 넣으면 됩니다. 주소는 그 브라우저가
기억하므로 한 번만 넣으시면 됩니다.

여기서 할 수 있는 일:

- 프로그램을 고르고 **1차키 1개 + 2차키 3개(PC·노트북·휴대폰)** 를 발급
- 그 자리에서 **이메일 발송**
- 발급한 키 목록 보기, 정지·풀기·지우기
- 프로그램 하나만 초기화

## 다시 배포할 때 — 꼭 보세요

코드를 고친 뒤에는 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**
로 하십시오.

**새 배포** 를 누르면 **주소가 바뀝니다.** 이미 고객에게 알려 준 주소가
죽어서, 판 키가 전부 안 먹는 것처럼 보이게 됩니다.

---

## 한도

구글이 하루에 허용하는 양이 있습니다. 개인 Gmail 계정 기준으로 메일 발송이
가장 빡빡합니다(하루 100통 안팎). 정확한 수는 계정 종류와 시점에 따라
달라지므로 [구글 문서](https://developers.google.com/apps-script/guides/services/quotas)
를 보세요.

한도를 넘어 메일이 안 나가도 **키는 이미 만들어져 있습니다.** 관리자 화면이
그 키를 보여 주니 복사해서 직접 보내시면 됩니다. 그렇게 되도록 일부러
만들었습니다 — 메일이 막혔다고 고객에게 줄 키까지 사라지면 안 되니까요.

## 고쳤을 때 — 올리기 전에 시험

이 폴더의 시험은 **실제로 올릴 `keyserver.gs` 그 파일을** 돌립니다.
다시 만든 사본이 아닙니다.

```bash
node --test server/tests/keyserver.test.js    # 서버 규약
pytest tests/test_keyserver_web.py            # 서버 + 관리자 화면(브라우저)
```

관리자 화면을 눈으로 보시려면:

```bash
node server/tests/serve.js 8790
# http://127.0.0.1:8790/admin.html  (비밀번호: 주인비밀번호7)
```

## 무엇이 막혀 있나

| | |
|---|---|
| 비밀번호 없이 목록 보기 | 막힘 |
| `ADMIN_PASSWORD` 를 안 정한 채 배포 | 아무도 못 들어옴 |
| 산 사람이 관리자키를 찍어 내기 | 막힘 (재판매 방지) |
| 학원 A 가 학원 B 의 고객 보기·정지·삭제 | 막힘 |
| 한 프로그램 키로 다른 프로그램 문 열기 | 막힘 |
| 같은 2차키로 다른 기기에서 들어오기 | 열리고, **먼저 있던 기기가 잠김** |
| 1차키를 정지하면 (시트에서 손으로 해도) | 딸린 2차키 세션까지 끊김 |
| 키를 찍어 보기 | 10분에 10번까지 |
| 목록에 남의 세션 표가 딸려 나오기 | 막힘 |
| 서버가 터졌을 때 시트 id 가 새기 | 막힘 |
| 초기화 | `confirm=초기화` 라고 적어야 움직임 |

전부 시험으로 지키고 있습니다. 일부러 뚫어 보고 시험이 잡는지도 확인했습니다.

## 되살리기

장부가 구글 시트라, 백업이 따로 필요 없습니다. 시트를 열어
**파일 → 사본 만들기** 를 눌러 두시면 그것이 그대로 백업입니다.
시트에서 값을 직접 고치셔도 서버가 그 값을 그대로 따릅니다
(예: `status` 칸을 `suspended` 로 바꾸면 그 키가 그 자리에서 막힙니다).
