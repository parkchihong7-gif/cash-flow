# cash-flow

부업 프로그램 제작·판매 프로젝트. 작업 지침과 조사 결과 전문은 [`CLAUDE.md`](./CLAUDE.md)에 있다.

## 구조

```
CLAUDE.md      작업 브리프 (조사 결과 · 금지 사항 · 우선순위)
products/      상품별 폴더 (상품 1개 = 폴더 1개)
```

## 시작하기

1. `CLAUDE.md` §3 절대 금지 사항을 먼저 읽는다.
2. `CLAUDE.md` §5 우선순위에서 착수할 상품을 고른다.
3. `products/<이름>/` 을 만들고 §7 코딩 작업 규칙에 따라 구현한다.

비밀키는 `.env`에 두고 커밋하지 않는다. 각 상품 폴더의 `.env.example`을 복사해 쓴다.
