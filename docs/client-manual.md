# 사용 설명서 (구매자용)

> 구매해 주셔서 감사합니다.
> **컴퓨터를 잘 모르셔도 따라 하실 수 있게** 순서대로 적었습니다.
> 중간에 막히시면 6장을 보시고, 그래도 안 되면 판매자에게 문의해 주세요.

---

## 1장. 무엇을 받으셨나요

프로그램과 함께 **관리 화면(대시보드)** 을 받으셨습니다.
명령어를 외울 필요 없이, 브라우저에서 버튼을 눌러 프로그램을 쓰실 수 있습니다.

화면은 이렇게 생겼습니다.

- **왼쪽**: 가지고 계신 프로그램 목록 (1번, 2번…)
- **가운데**: 선택한 프로그램의 내용
- **위쪽 탭**: 열람 / 수정 / 테스트 / 회원관리 / 매뉴얼

가장 많이 쓰실 곳은 **테스트** 탭입니다. 여기서 실행합니다.

## 2장. 처음 준비 (한 번만 하면 됩니다)

### 2-1. 파이썬 설치 확인

이 프로그램은 파이썬이라는 프로그램 위에서 돕니다.

**Windows**: 시작 메뉴에서 `cmd` 를 검색해 명령 프롬프트를 열고 아래를 칩니다.
**Mac**: `터미널` 앱을 열고 아래를 칩니다.

```
python --version
```

`Python 3.11.0` 처럼 숫자가 나오면 됩니다 (3.11 이상이어야 합니다).

**"찾을 수 없다"고 나오면** https://www.python.org 에서 내려받아 설치하세요.
Windows 라면 설치 첫 화면에서 **"Add Python to PATH" 를 반드시 체크**하셔야 합니다.

### 2-2. 필요한 부품 설치

받으신 폴더 안에서 아래 한 줄을 실행합니다.

```
pip install -r requirements.txt
```

몇 분 걸립니다. 글자가 빠르게 지나가다 멈추면 끝난 것입니다.

### 2-3. AI 키 발급받기

이 프로그램은 Claude 라는 AI 를 씁니다. **키는 직접 발급받으셔야 합니다.**

1. https://console.anthropic.com 에 가입합니다 (구글 계정으로 가능)
2. 왼쪽 메뉴 **Settings → API Keys** 로 갑니다
3. **Create Key** 를 누르고 이름은 아무거나 적습니다
4. `sk-ant-` 로 시작하는 긴 글자가 나옵니다. **이 창을 닫으면 다시 볼 수 없으니 복사해서 메모장에 붙여두세요**
5. 왼쪽 메뉴 **Billing** 에서 카드를 등록하고 **10달러 정도 충전**합니다

> **💰 비용을 미리 알려드립니다**
>
> 프로그램을 한 번 돌릴 때마다 **수백 원** 정도의 AI 사용료가 발생합니다.
> 10달러(약 1만 4천 원)를 충전하시면 수십 번은 쓰실 수 있습니다.
>
> 이 돈은 **판매자가 아니라 AI 회사(Anthropic)에 내는 것**입니다.
> 판매자는 이 금액을 받지 않습니다. 사용하신 만큼만 차감됩니다.

### 2-4. 키를 프로그램에 넣기

1. 받으신 폴더에서 `.env.example` 이라는 파일을 찾습니다
2. 복사해서 이름을 **`.env`** 로 바꿉니다 (앞에 점이 있습니다)
3. `.env` 를 메모장으로 엽니다
4. `ANTHROPIC_API_KEY=` 라고 적힌 줄을 찾아, `=` 뒤에 아까 복사한 키를 붙여넣습니다

   ```
   ANTHROPIC_API_KEY=sk-ant-여기에복사한키
   ```
5. 저장하고 닫습니다

> ⚠️ **이 파일은 비밀번호와 같습니다.** 누구에게도 보내지 마세요.
> 남에게 알려지면 그 사람이 쓴 AI 요금이 내 카드로 나갑니다.

### 2-5. 관리 화면 켜기

```
python -m dashboard
```

브라우저가 저절로 열립니다. 안 열리면 주소창에 아래를 직접 입력하세요.

```
http://127.0.0.1:8000
```

**화면 위에 노란 경고가 없으면 준비 끝입니다.**
노란 경고가 보이면 2-4 를 다시 확인해 주세요.

**끄는 법**: 검은 창에서 `Ctrl` 키와 `C` 키를 같이 누릅니다.

## 3장. 프로그램 쓰기

### 3-1. 먼저 읽어보기

왼쪽에서 프로그램을 누르면 **열람** 탭이 열립니다.
여기에 **이용 순서**가 1번부터 적혀 있습니다. 처음이라면 끝까지 읽어보세요.

### 3-2. 내 정보 입력하기

**수정** 탭으로 갑니다. **파일 편집** 표에서 "입력 파일" 옆의 **편집** 을 누릅니다.

글자를 채워 넣는 화면이 나옵니다. 각 항목이 무엇인지는 화면 설명을 보세요.

**입력할 때 지켜야 할 것**

- **숫자에는 쉼표를 넣지 마세요.** `149,000` (X) → `149000` (O)
- **주소는 `https://` 로 시작해야 합니다**
- **목록 항목 앞에는 `- ` (하이픈 + 공백)** 를 붙입니다
- **들여쓰기는 스페이스만.** 탭 키를 쓰면 오류가 납니다

다 쓰셨으면 **저장** 을 누릅니다.

> 💡 잘못 고쳐도 걱정 마세요. 저장할 때마다 직전 내용이 자동으로 보관됩니다.

### 3-3. 먼저 연습으로 돌려보기

**테스트** 탭으로 갑니다. 버튼이 두 개 있습니다.

| 버튼 | 설명 |
|---|---|
| **모의 실행 (비용 없음)** | 연습용. 돈이 들지 않고 몇 초면 끝납니다. **결과물 모양만** 볼 수 있고 내용은 예시입니다 |
| **실제 실행** | 진짜. AI 를 불러 내 정보로 만듭니다. 수백 원이 들고 2~5분 걸립니다 |

**처음에는 꼭 모의 실행부터** 눌러보세요. 어떤 모양의 결과가 나오는지 확인하는 단계입니다.

### 3-4. 진짜로 만들기

**실제 실행** 을 누릅니다. **2~5분 걸립니다.** 화면이 멈춘 것처럼 보여도 기다려 주세요.
창을 닫거나 새로고침하지 마세요.

### 3-5. 결과 보기

끝나면 색깔 있는 상자가 나옵니다.

| 색 | 뜻 | 할 일 |
|---|---|---|
| 🟢 초록 (성공) | 잘 만들어졌습니다 | **산출물 보기** 를 누르세요 |
| 🟡 노랑 (경고) | 만들어졌지만 고칠 곳이 있습니다 | 아래 글상자를 읽고 해당 부분 수정 |
| 🔴 빨강 (실패) | 만들어지지 않았습니다 | 6장을 보세요 |

**산출물 보기** 를 누르면 만들어진 파일 목록이 나옵니다.
각 파일 옆의 **열기** 를 누르면 브라우저에서 바로 볼 수 있습니다.

## 4장. ⚠️ 반드시 직접 확인하셔야 할 것

**여기가 가장 중요합니다. 건너뛰지 마세요.**

### 4-1. 나온 결과는 "초안"입니다

AI 가 만든 글은 그럴듯해 보이지만 **틀린 내용이 섞일 수 있습니다.**
반드시 처음부터 끝까지 읽어보시고 고쳐서 쓰세요.

### 4-2. 법으로 정해진 표기를 직접 채우셔야 합니다

만들어진 판매 페이지 맨 아래에 이런 부분이 비어 있습니다.

```
환불 정책: (판매 전 반드시 채우세요 ...)
사업자 정보 / 문의처: (판매 전 채우세요)
```

**이 부분을 비워둔 채 판매하면 법 위반입니다.**
온라인으로 물건을 파는 사람은 아래를 반드시 표시해야 합니다.

- 환불(청약철회) 가능 기간과 조건
- 상호, 대표자 이름, 사업자등록번호
- 통신판매업 신고번호
- 주소와 전화번호

파일을 메모장으로 열어 이 부분을 실제 내용으로 바꿔주세요.

### 4-3. 없는 후기나 실적을 넣지 마세요

후기가 없으면 **비워두시면 됩니다.** 비워두면 그 부분이 아예 만들어지지 않습니다.
빈칸이 허전하다고 그럴듯한 후기를 지어내면 표시광고법 위반입니다.

### 4-4. AI 표시가 자동으로 들어갑니다

만들어진 글 맨 아래에 이런 문구가 붙습니다.

> ※ 이 콘텐츠는 생성형 AI의 도움을 받아 제작되었습니다.

2026년 1월 시행된 법에 따른 표시입니다. **지우지 마세요.**

## 5장. 결과가 마음에 안 들 때

같은 정보로 다시 돌리면 조금씩 다른 글이 나옵니다. 몇 번 돌려보고 좋은 걸 고르셔도 됩니다.
(다만 돌릴 때마다 사용료가 듭니다.)

더 좋게 만드는 방법은 **입력을 더 구체적으로 쓰는 것**입니다.

| 이렇게 쓰면 | 이렇게 바꾸면 |
|---|---|
| "직장인" | "퇴근 후 1시간을 쓰는 3년차 사무직" |
| "시간이 절약됩니다" | "2시간 걸리던 일이 20분으로 줄어듭니다" |
| "콘텐츠 기획의 어려움" | "올릴 거리가 떠오르지 않아 한 시간씩 휴대폰만 봅니다" |

**대상은 좁을수록, 표현은 구체적일수록 좋은 글이 나옵니다.**

## 6장. 안 될 때 (증상별)

| 화면에 이렇게 나오면 | 뜻 | 이렇게 하세요 |
|---|---|---|
| `ANTHROPIC_API_KEY 가 없습니다` | 키를 안 넣었습니다 | 2-4 를 다시 |
| `Claude API 오류 401` | 키가 잘못됐습니다 | 콘솔에서 키를 새로 발급받아 다시 넣으세요 |
| `credit balance is too low` | 충전 잔액이 없습니다 | 콘솔 Billing 에서 충전 |
| `쿼터 초과` / `429` | 너무 자주 눌렀습니다 | **1분 기다렸다가** 다시. 계속 누르면 더 오래 걸립니다 |
| `입력이 올바르지 않습니다` | 입력 파일에 오류 | 어느 항목인지 메시지에 나옵니다. 3-2 의 주의사항 확인 |
| `ModuleNotFoundError` | 부품이 안 깔렸습니다 | 2-2 를 다시 |
| `Address already in use` | 이미 켜져 있습니다 | 브라우저에서 `http://127.0.0.1:8000` 접속 |
| 한글이 □□□ 로 깨짐 | 파일 저장 방식 문제 | 메모장에서 "다른 이름으로 저장" → 인코딩을 **UTF-8** 로 |
| 5분 넘게 안 끝남 | 시간 초과 | 자동으로 멈춥니다. 다시 실행해 보세요 |

**그래도 안 되면**: 화면에 나온 글자를 **그대로 복사**해서 판매자에게 보내주세요.
"안 돼요" 보다 훨씬 빨리 해결됩니다.

## 7장. 알아두시면 좋은 것

**Q. 인터넷 없이 쓸 수 있나요?**
아니요. AI 를 부르기 때문에 인터넷이 필요합니다. 모의 실행은 인터넷 없이도 됩니다.

**Q. 내가 입력한 내용이 어디로 가나요?**
입력하신 내용은 AI 에게 전달됩니다. 결과물은 내 컴퓨터에만 저장되고 다른 곳으로 가지 않습니다.

**Q. 몇 번까지 쓸 수 있나요?**
횟수 제한은 없습니다. AI 사용료(충전 잔액)가 남아 있는 만큼 쓰실 수 있습니다.

**Q. 다른 컴퓨터에서도 쓸 수 있나요?**
네. 폴더를 통째로 복사하시면 됩니다. `.env` 파일도 같이 복사하세요.

**Q. 만든 결과물을 팔아도 되나요?**
네, 만드신 결과물은 구매자님 것입니다. 다만 프로그램 자체를 재판매하시면 안 됩니다.

**Q. 이 프로그램이 돈을 벌어주나요?**
아니요. **글 쓰는 시간을 줄여주는 도구**입니다.
판매 성과는 상품, 가격, 얼마나 많은 사람이 보는지에 따라 달라집니다.
이 도구가 결과를 보장하지 않습니다.
