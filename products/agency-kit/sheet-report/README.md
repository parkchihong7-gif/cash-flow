# 모듈 B — 구글시트 주간 보고서

시트 범위를 읽어 **주간(또는 월간) 보고서**를 만듭니다. 마크다운과 워드로요.

---

## 숫자와 말의 경계

이 모듈에서 가장 중요한 설계입니다.

| | 누가 |
|---|---|
| 합계·증감·비중·상위 5 | **pandas** (`aggregate.py`) |
| 해석 3줄 · 할 일 2가지 | Claude (`narrate.py`) |

**Claude 는 계산하지 않습니다.** 이미 계산된 값을 인용만 합니다.

왜냐하면 모델이 더한 숫자는 사람이 검산할 수 없기 때문입니다. 보고서 숫자가
시트와 다르면 그 보고서는 한 번에 못 쓰게 되고, 대행 계약도 거기서 끝납니다.

그래서 **뒤에서 한 번 더 확인합니다.** 나온 글의 숫자가 집계에 있던 값인지
대조하고, 없는 숫자가 있으면 다시 시킵니다. 두 번 해도 안 되면 보고서에
"확인하세요" 를 적습니다. 조용히 넘어가지 않습니다.

---

## 설치와 실행

```bash
pip install -r requirements.txt
cp .env.example .env

# 시트로
python run.py --sheet <시트ID> --range "매출!A:F" --period week

# 시트가 아직 없으면 CSV 로
python run.py --csv sample_sales.csv --period week --dry-run
```

`--dry-run` 은 Claude 를 부르지 않습니다(비용 0원).

산출물은 `outputs/report_<날짜>.md` 와 `.docx` 입니다.

---

## 시트 준비

칸 이름은 **순서가 아니라 이름**으로 찾습니다. 이런 이름이면 됩니다.

| 찾는 것 | 되는 이름 |
|---|---|
| 날짜 | 날짜, 일자, date, 주문일, 결제일 |
| 금액 | 매출, 금액, amount, 결제금액, 판매액 |
| 분류(선택) | 채널, 상품, 카테고리, 구분, 품목 |

- 시트를 **서비스 계정 이메일에 '뷰어' 로 공유**해야 읽힙니다. 가장 흔한 실수입니다
- 위에 제목 줄이 있으면 범위를 `매출!A3:F` 처럼 잡아 주세요
- `1,200원` 같은 글자도 숫자로 읽습니다

## 보내기 (선택)

```bash
python run.py --csv sample_sales.csv --slack --email
```

주소가 없으면 **오류가 아니라 "안 보냈습니다"** 로 끝납니다. 파일은 이미
만들어져 있습니다.

슬랙은 '들어오는 웹훅' 만 씁니다. 봇 토큰은 권한 범위가 넓어 고객 작업 공간에
들이기 부담스럽습니다. 웹훅은 그 채널 하나에만 글을 쓸 수 있습니다.

## n8n 으로 매주 자동 실행

```bash
uvicorn serve:app --host 0.0.0.0 --port 8090     # 부를 수 있는 주소를 엽니다
python make_workflow.py                          # workflow.json 을 만듭니다
```

n8n 에서 `workflow.json` 을 가져오면 **매주 월요일 9시 → 보고서 생성 → 슬랙**
흐름이 만들어집니다.

- 노드 규격은 6번 상품(`products/n8n-gen/templates/nodes/`)의 틀을 그대로 씁니다.
  두 군데에 같은 값을 적어 두면 한쪽이 조용히 낡기 때문입니다
- **자격증명은 이름만** 들어 있습니다. 토큰은 n8n 화면에서 넣으세요
- n8n 이 도커 안이면 주소가 `localhost` 가 아니라 `host.docker.internal` 입니다

`serve.py` 에는 **인증이 없습니다.** 같은 기계나 사설망 안에서만 쓰고, 바깥에
열어야 하면 앞에 프록시를 두세요.

## 보내기 전에 보셔야 할 것

1. 합계가 시트 값과 맞는지 (한 칸만 찍어 보셔도 됩니다)
2. 해석에 적힌 숫자가 표와 같은지
3. 할 일 2가지가 **이번 주에 실제로 할 수 있는 일**인지

3번이 중요합니다. "마케팅 강화" 같은 말이 나오면 다시 시키세요. 프롬프트에
"달력에 적을 수 있는 일로 쓰라" 고 넣어 두었지만 가끔 뭉뚱그립니다.
