# 모듈 C — 인스타 예약 발행

이미지·릴스를 **정해진 시각에** 인스타그램에 올립니다.
공식 Instagram Graph API 만 씁니다.

---

## 없는 기능과 그 이유

이 모듈에는 **팔로우·언팔로우·좋아요·DM 발송 기능이 없습니다.** 못 만든 게
아니라 만들지 않았습니다.

| 기능 | 왜 없나 |
|---|---|
| 자동 팔로우 / 언팔로우 | Meta 플랫폼 정책 위반입니다. 계정이 정지됩니다 |
| 자동 좋아요 | 같습니다. '비정상 활동' 으로 잡힙니다 |
| 콜드 DM 발송 | 정책 위반이고, 받는 사람에게도 민폐입니다 |

이런 기능을 넣으면 **고객 계정이 날아갑니다.** 팔로워 3천 명을 모으는 데 1년이
걸리는데, 정지는 하루면 됩니다. 대행사가 고객 자산을 잃게 만드는 일은 하지
않습니다(CLAUDE.md §3-4).

허용되는 것은 **사용자가 먼저 행동한 대화에 24시간 안에 답하는 것**뿐입니다.
그건 이 모듈이 아니라 카카오 챗봇(모듈 A)이나 인스타 자동응답 도구의 영역입니다.

---

## 준비

### 계정

- **비즈니스 또는 크리에이터 계정**이어야 합니다. 개인 계정은 API 로 못 올립니다
- 페이스북 페이지와 연결되어 있어야 합니다
- Meta 개발자 앱에 `instagram_content_publish`, `instagram_basic`,
  `pages_read_engagement` 권한이 있어야 합니다

### 미디어 주소

인스타가 **직접 받아 갈 수 있는 공개 https 주소**여야 합니다.

- 되는 것: S3, 클라우드플레어 R2, 자체 서버, 이미지 호스팅
- **안 되는 것: 구글드라이브 공유 링크, 드롭박스 미리보기 링크**

이 부분에서 처음 쓰는 분들이 가장 많이 막힙니다.

### 설치

```bash
pip install -r requirements.txt
cp .env.example .env
```

토큰이 없어도 됩니다. **큐와 승인 흐름은 토큰 없이 그대로 돌아갑니다.**

---

## 쓰는 순서

```bash
python manage.py import queue.csv                   # 1. 큐에 넣기 (초안)
python manage.py draft 1 --note "가을 신상 사진"     # 2. 캡션 초안 만들기
python manage.py show 1                             # 3. 읽어 보기
python manage.py approve 1 --by "홍길동"             # 4. 사람이 승인
python manage.py run                                # 5. 때가 되면 올라감
```

### 4번을 건너뛸 수 없습니다

**승인하지 않은 글은 발행되지 않습니다.** 큐에서도 걸러 내고, 올리기 직전에
한 번 더 봅니다. 사람이 안 읽은 글이 고객 계정에서 나가는 일은 만들지 않습니다.

캡션을 고치면 **승인이 자동으로 풀립니다.** 승인한 문장과 다른 글이 나가면
안 되기 때문입니다.

---

## queue.csv

| 칸 | 뜻 |
|---|---|
| 발행시각 | `2026-09-18 11:00` |
| 미디어URL | 공개된 https 주소 |
| 캡션 | 비워 두면 `draft` 명령으로 만듭니다 |
| 해시태그 | `#태그1 #태그2` (10개 안쪽) |
| 종류 | `IMAGE` 또는 `REELS` |

같은 시각·주소는 다시 넣어도 건너뜁니다.

---

## 토큰 갱신 — 60일

```bash
python manage.py refresh-token
```

장기 토큰은 **60일이면 만료**됩니다. 만료되면 어느 날 조용히 안 올라갑니다.

그래서 리테이너 계약의 월 점검 항목에 넣어 두었습니다. 달력에 55일 뒤로
알림을 걸어 두시는 편이 안전합니다.

새 토큰은 화면에 전부 찍지 않고 `.token.new` 파일에 씁니다. 읽어서 `.env` 에
옮긴 뒤 지우세요.

---

## 한도

- 인스타는 **24시간에 25건**까지 받습니다. 넘으면 건너뛰고 기록에 남깁니다
- 릴스는 처리 시간이 걸립니다. 다 될 때까지 기다렸다가 올립니다(최대 2분)

---

## 안 될 때

| 증상 | 볼 곳 |
|---|---|
| `토큰이 만료됐거나 잘못됐습니다` | `refresh-token` 으로 갱신 |
| `권한이 모자랍니다` | 앱 권한 3가지 확인 |
| `미디어 주소가...` | 공개 https 인지. 드라이브 링크는 안 됩니다 |
| 올릴 때가 됐는데 안 올라감 | `manage.py list --status draft` — 승인을 안 하셨을 수 있습니다 |

`manage.py run --once` 로 한 번만 돌려 보면 무엇이 걸렸는지 한 줄씩 나옵니다.
