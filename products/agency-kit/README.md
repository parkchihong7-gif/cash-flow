# 11. 자동화 대행 납품 키트 (agency-kit)

소상공인에게 **설치해 주고 돈을 받는** 자동화 3종과 납품 문서 묶음입니다.

> **이 키트는 반복 업무 자동화 도구이며 매출을 보장하지 않습니다.**
> 문의 응대·주간 정산·게시물 예약에 드는 시간을 줄이는 것이 목적입니다.
> 그 시간으로 무엇을 하실지는 사장님이 정하십니다.

---

## 1. 무엇이 들어 있나

| 폴더 | 무엇 |
|---|---|
| `kakao-faq-bot/` | 카카오톡 채널 FAQ 챗봇 (오픈빌더 스킬 서버) |
| `sheet-report/` | 구글시트 → 주간 보고서 (마크다운 + 워드) |
| `insta-scheduler/` | 인스타그램 예약 발행 (승인한 것만) |
| `deliverables/` | 설치 가이드·계약서·점검표·크몽 상세페이지·AI 고지문 |

각 폴더에 README 가 따로 있습니다. **모듈은 따로 팔 수 있습니다.**

---

## 2. 빠른 시작

```bash
pip install -r requirements.txt

python cli.py doctor            # 돌 준비가 됐는지 봅니다
python cli.py demo --dry-run    # 세 모듈을 한 번씩 돌려 봅니다 (비용 0원)
python cli.py package --client "동네빵집" --plan standard
```

`demo` 는 세 모듈을 전부 돌려 보고 결과를 한 장으로 정리합니다.
시연할 때와 설치 직후 점검에 씁니다.

`package` 는 고객 이름을 채운 **납품 폴더**를 만듭니다.
`.env`·기록·이전 산출물은 빼고 복사하므로 그대로 압축해 보내셔도 됩니다.

## 3. 모듈마다 양보하지 않은 것

### A. 카카오 챗봇 — 5초

오픈빌더는 5초 안에 답을 못 받으면 끊습니다. 끊기면 고객 화면에는
"오류가 발생했습니다" 만 보입니다.

그래서 **어떤 일이 있어도 시간 안에 무언가를 돌려줍니다.** 글자 맞추기는 0초,
Claude 는 남은 시간까지만, 넘으면 "잠시 후 다시 문의" 로 넘깁니다.
기다리다 못 받으면 버립니다. 늦게 온 답은 쓸 데가 없습니다.

그리고 **시트에 있는 답은 그대로 내보냅니다.** 고객이 검수한 문장이라
AI 가 다시 쓰지 않습니다.

### B. 주간 보고서 — 숫자와 말의 경계

합계·증감·비중은 pandas 가 계산합니다. Claude 는 **해석 3줄과 할 일 2가지**만
씁니다. 모델이 더한 숫자는 사람이 검산할 수 없기 때문입니다.

나온 글의 숫자가 집계에 있던 값인지 **뒤에서 대조**합니다. 없는 숫자가 있으면
다시 시키고, 두 번 해도 안 되면 보고서에 "확인하세요" 를 적습니다.

### C. 인스타 예약 발행 — 사람 승인

**승인하지 않은 글은 발행되지 않습니다.** 큐에서 거르고, 올리기 직전에 한 번 더
봅니다. 캡션을 고치면 승인이 자동으로 풀립니다.

**자동 팔로우·좋아요·DM 발송 기능은 없습니다.** Meta 정책 위반이라 계정이
정지되고, 팔로워를 모으는 데 걸린 1년이 하루에 사라집니다(CLAUDE.md §3-4).

## 4. 파는 구성

| 패키지 | 구성 | 값 |
|---|---|---|
| BASIC | 챗봇만 | 550,000원 |
| STANDARD | 챗봇 + 보고서 | 880,000원 |
| PREMIUM | 3종 + 교육 2시간 | 1,200,000원 |
| 월 유지보수 | 점검·FAQ 개선·규격 변경 대응 | 50,000~100,000원 |

상세페이지 초안은 `deliverables/KMONG_LISTING.md` 에 있습니다.
5번 상품(크몽 상세페이지 카피 생성기)의 서식을 그대로 따릅니다.

### 유지보수를 꼭 권해 드리세요

- 인스타 토큰은 **60일마다 만료**됩니다. 그냥 두면 어느 날 조용히 멈춥니다
- 카카오·구글·메타는 규격을 예고 없이 바꿉니다
- 못 답한 질문을 모아 FAQ 를 채워 가는 것이 챗봇 품질의 전부입니다

이 세 가지가 월 유지비를 받는 실제 근거입니다.

## 5. 설치·납품 흐름

```
상담 → 준비물 안내 → FAQ 30줄 함께 채우기 → 설치 → 점검표 20항목 함께 확인
```

`deliverables/INSTALL_GUIDE.md` 가 고객용 설치 문서이고,
`deliverables/HANDOVER_CHECKLIST.md` 가 납품하는 날 같이 보는 점검표입니다.

**모든 키는 고객 계정으로 발급하십니다.** 대행사 계정으로 만들면 계약이 끝날 때
서로 곤란해집니다. 점검표 3번 항목입니다.

모두 **고객 계정으로 결제**합니다. 상담할 때 미리 말씀드리세요.

## 7. 한계와 정직하게 말할 것

- **AI 답변은 틀릴 수 있습니다.** 그래서 시트에 있는 질문은 시트 문장을 그대로
  내보내고, 없는 질문일 때만 AI 가 답하며 "담당자 확인 필요" 를 붙입니다
- **문의가 하루 5건 미만이면 굳이 필요하지 않습니다.** 직접 답하시는 편이
  빠릅니다. 이런 고객에게는 권하지 마세요
- 상담 내용이 매번 다른 업종(법률·의료)에는 맞지 않습니다
- 보고서는 **시트에 적힌 것만** 봅니다. 현금 결제나 누락분은 빠집니다
- 이 키트는 매출이나 문의 증가를 약속하지 않습니다

## 8. 규정

- AI 생성물 표시를 기본으로 켭니다 (인공지능기본법 제31조, 최대 3,000만 원 과태료)
- 대화 기록에 **이용자 아이디 원문을 저장하지 않습니다.** 전화번호·이메일·
  카드번호도 지우고 저장합니다
- 공식 API 만 씁니다. 브라우저 매크로나 비밀번호 저장형 자동화는 없습니다
- 사람 검수 지점을 파이프라인에 명시적으로 둡니다 (인스타 승인, 보고서 확인)

`deliverables/AI_NOTICE.md` 를 고객에게 함께 전달하세요.
