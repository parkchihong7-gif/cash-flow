# 설치 가이드

이 문서는 **개발을 모르셔도** 따라 하실 수 있게 썼습니다.
모듈 하나에 30분 정도 잡으시면 됩니다.

세 개를 한 번에 하지 마세요. **하나 끝내고 며칠 써 보신 뒤** 다음 것을 하세요.

> 📷 [스크린샷 자리 — 전체 구성도]

---

## 0. 먼저 준비할 것 (공통, 20분)

### 0-1. 컴퓨터 또는 서버

- 챗봇(모듈 A)은 **24시간 켜져 있어야** 합니다. 사무실 컴퓨터로는 어렵습니다
- 클라우드 서버 월 5,000~10,000원짜리면 충분합니다
- 보고서(모듈 B)와 인스타(모듈 C)는 필요할 때만 켜도 됩니다

### 0-2. Claude API 키

1. console.anthropic.com 에 가입합니다
2. API Keys → Create Key
3. 만들어진 키를 복사해 둡니다 (**다시 못 봅니다**)
4. 결제 수단을 등록합니다. 월 1만 원이면 작은 가게 문의량은 충분합니다

> 📷 [스크린샷 자리 — API 키 발급 화면]

### 0-3. 구글 서비스 계정 (모듈 A·B)

시트를 읽는 데 씁니다.

1. console.cloud.google.com → 새 프로젝트
2. API 및 서비스 → 라이브러리 → **Google Sheets API** 사용 설정
3. 사용자 인증 정보 → 서비스 계정 만들기
4. 키 → 새 키 만들기 → **JSON** → 내려받기
5. 내려받은 파일을 `credentials.json` 으로 이름을 바꿉니다

⚠️ **여기가 제일 많이 막히는 곳입니다.**
파일 안에 `client_email` 이 있습니다. 그 이메일 주소를 복사해서,
**읽을 시트에서 공유 → 그 주소를 뷰어로 추가**하세요.
이걸 안 하면 "권한이 없습니다"(403) 가 납니다.

> 📷 [스크린샷 자리 — 시트 공유 화면에 서비스 계정 이메일 넣기]

## 1. 모듈 A — 카카오 FAQ 챗봇 (30분)

### 1-1. FAQ 시트 만들기 (10분)

구글시트를 새로 만들고 시트 이름을 `FAQ` 로 바꿉니다. 첫 줄에 이렇게 씁니다.

| 질문 | 답변 | 카테고리 | 수정일 |
|---|---|---|---|
| 영업시간이 어떻게 되나요? | 평일 10시~19시입니다. | 기본정보 | 2026-09-01 |

**30줄쯤 채우고 시작하세요.** 완벽하게 채우려 하지 마시고, 실제로 많이 들어오는
질문부터 넣으세요. 못 답한 질문은 프로그램이 모아 줍니다.

### 1-2. 서버 띄우기 (10분)

```bash
cd kakao-faq-bot
cp .env.example .env        # 열어서 키와 SHEET_ID 를 채웁니다
docker compose up -d
curl localhost:8080/health  # {"status":"ok", ...} 가 나오면 됩니다
```

`SHEET_ID` 는 시트 주소 가운데의 긴 문자열입니다.
`docs.google.com/spreadsheets/d/` **여기** `/edit`

### 1-3. https 주소 만들기 (5분)

오픈빌더는 **https 주소만** 받습니다. 두 가지 길이 있습니다.

**(가) 이미 도메인이 있으시면** — Caddy 를 앞에 두면 인증서가 자동입니다.

```
your-domain.com {
    reverse_proxy localhost:8080
}
```

**(나) 도메인이 없으시면** — 클라우드(Render, Railway 등)에 올리면 https 주소를
같이 줍니다. 이 경우 `Dockerfile` 을 그대로 쓰시면 됩니다.

### 1-4. 오픈빌더 연결 (5분)

1. 카카오 i 오픈빌더 → 스킬 → 새 스킬
2. URL 에 `https://내주소/skill`
3. 시나리오 → 폴백 블록 → 응답을 '스킬데이터' 로 바꾸고 이 스킬 선택
4. 배포

> 📷 [스크린샷 자리 — 오픈빌더 스킬 등록 화면]

### 1-5. 확인

채널에 "영업시간이요" 라고 보내 보세요. 시트의 답이 오면 끝입니다.

안 오면 `docker compose logs -f` 를 보세요.

## 2. 모듈 B — 주간 보고서 (20분)

### 2-1. 시트 준비

매출 자료가 들어 있는 시트에 **날짜**와 **금액** 칸이 있으면 됩니다.
칸 이름은 '날짜/일자/date', '매출/금액/amount' 중 아무거나 괜찮습니다.

서비스 계정 이메일을 **뷰어로 공유**하는 것을 잊지 마세요.

### 2-2. 한 번 돌려 보기

```bash
cd sheet-report
cp .env.example .env
python run.py --csv sample_sales.csv --period week --dry-run
```

`outputs/` 에 `.md` 와 `.docx` 가 생기면 됩니다. 이제 진짜 시트로:

```bash
python run.py --sheet <시트ID> --range "매출!A:F" --period week
```

### 2-3. 매주 자동으로 (선택, 10분)

n8n 이 있으시면 `workflow.json` 을 가져오시면 됩니다.
없으시면 그냥 월요일마다 위 명령을 한 번 치셔도 됩니다. 10초면 끝납니다.

> 📷 [스크린샷 자리 — 완성된 보고서 예시]

## 3. 모듈 C — 인스타 예약 발행 (30분)

### 3-1. 계정 확인 (5분)

- 인스타 계정이 **비즈니스 또는 크리에이터**인지 (개인 계정은 안 됩니다)
- 페이스북 페이지와 연결되어 있는지

인스타 앱 → 설정 → 계정 유형에서 바꾸실 수 있습니다.

### 3-2. 토큰 받기 (15분)

1. developers.facebook.com → 앱 만들기 → '비즈니스'
2. 제품 추가 → Instagram Graph API
3. 권한: `instagram_content_publish`, `instagram_basic`, `pages_read_engagement`
4. 그래프 API 탐색기에서 토큰을 만듭니다
5. `.env` 에 `IG_ACCESS_TOKEN` 과 `IG_USER_ID` 를 넣습니다
6. `python manage.py refresh-token` 으로 **60일 토큰**으로 바꿉니다

> 📷 [스크린샷 자리 — 그래프 API 탐색기에서 토큰 만들기]

⚠️ 토큰은 **60일이면 만료**됩니다. 달력에 55일 뒤 알림을 걸어 두세요.

### 3-3. 큐에 넣고 승인하기 (10분)

```bash
cd insta-scheduler
python manage.py import queue.csv
python manage.py draft 1 --note "사진 설명" --brand "가게 이름"
python manage.py show 1                       # 읽어 보세요
python manage.py approve 1 --by "사장님"
python manage.py run                          # 켜 두면 때가 됐을 때 올라갑니다
```

**승인 전에는 아무것도 올라가지 않습니다.** 이건 안전장치입니다.

## 5. 자주 막히는 곳

| 증상 | 거의 이것입니다 |
|---|---|
| 시트를 못 읽음 (403) | 서비스 계정 이메일을 시트에 공유 안 함 |
| 오픈빌더가 응답을 못 받음 | http 주소를 넣음 (https 여야 합니다) |
| 챗봇이 "잠시 후" 만 함 | Claude API 키가 없거나 잔액이 없음 |
| 인스타 미디어 오류 | 구글드라이브 링크를 씀 (공개 https 여야 합니다) |
| 인스타 토큰 오류 | 60일이 지남 |

30분 해 보시고 안 되면 연락 주세요. 대부분 5분 안에 풀립니다.
