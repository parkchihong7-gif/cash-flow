# 크몽 등록용 상세페이지

> 이 문서는 **5번 상품(크몽 상세페이지 카피 생성기)의 서식**을 그대로 따릅니다.
> 입력 파일은 `deliverables/kmong_input.yaml` 입니다. API 키를 넣고
> `cd products/kmong-copy && python cli.py build ../agency-kit/deliverables/kmong_input.yaml`
> 를 돌리면 이 문서를 다시 만들 수 있습니다.
>
> **등록 전에 판매자가 직접 읽고 고쳐야 합니다.** 특히 실적·후기 자리는
> 비워 두었습니다. 없는 수치를 지어내면 서비스가 내려갑니다.

---

## 제목 5안

1. 카톡 문의 응대, 구글시트 한 줄로 관리하는 챗봇 설치해 드립니다
2. 소상공인 업무 자동화 3종 — 챗봇·주간보고서·인스타 예약 설치
3. 매주 반복하는 문의 응대와 정산 보고, 자동화로 시간을 줄여 드립니다
4. 1인 가게용 자동화 설치 (카톡 챗봇 + 시트 보고서 + 인스타 예약)
5. 개발 몰라도 됩니다 — 시트로 관리하는 카톡 FAQ 챗봇 설치

**고르는 기준**: 1번과 5번이 "개발 몰라도 된다" 를 앞세워 클릭이 잘 나옵니다.
2번은 무엇을 파는지 가장 분명합니다.

---

## 서비스 소개

문의 응대와 주간 정산에 매주 몇 시간씩 쓰고 계신 사장님을 위한 자동화 설치입니다.

카카오톡 채널에 들어온 질문에 **구글시트에 적어 두신 답**으로 자동 응답하고,
매출 시트를 읽어 **주간 보고서**를 만들고, 인스타 게시물을 **정해진 시각에**
올립니다.

코드를 만지실 필요가 없습니다. 답변을 바꾸고 싶으시면 **구글시트 한 줄만
고치시면** 됩니다.

## 이런 분께 추천합니다

- 카톡 문의에 같은 답을 하루에도 몇 번씩 하고 계신 분
- 영업시간·주차·환불 같은 질문이 반복되는 가게
- 매주 매출을 정리해 보고하거나 기록해 두시는 분
- 인스타에 올릴 글은 미리 써 두는데 시간 맞춰 올리기가 번거로우신 분

**이런 경우에는 맞지 않습니다**

- 문의가 하루 5건 미만이면 굳이 필요하지 않습니다. 직접 답하시는 편이 빠릅니다
- 상담 내용이 매번 다르고 개인 상황에 맞춰야 하는 업종(법률·의료 상담 등)
- **자동 팔로우·자동 좋아요·DM 대량 발송**을 원하시는 경우
  — 만들지 않습니다. 계정이 정지됩니다

## 진행 순서

**1. 상담 (구매 후 1일 내)**
어떤 문의가 많이 오는지, 어떤 시트를 쓰고 계신지 여쭤봅니다.

**2. 준비물 안내 (1~2일차)**
Claude API 키, 구글 서비스 계정, 인스타 비즈니스 계정 전환을 안내해 드립니다.
**모든 키는 사장님 계정으로 발급하십니다.** 제 계정으로 만들면 나중에
서로 곤란해집니다.

**3. FAQ 30줄 함께 채우기 (2~3일차)**
가장 오래 걸리는 부분입니다. 실제로 많이 오는 질문부터 채웁니다.

**4. 설치와 연결 (3~4일차)**
서버를 올리고 카카오 오픈빌더에 연결합니다.

**5. 함께 점검 (5일차)**
20항목 점검표를 화면을 같이 보면서 확인합니다.
"승인 없이는 인스타에 안 올라간다" 는 것도 직접 확인해 보십니다.

## 이 서비스의 차별점

### 구글시트 한 줄이면 답이 바뀝니다

답변을 고치려고 저를 부르실 필요가 없습니다. 시트를 고치시면 **5분 안에**
반영됩니다. 급하면 버튼 하나로 즉시 반영됩니다.

챗봇이 시트에 있는 답을 찾으면 **그 문장을 그대로** 내보냅니다. AI 가 다시
쓰지 않습니다. 사장님이 검수하신 문장이 그대로 나가야 환불·보증 같은 데서
문제가 생기지 않기 때문입니다.

### 보고서 숫자는 AI 가 만들지 않습니다

합계·증감·비중은 프로그램이 계산합니다. AI 는 **해석 3줄과 다음 주 할 일
2가지**만 씁니다. 그래서 보고서 숫자를 시트와 맞춰 보실 수 있습니다.

AI 가 집계에 없는 숫자를 쓰면 프로그램이 잡아내고 다시 시킵니다.

### 인스타는 승인해야만 올라갑니다

캡션 초안은 AI 가 쓰지만, **사람이 승인 버튼을 누르기 전에는 발행되지
않습니다.** 캡션을 고치면 승인이 자동으로 풀립니다.

자동 팔로우·좋아요·DM 발송 기능은 **넣지 않았습니다.** Meta 정책 위반이라
계정이 정지되고, 팔로워를 모으는 데 걸린 1년이 하루에 사라집니다.

## 패키지

### BASIC — 챗봇만 · 550,000원 · 5일

카톡 FAQ 챗봇 하나만 설치합니다.

- 오픈빌더 스킬 서버 설치와 연결
- 구글시트 FAQ 연동 (30줄까지 함께 작성)
- 설치 가이드 · AI 이용 고지문
- 납품 후 **2주** 안의 오류 수정

문의 응대만 줄이고 싶으신 분께 맞습니다.

### STANDARD — 챗봇 + 보고서 · 880,000원 · 7일  ⭐ 가장 많이 고르십니다

BASIC 에 주간 보고서를 더합니다.

- BASIC 전부
- 구글시트 → 주간 보고서 자동 생성 (워드·마크다운)
- 슬랙 또는 메일 발송 연결
- 매주 자동 실행 설정 (n8n 워크플로 포함)
- 납품 후 **1개월** 안의 오류 수정

문의도 줄이고 매출 정리도 자동으로 받아 보고 싶으신 분께 맞습니다.

### PREMIUM — 3종 + 교육 · 1,200,000원 · 10일

세 가지를 모두 설치하고 **직접 운영하시는 법**까지 알려 드립니다.

- STANDARD 전부
- 인스타그램 예약 발행 (큐·승인·토큰 갱신)
- **1:1 교육 2시간** (화면 공유) — 시트 관리, 못 답한 질문 확인, 캡션 승인
- 유지보수 계약서 초안
- 납품 후 **3개월** 안의 오류 수정

교육 2시간이 핵심입니다. 이걸 들으시면 웬만한 것은 직접 하실 수 있습니다.

### 월 유지보수 (선택) — 50,000~100,000원

- 월 1회 점검 (응답 현황, 못 답한 질문 목록, 인스타 토큰 만료일)
- FAQ 추가 제안
- 카카오·구글·메타 규격 변경 대응
- 월 2시간까지 문구·설정 변경

인스타를 쓰시면 권해 드립니다. **토큰이 60일마다 만료**되어 그냥 두면
어느 날 조용히 멈춥니다.

## 자주 묻는 질문

**Q. 설치하고 나면 제가 직접 관리할 수 있나요?**
네. FAQ 는 구글시트에서, 인스타 캡션은 명령 한 줄로 관리하십니다.
PREMIUM 의 교육 2시간을 들으시면 대부분 직접 하실 수 있습니다.

**Q. AI 답변이 틀리면 어떡하나요?**
시트에 있는 질문이면 **시트 문장이 그대로** 나가므로 틀릴 일이 없습니다.
시트에 없는 질문일 때만 AI 가 답하고, 그때는 "정확한 내용은 담당자 확인이
필요합니다" 가 붙습니다.

가격·환불처럼 중요한 내용은 **시트에 정확한 문장으로 넣어 두시는 것**이
가장 안전합니다.

**Q. 인스타 자동 팔로우도 되나요?**
안 됩니다. 만들지 않습니다. Meta 정책 위반이라 계정이 정지됩니다.
이 서비스는 **공식 API 로 예약 발행만** 합니다.

**Q. 비용이 얼마나 드나요?**
설치비 외에 Claude API 사용료가 듭니다. 작은 가게 문의량이면 **월 1만 원**
안쪽입니다. 서버를 쓰시면 월 5,000~10,000원이 더 듭니다. 모두 사장님
계정으로 결제하십니다.

**Q. 카톡 채널이 아직 없는데요?**
채널 개설부터 함께 해 드립니다. 30분이면 됩니다.

**Q. 답변이 늦게 오면 어떻게 되나요?**
카카오는 5초 안에 답을 못 받으면 끊습니다. 그래서 4초를 넘기면
"잠시 후 다시 문의해 주세요" 로 넘어가게 해 두었습니다. 오류 화면이
뜨는 것보다 낫습니다.

**Q. 환불이 되나요?**
작업 시작 전에는 전액 환불됩니다. 시작 후에는 크몽 정책을 따릅니다.
설치가 기술적으로 불가능한 경우(계정 조건 미충족 등)에는 전액 환불해 드립니다.

## 구매 전 확인해 주세요

- 카카오톡 **채널**이 필요합니다 (없으면 함께 만듭니다)
- 인스타는 **비즈니스·크리에이터 계정**이어야 합니다 (개인 계정은 API 로
  발행이 안 됩니다)
- Claude API 키 발급에 **해외 결제 카드**가 필요합니다
- 챗봇은 24시간 켜져 있어야 하므로 **서버 또는 클라우드**가 필요합니다
