# 문의 응답 템플릿 작성 규칙

크몽에서 문의 응답 속도와 태도가 판매로 이어진다.
미리 써 두면 **당황하지 않고, 실수로 정책을 어기지 않는다.**

## 8종

1. **견적 문의** — 범위를 물어보고 어느 패키지에 해당하는지 안내
2. **기간 단축 요청** — 가능한 경우와 조건, 불가능하면 왜
3. **범위 밖 요청** — 거절이 아니라 "별도 견적"으로 넘긴다
4. **수정 요청 (범위 안)** — 언제까지 가능한지, 어떻게 보내면 되는지
5. **수정 요청 (범위 초과)** — 추가 비용을 미리 밝힌다
6. **환불 요청** — 감정 상하지 않게, 절차를 명확히
7. **작업 지연 안내** — 먼저 알리는 쪽이 낫다
8. **완료 후 리뷰 요청** — 부담 주지 않게

## 공통 규칙

- **첫 문장에서 감사 인사.** 두 번째 문장부터 본론
- 답변 가능 시간을 밝힌다: "영업일 기준 24시간 안에"
- 거절할 때도 **대안을 준다**
- `[ ]` 로 채울 자리를 표시한다. 그대로 복사해 쓰되 상황에 맞게 고치라는 뜻

## 크몽 정책 (반드시 지킨다)

**외부 연락처를 절대 쓰지 않는다.** 전화번호·이메일·카카오톡·외부 링크 모두 금지다.
"크몽 메시지로 문의 주세요" 로 통일한다. 이걸 어기면 계정이 정지될 수 있다.

## 출력 형식

```json
{
  "scripts": [
    {"situation": "견적 문의", "when": "이럴 때 씁니다",
     "body": "안녕하세요, ... [채울 자리] ...", "tip": "쓸 때 주의할 점"}
  ]
}
```
