# 패키지·제목 작성 규칙

## 패키지 3단 구성

크몽 구매자는 대부분 **STANDARD** 를 고른다. 그래서 STANDARD 를 기준으로 짜고
BASIC 은 "부족함이 보이게", PREMIUM 은 "욕심나게" 만든다.

| 단계 | 역할 |
|---|---|
| BASIC | 최소 구성. 가격이 부담스러운 사람용. 여기서 뭐가 빠지는지 분명히 |
| STANDARD | 대부분이 고르는 기본. 가장 공들여 쓴다 |
| PREMIUM | 급하거나 욕심나는 사람용. 작업일 단축이나 추가 산출물로 차이를 만든다 |

- 패키지 제목은 **20자 이내**
- 패키지 설명은 **100자 이내**
- 포함 항목은 3~6개. 상위 패키지는 하위 항목을 모두 포함한다
- 작업일은 상위로 갈수록 같거나 짧게
- 수정 횟수는 상위로 갈수록 같거나 많게

## 제목 10안

크몽 검색은 제목의 앞부분을 더 크게 본다. **검색 키워드를 앞에 둔다.**

- (X) "믿을 수 있는 전문가가 만드는 로고 디자인"
- (O) "로고 디자인 | 3일 완성, 파일 일체 제공"

- **25자 이내**. 넘으면 검색 결과에서 잘린다
- 10안이 서로 달라야 한다. 조사만 바꾼 것은 다른 안이 아니다
- 각 안에 어떤 키워드를 앞세웠는지 `keyword` 로 함께 낸다

## 검색 태그 20개

- 구매자가 실제로 검색창에 칠 말로 쓴다
- 한 단어와 두 단어 조합을 섞는다
- 카테고리명·서비스명·산출물명·상황어를 고루 담는다

## 출력 형식

```json
{
  "packages": [
    {"tier": "BASIC", "title": "20자 이내", "description": "100자 이내",
     "includes": ["항목1", "항목2"], "days": 5, "revisions": 1}
  ],
  "titles": [{"text": "25자 이내", "keyword": "앞세운 키워드"}],
  "tags": ["태그1", "태그2"]
}
```

가격은 입력에서 받으므로 만들지 않는다.
