# 크몽 상세페이지 카피 생성기 (kmong-copy)

서비스 정보를 넣으면 **크몽 상세페이지 전체 + 패키지 3단 + 제목 10안 + 문의 응답 템플릿**을
만들고, 등록 전 점검까지 해 주는 CLI입니다.

> ## ⚠️ 이 도구는 초안 생성기입니다. 등록 전 판매자 검수가 필수입니다.
>
> 특히 **환불·수정 정책**은 실제 운영 방식과 맞춰 고치셔야 합니다.
> 상세페이지에 적은 내용과 실제 운영이 다르면 분쟁에서 불리합니다.

## 설치

```bash
# 저장소 루트에서
pip install -r requirements.txt
cp .env.example .env      # ANTHROPIC_API_KEY 를 채웁니다
```

## 실행

```bash
cd products/kmong-copy
python cli.py build service_input.yaml
python cli.py build service_input.yaml --dry-run   # 비용 없이 형태 확인
```

종료 코드: 0 점검 통과 / 2 확인 필요 / 1 오류.

## 크몽 등록 순서 매핑표

만들어진 파일을 크몽 어느 칸에 넣는지 순서대로 적었습니다.

| 순서 | 크몽 등록 화면 | 넣을 칸 | 쓸 파일 | 어디를 보나 |
|---|---|---|---|---|
| 1 | 서비스 등록 시작 | **카테고리** | — | 입력한 `category` 를 그대로 |
| 2 | 기본 정보 | **서비스 제목** (25자) | `title_variants.json` | `제목_후보` 10안 중 하나. 검색 키워드가 앞에 오는 것을 고르세요 |
| 3 | 기본 정보 | **검색 태그** | `title_variants.json` | `검색_태그` 20개를 그대로 |
| 4 | 가격 설정 | **BASIC 패키지** | `packages.json` | `패키지[0]` — 패키지명·설명·제공 항목·작업일·수정 횟수·가격 |
| 5 | 가격 설정 | **STANDARD 패키지** | `packages.json` | `패키지[1]` |
| 6 | 가격 설정 | **PREMIUM 패키지** | `packages.json` | `패키지[2]` |
| 7 | 서비스 설명 | **상세 설명 본문** | `detail_page.md` | 헤드라인부터 '작업 전 준비해 주실 것' 까지 |
| 8 | 서비스 설명 | **이미지 영역** | — | ⚠️ **직접 올리셔야 합니다.** 작업물 3~5장 |
| 9 | 요청사항 | **구매자 요청사항** | `detail_page.md` | '작업 전 준비해 주실 것' 섹션을 옮겨 적으세요 |
| 10 | 서비스 설명 | **수정·환불 안내** | `detail_page.md` | '수정·환불 정책' 표. **본인 기준으로 고친 뒤** 넣으세요 |
| 11 | FAQ | **자주 묻는 질문** | `detail_page.md` | '자주 묻는 질문' 7개를 질문/답변으로 나눠 입력 |
| 12 | 등록 전 | **최종 점검** | `compliance_report.md` | ⚠️ 항목이 없는지 확인 |
| 13 | 등록 후 | 문의가 오면 | `inquiry_scripts.md` | 상황별로 복사해서 답변 |

**7번 상세 설명**은 크몽 에디터가 마크다운을 그대로 받지 않습니다.
`detail_page.md` 를 열어 섹션 단위로 복사해 붙여넣고 제목·목록 서식을 에디터에서 다시 잡으세요.

## 입력 — `service_input.yaml`

| 키 | 설명 |
|---|---|
| `service_name` | 서비스 이름 |
| `category` | 크몽 카테고리 |
| `what_you_deliver` | 구매자가 실제로 받는 것 2~10개 |
| `who_for` | 누구를 위한 서비스인지 한 줄. **좁을수록 좋습니다** |
| `differentiators` | 차별점 **정확히 3개** |
| `turnaround_days` | 기본 작업일 (BASIC 기준) |
| `price_basic` / `price_standard` / `price_premium` | 가격. BASIC < STANDARD < PREMIUM |
| `proof` | 실적·후기. **비우면 '사례 준비 중'** |
| `faq_seed` | 꼭 넣고 싶은 FAQ 질문. 비워도 됩니다 |

## 산출물 — `outputs/<서비스명>/`

| 파일 | 내용 |
|---|---|
| `detail_page.md` | 상세페이지 전문. 헤드라인 → 요약 → 추천 대상 → 제공 내용(표) → 프로세스 5단계 → 차별점 → 포트폴리오 자리 → FAQ 7개 → 준비 요청 → 수정·환불 정책 → AI 고지 |
| `packages.json` | BASIC/STANDARD/PREMIUM. **크몽 입력 폼 필드명 기준** |
| `title_variants.json` | 제목 10안(25자 이내, 글자 수 표시) + 검색 태그 20개 |
| `inquiry_scripts.md` | 문의 응답 템플릿 8종 |
| `compliance_report.md` | 금지 문구·크몽 정책·전자상거래법 표기 검사 결과 |

## 세 가지 규칙을 프로그램이 강제합니다

### 1. 성과를 단정하는 표현 금지

성과를 단정하는 표현 30개를 검사합니다. 목록은 `shared/banned_phrases.py` 에 있습니다.
걸리면 해당 섹션만 최대 2회 다시 만들고, 그래도 남으면 `compliance_report.md` 에
경고로 남깁니다. 조용히 넘어가지 않습니다.

### 2. 성과 수치는 `proof` 에 있는 것만

`proof` 를 비우면 포트폴리오 자리에 **"사례 준비 중"** 이 들어가고,
프롬프트에도 "수치를 만들지 말 것"을 명시합니다.
지어낸 실적 하나가 서비스 전체를 내려가게 만듭니다.

### 3. 외부 연락처 유도 금지 (크몽 정책)

크몽은 플랫폼 밖 거래 유도를 금지합니다. 적발되면 서비스가 내려가고
반복되면 계정이 정지됩니다. 아래를 자동으로 잡습니다.

| 검사 항목 | 예 |
|---|---|
| 전화번호 | `010-1234-5678`, `02-123-4567` |
| 이메일 주소 | `hello@example.com` |
| 카카오톡 유도 | 카톡, 오픈채팅 |
| 다른 메신저 | 텔레그램, 라인, 위챗 |
| SNS 계정 | 인스타 DM, 네이버 톡톡 |
| 직거래 유도 | 직거래, 따로 연락, 계좌 이체 |
| 플랫폼 이탈 | 수수료 아끼고, 현금가 |
| 외부 링크 | `kmong.com` 이 아닌 주소 |

**AI가 만든 카피뿐 아니라 입력하신 값도 검사합니다.**
차별점 칸에 전화번호를 적는 경우가 실제로 있기 때문입니다.

## 판매자가 직접 채워야 하는 것

프로그램이 만들 수 없거나, 만들면 위험한 것들입니다.

- **포트폴리오 이미지** — 크몽 상세페이지의 이미지 영역. 작업물 3~5장
- **환불·수정 정책** — 초안은 드리지만 실제 운영 방식에 맞춰 고치세요
- **사업자 정보** — 상호·대표자명·사업자등록번호·통신판매업 신고번호

## 크몽 상세페이지 초안 (이 프로그램 자체를 팔 때)

### 상세페이지 쓰다가 등록을 미루고 계신가요

크몽에 서비스를 올리려면 제목·패키지 3단·상세 설명·FAQ·환불 정책을 전부 써야 합니다.
대부분 상세 설명에서 막혀 등록이 몇 주씩 밀립니다.

이 프로그램은 서비스 정보 9개를 적으면 **등록에 필요한 글 전부**를 초안으로 만들어 드립니다.

**이런 분께 맞습니다**
- 팔 서비스는 정해졌는데 상세페이지 글에서 막힌 분
- 패키지 3단을 어떻게 나눠야 할지 모르겠는 분
- 문의가 오면 뭐라고 답할지 매번 고민하는 분

**이런 분께는 맞지 않습니다**
- 아직 무엇을 팔지 정하지 못한 분 — 입력할 내용이 없습니다
- 이미 상세페이지가 있고 디자인만 바꾸고 싶은 분 — 글만 만듭니다
- 터미널에서 명령어를 실행하기 어려우신 분

**드리는 것**
- 상세페이지 전문 (11개 섹션, 크몽 구조 그대로)
- 패키지 3단 (크몽 입력 폼 칸에 맞춰 정리)
- 제목 10안 + 검색 태그 20개
- 문의 응답 템플릿 8종
- 등록 전 점검 보고서

**차별점**
- **크몽 정책 위반을 자동으로 잡습니다.** 전화번호·카톡·외부 링크를 8가지 패턴으로 검사하고,
  AI가 만든 글뿐 아니라 입력하신 값도 봅니다.
- 전자상거래법 필수 표기 5가지가 비었는지 확인합니다.
- 실적을 입력하지 않으면 수치를 만들지 않습니다. "사례 준비 중"으로 둡니다.
- 제목·패키지 글자 수 제한을 프로그램이 강제합니다. 크몽 폼에서 잘리지 않습니다.
- 어느 파일을 크몽 어느 칸에 넣는지 13단계 매핑표를 드립니다.

**미리 알려드립니다**
- 산출물은 **초안**입니다. 특히 환불 정책은 본인 운영 방식에 맞춰 고치셔야 합니다.
- 포트폴리오 이미지는 직접 올리셔야 합니다.
- Claude API 키가 필요하며 사용료는 별도입니다 (1회에 수백 원 수준).
- 판매량은 카테고리 경쟁·가격·포트폴리오에 따라 달라집니다. 이 도구는 등록 준비 시간을
  줄일 뿐이며 결과는 검증이 필요합니다.
