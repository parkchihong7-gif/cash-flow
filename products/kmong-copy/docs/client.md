# 크몽 상세페이지 카피 생성기 — 사용 설명서

> 구매해 주셔서 감사합니다.
> **컴퓨터를 잘 모르셔도 따라 하실 수 있게** 하나하나 적었습니다.
> 막히시면 7장을 보시고, 그래도 안 되면 판매자에게 문의해 주세요.

---

## 1장. 무엇을 받으셨나요

크몽에 서비스를 올릴 때 필요한 **글 전부**를 만들어 드리는 프로그램입니다.

| 파일 | 무엇인가요 |
|---|---|
| `detail_page.md` | 상세페이지 본문 전체 |
| `packages.json` | BASIC / STANDARD / PREMIUM 패키지 3단 |
| `title_variants.json` | 서비스 제목 10안 + 검색 태그 20개 |
| `inquiry_scripts.md` | 문의가 왔을 때 답할 템플릿 8종 |
| `compliance_report.md` | **등록 전 점검 결과** |

### 이 프로그램이 신경 쓴 것 — "올리기 전에 잡아 준다"

크몽에서 서비스가 내려가는 이유는 대개 세 가지입니다.
이 프로그램이 셋 다 검사합니다.

**1. 성과를 단정하는 표현**
"반드시 만족하신다" 같은 확정적 약속 30가지를 검사합니다.
걸리면 프로그램이 자동으로 다시 씁니다.

**2. 외부 연락처 유도 — 가장 많이 걸리는 부분입니다**
"급하시면 카톡 주세요" 한 줄로 서비스가 내려갈 수 있습니다.
크몽은 플랫폼 밖 거래 유도를 금지하기 때문입니다.
전화번호·이메일·카톡·텔레그램·외부 링크·직거래 유도를 자동으로 잡습니다.

**AI가 쓴 글뿐 아니라 사장님이 입력하신 값도 검사합니다.**
차별점 칸에 전화번호를 적는 경우가 실제로 많습니다.

**3. 지어낸 실적**
실적을 입력하지 않으시면 숫자를 아예 만들지 않고 "사례 준비 중"으로 둡니다.

### ⚠️ 먼저 알아두셔야 할 것

**나오는 글은 완성본이 아니라 초안입니다.**

특히 **환불·수정 정책**은 실제로 어떻게 운영하실지에 맞춰 고치셔야 합니다.
상세페이지에 적은 것과 실제가 다르면 분쟁이 생겼을 때 불리합니다.

## 2장. 처음 준비 (한 번만)

### 2-1. 파이썬이 있는지 확인

**Windows**: 시작 메뉴에서 `cmd` 검색 → 명령 프롬프트 실행
**Mac**: `터미널` 앱 실행

아래를 치고 엔터:

```
python --version
```

`Python 3.11.0` 처럼 숫자가 나오면 됩니다 (3.11 이상 필요).

**"찾을 수 없습니다"가 나오면** https://www.python.org 에서 내려받아 설치하세요.
Windows 는 설치 첫 화면에서 **"Add Python to PATH" 를 꼭 체크**하셔야 합니다.

### 2-2. 부품 설치

받으신 폴더 안에서:

```
pip install -r requirements.txt
```

### 2-3. AI 키 발급

1. https://console.anthropic.com 가입 (구글 계정 가능)
2. 왼쪽 **Settings → API Keys → Create Key**
3. `sk-ant-` 로 시작하는 긴 글자가 나옵니다.
   **창을 닫으면 다시 못 보니 메모장에 붙여두세요**
4. 왼쪽 **Billing** 에서 카드 등록 + **10달러 정도 충전**

> **💰 비용 안내**
>
> 한 번 만들 때 **수백 원** 정도의 AI 사용료가 발생합니다.
> 10달러(약 1만 4천 원)면 수십 번은 만드실 수 있습니다.
>
> 이 돈은 **판매자가 아니라 AI 회사에 내는 것**입니다.
>
> 💡 이 프로그램은 다른 것보다 훨씬 쌉니다.
> 마음에 들 때까지 여러 번 돌려 보셔도 부담이 적습니다.

### 2-4. 키 넣기

1. 폴더에서 `.env.example` 파일을 찾습니다
2. 복사해서 이름을 **`.env`** 로 바꿉니다 (앞에 점이 있습니다)
3. 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 아까 키를 붙여넣습니다
4. 저장

> ⚠️ 이 파일은 비밀번호와 같습니다. 누구에게도 보내지 마세요.

### 2-5. 관리 화면 켜기

```
python -m dashboard
```

브라우저가 열립니다. 안 열리면 주소창에 `http://127.0.0.1:8000` 입력.
끄실 때는 검은 창에서 `Ctrl` + `C`.

## 3장. 서비스 정보 적기

관리 화면에서 **크몽 상세페이지 카피 생성기 → 수정 → 입력 파일 편집**을 누릅니다.

```yaml
service_name: "소상공인 로고 디자인"
category: "디자인 > 로고·브랜딩"
what_you_deliver:
  - "로고 원본 파일 (AI, SVG)"
  - "이미지 파일 (PNG, JPG)"
who_for: "명함과 간판을 만들어야 하는데 로고가 없는 1인 사업자"
differentiators:
  - "차별점 1"
  - "차별점 2"
  - "차별점 3"
turnaround_days: 5
price_basic: 90000
price_standard: 150000
price_premium: 250000
proof: []
faq_seed: []
```

### 하나씩 설명드리면

**`what_you_deliver` (제공 내용)**
구매자가 **손에 쥐는 것**을 적으세요. 2~10개.
- 그냥 그런 예: `정성껏 작업해 드립니다`
- 좋은 예: `로고 원본 파일 (AI, SVG)`

**`who_for` (대상)** — **여기가 제일 중요합니다.** 좁게 쓸수록 좋은 글이 나옵니다.
- 그냥 그런 예: `사업자`
- 좋은 예: `명함과 간판을 만들어야 하는데 로고가 없는 1인 사업자`

**`differentiators` (차별점)** — **정확히 3개**를 적으셔야 합니다.

경력이나 자격이 아니라 **구매자에게 뭐가 좋은지**를 적으세요.
- 그냥 그런 예: `10년 경력` — 그래서 구매자에게 뭐가 좋은지 안 보입니다
- 좋은 예: `파일 형식을 먼저 물어보고 필요한 것을 전부 드립니다`

**`price_basic` / `standard` / `premium`**
**반드시 싼 것부터 비싼 순서**여야 합니다. 어기면 오류가 납니다.
숫자만 적으세요. 쉼표를 넣으면 안 됩니다. (`150,000` ❌ → `150000` ⭕)

**`turnaround_days` (작업일)**
**지킬 수 있는 날짜**로 적으세요. 늦으면 평점이 깎입니다.

**`proof` (실적·후기)**
실적이 없으면 **`proof: []` 로 비워두세요.**
비워두면 포트폴리오 자리에 "사례 준비 중"이라고 들어갑니다.

⚠️ **없는 실적을 지어내지 마세요.** 나중에 문제가 되면 서비스가 내려갑니다.

### ⚠️ 여기에 연락처를 적지 마세요

차별점이나 제공 내용 칸에 전화번호·카톡 아이디를 적으시는 분이 많습니다.
**크몽 정책 위반이라 서비스가 내려갈 수 있습니다.**

프로그램이 잡아내긴 하지만, 애초에 적지 않으시는 편이 좋습니다.
문의는 크몽 메시지로만 받으세요.

### 편집할 때 주의

- **들여쓰기에 탭 키를 쓰지 마세요.** 스페이스만 씁니다
- 목록 앞의 `- ` (하이픈 + 공백)를 지우지 마세요
- 저장할 때 인코딩을 **UTF-8** 로

## 5장. ⚠️ 등록 전에 반드시

### 5-1. `compliance_report.md` 를 가장 먼저 엽니다

**상세페이지보다 이걸 먼저 보세요.** 순서대로 확인하시면 됩니다.

**① 크몽 정책 — 외부 연락처**
⚠️ 가 있으면 **등록하지 마세요.** 표에 어떤 문구가 어디에 있는지 나옵니다.
찾아서 지운 다음 등록하세요.

**② 금지 문구**
⚠️ 가 있으면 해당 표현을 상세페이지에서 찾아 고치세요.

**③ 전자상거래법 필수 표기**
비어 있는 항목이 있으면 채우세요. 법으로 표시할 의무가 있는 내용입니다.

### 5-2. 환불·수정 정책을 본인 기준으로 고치기

`detail_page.md` 의 '수정·환불 정책' 표는 **초안**입니다.
실제로 어떻게 운영하실지에 맞춰 고치세요.

- 수정은 정말 몇 번까지 해 주실 건가요
- 추가 수정 비용은 얼마인가요
- 어느 단계까지 환불해 주실 건가요

**적어놓고 안 지키면 분쟁에서 불리합니다.** 지킬 수 있는 선으로 적으세요.

### 5-3. 포트폴리오 이미지 준비

프로그램은 글만 만듭니다. **이미지는 직접 올리셔야 합니다.**

크몽 상세페이지에는 이미지 영역이 따로 있습니다. 작업물 3~5장을 올리세요.
실적이 없으셔도 **샘플 작업물을 만들어 올리는 편**이 훨씬 낫습니다.

### 5-4. 사업자 정보 확인

크몽 판매자 정보에 상호·대표자명·사업자등록번호를 등록하셔야 합니다.
사업자가 아니시면 크몽의 개인 판매자 조건을 확인하세요.

## 6장. 크몽에 등록하기

**README 의 '크몽 등록 순서 매핑표'** 를 옆에 띄워놓고 따라 하세요.
어느 파일을 어느 칸에 넣는지 13단계로 적혀 있습니다.

간단히 정리하면:

| 크몽 화면 | 넣을 것 |
|---|---|
| 서비스 제목 | `title_variants.json` 의 10안 중 하나 |
| 검색 태그 | `title_variants.json` 의 태그 20개 |
| 패키지 3개 | `packages.json` 을 칸별로 |
| 상세 설명 | `detail_page.md` 본문 |
| 이미지 | **직접 올리세요** |
| FAQ | `detail_page.md` 의 질문 7개 |

### 제목 고르는 법

`title_variants.json` 에 10안이 있고 각각 **앞세운 키워드**가 적혀 있습니다.

**크몽 검색은 제목 앞부분을 더 크게 봅니다.**
사람들이 실제로 검색할 말이 앞에 오는 안을 고르세요.

### 상세 설명 붙여넣기

크몽 에디터는 `## 제목` 같은 표시를 그대로 받지 않습니다.
`detail_page.md` 를 열어 **섹션 단위로 복사**해 붙여넣고,
제목 굵기나 목록 서식은 크몽 에디터에서 다시 잡으세요.

### 문의가 오면

`inquiry_scripts.md` 를 열어 상황에 맞는 템플릿을 복사하세요.
`[ ]` 안은 상황에 맞게 채우시면 됩니다.

⚠️ 템플릿에 연락처를 추가하지 마세요. 크몽 메시지로만 답하세요.

## 7장. 안 될 때

| 화면에 이렇게 나오면 | 이렇게 하세요 |
|---|---|
| `가격은 BASIC < STANDARD < PREMIUM` | 가격을 싼 것부터 비싼 순서로 |
| `차별점` 관련 오류 | 정확히 3개로 |
| `산출물` 관련 오류 | 2개 이상 10개 이하로 |
| `작업일` 관련 오류 | 1~90 사이 숫자로 |
| `ANTHROPIC_API_KEY 가 없습니다` | 2-4 를 다시 |
| `credit balance` 가 보임 | 충전 잔액이 없습니다. 콘솔 Billing 에서 충전 |
| `쿼터 초과` | **1분 기다렸다가** 다시 |
| `ModuleNotFoundError` | 부품이 안 깔렸습니다. 2-2 를 다시 |
| 한글이 □□□ 로 깨짐 | 저장할 때 인코딩을 **UTF-8** 로 |

**그래도 안 되면** 화면 글자를 **그대로 복사**해서 판매자에게 보내주세요.

## 8장. 자주 묻는 것

**Q. 결과가 마음에 안 듭니다.**
`who_for` 를 더 좁게, `differentiators` 를 더 구체적으로 써서 다시 돌려보세요.
이 프로그램은 비용이 적게 들어 여러 번 돌려 고르셔도 됩니다.

**Q. 제목이 25자를 넘으면 어떻게 되나요?**
프로그램이 자동으로 잘라냅니다. 크몽 폼에서 잘리지 않도록 미리 맞춥니다.

**Q. 패키지 가격을 나중에 바꿔도 되나요?**
네. `packages.json` 은 참고용이고 실제 등록은 크몽 화면에서 하시는 거라
숫자만 바꿔 넣으시면 됩니다.

**Q. 실적이 하나도 없는데 괜찮을까요?**
`proof` 를 비우면 "사례 준비 중"으로 나옵니다. 정직한 편이 낫습니다.
대신 **샘플 작업물을 만들어 이미지로 올리세요.** 그게 첫 실적이 됩니다.

**Q. 크몽 말고 다른 플랫폼에도 쓸 수 있나요?**
상세페이지 글 자체는 쓸 수 있습니다. 다만 패키지 3단 구조와 글자 수 제한은
크몽 기준이라 다른 곳에서는 맞지 않을 수 있습니다.

**Q. 이걸 쓰면 주문이 들어오나요?**
이 도구는 **등록 준비 시간을 줄여주는 도구**입니다.
주문은 카테고리 경쟁·가격·포트폴리오에 따라 달라지며 이 도구가 보장하지 않습니다.
