# 크몽 상세페이지 카피 생성기 — 관리자 매뉴얼

> 이 프로그램을 **운영하고 판매하는 사람**을 위한 문서입니다.
> 구매자에게 줄 문서는 `docs/client.md` 입니다.

---

## 1장. 이 프로그램이 파는 것

### 1-1. 한 문단 요약

크몽에 서비스를 올릴 때 필요한 글 전부 — 상세페이지·패키지 3단·제목 10안·검색 태그·
문의 응답 템플릿 — 를 만들고, 등록 전에 정책 위반이 없는지 점검합니다.

### 1-2. 진짜 가치는 "점검"입니다

"크몽 상세페이지 대신 써 드립니다"는 흔합니다. 이 도구가 다른 점은
**올리기 전에 잡아 준다**는 것입니다.

크몽에서 서비스가 내려가는 이유는 대개 셋입니다.

| 이유 | 이 도구의 대응 |
|---|---|
| 성과를 단정하는 표현 | 30개 목록으로 검사, 걸리면 재작성 |
| 외부 연락처 유도 | 8가지 패턴으로 검사 (전화·카톡·외부 링크 등) |
| 지어낸 실적 | `proof` 가 비면 수치를 아예 만들지 않음 |

특히 **외부 연락처 유도**는 판매자 본인도 모르고 쓰는 경우가 많습니다.
"급하시면 카톡 주세요" 한 줄로 서비스가 내려갑니다.
이 도구는 AI가 쓴 글뿐 아니라 **판매자가 입력한 값까지** 검사합니다.
차별점 칸에 전화번호를 적는 일이 실제로 있기 때문입니다.

### 1-3. 두 번째 가치는 "등록 순서 매핑표"입니다

글을 다 받아도 크몽 등록 화면 앞에서 또 막힙니다. 어느 글을 어느 칸에 넣어야 하는지
모르기 때문입니다. README 에 13단계 매핑표가 있습니다.
**이걸 상세페이지에 스크린샷으로 넣으면 설득력이 큽니다.**

## 2장. 준비

### 2-1. API 키

1. https://console.anthropic.com/settings/keys 에서 키 발급 (`sk-ant-` 로 시작)
2. Billing 에서 카드 등록 + 충전
3. 저장소 맨 위 폴더의 `.env` 에 `ANTHROPIC_API_KEY=sk-ant-...` 저장
4. 대시보드 **기타 설정**에서 "API 키: 설정됨" 확인

### 2-2. 비용 감각

| 단계 | 호출 수 |
|---|---|
| 상세페이지 | 1회 |
| 패키지·제목·태그 | 1회 |
| 문의 응답 템플릿 | 1회 |
| **합계** | **3회** (재작성 발생 시 4~6회) |

**1회에 수백 원 수준으로 가장 쌉니다.** 5개 상품 중 비용이 가장 적게 듭니다.
여러 번 돌려 마음에 드는 결과를 고르셔도 부담이 적습니다.

## 3장. 운용

### 3-1. 입력 채우기

대시보드 **수정** 탭에서 `service_input.yaml` 을 엽니다.

| 항목 | 잘 쓰는 법 |
|---|---|
| `service_name` | 실제 서비스명 |
| `category` | 크몽 카테고리를 그대로 |
| `what_you_deliver` | **구매자가 손에 쥐는 것**으로. "정성껏 작업"(X) → "AI 원본 파일"(O) |
| `who_for` | **좁게.** "사업자"(X) → "명함을 만들어야 하는데 로고가 없는 1인 사업자"(O) |
| `differentiators` | 정확히 3개. 경쟁 서비스와 **실제로 다른 것**만 |
| `turnaround_days` | 지킬 수 있는 날짜. 늦으면 평점이 깎입니다 |
| `price_*` | BASIC < STANDARD < PREMIUM. 어기면 오류 |
| `proof` | **없으면 비우세요.** 지어내면 안 됩니다 |

### 3-2. 차별점 쓰는 법

여기가 상세페이지 품질을 가장 크게 좌우합니다.
**"왜 그게 구매자에게 이득인가"** 까지 쓸 수 있는 것만 적으세요.

- (X) "10년 경력" — 그래서 구매자에게 뭐가 좋은지 안 보입니다
- (O) "파일 형식을 먼저 물어보고 필요한 것을 전부 드립니다" — 다시 요청할 일이 없습니다

### 3-3. 실행 결과 읽기

```
  detail    1회 시도 — 통과
  packages  2회 시도 — 길이 3건 자동 보정
  scripts   1회 시도 — 통과

⚠ 확인이 필요합니다. compliance_report.md 를 열어 ⚠️ 항목을 고치세요.
```

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 통과 | 문제없음 | 없음 |
| `금지 문구 ...` | 2번 고쳐도 남음 | 직접 고쳐야 합니다 |
| `외부 연락처 ...` | 크몽 정책 위반이 남음 | **반드시** 지우세요 |
| `길이 N건 자동 보정` | 글자 수를 프로그램이 잘라냄 | 잘린 부분이 어색하지 않은지 확인 |

### 3-4. `compliance_report.md` 읽는 순서

1. **2번 크몽 정책** — ⚠️ 가 있으면 등록하지 마세요. 서비스가 내려갑니다
2. **1번 금지 문구** — ⚠️ 가 있으면 해당 표현을 찾아 고치세요
3. **3번 전자상거래법** — 비어 있는 항목을 채우세요
4. **4번 근거 없는 수치** — 실적을 안 넣었는데 숫자가 보이면 확인
5. **6번 최종 확인** — 체크박스를 하나씩

### 3-5. 등록할 때

README 의 **크몽 등록 순서 매핑표** 13단계를 따라가세요.
7번(상세 설명)이 가장 손이 갑니다. 크몽 에디터가 마크다운을 그대로 받지 않아
섹션 단위로 복사해 붙여넣고 서식을 다시 잡아야 합니다.

## 4장. 품질을 올리는 법

| 순서 | 무엇을 | 비용 | 효과 |
|---|---|---|---|
| 1 | `who_for` 를 좁게 쓴다 | 없음 | 가장 큼 |
| 2 | `differentiators` 를 이득 중심으로 다시 쓴다 | 없음 | 큼 |
| 3 | `prompts/detail_page.md` 를 고친다 | 없음 | 큼 |
| 4 | 여러 번 돌려 고른다 | 회당 수백 원 | 보통 |
| 5 | 모델을 올린다 | 증가 | 보통 |

이 프로그램은 호출이 3회뿐이라 **여러 번 돌려 고르는 방법**이 다른 상품보다 현실적입니다.

### 프롬프트 파일

| 파일 | 바뀌는 것 |
|---|---|
| `prompts/common.md` | 금지 표현, 실적 처리, 크몽 정책, 문체 — 전 섹션 공통 |
| `prompts/detail_page.md` | 상세페이지 섹션별 작성 방식 |
| `prompts/packages.md` | 패키지 3단 구성 원리, 제목·태그 |
| `prompts/inquiry.md` | 문의 응답 8종의 상황과 어투 |

### 검사 규칙을 늘리려면

`kmong_copy/policy.py` 의 `CONTACT_PATTERNS` 에 (설명, 정규식) 을 추가하세요.
크몽 정책이 바뀌거나 새로운 우회 표현이 보이면 여기를 고칩니다.

크몽 패키지 폼이 바뀌면 `kmong_copy/writers.py` 의 `KMONG_FIELDS` 를 고치세요.

## 5장. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| `가격은 BASIC < STANDARD < PREMIUM` | 가격 순서가 어긋남 | 순서대로 |
| `차별점` 관련 오류 | 정확히 3개가 아님 | 3개로 |
| `산출물` 관련 오류 | 2개 미만이거나 10개 초과 | 범위 안으로 |
| 외부 연락처 경고가 계속 뜸 | 입력값에 들어 있을 수 있음 | 보고서의 '앞뒤 문맥' 열을 보세요 |
| 제목이 자꾸 잘림 | LLM 이 25자를 못 지킴 | `prompts/packages.md` 에 좋은 예를 더 넣으세요 |
| `설정 오류: ANTHROPIC_API_KEY` | 키 미설정 | 2-1 |
| `쿼터 초과` | 호출이 몰림 | 1분 대기 후 다시 |

## 6장. 판매할 때

### 6-1. 상세페이지에 넣을 것

- **크몽 정책 위반을 자동으로 잡는다**는 점 — 가장 큰 차별점입니다
- 13단계 등록 매핑표 — 스크린샷으로 넣으면 설득력이 큽니다
- "초안 생성기이며 등록 전 판매자 검수가 필수"
- API 키는 구매자가 직접 발급, 사용료 별도 (1회 수백 원)

### 6-2. 쓰면 안 되는 표현

성과를 단정하는 표현은 쓰지 마세요. 프로그램이 산출물은 자동 검사하지만
**본인 상세페이지는 검사하지 않습니다.**

다만 이 프로그램으로 **자기 상세페이지를 만들면** 검사를 받게 됩니다.
그게 가장 좋은 시연이기도 합니다.

### 6-3. 묶음 구성

- **1번 퍼널 빌더 + 5번** — 크몽에 올리고 자체 랜딩까지
- **5번 단독으로 대행** — 상세페이지 작성 대행은 크몽에서 수요가 꾸준합니다.
  이 도구로 만들고 사람이 다듬어 납품하면 시간이 크게 줄어듭니다.

### 6-4. 회원관리 연동

1. **회원관리** → 고객 추가
2. 고객 상세 → **라이선스 발급** → 프로그램 `kmong-copy` 선택
3. 대행 작업 시 테스트 탭에서 고객을 지정해 실행하면 이력이 남습니다
