# 17. 연예인 착용템 쇼츠 기획기 (celeb-shorts)

연예인이 착용·추천한 아이템을 소개하고 **비슷한 상품**을 상품 태그로 연결하는
15초 세로 쇼츠의 **기획서**를 만듭니다. 영상 렌더링은 다음 단계에서 붙입니다.

연예인 쇼핑 쇼츠는 강의가 많이 팔리는 주제지만, 채널이 망가지는 길도 분명합니다.
연예인 영상·얼굴을 쓰다 저작권 신고를 받거나, 확인 안 된 아이템을 "○○ 착용템" 이라고 하거나,
대가성 문구를 빠뜨리는 경우입니다. 이 도구는 그 길을 **프로그램 안에서 막는 것**이 목적입니다.

---

## 1. 무엇이 나오나

`outputs/<연예인-상황>/` 아래 여섯 개입니다.

| 파일 | 무엇 |
|---|---|
| `plan.md` | **사람이 보는 기획서.** 장면표(시간·자막·내레이션·화면·아이템), 검사 결과, 승인 방법 |
| `subtitles.srt` | 자막 파일. 편집 프로그램에 그대로 넣습니다 (한 장 15자 이내) |
| `description.txt` | 설명란. 대가성 문구 + 본문 + 출처 + 해시태그 + AI 표시 |
| `shopping_list.csv` | 아이템별 소개 방식·검색어·쿠팡 검색 주소 |
| `checklist.md` | 올리기 전 사람이 확인할 것 |
| `plan.json` | 전체 결과와 승인 기록. 다음 단계(영상 만들기)가 읽습니다 |

## 2. 프로그램이 막는 것

| 규칙 | 어떻게 |
|---|---|
| 연예인 얼굴·방송 화면 금지 | 장면 화면은 `상품 이미지 / 직접 찍은 사진 / 글자 화면` 셋 중에서만 고를 수 있습니다 |
| 출처 없으면 이름 안 씀 | `source_url` 이 비면 이름을 Claude 에 넘기지도 않고, 결과에 섞이면 지웁니다 |
| 확인 안 된 아이템은 '비슷한 스타일' | "똑같은", "동일 제품", "정품" 을 쓰면 막음(⛔) |
| 출처 없는 가격·'원가' 금지 | 가격 출처가 없으면 가격을 넘기지 않고, 숫자가 나오면 막음 |
| 건강식품 효능 표현 금지 | 분류가 건강식품이면 "면역·다이어트·혈당·피로 회복·예방·치료" 등이 나올 때 막음 |
| 화장품 의약품 표현 금지 | 분류가 뷰티면 "치료·재생·아토피·염증" 은 막음, "미백·주름 개선" 은 인증 확인 경고 |
| 지어낸 추천 금지 | "추천한·애용·인생템" 은 확인 아이템에만. "연예인들·셀럽들이 쓰는" 은 늘 막음 |
| 금지 문구 | 과장·보장 표현 공용 목록(`shared/banned_phrases.py`) |
| 대가성 문구 | 설명란 첫 줄에 쿠팡·유튜브 문구. 지우는 옵션 없음 |
| AI 생성물 표시 | 기본 켜짐 (`--no-ai-label` 로 본문 표시만 끌 수 있고, plan.json 기록은 남음) |
| 사람 승인 | 막음이 남았거나 모의 실행이면 `approve` 가 거절합니다 |

## 3. 설치

```bash
pip install -r ../../requirements.txt -r requirements.txt
cp .env.example .env        # ANTHROPIC_API_KEY 를 넣으세요 (모의 실행은 키 없이 됨)
```

## 4. 사용법

```bash
# 입력 예시를 고친 뒤
python cli.py build shorts_input.yaml --dry-run    # 비용 0원, 모양만
python cli.py build shorts_input.yaml              # Claude 1회
python cli.py check outputs/<폴더>                 # 고친 뒤 다시 검사
python cli.py approve outputs/<폴더> --name 홍길동  # 사람 승인
```

입력(`shorts_input.yaml`)의 아이템은 한 줄에 하나입니다.

```yaml
items:
  - "블랙 숄더백 | 브랜드B | o | 3200000 | 예시뉴스 | 블랙 숄더백 | 패션"
  - "와이드 데님 | | x | | | 와이드 데님 팬츠 | 패션"
```

`이름 | 브랜드 | 확인(o/x) | 가격 | 가격 출처 | 쇼핑 검색어 | 분류` 순서입니다.
분류는 패션(비우면 패션)·뷰티·건강식품·기타입니다.

`checklist.md` 끝에는 **처음 한 번 해 둘 채널 설정**(브랜드 계정, 업로드 기본설정의 유료 프로모션,
쇼핑 제휴 가입, 채널 설명의 제휴 고지, 채널 구매 안 하기)이 들어 있습니다.

종료 코드는 0 문제 없음, 2 볼 것이 있음(경고·막음), 1 실패입니다.

## 5. 링크는 어디에

쇼츠 설명란·댓글 링크는 눌리지 않습니다(2023년부터).

- 유튜브 쇼핑 제휴(구독자 500명 + YPP): 업로드 화면 '상품' 에서 태그합니다. 공개 API 가 없어 손으로 합니다.
- 그 전: 관련 롱폼 영상 연결 또는 채널 프로필 링크.

## 6. 판매 문구 초안 (크몽용)

> **연예인 착용템 쇼츠, 저작권·표시 걱정을 줄이는 기획 도구**
>
> 아이템과 출처를 적으면 15초 쇼츠 기획서(장면표·자막 파일·설명란·상품 목록)가 나옵니다.
> 연예인 얼굴 사진 없이 상품 이미지와 자막으로 구성하고, 대가성 문구와 AI 생성물 표시를
> 자동으로 넣습니다. 출처가 없는 이름·가격은 쓰지 않도록 검사합니다.
>
> - 기획·자막·표시 문구 작성 시간을 줄여 줍니다
> - 결과는 초안입니다. 확인하고 승인한 뒤 사용하세요
> - 판매 성과는 채널·상품·시기에 따라 다르며, 검증이 필요합니다

## 7. 셀럽오르빗 운영 앱 (만드는 중)

이 기획기를 키워 채널 «셀럽오르빗» 을 운영하는 로컬 웹앱을 만들고 있습니다.
설계와 단계는 `docs/celeb-orbit-design.md` 에 있습니다.

| 조각 | 내용 | 상태 |
|---|---|---|
| ① | 뼈대 — DB · 브랜드 설정(이름·슬로건·색 5개) · 백업/복원 · 작업 기록(3회 재시도) | ✅ |
| ② | 상품 · 출처(연예인 본인 영상은 시간까지) · 검증 4단계 · 제휴 링크(사람이 붙여 넣은 것만) · 이미지 라이선스 | ✅ |
| ③ | 대본 3안(호기심·정보·가격/사용법) — 17번 규칙 + 0~3초 훅(막음)·제품명 4초 뒤 공개(경고), 고치면 다시 검사, 승인은 이름 + «내 말 한 줄» | ✅ |
| ④ | 레트로 렌더 — 템플릿 5종(설정 파일 `orbit/video_templates.yaml`), 종이·망점·색 어긋남·손그림 별·궤도, 상단 고정 제목 띠, 늘 보이는 광고 표시, 끝 카드(내 말 한 줄·고지), 권리 있는 상품 이미지 또는 자체 그래픽 카드, 음악(라이선스 기록)·Google TTS(선택), 1080×1920 mp4 | ✅ |
| ⑤ | 권리 검사 · 채널 설정 점검표 · 최종 승인 · 업로드용 제목과 설명 | 다음 |

영상 만들기에는 **FFmpeg** 가 필요합니다(Windows: `winget install Gyan.FFmpeg`). 글꼴은 OFL 라이선스의
검은고딕·도현을 `orbit/fonts/` 에 동봉했습니다. AI 음성은 `.env` 에 `GOOGLE_TTS_API_KEY` 가 있을 때만 켜집니다.

강의 분석과 수정안은 `docs/orbit-video-analysis.md` 에 있습니다. 프로그램이 하지 않는 것:
남의 영상 내려받기·편집, 레퍼런스 영상 제목 본뜨기, 자동 시청·구독·댓글, 제휴 링크 임의 생성.

Windows: `설치.bat` → `실행.bat` 을 더블클릭하면 브라우저에 `http://127.0.0.1:8017` 이 열립니다.
다른 OS: `python -m orbit`. 데이터는 `data/orbit.db` 한 파일입니다(저장소에 올리지 않음).
