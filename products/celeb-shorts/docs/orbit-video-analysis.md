> 분석 자료: 사장님이 붙여 주신 **자막 전사문(0:00~19:40)** 하나. 영상 화면은 보지 못했다.

### A-3. 수익 요소로 주장한 것 (모두 [강의])
- 쿠팡 진입만 시키면 다른 상품 구매에도 수수료 (0:58–1:18)
- 쇼핑 태그(쇼핑 스티커) 수익이 조회수 수익보다 훨씬 크다 — 한 영상 예상 수익 550만 원 중 쇼핑 510만, 조회수 40만 (11:08–11:20)
- 그 영상: 조회수 325만, 구독 +204, 쿠팡 총매출 1억 1,800만 원, 수수료 약 600만 원, 주문 건수 [자막 불명] (10:01–11:47)
- 채널 영상 9개 중 1개가 터진 경우 (9:45)

> 위 숫자는 강의자 채널의 한 사례다. 같은 결과를 기대할 근거가 되지 않는다.
> (참고 계산: 강의자 숫자대로면 매출 대비 수수료는 약 5%다.)

## B. 유튜브 채널 설정 — 강의 vs 공식

| 설정 | 강의 (시간) | 공식 기준 / 판정 |
|---|---|---|
| 구글 계정 | 지금 계정이나 새 계정 (1:53) | **브랜드 계정** 권장(관리자 추가·소유권 이전). 강의는 언급 없음 |
| 계정 보안 | **언급 없음** | [공식] YPP 가입에는 구글 계정 **2단계 인증**이 필요하다고 안내됨 [확인 필요]. 채널 탈취 대비로도 필수 |
| 기본 통화 원화 | 설정 → 일반 (4:06) | [공식] 표시 단위일 뿐. 수익에는 영향 없음 |
| 거주 국가 대한민국 | 설정 → 채널 (4:18) | [공식] YPP·쇼핑 제휴 자격이 국가에 따라 다르므로 **정확히** 넣어야 함 |
| 채널 키워드 | Gemini로 만들어 넣기 (4:22–4:45) | [공식] 기능은 있음. 노출 효과는 공식 확인 안 됨 |
| 아동용 기본값 «아니요» | 고급 설정 (4:47–5:01) | [공식] 시청자층 설정은 **사실대로** 해야 하는 의무 항목. 셀럽오르빗은 아동용이 아니므로 «아니요» 가 맞음 |
| 업로드 기본 설정 | «그대로 두기» (5:03) | 셀럽오르빗은 설명란 첫 줄에 대가성 문구를 기본으로 넣는 것을 권장. **유료 프로모션 표시는 업로드할 때마다 확인** [업로드 기본설정에 이 항목이 있는지 확인 필요] |
| 배너·프로필 | 미리캔버스 무료 (5:10–5:17) | 무료 템플릿의 상업 이용 조건 [확인 필요]. 셀럽오르빗은 앱이 직접 만든다 |
| 핸들·설명 | Gemini 설명 (5:19–5:30) | [공식] 기능. 설명에 «제휴 링크로 수수료를 받는다» 문장 권장 |
| 연락처 이메일 | 이메일 칸 + 설명란 중복 (5:30–5:50) | [공식] 기능. 중복 기재는 강의자 습관 |
| 링크 | 인포크 링크 (5:50–5:57) | [공식] 채널 링크 기능. 인포크는 외부 서비스(공식 연동 여부 확인 안 됨) |
| 홈 탭 끄기 | 항상 끈다 (5:59–6:13) | **[확인 필요]** 지금 맞춤설정에 이 스위치가 있는지, 효과가 있는지 공식 자료로 확인 못 함 |
| 쇼핑 태그 | 수익 화면에서 언급 (11:10–11:18) | [공식] 유튜브 쇼핑 제휴. 한국은 구독자 500명 + YPP 조건(2026.3~, 프로젝트 조사 기준) |
| 유료 프로모션·AI 표시 | **언급 없음** | [공식] 유료 프로모션 표시와 «변경되거나 합성된 콘텐츠» 표시는 해당되면 의무. 쿠팡 대가성 문구도 필수 |

### B-2. «계정 키우기»(1:53–3:56)에 대한 판단
- 사람이 직접 보고 싶은 영상을 보고 구독하는 것은 문제없다.
- **프로그램이 대신 시청·좋아요·구독·댓글을 하면 안 된다.** 유튜브의 가짜 참여(fake engagement) 정책 위반이고, CLAUDE.md 3장 7번(비공식 자동화 금지) 위반이다. → 셀럽오르빗에는 **체크리스트로만** 넣고 자동화하지 않는다.
- «로봇으로 오해받는다» «알고리즘이 맞춰진다» 는 강의자 경험이며 공식 근거는 없다.

## C. 영상 소재 발굴 — 자동화 가능 / 수동

| 강의 과정 (시간) | 셀럽오르빗에서 | 방법 |
|---|---|---|
| 골든파인더에서 키워드 «연예인 추천템» + 기간 + 조회수 정렬 (12:27–12:36) | **API로 자동** | YouTube Data API `search.list`(q, publishedAfter, regionCode=KR, videoDuration=short, order=viewCount) |
| 점수 보고 고르기 (12:36–12:40) | **API로 자동** (점수 공식은 우리 것) | `videos.list`(조회·좋아요·댓글) + `channels.list`(구독자) → **조회수 ÷ 구독자** |
| 구독자 적은데 조회수 같은 영상 선택 (12:42–12:59) | **자동 정렬 + 사람이 선택** | 위 비율로 정렬. 구독자 수를 숨긴 채널은 «비율 계산 불가» 로 표시 |
| 연예인 본인 채널에서 원본 영상 찾기 (13:23–13:28) | **사람이 출처로 등록** | 원본 영상 주소 + **시간(예: 1:47)** 을 «출처» 로 저장. 영상은 받지 않는다 |
| 유튜브 «질문하기»로 상품 이야기 시간 찾기 (13:32–13:47) | **수동** | 공개 API 없음. 사람이 유튜브에서 직접 |
| 레퍼런스 영상으로 제목 짓기 (16:10–16:44) | **방식을 바꿔 자동** | 남의 영상 제목을 학습시키지 않고, **검증된 사실(출처)** 로 Claude가 제목 후보를 만든다 |

**바꾸는 점 하나:** 강의는 인기 영상을 **따라 만들 대상**으로 고른다. 셀럽오르빗은 같은 목록을 **«어떤 연예인·상품 주제에 수요가 있나» 를 보는 신호**로만 쓴다(CLAUDE.md 3장 1번 «공백 발굴» 방향). 목록에는 제목·숫자·링크만 보이고 영상 내려받기 기능은 없다.

**강의에서 쓸 만한 것:** 연예인 **본인 채널 영상의 그 시간대**는 «연예인이 직접 쓴다고 말함» 을 보여 주는 가장 강한 출처다. → 출처에 «연예인 본인 영상» 종류와 **시간 칸**을 더한다(관계: 추천확인/사용확인의 근거).

할당량: `search.list` 는 1회 100단위, 하루 기본 10,000단위 → **하루 약 100번 검색** (CLAUDE.md 조사 기준). 넘으면 다음 날까지 대기.

## D. 시청자 데이터 — 강의자가 쓴 기준

| 항목 | 강의 내용 (시간) | 강의자 기준 | API로 가져오기 |
|---|---|---|---|
| 조회수 / 유효 조회수 | 유효 조회수 = «반 이상 시청한 진짜 조회수», 수익화 기준 (8:15–8:49) | 수치 기준 없음 | YouTube Analytics API. 쇼츠 «유효 조회수» 지표 이름과 정의는 [확인 필요] — **«반 이상 시청» 정의는 강의자 설명이며 공식 정의로 확인 못 함** |
| 성별 | 가장 중요 (7:25–7:42) | **남성 90% 이상이면 곤란** | Analytics API `viewerPercentage` × gender |
| 연령 | 가장 중요 (7:25–8:04) | **10대·70대 이상 쏠림은 곤란**, 강의자 채널은 **25~35세·여성 다수** | `viewerPercentage` × ageGroup |
| 시청 시간대 | 6~8시 유입 많음 (7:06–7:14) | 수치 기준 없음 | Analytics API에 같은 지표가 있는지 [확인 필요] — 없으면 스튜디오에서 보기 |
| 신규·재방문, 비구독자 | (6:56–7:23) | 비구독자가 많으면 쇼츠 피드 노출 중 | 일부 지표 [확인 필요] |
| 시청 유지율 | 그래프로 이탈 시점 확인, **초반 3초 이탈** (10:12–10:52) | 수치 기준 없음 | `audienceWatchRatio` (영상 구간별) |
| 트래픽 | 쇼츠 피드 vs **검색(탐색)** — 쇼핑 키워드를 유튜브에서 검색하는 시청자가 많다 (8:50–9:27) | 수치 기준 없음 | `insightTrafficSourceType` |
| 시청자 참여도 | 여러 점수 종합 (9:29–9:43) | 수치 기준 없음 | 어떤 지표인지 [확인 필요] |
| 영상별 비교 | 인기 쇼츠, 영상별 분석 (9:45–11:06) | — | 영상별 조회 |
| 쇼핑 수익 | 쇼핑 태그 수익·쿠팡 매출·주문·반품 (11:08–11:47) | — | API 제공 여부 [확인 필요] → 없으면 **스튜디오 숫자를 사람이 입력** |

**영상에 없는 기준(유지율 몇 % 이상 등)은 만들지 않았다.**

## 결과물 B. 실무 체크리스트 (셀럽오르빗 운영자용)

**계정·보안 (처음 한 번)**
- [ ] 채널을 브랜드 계정으로 만들었다
- [ ] 구글 계정 2단계 인증을 켰다 [YPP 요건 여부 확인 필요]
- [ ] 다른 사람 채널을 사지 않았다
- [ ] (사람이 직접) 관심 주제 영상을 보고 구독했다 — 프로그램으로 하지 않는다

**채널 기본 설정 (처음 한 번)**
- [ ] 거주 국가: 대한민국
- [ ] 기본 통화: 원화 (표시용)
- [ ] 시청자층 기본값: 아동용 아님 (사실대로)
- [ ] 채널 키워드·설명 입력 — 설명에 «제휴 링크·상품 태그로 수수료를 받습니다» 포함
- [ ] 연락처 이메일
- [ ] 채널 링크: 상품 모음 링크(인포크 등)
- [ ] 배너·프로필: 셀럽오르빗 앱이 만든 이미지
- [ ] (선택) 홈 탭 끄기 — 기능 존재 여부 확인 필요

**업로드할 때마다**
- [ ] 첫 3초에 강한 한마디, 제품명은 뒤에서 공개
- [ ] 연예인 원본 영상·사진을 한 장면도 쓰지 않았다
- [ ] 설명란 첫 줄 대가성 문구
- [ ] «유료 프로모션 포함» 체크
- [ ] AI 음성·이미지를 썼으면 «변경되거나 합성된 콘텐츠» 체크
- [ ] 아동용 «아니요»
- [ ] (쇼핑 제휴 자격이 있으면) 상품 태그
- [ ] 상품 모음 링크에 이번 상품 추가

**주마다 분석**
- [ ] 연령·성별이 구매층(강의자 기준: 여성·25~35세 쪽)에서 많이 벗어나지 않았나 — 벗어나면 소재 조정
- [ ] 유지 그래프에서 초반 3초 이탈 확인 → 다음 영상 훅 수정
- [ ] 쇼츠 피드 vs 검색 유입 — 검색 유입이 많은 상품 키워드 기록
- [ ] 쇼핑 수익·쿠팡 실적을 앱에 입력(연동 전)

| 8 | **17번 확인표 정정**: «업로드 기본설정에서 유료 프로모션 기본 켜기» → «업로드할 때마다 체크 (기본설정에 항목이 있으면 켜기 — 확인 필요)» | 공식 메뉴로 확인하지 못한 문장을 이미 넣어 두었음 |

**정할 것 (사장님)**
- 2단계 인기 쇼츠 발굴은 16번 «니치 리서치» 의 유튜브 수집기와 하는 일이 겹친다. 16번 코드를 가져다 쓰려면 번호를 넘나드는 일이라 따로 허락이 필요하다. 아니면 17번 안에 작게 새로 만든다(추천: 17번 안에 작게).
- 슬로건: 이번 요청서에도 원래 문구가 적혀 있다. 지금 앱 기본값은 «스타 스타일, 여기서 찾기».

## F. 골든파인더 연동 검토

| 질문 | 답 |
|---|---|
| 강의에서 하는 일 | 키워드·기간·조회수로 유튜브 영상을 걸러 «좋은 점수» 영상만 보여 줌 (12:13–12:40). 점수 공식은 강의에 없음 |
| 없이 구현 가능한 기능 | 키워드·기간·조회수 검색, 구독자 대비 조회수 정렬 — **YouTube Data API로 모두 가능** |
| 쓰면 편한 점 | 이미 만들어진 화면, 그쪽의 점수 공식, 할당량 관리를 신경 쓰지 않아도 됨 |
| 공식 연동 API | **확인되지 않음.** 사이트는 이 작업 환경에서 접속이 막혀 있고 검색에서도 API 안내를 찾지 못함 → 연동 가능하다고 가정하지 않음 |
| 유료 서비스가 필요한가 | 셀럽오르빗 목적(수요 신호 파악)에는 **필요 없음**. 사장님이 따로 쓰시는 것은 자유이며, 거기서 본 **상품 이름만** 앱에 직접 등록하면 됨. 사이트 내용을 자동으로 가져오는 기능은 만들지 않음 |
