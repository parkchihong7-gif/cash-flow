# 연예인 착용템 쇼츠 기획기 — 사용 설명서

> 구매해 주셔서 감사합니다. 막히시면 5장을 보세요.

## 1장. 무엇을 받으셨나요

아이템과 출처를 적으면 **15초 쇼츠 기획서**를 만들어 드리는 프로그램입니다.
장면마다 몇 초에 어떤 자막과 말을 넣고, 화면에 무엇을 보여 줄지가 적혀 나옵니다.

### ⚠️ 먼저 알아두셔야 할 것

- **연예인 얼굴 사진·방송 화면은 쓰지 마세요.** 저작권 신고와 초상·이름 사용 분쟁의 원인입니다.
  프로그램도 상품 이미지와 글자 화면만 제안합니다.
- **착용 사실을 확인한 기사가 없으면 이름을 쓰지 않습니다.** 그때는 '비슷한 스타일' 쇼츠가 됩니다.
- 결과는 **초안**입니다. 직접 읽고 고친 뒤 승인하세요.

## 2장. 입력하기

`shorts_input.yaml` 을 엽니다.

| 칸 | 적는 것 |
|---|---|
| celebrity | 연예인 이름 (문구로만 나옵니다) |
| occasion | 어디서 — 공항 출국, 드라마 ○○ 3화 등 |
| source_url / source_name | 착용 사실을 확인한 기사·공식 SNS 주소와 매체 이름 |
| duration_sec | 길이(초). 기본 15 |
| items | 아이템 한 줄에 하나: `이름 | 브랜드 | o/x | 가격 | 가격 출처 | 검색어` |

기사에서 직접 확인한 아이템만 `o` 로 적으세요. 모르면 `x` 입니다.

## 3장. 만들기

1. 모의 실행 — 비용 없이 모양만 봅니다.
2. 실제 실행 — 기획서를 만듭니다.

## 4장. 올리기 전에

1. `plan.md` 의 자막과 말을 내 말투로 고칩니다. 내 의견 한 줄을 꼭 넣으세요.
2. `checklist.md` 를 하나씩 확인합니다.
3. 승인: `python cli.py approve outputs/<폴더> --name 내이름`
4. 업로드할 때 `description.txt` 를 설명란에 그대로 붙이고,
   '유료 프로모션 포함' 과 '변경되거나 합성된 콘텐츠' 를 사실대로 체크합니다.

## 5장. 막혔을 때

| 증상 | 이유와 해결 |
|---|---|
| 연예인 이름이 빠졌다 | 출처 주소가 비었습니다. 기사 주소를 넣으세요 |
| ⛔ 막음이 떠서 승인이 안 된다 | `plan.md` 의 '검사 결과' 를 보세요. 출처 없는 가격·'원가'·'똑같은' 이 대부분입니다 |
| 쇼츠 설명란 링크가 안 눌린다 | 정상입니다. 유튜브 쇼핑 상품 태그나 채널 프로필 링크를 쓰세요 |
