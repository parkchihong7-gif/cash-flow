# 학술대회·팝업 출결 체크

현장에서 스마트폰·태블릿으로 QR 출결과 현장 등록을 처리하는 웹앱입니다. 운영 방식은 두 가지입니다.

| 운영 방식 | 쓰는 곳 | 하는 일 |
|---|---|---|
| **학술대회** | 의협 평점이 걸린 학회·세미나 | 입실·퇴실 QR, 체류시간·예상 평점, 동명이인 뒷자리 확인 |
| **팝업** | 팝업스토어·전시·설명회 | 입구 QR로 방문자가 직접 등록(개인정보 동의) → 방문 기록·방문자 명단 |

| 파일 | 역할 |
|---|---|
| `index.html` | 직원·패드용 출결 앱 (서버 없이도 단독으로 동작) |
| `register.html` | 참가자가 자기 휴대폰으로 여는 현장 등록 화면 |
| `apps-script/Code.gs` | 구글 시트 연동 서버 (여러 패드 연동·현장 등록에 필요) |

연동 없이 쓰면 자료는 그 기기 브라우저(LocalStorage)에만 저장됩니다.

## 여는 방법
- **PC**: `index.html` 을 더블클릭 → 크롬/엣지에서 열림. 웹캠 또는 USB QR 리더기 사용.
- **스마트폰·태블릿**: 카메라는 `https://` 주소에서만 켜지는 기기가 많습니다.
  GitHub Pages·Netlify 등 정적 호스팅에 이 파일 하나를 올려 주소로 여세요. (자료는 여전히 기기 안에만 저장)
- Tailwind·jsQR·QR 생성 라이브러리를 CDN에서 불러오므로 **처음 열 때 인터넷이 필요**합니다.
  안드로이드 크롬은 기본 QR 인식기(BarcodeDetector)를 먼저 씁니다.

## 기능
1. **명단 올리기** — 엑셀 표 복사·붙여넣기 또는 CSV(UTF-8·EUC-KR 모두). 제목: 이름·소속·전화번호·면허번호·QR코드ID
   (출결상태·입실시간·퇴실시간도 읽음). QR코드ID가 없으면 `A0001` 형식으로 자동 부여.
2. **QR 스캔** — 카메라 또는 USB/블루투스 리더기. 성공 시 초록 화면 반짝임 + 삑 소리 + 진동.
   - 모드: **자동**(입실↔퇴실 토글) / **입실 전용** / **퇴실 전용** — 출입구를 나눠 운영할 때 기기마다 지정
   - 장소(등록데스크·룸 이름)가 기록마다 남음, 퇴실 후 다시 찍으면 **재입실**로 구간이 추가됨
3. **검색·수동 처리** — 이름·전화 뒷자리·소속·초성(ㅎㄱㄷ)으로 실시간 검색, 큰 버튼으로 입실/퇴실.
4. **내보내기** — 출결 현황 CSV(최초 입실·최종 퇴실·총 체류시간·예상 평점·수동 여부), 스캔 기록 전체 CSV, JSON 백업/복원.
5. **QR 명찰 인쇄** — 명단 전체의 QR을 A4 격자로 인쇄.

## 엄격한 입·퇴실 (연수평점용)
- 같은 사람이 **N초 안에 다시 찍으면 무시**(기본 60초)
- 자동 모드에서 **입실 후 N분 안의 재스캔은 퇴실로 처리하지 않음**(기본 10분) — 실수로 두 번 찍어 퇴실되는 것을 방지
- **입실 기록 없이는 퇴실 불가**
- 모든 처리(QR·리더기·수동·취소)가 시간·장소·방식과 함께 지워지지 않는 기록으로 남음. 수동 처리는 CSV에 «수동 포함»으로 표시
- 퇴실을 안 찍은 사람은 체류시간에 넣지 않고 «퇴실 미기록»으로 표시
- 예상 평점 = 체류시간 ÷ (1점당 분, 기본 60) — 하루 최대값 설정. **참고값이며 실제 인정 평점은 학회·의협 기준으로 확정**
- 관리자 PIN: 명단·설정 화면과 «직전 처리 취소»를 잠금

## 동명이인
- 모든 화면에서 **전화번호 뒷자리 4자리**를 크게 표시
- 같은 이름이 2명 이상이면 «동명이인» 표시, 수동 처리 때 **본인에게 뒷자리를 물어 입력해야** 버튼이 열림
  (설정에서 «항상 뒷자리 입력»으로 모든 수동 처리에 적용 가능)

## 구글 시트 연동 (여러 패드 · 현장 등록)

입구 패드·출구 패드·현장 등록 페이지가 **같은 구글 시트**에 기록을 모읍니다. 비용 없음, 서버 없음.

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다 (행사마다 하나).
2. 메뉴 **확장 프로그램 → Apps Script** → 기존 내용을 지우고 `apps-script/Code.gs` 내용을 붙여넣고 저장.
3. 위쪽 함수 선택에서 `setup` → **실행** → 권한 허용. 시트에 «설정·명단·기록» 탭이 생기고 «설정» 탭에 **직원코드**가 생깁니다.
4. «설정» 탭에서 행사명·운영방식(학술대회/팝업)·주최·문의·보유기간을 채웁니다.
5. Apps Script **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자 «나», 액세스 권한 «모든 사용자» → **웹 앱 주소** 복사.
6. 각 패드의 출결 앱 **명단·설정 → 여러 기기 연동**에 웹 앱 주소·직원코드·기기 이름(예: 1층 입구) 입력 → 연결.
   - 처음 연결하는 기기에 명단이 있으면 «시트로 보내고 연결»을 누르면 됩니다. 다른 패드는 연결만 하면 명단을 받아 옵니다.
7. 현장 등록을 쓰려면 **현장 등록 QR → A4 안내문 인쇄** 후 입구에 붙입니다.

동작 방식
- 스캔은 패드에 먼저 저장되고 8초마다 시트와 맞춥니다. **와이파이가 끊겨도 스캔은 계속**되고, 화면 위에 «연동 끊김 (대기 N건)»이 보이다가 연결되면 자동으로 올라갑니다.
- 기록마다 기기 이름이 남아 «어느 패드에서 입실·퇴실했는지» 시트와 CSV에서 확인할 수 있습니다.
- 행사명·운영방식은 시트 «설정» 탭이 기준입니다. 패드에서는 바꿀 수 없습니다.
- «기록» 탭의 행을 **중간만 지우지 마세요.** 지우려면 제목 줄만 남기고 전부 지운 뒤 각 패드에서 «지금 맞추기».
- 인터넷 없이 여러 패드를 썼다면 각 패드에서 «백업 파일 저장» → 한 패드에서 «백업 불러오기·합치기»로 모읍니다.

## 현장 등록 (register.html)
- 이름·휴대폰(필수), 소속·이메일(선택), 학술대회는 면허번호(선택).
- **개인정보 수집·이용 동의(필수)**: 수집 주체·항목·목적·보유기간을 시트 «설정»에서 읽어 보여 줍니다. 만 14세 이상 확인(필수), 마케팅 수신(선택, 따로 기록).
- 등록하면 휴대폰에 **개인 QR**이 나옵니다. 같은 휴대폰으로 주소를 다시 열면 같은 QR이 다시 나옵니다.
- 같은 번호 재등록: 팝업은 같은 이름이면 기존 QR을 다시 보여 주고, 학술대회는 대리 출석을 막기 위해 등록데스크로 안내합니다.
- 팝업에서 «등록 즉시 입장 = 예»면 등록과 동시에 방문으로 기록됩니다.
- 자동으로 만드는 QR코드ID는 추측하기 어려운 무작위 코드입니다(남의 번호로 찍는 대리 출석 방지).

## 무인 모드 (거치대 패드)
- 스캔 화면 아래 **무인 모드** → 카메라와 결과만 크게 보이고, 6초 뒤 대기 화면으로 돌아갑니다.
- 명단·설정의 **카메라 기본 방향 = 앞 카메라**로 두면 참가자가 화면을 보며 QR을 댈 수 있습니다.
- 끝내기는 오른쪽 위 «관리자» → **관리자 PIN**. PIN을 꼭 설정하세요.
- 아이패드는 «설정 → 손쉬운 사용 → 사용법 유도 접근»을 켜면 다른 앱으로 못 나갑니다.

## 주의
- 자료는 그 기기·그 브라우저에만 있습니다. 행사 중간중간 **백업 파일 저장**을 권장합니다.
- 연동하지 않고 여러 기기를 쓰면 기기마다 기록이 따로 쌓입니다. 위의 «백업 불러오기·합치기»로 모으세요.
- 시트에는 참가자 개인정보가 쌓입니다. 시트 공유 범위를 담당자로 제한하고, 보유기간이 지나면 지우세요.
- 등록 페이지 주소(웹 앱 주소 포함)는 공개돼도 등록만 가능합니다. 명단·기록을 읽고 쓰려면 직원코드가 필요합니다.
