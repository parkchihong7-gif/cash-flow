# 공인중개사 기출 풀이 분석기 — 사용 설명서

컴퓨터를 잘 모르셔도 따라 하실 수 있게 적었습니다.

---

## 1. 이 프로그램이 해 드리는 것

기출을 풀고 **채점만 하고 넘기는 일**을 막아 드립니다.

70점이 나왔다고 칩시다. 그래서 무엇을 해야 할까요? "더 열심히" 말고는 나오는
게 없습니다. 이 프로그램은 대신 이렇게 말해 드립니다.

> 부동산공법이 28점입니다. 과락입니다.
> 국토계획법 총칙이 8%, 개발행위허가가 17%입니다.
> 틀린 이유의 60%가 '몰라서' 입니다. 문제를 더 푸실 때가 아니라 그 단원을
> 처음부터 다시 보실 때입니다.

---

## 2. 먼저 아셔야 할 것

### 기출문제는 들어 있지 않습니다

이 프로그램에는 **문제가 하나도 없습니다.** 가지고 계신 문제집이나 기출집으로
푸시고, **결과만** 적으시면 됩니다.

문제 지문을 적는 칸도 없습니다. 일부러 안 만들었습니다. 시험문제는 저작물이라
함부로 옮겨 적으면 안 되기 때문입니다.

### 합격을 약속하지 않습니다

어디가 약한지 좁혀 드릴 뿐입니다. 공부는 여전히 직접 하셔야 합니다.

---

## 3. 준비

### 컴퓨터

집에 있는 보통 컴퓨터면 됩니다. 윈도우·맥 모두 됩니다.
**인터넷도 필요 없습니다.** 비행기 안에서도 돕니다.

### 비용

**0원입니다.** 계정을 만들 것도, 매달 내는 돈도 없습니다.

맨 마지막 '다음 2주' 계획만 인공지능이 써 드리는데, 이건 선택입니다.
안 쓰셔도 같은 자리에 계획이 나옵니다(문장만 조금 딱딱합니다).
쓰시려면 API 키라는 것이 필요하고, 한 번 쓸 때 100원 안팎이 듭니다.

### 처음 한 번

관리 화면(통합 관리자 대시보드)에서 13번을 여시면 버튼으로 다 됩니다.
직접 명령어로 하시려면:

```
pip install -r requirements.txt
```

## 4. 쓰는 순서

### 4-1. 빈 표 만들기

```
python cli.py sheet --round 36회
```

`data` 폴더에 `records_36회.csv` 가 생깁니다. **엑셀로 여시면 됩니다.**

2차 과목만 보실 거면:

```
python cli.py sheet --round 36회 --subject public --subject tax
```

### 4-2. 풀면서 채우기

| 칸 | 어떻게 적나 |
|---|---|
| 정오 | 맞았으면 `O`, 틀렸으면 `X` |
| 단원 | 그 문제가 어느 단원인지 |
| 이유 | **틀렸을 때만**. 몰라서 / 헷갈려서 / 실수 / 시간부족 |
| 소요초 | 시간을 재셨다면. 안 재셔도 됩니다 |

**안 푸신 줄은 비워 두세요.** 알아서 빠집니다. 한 번에 다 채우실 필요 없습니다.

단원 이름이 헷갈리시면:

```
python cli.py subjects
```

### 4-3. '이유' 를 성의 있게 적으세요

여기가 이 프로그램의 핵심입니다. 네 가지가 서로 **해야 할 일이 다릅니다.**

| 적으실 말 | 이런 때 |
|---|---|
| 몰라서 | 보기를 봐도 무슨 소린지 몰랐다 |
| 헷갈려서 | 둘 중 하나인 건 알았는데 골랐더니 틀렸다 |
| 실수 | 알고 있었는데 '옳지 않은 것' 을 '옳은 것' 으로 읽었다 |
| 시간부족 | 시간에 쫓겨 찍었다 |

'실수' 가 많은 분이 개념 강의를 다시 듣는 것은 시간 낭비입니다.
**그걸 알려 드리려고 만든 칸입니다.**

### 4-4. 보고서 보기

```
python cli.py report --input data/records_36회.csv
```

`outputs` 폴더에 두 개가 생깁니다.

- `report_날짜.md` — 메모장으로 열립니다
- `report_날짜.html` — 더블클릭하면 브라우저로 열립니다. 그림이 있습니다

## 5. 보고서 읽는 법

### 5-1. 맨 위 — 과락

제일 먼저 나오는 것이 **과락 위험 과목**입니다. 평균이 아닙니다.

공인중개사는 매 과목 40점, 평균 60점이면 붙습니다. 그런데 이 구조 때문에
**평균 65점으로 떨어지는 일**이 생깁니다. 한 과목이 38점이면 나머지가 아무리
좋아도 끝입니다.

빨간 줄이 보이면 **그 과목부터** 하세요. 다른 건 나중입니다.

### 5-2. 약한 단원

**3문항 이상 푸신 단원만** 나옵니다. 한두 문제로는 잘하는지 못하는지 알 수
없어서 일부러 뺐습니다. 더 푸시면 그때 나옵니다.

### 5-3. 왜 틀렸나

이유별 건수와 **해야 할 일**이 같이 적혀 있습니다. 여기만 보셔도 됩니다.

### 5-4. 시간

한 과목 50분에 40문항이니 **한 문제 75초**가 기준입니다.
90초가 넘으면 실력과 별개로 못 푸는 문제가 생깁니다.

### 5-5. 그림이 안 보이면

`report_날짜.html` 의 그림은 인터넷이 있어야 그려집니다. 없으면 표만 보이고,
**왜 안 보이는지 화면에 적혀 있습니다.** 고장이 아닙니다. 숫자는 표에 다 있습니다.

## 6. 자주 묻는 것

**Q. 문제집을 따로 사야 하나요**
네. 이 프로그램에는 문제가 없습니다.

**Q. 엑셀에서 한글이 깨집니다**
파일을 엑셀에서 바로 열지 마시고, 엑셀을 먼저 켠 뒤 '열기' 로 불러오시면서
'UTF-8' 을 고르세요. 구글 스프레드시트로 여시면 그냥 됩니다.

**Q. 두 회차를 같이 보고 싶습니다**
한 파일에 이어 적으시면 됩니다. 회차 칸만 다르게 적으세요.

**Q. 다시 풀었더니 점수가 올랐습니다. 비교되나요**
같은 파일에 회차를 다르게 적어 두시면 회차 목록이 같이 나옵니다.
단원별로는 합쳐서 셉니다.

**Q. 점수를 예측해 주나요**
안 해 드립니다. 보고서의 '환산 점수' 는 *지금 정답률이 40문항 내내 이어진다면*
이라는 가정일 뿐입니다. 실제 시험은 회차마다 난이도가 다릅니다.

**Q. 제 기록이 어디로 가나요**
아무 데도 안 갑니다. 인터넷을 쓰지 않습니다. 파일은 컴퓨터 안에만 있습니다.

- 맞은 문제에 이유가 적혀 있다고 나오면 → 줄이 한 칸 밀린 것입니다

  샘플 자료로 도니 내 파일 문제인지 프로그램 문제인지 갈립니다

## 8. '다음 2주' 계획은 초안입니다

보고서 맨 아래에 나오는 계획은 **초안**입니다. 그대로 따르실 필요 없습니다.

인공지능이 쓴 초안이든 규칙으로 쓴 초안이든, 그 사람의 사정(직장인인지 전업인지,
시험까지 몇 달 남았는지)은 모릅니다. **읽어 보시고 본인 상황에 맞게 고치세요.**

인공지능이 쓴 초안에는 보고서 끝에 그렇게 적힌 한 줄이 붙습니다. 법으로 정해진
표시입니다(인공지능기본법).

## 9. 실제로 이렇게 쓰시면 됩니다

### 처음 한 달

1. 한 회차를 풉니다 (한 과목씩 나눠 푸셔도 됩니다)
2. 채점하면서 표를 채웁니다 — **이유 칸을 꼭 적으세요**
3. 보고서를 만듭니다
4. 과락 과목의 약한 단원 두 개만 골라 그 주에 봅니다

**두 개만** 고르는 게 중요합니다. 다섯 개를 고르면 아무것도 안 됩니다.

### 두 달째부터

같은 방식으로 회차를 늘려 갑니다. 한 파일에 계속 이어 적으시면 됩니다.
회차 칸만 다르게 적으세요.

### 시험 두 달 전

이유 칸에서 '시간부족' 이 늘어나기 시작합니다. 이때부터는 **시간을 재고**
푸세요. 소요초 칸을 채우시면 어느 과목에서 시간이 새는지 보입니다.

## 10. 비용을 다시 정리하면

| 무엇 | 비용 |
|---|---|
| 프로그램 자체 | 사실 때 한 번 |
| 매달 내는 돈 | **없습니다** |
| 인터넷 | 필요 없습니다 |
| 계정 | 필요 없습니다 |
| 인공지능 계획(선택) | API 키를 만드시면 한 번에 100원 안팎 |

마지막 줄만 선택입니다. **안 쓰셔도 같은 자리에 계획이 나옵니다.**
API 키는 인공지능 회사에서 받는 비밀번호 같은 것인데, 없어도 이 프로그램의
95%는 그대로 돕니다.

## 11. 파일을 잃어버리지 않으려면

기록표(`records_36회.csv`)는 **여러 달 쌓이는 파일**입니다. 잃어버리면 처음부터
다시 적어야 합니다.

- 구글 드라이브나 원드라이브 폴더 안에 두시면 자동으로 백업됩니다
- 아니면 한 주에 한 번 USB 나 메일로 자신에게 보내 두세요

보고서(`outputs` 폴더)는 다시 만들 수 있으니 백업 안 하셔도 됩니다.

---

## 12. 관리 화면에서 하실 수 있는 것

통합 관리자 대시보드를 켜시면 명령어를 안 치고도 됩니다.

| 탭 | 하는 일 |
|---|---|
| 열람 | 이용 순서와 자주 묻는 것 |
| 수정 | 단원 목록을 본인 교재에 맞게 고치기 |
| 테스트 | 버튼 하나로 보고서 만들기 (모의 실행은 비용 0원) |
| 매뉴얼 | 이 문서 |

**수정 탭의 '과목·단원 목록'** 을 한 번 손보시길 권합니다. 쓰시는 교재와 단원
이름이 맞으면 표를 채우는 게 훨씬 수월해집니다.
