# 13. 공인중개사 기출 풀이 분석기 (exam-drill)

기출을 **몇 개 틀렸는지**가 아니라 **어디서 왜 틀렸는지**를 봅니다.

> **이 프로그램에는 기출문제가 들어 있지 않습니다.**
> 문제 지문·보기·정답을 담지도, 배포하지도 않습니다. 넣는 칸조차 없습니다.
> 이유는 아래 §2 에 적었습니다.

---

## 1. 무엇을 하나

```
빈 기록표 받기  →  풀면서 O/X·단원·이유 적기  →  약한 단원과 처방
 cli.py sheet                                     cli.py report
```

들어가는 것은 한 줄에 다섯 칸입니다.

| 칸 | 예 | 설명 |
|---|---|---|
| 회차 | `35회` | 어느 회차를 푼 건지 |
| 과목 | `public` | 5과목 중 하나 |
| 문항번호 | `17` | 1~40 |
| 정오 | `X` | 맞으면 O, 틀리면 X |
| 단원 | `개발행위허가` | 본인이 고릅니다 |
| 이유 | `몰라서` | 틀렸을 때만. 4가지 중 하나 |
| 소요초 | `95` | 잰 사람만 |

나오는 것은 보고서 두 벌(`.md`, `.html`)입니다.

---

## 2. 왜 문제를 담지 않나 — 시험문제는 저작물입니다

기출문제를 모아 파는 도구를 만들면 제일 빨리 망합니다.

**법원은 시험문제를 어문저작물로 봅니다.** 대학 입시문제에 대해 대법원이
그렇게 판단한 사례가 있고(2007다354), 수능·모의고사 문제를 무단으로 실은
문제집이 제재를 받은 일도 여러 번 있었습니다. 국가시험 문제라고 해서 자동으로
자유롭게 쓸 수 있는 것이 아닙니다.

저작권법 제7조가 보호에서 빼는 것은 법령·고시·공고·판결 같은 것입니다.
**시험 과목 구성과 배점, 합격 기준은 여기 해당해서 이 프로그램도 그 정보는
씁니다.** 하지만 문제 본문은 다릅니다.

### 그래서 이렇게 설계했습니다

| 막는 곳 | 어떻게 |
|---|---|
| **기록표 서식** | 지문·보기·정답을 적는 칸 자체가 없습니다 |
| 저장 | 프로그램이 문제 텍스트를 읽지도, 저장하지도 않습니다 |
| 보고서 | 단원 이름과 숫자만 실립니다 |
| Claude 입력 | 단원명·점수·이유 분포만 보냅니다 |
| 문제 생성 | "비슷한 문제를 만들어 주는" 기능을 넣지 않았습니다 |

마지막 줄이 중요합니다. 틀린 문제를 넣으면 비슷한 문제를 만들어 주는 기능은
만들기 쉽고 잘 팔릴 것 같지만, 그건 원문을 바탕으로 파생물을 만드는 일입니다.
**칸이 있으면 언젠가 채우게 됩니다. 그래서 칸을 안 만들었습니다.**

> 본인이 산 문제집·기출집을 **본인이 풀고 결과만 적는 것**은 아무 문제가 없습니다.
> 이 프로그램은 딱 거기까지만 합니다.

## 3. 설치

```bash
pip install -r requirements.txt     # 루트 requirements.txt 로도 됩니다
```

**계정도 키도 필요 없습니다.** 인터넷 없이 돕니다.

`ANTHROPIC_API_KEY` 가 있으면 마지막 '다음 2주' 계획을 Claude 가 씁니다.
없으면 규칙으로 씁니다. 둘 다 내용은 비슷합니다.

```bash
python cli.py report --demo --dry-run     # 샘플 자료로 흐름 보기
```

## 4. 쓰는 순서

### 4-1. 빈 기록표 만들기

```bash
python cli.py sheet --round 36회
python cli.py sheet --round 36회 --subject public --subject tax   # 2차만
```

`data/records_36회.csv` 가 생깁니다. 엑셀로 열면 됩니다.

### 4-2. 풀면서 채우기

한 회차를 다 풀고 한 번에 채워도 되고, 10문제씩 채워도 됩니다.
**안 푼 줄은 비워 두세요.** 비어 있으면 계산에서 알아서 빠집니다.

단원 이름이 헷갈리면:

```bash
python cli.py subjects        # 과목별 단원 목록
```

### 4-3. 보고서

```bash
python cli.py report --input data/records_36회.csv
```

## 5. 무엇을 보나

### 5-1. 과락이 제일 위에 옵니다

공인중개사는 **절대평가**입니다. 매 과목 40점, 평균 60점이면 붙습니다.
남과 견줄 것이 없습니다.

그런데 이 구조 때문에 **평균 65점으로 떨어지는 일**이 생깁니다.
한 과목이 38점이면 나머지가 아무리 좋아도 끝입니다.

그래서 보고서 맨 위는 평균이 아니라 **과락 위험 과목**입니다.

### 5-2. 왜 틀렸는지가 정답률보다 쓸모 있습니다

정답률만 보면 "공법을 더 해야겠다" 에서 끝납니다. 그런데 무엇을 더 해야
하는지는 이유마다 다릅니다.

| 이유 | 해야 할 일 |
|---|---|
| **몰라서** | 그 단원을 처음부터. 문제를 더 푸는 건 나중입니다 |
| **헷갈려서** | 섞이는 둘을 나란히 놓고 **차이만** 적은 비교표 |
| **실수** | 개념 공부는 필요 없습니다. 지문에 조건을 표시하며 읽는 습관 |
| **시간부족** | 시간을 재고 풉니다. 75초 넘기면 넘어가는 연습 |

'실수' 가 많은 사람이 개념 강의를 다시 듣는 것은 시간 낭비입니다.
**이 구분이 이 프로그램의 핵심입니다.**

### 5-3. 단원은 3문항 이상 푼 것만 셉니다

한두 문제로는 잘하는지 못하는지 알 수 없습니다. 2문제 중 1개 틀렸다고
50%라고 적으면 그건 숫자가 아니라 착시입니다.

### 5-4. 시간

한 과목 50분에 40문항이니 **문항당 75초**가 기준입니다.
중앙값을 씁니다. 한 문제에서 5분 붙잡고 있었던 것이 평균을 통째로 끌고 가기 때문입니다.

---

## 6. 한계

- **푼 문제만 가지고 셉니다.** 안 푼 단원의 실력은 알 수 없습니다
- 환산 점수는 "지금 정답률이 40문항 내내 이어진다면" 이라는 가정입니다.
  실제 시험 점수가 아닙니다
- 단원 분류는 본인이 합니다. 잘못 분류하면 결과도 그만큼 어긋납니다
- **합격을 예측하지 않습니다.** 어디가 약한지 좁혀 줄 뿐입니다

---

## 7. 판매 문구 초안

> 기출을 풀고 **채점만 하고 넘기지 않게** 해 드립니다.
>
> - 과목별 환산 점수와 **과락 위험**을 먼저 보여 드립니다
> - 단원별 정답률로 어디가 약한지 좁힙니다 (3문항 이상 푼 단원만)
> - **왜 틀렸는지**를 네 가지로 나눠, 이유마다 다른 처방을 드립니다
>
> **기출문제는 들어 있지 않습니다.** 가지고 계신 문제집으로 푸시고, 결과만
> 적으시면 됩니다. 문제 지문을 적는 칸은 아예 없습니다.
>
> 계정도 인터넷도 필요 없고, 합격을 약속하지 않습니다.
