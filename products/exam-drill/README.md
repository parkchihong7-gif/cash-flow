# 1. 공인중개사 기출문제 (exam-drill)

공인중개사 기출문제 **4,400문항**을 브라우저에서 풀고, 채점하고,
틀린 것만 모아 다시 보는 웹 프로그램.

> **본체는 이 저장소에 없습니다.**
> GitHub Pages 에서 돕니다. 이 폴더는 대시보드가 그 프로그램을 가리키고
> 접속키를 발급하기 위한 **명세와 문서**입니다.

---

## 들어 있는 것

| | |
|---|---|
| 회차 | 제15회 ~ 제36회 (22개 회차) |
| 문항 | 4,400 (1차 1,760 · 2차 2,640) |
| 1차 | 부동산학개론 · 민법 및 민사특별법 |
| 2차 | 공인중개사법령 및 중개실무 · 부동산공법 · 부동산공시에 관한 법령 및 부동산세법 |
| 보기 | 전 문항 5지선다 |

```
모의 기출문제  ─┘     │              └──> 복습함 ──> 다시 풀기
                      └─> 💬 메모 · ✅ 정답 확인 · 🤖 AI 문제풀이
```

## 어떻게 도는가

```
GitHub Pages            구글 앱스 스크립트          구글 시트
(프로그램 본체)   ←───→   (접속키 서버)      ←───→   (장부)
      ↑                        ↑
   고객 브라우저          통합 관리자 대시보드
   (성적 저장)             [🔑 접속키 발급하기]
```

**서버 비용이 0원입니다.** 셋 다 무료 서비스입니다.

### 접속키 — 이중키

한 사람에게 키가 네 개 나갑니다.

- **1차키 1개** — 그 사람
- **2차키 3개** — PC · 노트북 · 휴대폰

둘을 같이 넣어야 열립니다. 기기 세 대까지 쓰고,
**같은 2차키로 다른 곳에서 또 들어가면 먼저 있던 쪽이 끊깁니다.**

### 성적은 브라우저 안에만

푼 기록·점수·메모는 서버로 가지 않고 **그 브라우저**에 저장됩니다.
기록을 지우거나 기기를 바꾸면 성적도 사라집니다. 파실 때 미리 말씀하셔야 합니다.

---

## 쓰는 법

### 사장님 (파는 쪽)

통합 관리자 대시보드에서 **1번**을 엽니다.

| 버튼 | 어디로 |
|---|---|
| **관리자 모드 ↗** | 키 발급·목록 화면 |
| **클라이언트 모드 ↗** | 고객이 보는 화면 = **고객에게 보낼 주소** |
| **🔑 접속키 발급하기 ↗** | 앱스 스크립트 키 관리자 |

세 번째 버튼은 `.env` 에 주소가 있을 때만 보입니다.

```
KEYSERVER_URL=https://script.google.com/macros/s/……/exec
```

**저장소가 공개라 이 주소를 파일에 박지 않았습니다.** `.env` 는 커밋되지 않습니다.

발급 화면에서 개수·유효기간·이름·이메일을 넣고 **[이메일로 배포]** 를 누르면
**주소와 키 네 개가 한 통에** 갑니다. 주소를 따로 알려 주실 필요가 없습니다.

### 고객

메일의 주소를 열고 1차키 + (그 기기용) 2차키를 넣으면 끝입니다.
설치할 것이 없습니다.

## 팔기 전에 — 기출문제 재배포 권리

**이 프로그램에는 실제 기출문제가 지문·보기까지 통째로 들어 있습니다.**

공개된 자료를 모아 상품으로 파는 것은 별개의 판단을 받습니다.
팔기 전에 확인하십시오.

1. **한국산업인력공단**(Q-Net)에 문의하고 답변을 글로 받아 두기
2. **한국저작권위원회** 무료 상담 (1800-5455)
3. 답이 애매하면 팔지 않기

자세한 것은 [관리자 매뉴얼 2장](docs/admin.md)에 있습니다.
**법률 자문이 아닙니다.** 이 항목은 프로그램이 대신 해결해 드릴 수 없습니다.

## 판매 문구 초안

> **공인중개사 기출 4,400문항, 설치 없이 브라우저에서.**
>
> 제15회부터 제36회까지 22개 회차, 1차·2차 5과목이 들어 있습니다.
> 주소를 열고 받으신 키를 넣으면 바로 시작됩니다. 휴대폰에서도 됩니다.
>
> - **회차별·과목별** 로 골라 풉니다. 약한 과목만 몰아서도 됩니다
> - **모의 기출문제** — 출제 순서와 보기 순서를 섞어 "위치 외우기" 를 막습니다
> - **복습함** — 틀린 문제가 자동으로 모입니다. 종이 문제집으로는 손이 많이 가는 일입니다
> - **통계** — 가장 취약한 과목을 짚어 줍니다. 과락이 있는 시험이라 평균보다 이쪽이 중요합니다
> - **AI 문제풀이** — 모르는 문항을 쓰시던 AI에게 바로 물어보실 수 있습니다
>
> 한 분이 PC·노트북·휴대폰 **세 대**까지 쓰십니다.
>
> 성적은 쓰시는 브라우저에 저장됩니다. 서버로 올라가지 않습니다.
> 대신 브라우저 기록을 지우면 성적도 같이 사라지니 주의해 주세요.
>
> 합격을 약속하지 않습니다. 푸신 만큼 결과가 나옵니다.
> AI가 쓴 풀이는 초안이니 정답은 [✅ 정답 확인] 으로 보셔야 합니다.
