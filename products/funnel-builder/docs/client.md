# 퍼널 빌더 — 사용 설명서

> 구매해 주셔서 감사합니다. 이 문서 하나만 따라 하시면 됩니다.
> 막히는 곳이 있으면 판매자에게 문의해 주세요.

## 이 프로그램이 해주는 일

상품 정보를 적어 넣으면 **판매 페이지 글과 이메일 5통 초안**을 만들어 드립니다.

| 만들어 주는 것 | 설명 |
|---|---|
| 랜딩 페이지 (HTML 파일 1개) | 그대로 홈페이지에 올릴 수 있습니다. 휴대폰에서도 잘 보입니다 |
| 이메일 5통 | 신청일로부터 0·1·3·5·7일에 보내는 순서로 구성돼 있습니다 |
| 무료 자료 목차 | 이메일 주소를 받기 위해 나눠줄 자료의 목차입니다 |
| 헤드라인 10개 + 버튼 문구 5개 | 어느 쪽이 반응이 좋은지 비교해 볼 수 있습니다 |
| 점검 리포트 | 어떤 부분을 직접 고쳐야 하는지 알려줍니다 |

**솔직하게 말씀드립니다.** 이 프로그램은 글 쓰는 시간을 줄여주는 도구입니다.
나온 결과를 그대로 올리면 안 되고, 반드시 읽고 고치셔야 합니다.
판매 성과는 상품·가격·유입에 따라 달라지며 이 도구가 보장하지 않습니다.

## 1. 준비 (처음 한 번)

### 1-1. 프로그램 설치

```
pip install -r requirements.txt
```

### 1-2. Claude API 키 발급

이 프로그램은 Claude 라는 AI 를 사용합니다. **키는 직접 발급받으셔야 합니다.**

1. https://console.anthropic.com 에 가입합니다
2. Settings → API Keys → Create Key 를 누릅니다
3. `sk-ant-` 로 시작하는 문자열이 나옵니다. **이때 한 번만 보이니 복사해 두세요**
4. Billing 메뉴에서 카드를 등록하고 10달러 정도 충전합니다

> **비용 안내**
> 퍼널 1건을 만들 때마다 수백 원 정도의 사용료가 Anthropic 에 발생합니다.
> 10달러를 충전하면 수십 건은 만들 수 있습니다. 판매자에게 내는 돈이 아니라
> AI 사용료이며, 판매자는 이 금액을 받지 않습니다.

### 1-3. 키 넣기

프로그램 폴더의 `.env.example` 파일을 복사해 `.env` 라는 이름으로 만들고, 안의
`ANTHROPIC_API_KEY=` 뒤에 복사해둔 키를 붙여넣습니다.

> `.env` 파일은 비밀번호와 같습니다. 누구에게도 보내지 마세요.

## 2. 상품 정보 적기

`funnel_input.yaml` 파일을 메모장이나 편집기로 엽니다. 9개 칸이 있습니다.

```yaml
product_name: "상품 이름을 그대로"
target: "누가 살 물건인지 한 줄로"
price: 149000
core_promise: "이걸 사면 뭐가 달라지는지 한 줄로"
lead_magnet_title: "무료로 나눠줄 자료 제목"
pain_points:
  - "고객이 겪는 어려움 1"
  - "고객이 겪는 어려움 2"
  - "고객이 겪는 어려움 3"
proof: []
cta_url: "https://결제페이지주소"
sender_name: "이메일 보내는 사람 이름"
```

### 잘 쓰는 요령

**`target` 은 좁게.** "직장인" 보다 "퇴근 후 1시간 쓰는 3년차 사무직" 이 훨씬 좋은 글이 나옵니다.
넓게 쓰면 누구에게도 와닿지 않는 문장이 나옵니다.

**`pain_points` 는 고객이 쓰는 말로.** "콘텐츠 기획의 어려움" 이 아니라
"올릴 거리가 떠오르지 않아 한 시간씩 휴대폰만 본다" 처럼요.

**`proof` 에 없는 후기를 넣지 마세요.** 후기나 실적이 없으면 `proof: []` 로 비워두세요.
비워두면 그 부분이 아예 만들어지지 않습니다. 없는 후기를 지어내면 법에 걸립니다.

### 자주 하는 실수

- 가격에 쉼표 → `149,000` (X) `149000` (O)
- 어려움을 2개만 적음 → 최소 3개, 최대 5개
- 주소에 `https://` 빠뜨림

## 3. 만들기

### 먼저 모의 실행

```
python cli.py build funnel_input.yaml --dry-run
```

비용이 들지 않고 몇 초 만에 끝납니다. **어떤 모양으로 나오는지**만 보는 단계입니다.
나온 글은 예시라 의미가 없습니다.

`outputs` 폴더에 생긴 `landing.html` 을 더블클릭해서 브라우저로 열어보세요.

### 실제로 만들기

```
python cli.py build funnel_input.yaml
```

2~4분 걸립니다. 화면이 멈춘 것 같아도 기다려 주세요.

## 4. 결과 확인하고 고치기

`outputs/상품이름/` 폴더에 파일들이 생깁니다.

### 4-1. `build_report.md` 를 먼저 엽니다

어떤 부분을 고쳐야 하는지 적혀 있습니다. 경고가 있으면 그 부분부터 처리하세요.

### 4-2. 반드시 직접 채워야 하는 것

랜딩 페이지 맨 아래에 이렇게 비어 있는 부분이 있습니다.

```
환불 정책: (판매 전 반드시 채우세요 ...)
사업자 정보 / 문의처: (판매 전 채우세요)
```

**여기를 안 채우면 법 위반입니다.** 온라인으로 물건을 파는 사람은 환불 조건과
사업자 정보를 반드시 표시해야 합니다. `landing.html` 을 편집기로 열어
이 두 줄을 찾아 실제 내용으로 바꿔주세요.

### 4-3. 이메일 5통 읽기

`emails` 폴더에 5개 파일이 있습니다. 파일 맨 위를 보면

```
subject: "제목입니다"
send_day: 3
```

`send_day` 는 **신청일로부터 며칠 뒤에 보낼지**입니다. 0 이면 신청 즉시, 3 이면 3일 뒤.

5통을 다 읽어보시고 어색한 문장이나 사실과 다른 내용을 고치세요.
AI 가 쓴 글이라 그럴듯하지만 틀린 내용이 섞일 수 있습니다.

## 5. 올리기

1. `landing.html` 을 홈페이지나 호스팅 서비스에 올립니다
2. 이메일 5통을 쓰시는 발송 도구(스티비·메일침프 등)에 붙여넣고 발송일을 맞춥니다
3. 무료 자료 목차를 보고 실제 자료(PDF 등)를 만듭니다

## 6. 안 될 때

| 화면에 이렇게 나오면 | 이렇게 하세요 |
|---|---|
| `ANTHROPIC_API_KEY 가 없습니다` | `.env` 파일에 키를 안 넣었습니다. 1-3 을 다시 |
| `Claude API 오류 401` | 키가 잘못됐습니다. 콘솔에서 새로 발급받으세요 |
| `credit balance` 라는 말이 보임 | 충전 잔액이 없습니다. 콘솔 Billing 에서 충전 |
| `쿼터 초과` | 너무 자주 불렀습니다. **1분 기다렸다가** 다시 하세요 |
| `입력이 올바르지 않습니다` | 어느 항목이 잘못됐는지 메시지에 나옵니다. 2장 참고 |
| 한글이 깨져 보임 | 파일을 저장할 때 인코딩을 UTF-8 로 |

그래도 안 되면 화면에 나온 메시지를 **그대로 복사해서** 판매자에게 보내주세요.

## 7. 기억해 주실 것

- 나온 글은 **초안**입니다. 반드시 읽고 고쳐서 쓰세요
- 환불 정책과 사업자 정보는 **직접** 채우셔야 합니다
- 없는 후기나 실적을 넣지 마세요
- AI 가 만든 콘텐츠라는 표시가 자동으로 들어갑니다 (2026년 1월 시행된 법에 따른 것입니다)
- 판매 성과는 상품과 시장에 따라 달라집니다. 이 도구는 글 쓰는 시간을 줄여줄 뿐입니다
