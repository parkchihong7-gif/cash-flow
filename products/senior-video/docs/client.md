# 시니어 영상 비용 견적·절감기 — 사용 설명서

---

## 1. 이 프로그램이 해 드리는 것

어르신 대상 유튜브 영상을 만드실 때,

1. **얼마나 드는지** 미리 계산해 드립니다
2. **어디서 새는지** 짚어 드립니다
3. **무엇을 아낄 수 있고, 대신 무엇을 내줘야 하는지** 알려 드립니다
4. **어르신이 보기 편한 영상의 기준**에 맞는지 봐 드립니다

영상을 만들어 주지는 않습니다. 계산하고 점검하는 도구입니다.

---

## 2. 먼저 아셔야 할 것

### 자동으로 올려 드리지 않습니다

**일부러 안 만들었습니다.** 유튜브가 2025년 7월부터 사람 손이 안 닿은 대량
업로드를 수익 창출에서 빼고 있습니다. 자동 업로드는 돈을 아끼는 게 아니라
채널을 잃는 길입니다.

대신 **승인 대기열**을 드립니다. 만드신 영상을 목록에 넣고, 확인하신 뒤
승인하시면 올릴 것 목록에 들어갑니다.

### 하루 6편이 끝입니다

유튜브에서 프로그램으로 영상을 올릴 수 있는 양에 한도가 있습니다.
하루 6편입니다. 이건 돈을 더 낸다고 늘어나지 않습니다(신청해서 심사를 받아야 합니다).

### 견적은 추정치입니다

공개된 요금표로 계산한 값입니다. 실제 청구액은 각 서비스의 사용량 화면이
기준이고, 요금은 자주 바뀝니다.

---

## 3. 준비

### 컴퓨터

집에 있는 보통 컴퓨터면 됩니다. **견적과 점검은 인터넷도 필요 없습니다.**

### 비용

**이 프로그램 자체는 0원입니다.** 외부 서비스를 부르지 않고 계산만 합니다.
API 키도 필요 없습니다.

돈이 드는 것은 실제로 영상을 만드실 때입니다. 그 금액이 견적서에 나옵니다.

### 실제로 유튜브에 올리시려면

이건 따로 준비가 필요합니다. 관리 화면의 **권한·환경** 탭에 정리해 두었습니다.

| 무엇 | 걸리는 시간 |
|---|---|
| 유튜브 채널 | 바로 |
| 구글 API 프로젝트(OAuth) | 바로 |
| **API 감사 승인** | **며칠~몇 주** |

마지막 줄이 중요합니다. 감사를 받기 전에는 프로그램으로 올린 영상이
**비공개로 잠깁니다.** 채널을 시작하시기 전에 먼저 신청하세요.

## 4. 쓰는 순서

### 4-1. 기획 수치 적기

`plan.yaml` 파일을 메모장으로 열어 고치시면 됩니다.

```
title: 어르신을 위한 스마트폰 사용법
script_chars: 1500      대본 글자 수
images: 12              쓸 이미지 장 수
monthly_videos: 20      한 달에 몇 편
tts: clova              어떤 음성을 쓸지
```

아래쪽 시니어 규격 항목은 **비워 두셔도 됩니다.** 적으시면 맞는지 봐 드립니다.

### 4-2. 견적 내기

```
python cli.py estimate --input plan.yaml
```

`outputs` 폴더에 견적서가 생깁니다. 메모장으로 열립니다.

처음이시면 샘플로 먼저 보세요.

```
python cli.py estimate --demo
```

### 4-3. 견적서 읽는 법

**'한 줄'** 부터 보세요. 편당·월·연 비용과 **가장 큰 줄**이 적혀 있습니다.
줄이시려면 그 줄부터 손대셔야 합니다.

**'줄일 수 있는 것'** 표에서 ⚠ 표시를 보세요. 그건 돈은 아끼지만
**어르신 시청자에게 불리해지는** 선택입니다.

### 4-4. 규격 점검

견적서에 같이 나옵니다. 권장값을 벗어난 항목은 **왜 그게 중요한지**까지
적혀 있습니다.

```
python cli.py spec      항목별로 자세히
```

### 4-5. 승인 대기열

영상을 다 만드셨으면:

```
python cli.py queue add "어르신 스마트폰 3편" --chars 1500
python cli.py queue list
python cli.py approve 1 --by 홍길동
```

**승인하시는 분 이름을 꼭 넣으셔야 합니다.** 이름이 없으면 프로그램이
거절합니다. 사람이 봤다는 기록이 남아야 '검수' 이기 때문입니다.

---

## 5. 어르신이 보기 편한 영상이란

취향 문제가 아니라 **몸이 달라서** 생기는 기준입니다.

| 기준 | 권장값 | 왜 |
|---|---|---|
| 자막 크기 | 64px 이상 | 작은 글씨를 못 읽습니다. 자막이 본문입니다 |
| 자막 한 줄 | 16자 이하 | 길면 눈이 줄을 놓칩니다 |
| 말 속도 | 분당 300음절 이하 | 빠르면 들려도 뜻이 안 남습니다 |
| 배경음악 | -18dB 이하 | 소음 속에서 말소리를 골라내기가 어렵습니다 |
| 장면 전환 | 4초 이상 | 빨리 바뀌면 내용을 놓칩니다 |
| 명도 대비 | 4.5:1 이상 | 밝은 사진 위 흰 글자가 가장 흔한 실수입니다 |
| 영상 길이 | 8~15분 | 쇼츠는 이 시청자층에 잘 안 맞습니다 |

### 특히 배경음악

나이가 들면 **높은 소리부터** 안 들리기 시작합니다. 자음(ㅅ·ㅊ·ㅋ) 소리가
거기 몰려 있어서, "말은 들리는데 무슨 말인지 모르겠다" 가 됩니다.

배경음악이 있으면 이게 훨씬 심해집니다. **아예 빼시는 것도 좋습니다.**

---

## 6. 대본은 초안입니다

인공지능으로 대본을 만드시는 경우, 그건 **초안**입니다.

**소리 내어 한 번 읽어 보세요.** 눈으로 읽으면 안 걸리던 어색한 문장이
바로 걸립니다. 어르신 대상 영상은 특히 그렇습니다.

인공지능이 만든 산출물에는 그렇게 표시하는 것이 법으로 정해져 있습니다
(인공지능기본법).

---

## 7. 자주 묻는 것

**Q. 왜 자동 업로드를 안 해 주나요**
유튜브 정책 때문입니다. 사람 검수 없는 대량 업로드는 수익 창출에서 빠집니다.

**Q. 하루 20편 올린다는 곳도 있던데요**
여러 계정을 쓰거나, 구글에 신청해서 한도를 늘렸거나, 아니면 안 되는 걸
된다고 하는 것입니다.

**Q. 견적이 실제랑 다르면요**
추정치입니다. 단가표의 출처를 같이 드리니 직접 확인해 보실 수 있습니다.

```
python cli.py rates
```

**Q. 음성을 싼 걸로 바꿔도 되나요**
됩니다. 다만 ⚠ 표시가 붙은 것은 어르신 시청자에게 불리합니다.
아끼는 돈이 연 1만 원대인데 시청자가 떠나면 손해입니다.

**Q. 조회수를 늘려 주나요**
아니요. 비용을 계산하고 규격을 점검하는 도구입니다.

## 8. 관리 화면에서

통합 관리자 대시보드 2번을 여시면 버튼으로 하실 수 있습니다.

| 탭 | 하는 일 |
|---|---|
| 열람 | 이용 순서와 자주 묻는 것 |
| 수정 | 단가표와 시니어 규격 고치기 |
| 테스트 | 버튼 하나로 견적서 만들기 (비용 0원) |
| 권한·환경 | 유튜브에 올리시려면 무엇이 필요한지 |

**권한·환경 탭을 먼저 보세요.** 감사 신청에 몇 주가 걸린다는 걸 미리 아시면
일정을 잡기가 훨씬 수월합니다.

- 기획 파일을 못 읽는다고 나오면 → 항목 이름을 바꾸지 않으셨는지 보세요
- 승인이 안 된다고 나오면 → `--by` 에 이름을 넣으셨는지 보세요
- 그 밖에는 관리 화면 **테스트** 탭에서 샘플로 한 번 돌려 보세요

## 10. 영상 한 편 만드는 실제 순서

이 프로그램이 들어가는 자리를 표시해 두었습니다.

| 순서 | 하는 일 | 이 프로그램이 하는 일 |
|---|---|---|
| 1 | 주제 정하기 | — |
| 2 | 대본 쓰기 | — (다른 프로그램이나 직접) |
| 3 | **견적 내 보기** | ← 여기 |
| 4 | 음성 만들기 | — |
| 5 | 이미지 고르기 | — |
| 6 | 영상 합치기 | — |
| 7 | **규격 점검** | ← 여기 |
| 8 | **대기열에 넣고 승인** | ← 여기 |
| 9 | 올리기 | — |

3번을 **처음 한 번만** 하시면 됩니다. 매 편 할 일은 아닙니다.
기획이 비슷하면 비용도 비슷하기 때문입니다. 다만 요금제가 바뀌거나
편수를 크게 늘리실 때는 다시 내 보세요.

## 11. 비용을 실제로 줄이신 분들의 순서

대체로 이 순서로 줄입니다. 위에서부터 손대는 게 효율이 좋습니다.

### 1) 인사말·마무리 음성 재사용

매 편 똑같이 들어가는 "안녕하세요, OO채널입니다" 와 "구독 부탁드립니다" 를
**한 번만 만들어 파일로 두고** 붙이시면 됩니다.

금액은 크지 않지만 **대가가 하나도 없습니다.** 어차피 같은 문장이니까요.
먼저 하세요.

### 2) 이미지를 무료 스톡으로

대개 여기서 가장 많이 줄어듭니다. 다만 **라이선스를 한 장씩 확인**하셔야 합니다.
'상업적 이용 가능' 표기를 보세요. 이걸 안 보고 쓰시면 나중에 문제가 됩니다.

### 3) 대본 모델을 낮추기

기획이 복잡한 편에서만 품질 차이가 납니다. **첫 기획만 좋은 모델로 잡고
나머지는 내려도** 됩니다.

### 4) 음성 엔진 — 여기는 신중하게

⚠ 표시가 붙는 이유가 있습니다. 어르신 대상 영상에서 **발음 명료도는
비용보다 중요합니다.** 아끼는 돈이 연 1만 원대인데 시청자가 떠나면 손해입니다.

바꾸시겠다면 **같은 대본으로 두 엔진 음성을 만들어 실제 시청자께 들려 드려 보세요.**
차이를 못 느끼시면 바꾸셔도 됩니다.

### 5) 편수 줄이기 — 마지막 수단

편수를 줄이면 노출이 줄 수 있습니다. 다만 편당 공을 더 들이게 되니 품질은
올라갑니다. 유튜브 정책상으로도 양산보다 낫습니다.

## 12. 파일이 어디 있나

| 파일 | 무엇 |
|---|---|
| `plan.yaml` | 기획 수치. 메모장으로 고치시면 됩니다 |
| `data/unit_costs.yaml` | 단가표. 요금이 바뀌면 여기를 고칩니다 |
| `outputs/` | 만들어진 견적서 |
| `queue.db` | 승인 대기열. 지우지 마세요 |

`queue.db` 는 승인 기록이 남는 파일입니다. 나중에 "이거 누가 확인했더라" 를
찾으실 수 있습니다. 백업해 두시면 좋습니다.
