# 14. 시니어 영상 제작 비용 견적·절감기 (senior-video)

시니어 시청자를 노린 유튜브 채널의 **제작 비용이 어디서 새는지** 찾습니다.

> **자동 업로드 프로그램이 아닙니다.**
> 사람이 승인한 것만 올라가고, 승인 없이 올리는 경로가 코드에 없습니다.
> 이유는 §4 에 적었습니다.

---

## 1. 무엇을 하나

```
기획 수치 적기  →  견적서  →  줄일 곳과 그 대가  →  규격 점검  →  승인 대기열
  plan.yaml      cli.py estimate                                cli.py approve
```

| 하는 일 | 왜 |
|---|---|
| **비용 견적** | 음성·이미지·대본·렌더로 쪼개서 어디가 큰지 봅니다 |
| **절감안** | 아끼는 돈과 **내주는 것**을 나란히 놓습니다 |
| **시니어 규격 점검** | 자막 크기·말 속도·배경음 같은 것이 맞는지 봅니다 |
| **업로드 한도 계산** | 하루 6편이 끝이라는 사실을 미리 알려 드립니다 |
| **승인 대기열** | 사람이 본 것만 올라가게 막습니다 |

---

## 2. 왜 '시니어' 인가 — 취향이 아니라 몸이 다릅니다

이 상품이 '싼 영상 공장' 과 갈리는 지점입니다. 60대 이상이 보는 영상은
20대가 보는 영상과 **만드는 법이 다릅니다.**

| 사실 | 그래서 |
|---|---|
| **노인성 난청은 고주파부터 옵니다** (4kHz 대역이 먼저) | 자음(ㅅ·ㅊ·ㅋ)이 그 대역에 몰려 있습니다. "말은 들리는데 무슨 말인지 모르겠다" 가 여기서 나옵니다 |
| **소음 속 말소리 분리가 특히 어려워집니다** | 배경음악을 평소보다 더 낮춰야 합니다. 젊은 시청자 기준(-12dB)으로는 부족합니다 |
| **노안으로 작은 글씨를 못 읽습니다** | 자막이 장식이 아니라 본문이 됩니다 |
| **빠른 화면 전환을 따라가기 어렵습니다** | 쇼츠 문법을 그대로 가져오면 역효과입니다 |

### 권장값

```
자막 64px 이상 · 한 줄 16자 이하 · 분당 300음절 이하 · 배경음 -18dB 이하
장면 4초 이상 · 명도 대비 4.5:1 이상 · 영상 8~15분
```

```bash
python cli.py spec      # 항목별로 왜 그런지까지
```

**법이 아니라 권장값입니다.** 다만 지키면 시청 지속 시간이 달라집니다.
이 규격 자체가 이 상품에서 파는 것의 큰 부분입니다.

---

## 3. 비용은 대개 세 군데서 샙니다

```bash
python cli.py estimate --demo      # 샘플 기획으로 견적
python cli.py estimate --input plan.yaml
```

견적은 항목별로 쪼개서 나오고, **가장 큰 줄을 짚어 줍니다.**

### 공짜 절감은 하나뿐입니다

"품질 그대로 비용만 절반" 은 대개 거짓말입니다. 대부분은 뭔가를 내줍니다.
그래서 이 프로그램은 **아낀 돈과 그 대가를 나란히** 적습니다.

예외가 하나 있습니다. **인사말·마무리 음성 재사용**입니다. 매 편 똑같이
들어가는 220자쯤을 한 번만 만들어 두고 붙이면 됩니다. 어차피 같은 문장이라
품질이 떨어질 데가 없습니다.

⚠ 표시가 붙은 절감안은 **시니어 시청자에게 불리해지는** 선택입니다.
돈은 아끼지만 이 채널이 노리는 사람이 떠날 수 있습니다. 판단은 사람이 합니다.

### 단가는 추정치입니다

`data/unit_costs.yaml` 에 출처와 기준일이 같이 적혀 있습니다.

```bash
python cli.py rates
```

**요금제는 자주 바뀝니다.** 그래서 출처가 없는 단가는 프로그램이 읽는 단계에서
거절합니다. 고칠 때 출처도 같이 고치게 만드는 장치입니다.

---

## 4. 자동 업로드를 안 만든 이유

### 유튜브 정책

유튜브는 2025년 7월부터 **'양산형(비진정성) 콘텐츠'** 를 수익 창출에서 빼는
방향으로 정책을 정리했습니다. 사람 손이 안 닿은 대량 업로드는 채널 자체를
위험하게 만듭니다.

비용을 아끼자고 검수를 건너뛰면, 아낀 돈보다 잃는 게 큽니다.

### 쿼터 — 하루 6편이 끝입니다

| 호출 | 유닛 |
|---|---|
| 하루 한도 | 10,000 |
| **업로드 한 번 (`videos.insert`)** | **1,600** |

산술적으로 **하루 6편**입니다. "하루 20편 자동 업로드" 를 파는 사람들이
이 숫자를 말하지 않습니다.

```bash
python cli.py quota --monthly 60
```

### 감사(audit) 를 먼저 신청하세요

**새로 만든 구글 API 프로젝트로 올린 영상은 비공개로 잠깁니다.** 구글에 API
감사를 신청해 승인을 받아야 공개로 올릴 수 있습니다. 신청부터 답까지 며칠에서
몇 주가 걸립니다. **채널을 열기 전에 먼저 신청하세요.**

### 그래서 이 프로그램은

큐만 관리합니다.

```bash
python cli.py queue add "어르신 스마트폰 3편" --chars 1500
python cli.py queue list
python cli.py approve 1 --by 박치홍
```

**승인한 사람 이름이 없으면 승인이 아닙니다.** 이름 없는 승인은 자동 승인과
다르지 않기 때문에 프로그램이 거절합니다.

---

## 5. 설치

```bash
pip install -r requirements.txt
```

**견적과 규격 점검은 계정도 인터넷도 필요 없습니다.**
실제로 올리시려면 유튜브 채널과 구글 API 프로젝트(OAuth)가 필요하고,
위에 적은 감사 절차가 있습니다.

---

## 6. 한계

- **단가는 추정치입니다.** 실제 청구액은 각 서비스의 사용량 화면이 기준입니다
- 조회수·수익을 예측하지 않습니다
- 시니어 규격은 권장값이고, 채널마다 맞는 값이 다를 수 있습니다
- 이 프로그램은 영상을 만들지 않습니다. **얼마 드는지와 무엇을 지켜야 하는지**를
  계산할 뿐입니다

---

## 7. 판매 문구 초안

> 시니어 대상 유튜브 채널의 **제작 비용이 어디서 새는지** 찾아 드립니다.
>
> - 음성·이미지·대본·렌더로 쪼갠 견적서. 가장 큰 줄을 짚어 드립니다
> - 절감안마다 **무엇을 내주는지** 같이 적습니다. 공짜 절감은 하나뿐입니다
> - 자막 크기·말 속도·배경음 등 **시니어 시청자 규격** 점검
> - 업로드 한도(하루 6편)와 감사 절차를 미리 알려 드립니다
>
> **자동 업로드 프로그램이 아닙니다.** 사람이 승인한 것만 올라갑니다.
> 조회수나 수익을 약속하지 않습니다.
