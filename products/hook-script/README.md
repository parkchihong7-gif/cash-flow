# 후킹 대본 생성기 (hook-script)

롱폼·쇼츠·릴스 **대본 초안**을 포맷별로 만드는 CLI입니다.
첫 3초 후크 후보 10개를 먼저 뽑고, 그중 하나를 골라 본문을 씁니다.

> ## ⚠️ 이 도구는 초안 생성기입니다. 발행 전 사람 검수가 필수입니다.
>
> 나온 대본을 그대로 읽어 올리면 **유튜브 양산형(비진정성) 콘텐츠 정책**(2025.7)에
> 걸려 수익화에서 제외될 수 있습니다. 모든 대본에 함께 나오는 `checklist.md` 의
> "사람이 반드시 추가할 것" 3가지(개인 경험·실제 사례·시청자 의견)를 채우는 것이
> 이 도구를 제대로 쓰는 방법입니다. 그 3가지가 대본을 내 것으로 만듭니다.

## 설치

```bash
# 저장소 루트에서
pip install -r requirements.txt
cp .env.example .env      # ANTHROPIC_API_KEY 를 채웁니다
```

## 실행

```bash
cd products/hook-script

# 1) YAML 입력
python cli.py build script_input.yaml

# 2) 인자로 직접
python cli.py build --topic "주제" --format shorts --duration 30 --audience "사무직 3년차"

# 3) 후크를 바꿔서 다시 (1위가 마음에 안 들 때)
python cli.py build script_input.yaml --hook-index 3

# 4) 여러 주제를 한 번에
python cli.py build --batch topics.txt --format shorts --duration 30 --audience "사무직 3년차"

# 5) 비용 없이 형태만 보기
python cli.py build script_input.yaml --dry-run
```

| 옵션 | 설명 |
|---|---|
| `--hook-index N` | 쓸 후크 번호 (1부터, 기본 1 = 강도 1위) |
| `--chapters N` | 롱폼 챕터 수 (5~7, 기본 6) |
| `--batch FILE` | 주제가 한 줄에 하나씩 적힌 파일. 각 주제로 한 편씩 |
| `--model MODEL` | Claude 모델 ID |
| `--no-ai-label` | AI 생성물 표시를 끕니다 |
| `--dry-run` | Claude 를 부르지 않고 예시 콘텐츠로 (비용 없음) |
| `--out DIR` | 산출물 상위 폴더 (기본 `outputs/`) |

종료 코드: 0 정상 / 2 확인 필요(금지 문구·길이 보정 발생) / 1 오류.

## 입력

| 키 | 설명 |
|---|---|
| `topic` | 다룰 주제 |
| `format` | `long`(롱폼) / `shorts`(유튜브 쇼츠) / `reels`(인스타 릴스) |
| `duration_sec` | 쇼츠·릴스 15~60초, 롱폼 300~1200초 |
| `audience` | 누가 보는 영상인지 한 줄. **좁을수록 좋습니다** |
| `tone` | `정보형` / `스토리형` / `반전형` |
| `cta` | `구독` / `링크` / `댓글` |
| `evidence` | 참고할 사실 자료. **없으면 빈 리스트** |

`evidence` 를 비우면 대본에 수치·출처·통계를 **아예 넣지 않습니다.**
지어낸 통계 하나가 채널 신뢰를 통째로 무너뜨리기 때문입니다.

## 산출물 — `outputs/<주제>-<포맷>-<길이>s/`

| 파일 | 내용 |
|---|---|
| `script.md` | 타임코드 구간별 대본 |
| `hooks.json` | 첫 3초 후크 후보 10개. 멈춤 이유 태그와 예상 강도(1~5) |
| `titles.json` | 제목 후보 10개(40자 이내), 썸네일 문구 5개(12자 이내) |
| `checklist.md` | 양산형 회피 체크리스트 + 사람이 추가할 3가지 |
| `ai_label.txt` | 영상 설명란에 넣을 AI 사용 고지 문구 |

### 대본 구조

**쇼츠·릴스** — 길이에 비례해 구간을 나눕니다. 30초면 이렇게 됩니다.

```
[0~3초]   후크
[3~7초]   문제 제기
[7~13초]  핵심 포인트 1
[13~20초] 핵심 포인트 2
[20~26초] 핵심 포인트 3
[26~30초] CTA
```

**한 줄이 한 자막 단위이고 15자를 넘지 않습니다.** 화면에 한 번에 뜨는 글자이기
때문입니다. 넘으면 자동으로 의미 단위로 쪼개고 `checklist.md` 에 기록합니다.

**롱폼** — 후크(30초) → 약속(30초) → 챕터 5~7개 → 요약(60초) → CTA(30초).
각 챕터에 제목·핵심 문장·본문·예시·전환 문장이 들어가고 타임코드가 붙습니다.
600초면 챕터 6개가 각 75초씩 배정됩니다.

## 만들지 않는 기능

- **다른 채널·영상을 그대로 재현하는 기능은 없습니다.** "터진 영상 찾아서 따라 만들기"
  류 도구는 표절 논란으로 서비스가 종료된 전례가 있습니다. 이 도구는 주제와 자료로
  독자적인 구성을 만듭니다. `evidence` 는 사실 자료만 받습니다.
- 성과를 단정하는 표현은 자동으로 검사해 걸러냅니다.

## 어떻게 만드는가

```
후크 10개 → (하나 선택) → 본문 → 제목·썸네일 → 체크리스트
```

앞 단계 결과가 뒤 단계 프롬프트의 컨텍스트로 들어갑니다.
포맷별 규칙은 `prompts/format_shorts.md` 와 `prompts/format_long.md` 에 나뉘어 있고,
공통 규칙(멈춤 이유 8가지, 사실 조작 금지)은 `prompts/common.md` 에 있습니다.
카피 품질을 바꾸려면 이 파일들을 고치세요.

생성된 모든 텍스트는 두 가지 검사를 통과해야 합니다.

1. **금지 문구** — `shared/banned_phrases.py` 의 목록
2. **길이 제한** — 쇼츠 자막 15자, 제목 40자, 썸네일 12자

걸리면 해당 섹션만 최대 2회 다시 만들고, 그래도 남으면 기계적으로 보정한 뒤
`checklist.md` 에 경고로 남깁니다. 조용히 넘어가지 않습니다.

## 크몽 상세페이지 초안

### 대본 쓰는 시간을 줄이는 도구

영상 한 편을 올리기까지 가장 오래 걸리는 건 촬영이 아니라 대본입니다.
주제는 정했는데 첫 3초를 뭐라고 시작할지 몰라 며칠이 지나갑니다.

이 프로그램은 주제와 시청자를 적으면 **후크 후보 10개와 타임코드가 붙은 대본 초안**을
만들어 드립니다. 롱폼·쇼츠·릴스 각각의 구조에 맞춰서요.

**이런 분께 맞습니다**
- 주제는 계속 떠오르는데 대본 구조를 매번 새로 고민하는 분
- 쇼츠 자막을 몇 글자로 끊어야 할지 감이 없는 분
- 롱폼 챕터 구성과 전환 문장에서 막히는 분

**이런 분께는 맞지 않습니다**
- 대본 없이 즉흥으로 찍는 방식이 잘 맞는 분
- AI가 쓴 글을 그대로 올리고 싶은 분 — 이 도구는 사람 검수를 전제로 만들었습니다
- 터미널에서 명령어 한 줄을 실행하기 어려우신 분

**드리는 것**
- 타임코드 구간별 대본 (쇼츠는 자막 단위까지 끊어서)
- 첫 3초 후크 후보 10개 + 각각 어떤 심리 요인을 썼는지 태그
- 제목 10개, 썸네일 문구 5개
- 양산형 회피 체크리스트 (이 대본에 사람이 뭘 더해야 하는지 구체적으로)
- 설명란용 AI 고지 문구

**차별점**
- 후크마다 어떤 심리 요인을 조합했는지 태그로 남깁니다. 어떤 후크가 통했는지
  나중에 해석할 수 있습니다.
- 쇼츠 자막 15자 제한을 프로그램이 강제합니다. 넘으면 쪼개고 기록합니다.
- 참고 자료를 넣지 않으면 수치를 아예 만들지 않습니다. 없는 통계를 지어내지 않습니다.
- 다른 채널을 복제하는 기능이 없습니다. 표절 논란 리스크를 설계 단계에서 뺐습니다.
- 인공지능기본법(2026.1.22 시행) 표시 문구를 함께 만들어 드립니다.

**미리 알려드립니다**
- 산출물은 **초안**입니다. 그대로 찍지 마시고 체크리스트의 3가지를 채우세요.
- Claude API 키가 필요하며 사용료는 별도입니다 (1편에 수백 원 수준).
- 조회수와 구독자 증가는 주제·채널·시장에 따라 달라집니다. 이 도구는 대본 쓰는
  시간을 줄일 뿐이며 결과는 검증이 필요합니다.
