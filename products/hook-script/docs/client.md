# 후킹 대본 생성기 — 사용 설명서

> 구매해 주셔서 감사합니다.
> **컴퓨터를 잘 모르셔도 따라 하실 수 있게** 하나하나 적었습니다.
> 막히시면 7장을 보시고, 그래도 안 되면 판매자에게 문의해 주세요.

---

## 1장. 무엇을 받으셨나요

주제를 적으면 **영상 대본 초안**을 만들어 드리는 프로그램입니다.

### 만들어 주는 것 5가지

| 파일 | 무엇인가요 |
|---|---|
| `script.md` | 대본. 몇 초에 무슨 말을 할지 시간까지 적혀 있습니다 |
| `hooks.json` | 첫 3초에 쓸 문장 후보 10개 |
| `titles.json` | 영상 제목 10개 + 썸네일에 쓸 짧은 문구 5개 |
| `checklist.md` | **올리기 전에 직접 확인할 목록** (가장 중요합니다) |
| `ai_label.txt` | 설명란에 넣을 문구 |

### ⚠️ 먼저 알아두셔야 할 것

**이 프로그램이 만든 대본을 그대로 읽어서 올리면 안 됩니다.**

유튜브는 2025년 7월부터 '양산형 콘텐츠'를 수익화에서 제외합니다.
AI가 쓴 대본만으로 만든 영상이 여기에 걸릴 수 있습니다.

그래서 이 프로그램은 **`checklist.md` 에 "사장님이 직접 채워야 할 3가지"를
주제에 맞게 구체적으로 알려드립니다.** 그 3가지를 채우는 것이
이 대본을 내 영상으로 만드는 작업입니다. 어렵지 않습니다.

1. 본인이 겪은 일 한 가지
2. 실제 사례나 화면 캡처
3. 시청자가 실제로 한 질문

## 2장. 처음 준비 (한 번만)

### 2-1. 파이썬이 있는지 확인

**Windows**: 시작 메뉴에서 `cmd` 검색 → 명령 프롬프트 실행
**Mac**: `터미널` 앱 실행

그다음 아래를 치고 엔터:

```
python --version
```

`Python 3.11.0` 처럼 숫자가 나오면 됩니다 (3.11 이상 필요).

**"찾을 수 없습니다"가 나오면** https://www.python.org 에서 내려받아 설치하세요.
Windows 는 설치 첫 화면에서 **"Add Python to PATH" 를 꼭 체크**하셔야 합니다.

### 2-2. 부품 설치

받으신 폴더 안에서:

```
pip install -r requirements.txt
```

글자가 쭉 지나가다 멈추면 끝입니다.

### 2-3. AI 키 발급

이 프로그램은 Claude 라는 AI 를 씁니다. **키는 직접 발급받으셔야 합니다.**

1. https://console.anthropic.com 가입 (구글 계정 가능)
2. 왼쪽 **Settings → API Keys → Create Key**
3. `sk-ant-` 로 시작하는 긴 글자가 나옵니다.
   **창을 닫으면 다시 못 보니 메모장에 붙여두세요**
4. 왼쪽 **Billing** 에서 카드 등록 + **10달러 정도 충전**

> **💰 비용 안내**
>
> 대본 한 편에 **수백 원** 정도의 AI 사용료가 발생합니다.
> 10달러(약 1만 4천 원)면 수십 편은 만드실 수 있습니다.
>
> 이 돈은 **판매자가 아니라 AI 회사에 내는 것**입니다.
> 판매자는 이 금액을 받지 않습니다. 쓴 만큼만 차감됩니다.

### 2-4. 키 넣기

1. 폴더에서 `.env.example` 파일을 찾습니다
2. 복사해서 이름을 **`.env`** 로 바꿉니다 (앞에 점이 있습니다)
3. 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 아까 키를 붙여넣습니다
4. 저장

> ⚠️ 이 파일은 비밀번호와 같습니다. 누구에게도 보내지 마세요.

### 2-5. 관리 화면 켜기

```
python -m dashboard
```

브라우저가 열립니다. 안 열리면 주소창에 `http://127.0.0.1:8000` 입력.
끄실 때는 검은 창에서 `Ctrl` + `C`.

## 3장. 주제 적기

관리 화면에서 **후킹 대본 생성기 → 수정 → 입력 파일 편집**을 누릅니다.

```yaml
topic: "다룰 주제를 한 줄로"
format: shorts
duration_sec: 30
audience: "누가 보는 영상인지 한 줄로"
tone: 정보형
cta: 구독
evidence: []
```

### 하나씩 설명드리면

**`topic` (주제)**
질문이나 주장 형태가 좋습니다.
- 그냥 그런 예: `엑셀 팁`
- 좋은 예: `같은 프로그램을 쓰는데 왜 누구는 두 배 빠를까`

**`format` (포맷)** — 셋 중 하나를 그대로 적습니다.

| 적을 값 | 무엇 |
|---|---|
| `shorts` | 유튜브 쇼츠 |
| `reels` | 인스타그램 릴스 |
| `long` | 일반 가로 영상 (롱폼) |

**`duration_sec` (길이, 초 단위)**
- 쇼츠·릴스: **15 ~ 60** 사이
- 롱폼: **300 ~ 1200** 사이 (5분 ~ 20분)

범위를 벗어나면 오류가 납니다. 10분 영상이면 `600` 입니다.

**`audience` (시청자)** — **여기가 제일 중요합니다.**
좁게 쓸수록 좋은 대본이 나옵니다.
- 그냥 그런 예: `직장인`
- 좋은 예: `매일 같은 보고서를 만들고 프로그램을 바꿀 권한은 없는 사무직 3년차`

**`tone` (말투)** — 셋 중 하나

| 적을 값 | 언제 쓰나 |
|---|---|
| `정보형` | 방법을 알려주는 영상. 가장 무난합니다 |
| `스토리형` | 내 경험을 이야기하는 영상. **경험이 실제로 있을 때만** |
| `반전형` | "다들 이렇게 아는데 사실은" 형태 |

**`cta` (마지막에 요청할 행동)** — 하나만 고릅니다

| 적을 값 | 무엇 |
|---|---|
| `구독` | 구독과 알림 설정 |
| `링크` | 설명란 링크 클릭 |
| `댓글` | 댓글 유도 |

**`evidence` (참고 자료)**
숫자나 자료가 있으면 적고, **없으면 `[]` 로 비웁니다.**

```yaml
evidence: []
```

비워두면 대본에 숫자가 아예 안 들어갑니다. **이게 안전합니다.**
없는 통계를 넣으면 나중에 문제가 됩니다.

자료가 있으면 이렇게:

```yaml
evidence:
  - "내 채널 6월 쇼츠 12편 평균 조회수 3,200회 (유튜브 스튜디오)"
```

### 자주 하는 실수

- 길이를 범위 밖으로 씀 (쇼츠에 `120` 등)
- 포맷을 한글로 씀 → `shorts`, `reels`, `long` 영어 그대로
- 들여쓰기에 탭 키 사용 → **스페이스만** 쓰세요
- 목록 앞에 `- ` (하이픈 + 공백) 를 빠뜨림

## 4장. 만들기

### 4-1. 먼저 연습

관리 화면 **테스트** 탭 → **모의 실행 (비용 없음)**

돈이 들지 않고 몇 초면 끝납니다. **결과물 모양만** 보는 단계입니다.
나온 글은 예시라 내용은 의미가 없습니다.

### 4-2. 진짜 만들기

**실제 실행** 을 누릅니다. 1~3분 걸립니다. 화면이 멈춘 것 같아도 기다려 주세요.

### 4-3. 결과 보기

| 색 | 뜻 | 할 일 |
|---|---|---|
| 🟢 초록 | 잘 만들어졌습니다 | **산출물 보기** 클릭 |
| 🟡 노랑 | 만들어졌지만 확인할 게 있습니다 | `checklist.md` 의 표를 보세요 |
| 🔴 빨강 | 실패 | 7장 참고 |

## 5장. ⚠️ 올리기 전에 반드시

### 5-1. `checklist.md` 를 가장 먼저 엽니다

**대본보다 이걸 먼저 보세요.** 여기에 "직접 채워야 할 3가지"가
이번 주제에 맞게 구체적으로 적혀 있습니다. 예를 들면:

```
### 1. 개인 경험
- 넣을 위치: 문제 제기 (3~7초)
- 무엇을: 이 설정을 바꾸기 전에 실제로 몇 분을 썼는지
- 왜: 숫자가 본인 것이어야 시청자가 믿습니다
- 어떻게 구하나: 지난주 작업 기록을 확인하세요
```

시키는 대로 채우시면 됩니다. **이 3가지를 채우는 것이 이 프로그램을 쓰는 이유입니다.**

### 5-2. `[사람이 채울 곳]` 표시 지우기

대본 안에 이런 표시가 있습니다.

```
**예시** — [사람이 채울 곳: 본인이 쓰는 프로그램의 실제 설정 경로]
```

**이걸 그대로 두고 찍으면 안 됩니다.** 실제 내용으로 바꿔주세요.

### 5-3. 설명란에 고지 문구 넣기

`ai_label.txt` 파일을 열어 내용을 복사해서 영상 설명란에 붙여넣으세요.
2026년 1월 시행된 법에 따른 표시입니다.

그리고 **유튜브 업로드 화면에 '변경된 콘텐츠 또는 합성 콘텐츠' 라는 항목**이 있습니다.
목소리나 얼굴을 AI로 만드셨다면 사실대로 체크하세요.

### 5-4. 숫자 확인

`evidence` 를 비워두셨다면 대본에 숫자가 없어야 정상입니다.
혹시 숫자가 보이면 사실인지 꼭 확인하세요.

## 6장. 결과물 쓰는 법

### 6-1. 쇼츠·릴스 대본

```
## [0~3초] 후크
*화면: 얼굴 클로즈업*

- 3초 만에 끝납니다
- 이 설정 하나만
```

- `[0~3초]` — 이 구간을 몇 초에 찍을지
- `*화면: ...*` — 촬영·편집 참고
- `- ` 로 시작하는 줄 하나가 **자막 한 장**입니다

**한 줄이 15자를 넘지 않게 프로그램이 맞춰줍니다.** 화면에 한 번에 뜨는 글자라
길면 읽기 전에 넘어가기 때문입니다. 자막 프로그램에 그대로 옮기시면 됩니다.

### 6-2. 롱폼 대본

챕터마다 이런 것들이 있습니다.

- **핵심** — 이 챕터에서 시청자가 가져갈 문장 하나
- 본문 — 말할 내용
- **예시** — 구체적인 사례 (여기가 `[사람이 채울 곳]` 인 경우가 많습니다)
- *전환* — 다음 챕터로 넘어가는 말. **이걸 빠뜨리면 사람들이 나갑니다**

### 6-3. 후크 10개 활용

`hooks.json` 에 첫 3초 문장 후보 10개가 있습니다.
1번이 마음에 안 드시면 다른 번호로 다시 만들 수 있습니다.

관리 화면이 아니라 명령어로 하셔야 합니다:

```
python cli.py build script_input.yaml --hook-index 3
```

(3번 후크로 다시 만듭니다. 비용이 또 듭니다.)

### 6-4. 제목과 썸네일

`titles.json` 에 제목 10개, 썸네일 문구 5개가 있습니다.

**제목과 썸네일에 같은 말을 쓰지 마세요.** 같은 말을 두 번 보여주면 정보가 절반입니다.
제목이 "설정 3개로 10분 아끼기"면 썸네일은 "10분 → 1분" 처럼 다르게요.

## 7장. 안 될 때

| 화면에 이렇게 나오면 | 이렇게 하세요 |
|---|---|
| `duration_sec 은 15~60초여야 합니다` | 쇼츠·릴스는 15~60, 롱폼은 300~1200 |
| `ANTHROPIC_API_KEY 가 없습니다` | 2-4 를 다시 |
| `Claude API 오류 401` | 키가 잘못됐습니다. 콘솔에서 새로 발급 |
| `credit balance` 가 보임 | 충전 잔액이 없습니다. 콘솔 Billing 에서 충전 |
| `쿼터 초과` | 너무 자주 눌렀습니다. **1분 기다렸다가** 다시 |
| `입력이 올바르지 않습니다` | 어느 항목이 문제인지 메시지에 나옵니다. 3장 확인 |
| `ModuleNotFoundError` | 부품이 안 깔렸습니다. 2-2 를 다시 |
| 한글이 □□□ 로 깨짐 | 저장할 때 인코딩을 **UTF-8** 로 |
| 자막이 이상하게 끊김 | 프로그램이 15자에 맞추려고 자동으로 나눈 것입니다. 직접 고치셔도 됩니다 |

**그래도 안 되면** 화면 글자를 **그대로 복사**해서 판매자에게 보내주세요.

## 8장. 자주 묻는 것

**Q. 같은 주제로 여러 번 돌려도 되나요?**
네. 돌릴 때마다 조금씩 다르게 나옵니다. 마음에 드는 걸 고르세요. (매번 비용이 듭니다)

**Q. 여러 주제를 한 번에 만들 수 있나요?**
네. `topics.txt` 에 주제를 한 줄씩 적고:
```
python cli.py build --batch topics.txt --format shorts --duration 30 --audience "대상"
```
**먼저 1편으로 결과를 확인한 뒤 배치를 돌리세요.** 설정이 틀린 채로 10편을 만들면
비용이 그대로 나갑니다.

**Q. 다른 채널 영상을 넣으면 비슷하게 만들어 주나요?**
아니요. 그 기능은 일부러 넣지 않았습니다. 특정 영상을 따라 만드는 도구는
표절 문제로 서비스가 중단된 사례가 있습니다. 이 프로그램은 주제를 받아
독자적으로 구성을 만듭니다.

**Q. 대본대로 안 찍어도 되나요?**
네. 참고용 초안입니다. 말이 편한 대로 바꾸세요. 구조(몇 초에 무엇)만 지키셔도 충분합니다.

**Q. 조회수가 오르나요?**
이 도구는 **대본 쓰는 시간을 줄여주는 도구**입니다.
조회수는 주제·채널·시장에 따라 달라지며 이 도구가 보장하지 않습니다.

**Q. 인터넷이 필요한가요?**
네, AI 를 부르기 때문에 필요합니다. 모의 실행은 인터넷 없이도 됩니다.

## 마지막으로

세 가지만 기억하시면 됩니다.

1. **`audience` 를 좁게 쓴다** — 대본 품질이 여기서 갈립니다
2. **`checklist.md` 의 3가지를 반드시 채운다** — 이게 핵심 작업입니다
3. **`[사람이 채울 곳]` 표시를 그대로 두고 찍지 않는다**
