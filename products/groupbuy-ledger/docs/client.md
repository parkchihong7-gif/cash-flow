# 고객용 매뉴얼 — 공구 정산 장부

공동구매 주문·정산·재고를 한 파일에서 보는 엑셀 장부입니다.
엑셀을 많이 다뤄 보지 않으셨어도 따라올 수 있게 썼습니다.

---

## 1장. 이 장부가 해 주는 것

주문 한 줄을 적으면 **나머지가 저절로 따라옵니다.**

```
주문 한 줄 입력
   ↓
재고가 줄어들고
정산이 다시 계산되고
발송 목록에 올라가고
대시보드 그래프가 바뀝니다
```

**직접 하셔야 하는 것은 두 가지뿐입니다.**

1. 주문을 적는 것 (또는 CSV 로 한 번에 넣는 것)
2. 발송한 뒤 배송상태를 바꾸고 송장번호를 적는 것

### 해 주지 않는 것

- 결제·환불 처리 — 장부에 적을 뿐, 실제 돈이 오가지는 않습니다
- 주문을 자동으로 확정하거나 발송 처리하기 — 상태를 바꾸는 것은 언제나 사람입니다
- 정산 확정 — 마지막에 통장 잔액과 맞춰 보시는 것은 직접 하셔야 합니다

마지막 항목이 중요합니다. 장부의 순이익과 실제 통장 증감이 다르면,
대개 **배송비나 수수료율 설정이 실제와 다른 것**입니다. 9장에서 다룹니다.

---

## 2장. 직접 만들어 보실 분께 — 관리 화면 쓰는 법

장부 파일을 **받기만** 하신 분은 이 장을 건너뛰고 3장으로 가세요.
프로그램을 구매해 **직접 만들어 쓰시는 분**만 보시면 됩니다.

브라우저에서 관리 화면을 열고 왼쪽 목록에서 **7번 공구 정산 엑셀 자동 생성기**를 고릅니다.

| 탭 | 여기서 하는 일 |
|---|---|
| **열람** | 이용 순서·FAQ·이 매뉴얼 |
| **수정** | 상품 목록(`products.csv`)과 컬럼 매핑(`mapping.yaml`) |
| **테스트** | 모의 실행 / 실제 실행 |
| **회원관리** | 고객에게 납품하실 때 쓰는 목록 |
| **설정** | 기본 수수료율, AI 표시, 쓰는 모델 |

### 순서

1. **수정** 탭에서 `products.csv` 를 열어 파실 상품을 적습니다.

   ```csv
   상품코드,옵션,공급가,판매가,초기재고
   COFFEE-01,에티오피아 200g,9000,15000,60
   ```

   **상품코드는 주문 폼에서 쓰시는 이름과 맞추는 것이 가장 중요합니다.**
   한 글자만 달라도 재고가 자동으로 빠지지 않습니다.

2. **테스트** 탭에서 **모의 실행**을 먼저 누르세요. 비용이 들지 않습니다.
   샘플 주문으로 장부가 어떻게 생겼는지 볼 수 있습니다.

3. 마음에 들면 **실제 실행**을 누릅니다.

4. 만들어진 엑셀을 내려받아 3장부터 이어갑니다.

---

## 3장. 시트 여섯 장 둘러보기

파일을 열면 아래에 탭이 여섯 개 있습니다.

| 시트 | 무엇 | 직접 고치나요 |
|---|---|---|
| **설정** | 공구명·기간·수수료율·배송비 | **네** — 처음에 한 번 |
| **상품** | 파는 상품과 재고 | **네** — 상품이 늘면 |
| **주문** | 주문 한 줄씩 | **네** — 매일 |
| **정산** | 얼마 남았는지 | 아니요 — 보기만 |
| **배송** | 오늘 보낼 목록 | 아니요 — 복사만 |
| **대시보드** | 그래프와 경고 | 아니요 — 보기만 |

**뒤의 세 장은 보기만 하는 시트입니다.** 손으로 고치면 수식이 지워져서
다음부터 값이 안 바뀝니다.

### 회색 머리글 칸은 지우지 마세요

상품 시트의 `현재재고`부터 오른쪽, 주문 시트의 `발송순번`부터 오른쪽은
머리글이 **회색**입니다. 자동 계산용 칸입니다.

보기 싫으시면 **열 번호에서 오른쪽 클릭 → 숨기기** 를 하세요.
**지우면** 배송 시트와 대시보드가 빈칸이 됩니다.

---

## 4장. 처음 한 번 — 설정 시트

맨 앞 시트입니다. **여기 값을 바꾸면 정산이 전부 다시 계산됩니다.**

| 칸 | 어떻게 정하나요 |
|---|---|
| 공구명 | 회차를 알아볼 이름 |
| 시작일 / 종료일 | 대시보드의 일별 매출표가 이 기간으로 만들어집니다 |
| 기본 공급가 / 판매가 | 상품 시트에서 상품마다 따로 정하므로, 여기는 대표값입니다 |
| **배송비(건당)** | 택배비. **취소·환불을 뺀 건수만큼** 곱합니다 |
| **결제수수료율** | 쓰시는 결제 수단의 수수료. 보통 2~3.5% |
| **플랫폼수수료율** | 자체 폼으로 받으시면 **0** |
| 부가세 적용 | '예' = 받으신 돈에 부가세가 포함되어 있다는 뜻 |
| 부가세율 | 일반과세자 10%. 간이과세·면세면 **0** |

연한 회색 칸(기간, 기본 마진율)은 **자동 계산**입니다. 고치지 마세요.

### 수수료율은 정확히 넣으세요

가장 자주 틀리는 칸입니다. `3.2%` 를 넣으시려면 `0.032` 또는 `3.2%` 로 쓰세요.
`3.2` 라고 쓰면 **320%** 가 되어 순이익이 크게 마이너스로 나옵니다.

## 5장. 주문 넣기

### 방법 ① CSV 로 한 번에 (권장)

구글폼이나 쇼핑몰에서 주문을 엑셀·CSV 로 내려받아 넘겨 주시면, 한 번에 들어갑니다.
`타임스탬프`·`구매자명`·`주문상태` 처럼 컬럼 이름이 달라도 알아봅니다.

**같은 파일을 두 번 넣어도 주문이 두 배가 되지 않습니다.** 주문번호로 걸러냅니다.
그래서 "새 주문만 골라내기" 를 하지 않으셔도 됩니다. 매번 전체를 넣으시면 됩니다.

### 방법 ② 직접 치기

주문 시트에 한 줄씩 적습니다. 왼쪽부터 순서대로입니다.

| 칸 | 넣는 법 |
|---|---|
| 주문일 | `2026-09-05` 처럼 |
| 주문번호 | **겹치지 않게.** 아무 규칙이나 좋습니다 (`0905-01`) |
| 고객명 / 연락처 | 연락처는 `010-1234-5678` 그대로 |
| **상품코드** | **직접 치지 말고 목록에서 고르세요** (아래 참고) |
| 옵션 | 상품 시트의 옵션과 **똑같이** |
| 수량 / 결제금액 | 숫자만 |
| 결제수단 | 목록에서 고르기 |
| **배송상태** | **목록에서 고르기** — 대기/발송/완료/취소/환불 |
| 송장번호 / 메모 / 주소 | 있으면 |

### 드롭다운 쓰기

상품코드·결제수단·배송상태 칸을 클릭하면 **오른쪽에 작은 화살표**가 뜹니다.
누르면 고를 수 있는 목록이 나옵니다.

**꼭 목록에서 고르세요.** `배송중` 이라고 직접 치면 장부가 못 알아듣고,
발송 목록과 재고 계산에서 빠집니다. 다섯 가지뿐입니다.

| 상태 | 언제 |
|---|---|
| **대기** | 결제는 됐고 아직 안 보냄 → **배송 시트에 올라갑니다** |
| **발송** | 택배를 보냄 |
| **완료** | 고객이 받음 |
| **취소** | 보내기 전에 취소 → 매출에서 빠지고 **재고가 돌아옵니다** |
| **환불** | 보낸 뒤 환불 → 매출에서 빠지고 **재고가 돌아옵니다** |

취소·환불로 바꾸면 그 줄이 **회색에 취소선**으로 바뀝니다. 한눈에 보입니다.

## 6장. 발송하기

### ① 배송 시트를 엽니다

배송상태가 **대기**인 주문만 자동으로 모여 있습니다. 줄 순서는 택배사 접수 양식과 같습니다.

```
받는분성명 · 받는분전화번호 · 받는분주소 · 품목명 · 수량 · 배송메시지 · 주문번호 · 송장번호
```

### ② 복사해서 택배사에 넣습니다

내용이 있는 줄만 드래그해서 복사(Ctrl+C) 하고, 택배사 접수 화면에 붙여넣으세요.
아래 빈 줄은 복사하지 마세요.

택배사가 CSV 파일을 요구한다면 **손으로 저장하지 마세요.**
리포트를 만들 때 `발송목록_<회차>.csv` 가 같이 나옵니다. 내용이 같고, 그대로 올리시면 됩니다.

엑셀에서 직접 CSV 로 저장하실 수도 있지만(**파일 → 다른 이름으로 저장 → CSV**),
CSV 는 **시트 한 장만** 저장하기 때문에 원본 xlsx 를 덮어쓰면 다른 시트가 전부 날아갑니다.
같이 나온 CSV 파일을 쓰시는 편이 안전합니다.

### ③ 보낸 뒤 상태를 바꿉니다

주문 시트로 돌아와서 그 주문의 배송상태를 **발송**으로 바꾸고 송장번호를 적습니다.
바꾸는 즉시 배송 시트에서 그 줄이 사라집니다.

## 7장. 정산 보기

정산 시트가 위에서 아래로 이렇게 내려갑니다.

```
총매출              들어온 돈 전부 (취소·환불 포함)
− 취소·환불 차감     되돌려준 돈
= 순매출
− 결제수수료
− 플랫폼수수료
− 공급원가          실제로 나간 상품 원가
− 배송비
− 부가세
= 순이익            ← 이게 실제로 남은 돈
  순마진율          순이익 ÷ 순매출
```

아래쪽에는 **상품별 실적표**가 있습니다. 어느 옵션이 얼마나 팔렸고 얼마를 남겼는지,
순위까지 나옵니다.

### 이 숫자들이 뜻하는 것

- **순마진율이 20% 라면**, 10만 원을 팔았을 때 2만 원이 남는다는 뜻입니다.
- **취소·환불 건수가 많다면** 상세페이지와 실물의 차이, 배송 지연, 옵션 설명 부족을 의심해 보세요.
- **평균 객단가가 낮다면** 묶음 구성을 생각해 볼 수 있습니다.

다만 이건 숫자가 주는 힌트일 뿐입니다. 한 회차 결과만으로 판단하기는 이릅니다.

## 8장. 대시보드

세 가지가 있습니다.

1. **일별 매출 추이** (꺾은선) — 어느 날 주문이 몰리는지. 다음 회차 오픈 요일을 정할 때 참고
2. **상품별 이익 순위** (막대) — 매출이 아니라 **이익** 기준입니다. 많이 팔려도 이익이 적을 수 있습니다
3. **재고 경고** — 현재재고가 **10개 미만**인 옵션. 빨갛게 표시됩니다

**재고 경고가 뜨면 두 가지 중 하나를 하세요.**
추가 발주를 넣거나, 상세페이지에 품절 표시를 해 두세요.
그냥 두면 재고 없는 주문을 받게 됩니다.

---

## 9장. 마지막 확인 — 통장과 맞춰 보기

**이것만은 꼭 하세요.** 장부의 순이익과 실제 통장 증감을 맞춰 봅니다.

차이가 나면 대개 셋 중 하나입니다.

| 증상 | 원인 |
|---|---|
| 장부가 실제보다 **많게** 나옴 | 결제수수료율이 실제보다 낮게 설정됨 |
| 장부가 실제보다 **많게** 나옴 | 배송비를 실제보다 싸게 잡음 (제주·도서 추가비) |
| 장부가 실제보다 **적게** 나옴 | 취소된 주문의 상태를 아직 안 바꿈 |

한 번 맞춰 놓으면 다음 회차부터는 설정이 그대로 쓰이므로 다시 틀어질 일이 적습니다.

## 10장. 정산 리포트

회차가 끝나면 마크다운 파일로 정산 요약이 나옵니다.

- 정산 요약 / 주문 현황 / 상품별 실적
- 재고 경고, 발송 대기
- **코멘트 세 줄** — 가장 잘 팔린 옵션, 환불률, 다음 회차 제안
- 다음에 할 일

### 코멘트는 어떻게 만들어지나요

정산 숫자만 보고 AI 가 씁니다. **엑셀이 계산한 숫자만 쓰도록 막아 두었습니다.**
없는 숫자를 만들어 쓰면 프로그램이 다시 시키고, 그래도 안 되면 그 줄을 빼고
뺐다는 사실을 리포트에 적습니다.

AI 에게 보내는 것은 **집계된 숫자뿐입니다.** 고객 이름·연락처·주소는 보내지 않습니다.

### 리포트는 초안입니다

이 리포트의 숫자도, 코멘트도 **초안**입니다. 확정된 정산서가 아닙니다.

- **숫자** — 주문 시트에 적힌 대로 계산한 것입니다. 상태를 아직 안 바꾼 취소 건이 있으면
  그만큼 틀립니다. 9장대로 통장과 맞춰 보신 뒤에야 확정입니다.
- **코멘트** — 숫자만 보고 쓴 것이라 **현장 사정을 모릅니다.** 왜 그 옵션이 잘 나갔는지,
  왜 환불이 있었는지는 사장님만 아십니다.

그래서 순서가 이렇습니다.

```
장부가 초안을 만든다 → 사람이 확인하고 고친다 → 그때 확정된다
```

이 순서를 건너뛰지 마세요. 초안을 그대로 세무 자료나 정산 근거로 쓰시면 안 됩니다.

## 11장. 비용과 API 이야기

받으신 엑셀 장부를 쓰는 데는 **아무 비용도 들지 않습니다.**
파일을 열고 주문을 적고 정산을 보는 것은 엑셀만 있으면 됩니다.
인터넷에 연결되어 있지 않아도 됩니다.

비용이 드는 곳은 **정산 리포트의 코멘트 세 줄**뿐입니다. 이 부분만 AI 가 씁니다.

| 하는 일 | API 키 필요 | 비용 |
|---|---|---|
| 장부 만들기 | 아니요 | 없음 |
| 주문 CSV 넣기 | 아니요 | 없음 |
| 정산·재고·발송 목록 보기 | 아니요 | 없음 |
| 리포트의 코멘트 세 줄 | **네** | 한 번에 수십 원 수준 |

### API 키란 무엇인가요

AI 서비스를 쓸 때 "이 사람이 쓴 만큼 요금을 매긴다" 를 알아보게 하는 긴 글자입니다.
비밀번호와 같다고 보시면 됩니다.

직접 만들어 쓰시는 분은 `.env` 라는 파일에 이 키를 넣어 두십니다.
**이 파일은 절대 남에게 보내거나 공유 폴더에 두지 마세요.** 남이 쓰면 요금이 나갑니다.

장부 파일을 만들어 드린 분께 받기만 하셨다면, **API 키는 없어도 됩니다.**
코멘트 없이 정산 숫자만 보셔도 장부의 쓸모는 그대로입니다.

### AI 에게 무엇이 가나요

코멘트를 만들 때 AI 에게 보내는 것은 **집계된 숫자뿐입니다.**
순매출·순이익·환불률·옵션별 판매수량 같은 것들입니다.

**고객 이름·연락처·주소는 보내지 않습니다.** 주문 시트의 개인정보는
엑셀 파일 안에만 있고, 어디로도 나가지 않습니다.

## 12장. 자주 묻는 질문

**Q. 재고가 안 줄어듭니다.**
주문 시트의 상품코드·옵션이 상품 시트와 **한 글자라도** 다르면 연결되지 않습니다.
`에티오피아 200g` 과 `에티오피아200g` 은 다릅니다. 드롭다운에서 고르면 이 실수를 막습니다.

**Q. 정산이 전부 0원입니다.**
주문 시트가 비어 있거나, 결제금액 칸에 숫자가 아닌 글자가 들어갔는지 보세요.

**Q. 순이익이 마이너스로 크게 나옵니다.**
설정 시트의 수수료율을 확인하세요. `3.2` 라고 쓰면 320% 가 됩니다. `0.032` 로 쓰세요.

**Q. 배송 시트가 비어 있습니다.**
배송상태가 **대기**인 주문이 없는 것입니다. 전부 보내셨다면 정상입니다.

**Q. 취소된 주문의 재고는 돌아오나요?**
네. 배송상태를 **취소** 또는 **환불**로 바꾸면 그 수량이 재고로 돌아옵니다.
다만 환불은 실물이 돌아왔을 때만 재고로 치는 것이 맞으니, 실물이 안 돌아왔으면
메모에 적어 두고 재고를 따로 조정하세요.

**Q. 상품을 추가하고 싶어요.**
상품 시트의 빈 줄에 적으면 됩니다. 아래에 빈 줄이 20개 준비되어 있습니다.
회색 칸은 건드리지 마세요. 자동으로 채워집니다.

**Q. 주문이 100건이 넘어갑니다.**
주문 시트에도 빈 줄이 100개 준비되어 있습니다. 모자라면 만들어 주신 분께 말씀하세요.
줄을 직접 추가하면 회색 칸의 수식이 따라오지 않습니다.

**Q. 구글시트에서 열어도 되나요?**
열립니다. 수식도 대부분 그대로 돕니다. 다만 **차트 모양이 조금 달라지고**,
드롭다운이 다르게 보일 수 있습니다. 엑셀에서 쓰시는 편이 원래 모습입니다.

**Q. 다음 회차는 어떻게 하나요?**
새 장부를 만드는 편이 깔끔합니다. 회차별로 파일이 나뉘어 있어야 나중에 비교하기 좋습니다.
상품과 재고는 이어서 쓰고 싶으시면 만들어 주신 분께 말씀하세요.

**Q. 파일을 실수로 망가뜨렸어요.**
받으신 원본을 보관해 두셨다면 그걸로 다시 시작하시면 됩니다.
**주문 CSV 만 있으면 언제든 처음부터 다시 만들 수 있습니다.**

## 13장. 안전하게 쓰기

- **원본 파일을 따로 보관하세요.** 작업용 사본을 만들어 쓰시면 마음이 편합니다.
- **주문 시트에는 고객 개인정보가 들어 있습니다.** 이름·연락처·주소입니다.
  파일을 아무에게나 보내지 마시고, 공유 폴더에 두실 때는 접근 권한을 확인하세요.
- **회차가 끝나고 한참 지난 파일은 정리하세요.** 필요 없어진 개인정보를 계속 들고 있을
  이유가 없습니다.
- **CSV 로 저장할 때 조심하세요.** CSV 는 시트 한 장만 저장합니다.
  원본 xlsx 를 덮어쓰지 마세요.
- **자동으로 나가는 것은 없습니다.** 이 장부는 계산만 하고, 어디로도 연락을 보내지 않습니다.
