# maim 화면을 대시보드 디자인으로

`https://maim-1048530680370.us-central1.run.app/` 의 겉모습을 통합 관리자
대시보드와 같게 맞춘 것입니다. **여기 있는 것은 사본**입니다 — 실제로
돌아가는 곳은 다른 저장소(`parkchihong7-gif/maim`)입니다.

## 왜 여기에 두나

maim 은 저장소가 따로 있고, 지금 이 작업 자리에서는 그쪽에 **글을 쓸 권한이
없습니다**(읽기만 됩니다). 그래서 고친 파일을 여기에 두고, 사장님이 옮겨
붙이시게 했습니다. 권한이 열리면 이 폴더는 지워도 됩니다.

## 무엇을 바꿨나

바꾼 것은 `src/web/public/style.css` **한 파일뿐**입니다. `index.html` 과
`app.js` 는 손대지 않았습니다 — 그 두 파일에는 색이 한 군데도 박혀 있지
않아서, 색판만 갈면 화면 전체가 따라옵니다.

| | 전 | 후 |
|---|---|---|
| 바탕 | 어두운 남색 `#13151c` | 밝은 회색 `#f7f8fa` |
| 강조색 | 인디고 `#6366f1` | 대시보드 파랑 `#1f5eff` |
| 글꼴 | Segoe UI · 맑은 고딕 | 대시보드와 같은 묶음 |
| 카드 | 그림자로 띄움 | 테두리만 (대시보드와 같게) |
| 버튼 | 그러데이션 | 한 가지 색 |
| 고르는 칸 | 꾸밈 없음 (브라우저 기본) | 적는 칸과 같은 모양 |

**변수 이름은 그대로 뒀습니다.** `--gold` 는 이제 금색이 아니라 파랑이지만,
이름을 고치면 1,100줄을 다 건드려야 하고 그만큼 잘못 건드릴 자리가 늘어납니다.
maim 이 앞서 골드 → 인디고로 바꿀 때도 같은 방법을 썼습니다.

밝은 바탕에서 새로 필요해진 것이 하나 있습니다. 어두운 화면에서는 "더 밝은
면"이 떠 보였는데, 밝은 화면에서는 반대로 "더 눌린 면"이 들어가 보입니다.
그래서 마우스 올린 면을 `--bg-sunk` 로 따로 뒀습니다 — 안 그러면 흰 위에
흰이 되어 아무것도 안 보입니다.

## 옮겨 붙이는 법

```bash
git clone https://github.com/parkchihong7-gif/maim.git
cd maim
git checkout claude/great-brown-j376u0
```

그 다음 둘 중 **한 가지**만 하시면 됩니다.

**가) 파일을 덮어쓰기** — 쉬운 쪽

`style.css` 를 `maim/src/web/public/style.css` 자리에 덮어씁니다.

**나) 기운 조각 적용하기** — 그 사이 maim 쪽이 바뀌었을 때

```bash
git apply /경로/style.css.patch
```

어느 쪽이든 마지막은 같습니다.

```bash
git add src/web/public/style.css
git commit -m "화면 색을 통합 관리자 대시보드에 맞춤"
git push
```

maim 은 Cloud Run 의 "저장소에서 계속 배포" 가 켜져 있으면 **밀어 넣는 것만으로
새 화면이 올라갑니다.** 안 켜져 있으면 maim 저장소 README 의 배포 명령을 한 번
돌려 주세요.

## 확인할 곳

올린 뒤 이 다섯 군데를 눈으로 보세요. 밝은 바탕에서 어긋나기 쉬운 자리입니다.

1. 왼쪽 메뉴에 마우스를 올렸을 때 — **회색 면이 보여야** 합니다
2. 지금 보고 있는 메뉴 — 연한 파랑 바탕에 파란 글씨
3. 관리자 설정의 «2단계 — 주제 분야» 고르는 칸 — 테두리가 적는 칸과 같은 색
4. 포스팅 카드에 마우스를 올렸을 때 — 테두리가 파랗게
5. [저장] 같은 파란 버튼 — 그러데이션 없이 한 가지 색
