# 네이버 블로그 초안 생성기 — 사용 설명서

---

## 1. 이 프로그램이 해 드리는 것

1. 쓰려는 키워드로 **이미 몇 건이 쓰였는지** 보여 드립니다
2. 소제목을 나눈 **초안**을 만들어 드립니다
3. 협찬·제휴 글이면 **대가성 문구**를 넣어 드립니다
4. 올리기 전에 **탈이 날 만한 것**을 검사해 드립니다

마지막으로 복사해서 네이버 블로그에 붙이시면 됩니다.

---

## 2. 자동으로 올려 드리지 않습니다

### 왜

네이버는 **블로그에 글을 쓰는 기능을 프로그램에 열어 주지 않습니다.**
그래서 자동으로 올린다는 프로그램들은 전부 다른 방법을 씁니다.
**사장님 네이버 아이디와 비밀번호를 프로그램에 넣고**, 사람이 하는 것처럼
화면을 조작하는 방식입니다.

이건 네이버 약관 위반이라 **계정이 정지될 수 있습니다.** 블로그가 통째로
날아가는 것입니다. 그래서 저희는 그 방식을 쓰지 않습니다.

### 그리고 사실 이게 낫습니다

네이버 검색은 **직접 쓴 글인지**를 봅니다. 기계로 찍어낸 글은 아무리 많이
올려도 검색에 안 잡힙니다. 붙여넣기 전에 한 번 읽고 고치는 그 과정이
사실은 가장 중요한 일입니다.

---

## 3. 빈칸을 일부러 남깁니다

초안에는 이런 자리가 있습니다.

```
[직접 겪은 일을 여기에 쓰세요]
```

**여기를 채우지 않으면 검사에서 막힙니다.** 그냥 지우기만 해도 막힙니다.

귀찮게 느껴지실 수 있는데, 이게 이 프로그램의 핵심입니다.
남들과 똑같은 일반론만 있는 글은 검색에 안 올라갑니다.
**사장님만 쓸 수 있는 한두 문단**이 있어야 합니다.

두세 줄이면 충분합니다.

---

## 4. 준비

### 컴퓨터

집에 있는 보통 컴퓨터면 됩니다.

### 비용

| 무엇 | 비용 |
|---|---|
| 네이버 검색 API | **무료** (하루 25,000회) |
| 데이터랩 | **무료** |
| 초안 쓰기(선택) | 한 편에 100~200원 |

**네이버 키는 무료이고 5분이면 받습니다.** 심사도 없습니다.

### 네이버 키 받는 법 (5분)

1. `developers.naver.com` 에 들어가 로그인
2. **애플리케이션 등록**
3. 사용 API 에서 **검색**과 **데이터랩(검색어 트렌드)** 을 고릅니다
4. 나오는 **Client ID** 와 **Client Secret** 을 `.env` 파일에 넣습니다

### 키 없이 먼저 보시려면

```
python cli.py demand --fixture
python cli.py draft --dry-run
```

샘플 자료로 전체 흐름이 그대로 돕니다.

---

## 5. 쓰는 순서

### 5-1. 키워드 수요 보기

`keywords.txt` 에 볼 키워드를 한 줄에 하나씩 적으시고:

```
python cli.py demand
```

| 나오는 것 | 뜻 |
|---|---|
| 이미 쓰인 글 | 그 키워드로 네이버에 있는 블로그 글 수 |
| 경쟁 | 글 수로 본 붐비는 정도 |
| 흐름 | 검색이 오르는 중인지 |

**붐빈다고 꼭 피하실 것은 없습니다.** 각도가 다르면 자리가 있습니다.
오히려 **너무 한산한 키워드를 조심하세요.** 경쟁이 없는 게 아니라
찾는 사람이 없는 것일 수 있습니다.

### 5-2. 초안 만들기

`request.yaml` 을 메모장으로 열어 고치시면 됩니다.

```
topic: 전세 계약할 때 확인할 것
keyword: 전세 계약 주의사항
audience: 처음 전세를 구하는 사회 초년생
sponsor_kind: none        대가를 받으셨다면 여기를 바꾸세요
```

그다음:

```
python cli.py draft --input request.yaml
```

`outputs` 폴더에 초안이 생깁니다.

### 5-3. 빈칸 채우기

메모장으로 열어 `[직접 겪은 일을 여기에 쓰세요]` 를 지우고 직접 쓰세요.

### 5-4. 검사

```
python cli.py review --input outputs/draft_2026-09-18.md
```

| 표시 | 뜻 |
|---|---|
| ✗ | **고쳐야 합니다.** 그냥 올리시면 탈이 납니다 |
| ⚠ | 보시는 게 좋습니다 |
| · | 참고 |

✗ 가 하나도 없으면 올리셔도 됩니다.

### 5-5. 붙여넣기

파일 내용을 복사해서 네이버 블로그 글쓰기에 붙이시면 됩니다.
소제목(`##` 로 시작하는 줄)은 네이버 편집기에서 **제목 스타일**로 바꿔 주세요.

## 6. 협찬·제휴 글이라면

### 반드시 문구를 넣으셔야 합니다

원고료를 받으셨거나, 제품을 무상으로 받으셨거나, 제휴 링크를 다셨다면
**법으로 정해진 문구**를 넣으셔야 합니다.

`request.yaml` 에서:

```
sponsor_kind: sponsored     원고료를 받은 경우
sponsor_name: OO상사
```

그러면 초안 **맨 위**에 문구가 자동으로 들어갑니다.

**문구 없이는 파일이 아예 안 만들어집니다.** 일부러 그렇게 했습니다.

### 넣는 위치가 더 중요합니다

| 이렇게 하면 안 됩니다 | 왜 |
|---|---|
| 맨 아래에 작게 | 표시한 것으로 안 봅니다 |
| '더보기' 안에 | 같은 이유 |
| 해시태그 사이에 | 같은 이유 |
| "체험단입니다" 만 | 무엇을 받았는지가 없습니다 |
| 회색 작은 글씨 | 본문과 같은 크기·색이어야 합니다 |

문구만 따로 보시려면:

```
python cli.py disclosure --kind sponsored --name OO상사
```

---

## 7. 초안은 초안입니다

인공지능이 쓴 글은 **초안**입니다. 그대로 올리시면 안 됩니다.

**소리 내어 한 번 읽어 보세요.** 눈으로 읽으면 안 걸리던 어색한 문장이
바로 걸립니다.

인공지능이 만든 산출물에는 그렇게 표시하는 것이 법으로 정해져 있습니다
(인공지능기본법).

## 8. 자주 묻는 것

**Q. 자동으로 올려 주는 곳도 있던데요**
사장님 비밀번호를 프로그램에 넣는 방식입니다. 계정이 정지될 수 있습니다.

**Q. 월 검색량을 보고 싶습니다**
네이버가 공개 API 로 주지 않습니다. 검색광고 API 가 있는데 광고주 가입이
따로 필요합니다. 필요하시면 파신 분께 문의하세요.

**Q. 빈칸을 안 채우면 안 되나요**
검사에서 막힙니다. 두세 줄이면 충분합니다.

**Q. 상위 노출이 되나요**
약속드릴 수 없습니다. 검색 로직은 공개돼 있지 않습니다.

**Q. 하루에 몇 편까지 되나요**
프로그램은 제한이 없습니다. 다만 **하루 여러 편을 몰아 올리는 것은 권하지
않습니다.** 꾸준히 한 편씩이 낫습니다.

## 9. 관리 화면에서

통합 관리자 대시보드 3번을 여시면 버튼으로 하실 수 있습니다.

| 탭 | 하는 일 |
|---|---|
| 열람 | 이용 순서와 자주 묻는 것 |
| 수정 | 초안 프롬프트와 대가성 문구 고치기 |
| 테스트 | 버튼 하나로 샘플 초안 만들기 (비용 0원) |
| 권한·환경 | 네이버 키가 들어갔는지 확인 |

**권한·환경 탭**에서 네이버 키가 '넣었습니다' 로 나오는지 보세요.
'아직 안 넣었습니다' 면 수요 조회가 안 됩니다.

---

## 10. 막히면

- 키가 틀렸다고 나오면 → `.env` 의 Client ID/Secret 을 다시 보세요
- 권한이 없다고 나오면 → 개발자센터 앱 설정에서 **검색**과 **데이터랩**을
  둘 다 추가하셨는지 보세요
- 대가성 문구가 없다고 막히면 → `request.yaml` 의 `sponsor_kind` 를 보세요
- 그 밖에는 `--fixture` 나 `--dry-run` 으로 한 번 돌려 보세요.
  그건 되는데 실제가 안 되면 키 문제입니다

## 11. 실제로 이렇게 쓰시면 됩니다

### 한 주에 한 번, 30분

| 순서 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 1 | 이번 주에 쓸 키워드 3개를 `keywords.txt` 에 적고 수요 보기 | 3분 |
| 2 | 그중 하나를 골라 `request.yaml` 채우기 | 5분 |
| 3 | 초안 만들기 | 1분 |
| 4 | **빈칸 채우기** | 15분 |
| 5 | 검사하고 붙여넣기 | 5분 |

4번이 가장 오래 걸립니다. 그게 맞습니다. **거기가 이 글에서 유일하게
사장님만 쓸 수 있는 부분**이기 때문입니다.

### 빈칸에 무엇을 쓰나

막막하시면 이 세 가지 중 하나를 쓰세요.

1. **직접 겪은 일** — "작년에 계약할 때 이걸 놓쳐서 고생했습니다"
2. **손님한테 들은 말** — "상담하다 보면 이걸 제일 많이 물어보십니다"
3. **숫자** — "저희 사무소에서 작년에 처리한 건 중 절반이 이 경우였습니다"

셋 다 남이 못 쓰는 내용입니다. 그게 핵심입니다.

## 12. 키워드를 고르는 요령

### 붐비는 키워드도 각도를 바꾸면 됩니다

"전세 계약 주의사항" 은 백만 건이 넘습니다. 그런데

- "인천 구축 빌라 전세 계약 주의사항"
- "사회 초년생 첫 전세 계약 주의사항"
- "전세 계약 주의사항 중개사가 말 안 해 주는 것"

이렇게 좁히면 다릅니다. **사장님이 실제로 아는 각도**로 좁히세요.

### 흐름을 같이 보세요

글 수가 적어도 '내려가는 중' 이면 지는 주제입니다.
글 수가 좀 있어도 '오르는 중' 이면 지금 들어갈 만합니다.

---

## 13. 파일이 어디 있나

| 파일 | 무엇 |
|---|---|
| `keywords.txt` | 수요를 볼 키워드 목록 |
| `request.yaml` | 초안 요청. 글마다 고치시면 됩니다 |
| `outputs/` | 만들어진 초안 |
| `.env` | 네이버 키. **절대 남에게 보내지 마세요** |

`.env` 는 비밀번호와 같습니다. 화면 공유하실 때도 조심하세요.
