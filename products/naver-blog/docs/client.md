# 네이버 블로그 초안 생성기 — 사용 설명서

받으신 메일에 **주소와 접속 코드**가 들어 있습니다. 그것만 있으면 됩니다.

---

## 1. 이 프로그램이 해 드리는 것

**매일 아침, 블로그에 올릴 글과 대표 이미지 3장이 준비돼 있습니다.**

| | |
|---|---|
| 글 | 제목 · 본문 · 태그 |
| 후킹 제목 | 3종 (질문형 · 숫자형 · 공감형) 중에 고르십니다 |
| 이미지 | 3장. 무료 스톡에서 찾아 온 것 |
| 주기 | 매일 아침 자동. 급하면 [지금 생성] |

설치하실 것이 없습니다. 주소를 열면 됩니다. 휴대폰에서도 됩니다.

---

## 2. 먼저 아셔야 할 것 셋

### ① 발행은 직접 하십니다

**이게 이 프로그램의 설계입니다.** 글과 이미지까지 준비해 드리고,
**복사해서 네이버에 붙여넣고 발행하는 것은 본인이 하십니다.**

왜 그러냐면 — 예전에 자동 발행을 넣었다가 **네이버가 자동화를 탐지해
계정 보호조치**(비밀번호 강제 재설정)가 걸린 적이 있습니다. 그래서 그 기능을
통째로 걷어냈습니다.

이 프로그램에는 **네이버 비밀번호를 넣는 칸이 아예 없습니다.**
복사 한 번이 계정을 지킵니다.

### ② AI 가 쓴 것은 초안입니다

**직접 겪은 이야기를 더하지 않으면 네이버 검색에 잘 안 잡힙니다.**
네이버가 보는 것이 원본성입니다.

초안을 그대로 올리지 마시고, 본인 경험 한두 문단을 꼭 넣으십시오.
그것이 이 도구를 쓰는 분과 안 쓰는 분을 가릅니다.

### ③ Claude 구독이 필요합니다

글을 쓰는 데 씁니다. **가지고 계신 구독 한도 안에서** 돌아가고,
따로 요금이 청구되지 않습니다.

---

## 3. 처음 한 번

### 3-1. 코드 넣기

1. 메일의 주소를 누릅니다
2. **1차(초대) 코드**를 넣습니다
3. **기기별 2차 코드 3개**(PC · 노트북 · 휴대폰)가 화면에 나옵니다. **적어 두세요**
4. **지금 쓰는 기기에 맞는** 2차 코드를 넣습니다

> **여기서 제일 많이 헤매십니다.** PC용을 휴대폰에 넣으면 안 됩니다.
> 1차·2차 모두 **한 번만** 쓸 수 있으니 잘못 넣지 않게 복사해서 붙여넣으세요.

다른 기기에서 쓰실 때는 그 기기용 2차 코드를 넣으시면 됩니다. **세 대까지.**

### 3-2. 관리자 설정 — 세 가지

왼쪽 **⚙️ 관리자 설정**에서 순서대로.

**① AI 커넥트 연결**
- Claude 로그인
- 무료 이미지 API 키 3종 (Unsplash · Pexels · Pixabay)
  → 각 사이트에서 가입 즉시 발급됩니다. 무료입니다
  → **셋 다 넣으십시오.** 하나가 한도에 걸려도 나머지가 살아서 이미지가 계속 나옵니다

**② 블로그 주제 설정**
- 개인 / 기업 중에 고르고, 세부 주제를 정합니다

**③ 포스팅 방향 설정**
- 톤 프리셋 5종 중에 고르시거나 직접 만드실 수 있습니다
- **예시 포스팅 미리보기**가 있으니 보고 정하세요

### 3-3. 카테고리 만들기

**📁 블로그 관리**에서 쓰실 카테고리를 등록합니다.
**카테고리 하나가 초안 하나**입니다. 세 개 만들면 아침에 세 개가 쌓입니다.

최신 소식이 필요한 카테고리(뉴스·트렌드 등)는 **"검색 필요"**를 켜세요.

---

## 4. 매일 하는 일 — 5분

### 4-1. 쌓인 초안 보기

**📝 포스팅**에 카드로 쌓여 있습니다. 아침에 자동으로 만들어집니다.

급하시면 **[지금 생성]** 을 눌러 그 자리에서 만드실 수도 있습니다.
(2~3분 걸립니다)

### 4-2. 제목 고르기

후킹 제목이 **3종** 나옵니다.

| 종류 | 언제 |
|---|---|
| 질문형 | 검색으로 들어오는 글에 |
| 숫자·사실형 | 정보 정리 글에 |
| 공감형 | 경험담·일상 글에 |

마음에 드는 것을 복사하시면 됩니다.

### 4-3. 복사하기

- **제목 복사** · **본문 복사** 버튼
- **이미지는 각각 복사** — 클립보드에 **그림 자체**가 들어가서 네이버 편집기에
  바로 붙습니다. 내려받았다 올릴 필요가 없습니다

### 4-4. 네이버에 붙여넣고 발행

**여기가 본인이 하시는 자리입니다.**

1. 네이버 블로그 글쓰기를 엽니다
2. 제목·본문을 붙여넣습니다
3. 이미지를 붙여넣습니다
4. **직접 겪은 이야기를 한두 문단 더합니다** ← 이게 제일 중요합니다
5. 발행

### 4-5. 발행 완료로 표시

올리셨으면 카드에서 **[발행 완료]** 를 누릅니다.

**📜 발행 이력**에 쌓이고, 다음 초안을 만들 때 **최근 제목 20개와 겹치지 않게**
씁니다. 안 누르시면 비슷한 주제가 또 나올 수 있습니다.

---

## 5. 이미지에 대해

### 만드는 게 아니라 찾아 옵니다

무료 스톡 세 곳(Unsplash · Pexels · Pixabay)에서 검색해, 글에 가장 어울리는 것을
Claude 가 고릅니다. **AI 가 그림을 만들지 않습니다.**

크기와 비율만 네이버에 맞게 다듬습니다.

### 출처가 기록됩니다

채택한 이미지마다 **출처 사이트 · 원본 번호 · 원본 주소 · 라이선스 종류 ·
받은 시각**이 자동으로 남습니다.

**📜 발행 이력**에서 CSV 로 내려받으실 수 있습니다.
나중에 무료 이미지 정책이 바뀌어도 "그때는 무료였다"를 증빙하는 자료입니다.

### 이미지가 안 나올 때

무료 API 키가 없거나 전부 한도를 넘긴 것입니다.
**🏠 홈**의 **"AI 연결 상태"** 카드에 살아 있는 소스 개수가 나옵니다.

## 7. 자주 묻는 것

**Q. 자동으로 올려 주나요?**
아닙니다. 글과 이미지까지 준비해 드리고 복사·발행은 본인이 하십니다.
2장 ①을 보세요 — 계정을 지키기 위한 설계입니다.

**Q. 관리자 설정에 "접속 코드 관리"가 없어요**
**정상입니다.** 그 칸은 프로그램을 파신 분(마스터)에게만 보입니다.

**Q. Claude 요금이 따로 나오나요?**
아닙니다. 가지고 계신 **구독 한도 안에서** 돕니다.

**Q. 기기를 바꿨어요**
그 기기용 2차 코드가 남아 있으면 그것으로 들어가시면 됩니다.
셋 다 쓰셨으면 파신 분께 재발급을 요청하세요.

**Q. 코드를 잃어버렸어요**
1차·2차 모두 한 번만 씁니다. 파신 분께 다시 요청하셔야 합니다.

**Q. 같은 주제가 또 나와요**
최근 제목 20개와 안 겹치게 쓰고 있습니다. 카테고리를 늘리시면 다양해집니다.
그리고 올리신 뒤 **[발행 완료]** 를 꼭 눌러 주세요.

**Q. 첫 접속이 느려요**
안 쓸 때 서버가 잠들어 있어서 그렇습니다. 2~10초면 깨어납니다.
그 대신 요금이 거의 안 듭니다.

**Q. API 를 다뤄야 하나요?**
무료 이미지 사이트에서 키를 받아 **한 번 붙여넣는 것**이 전부입니다.
가입하면 화면에 바로 뜹니다. 프로그램을 설치하거나 코드를 쓰실 일은 없습니다.

## 8. 비용

프로그램을 쓰시는 데 **추가 비용이 없습니다.**

| 항목 | 비용 |
|---|---|
| 프로그램 | 구입하신 값 외에 없음 |
| 글쓰기 | 본인 Claude **구독 한도 안에서** |
| 이미지 | 0원 (무료 스톡) |
| 서버 | 0원 (파신 분이 부담) |

---

## 9. 막히면

먼저 이 셋을 해 보십시오.

1. **새로 고침** (Ctrl+F5 / 휴대폰은 창을 닫았다 다시 열기)
2. 🏠 홈의 **"AI 연결 상태"** 확인 — Claude 와 이미지 소스가 살아 있는지
3. 코드를 **복사해서** 붙여넣기 (손으로 치면 O 와 0 을 헷갈립니다)

그래도 안 되면 파신 분께 연락하십시오. 파신 분은 **관리 화면**에서
발급 내역과 상태를 보실 수 있어, 코드 문제인지 아닌지 바로 확인해 드립니다.
**어느 화면에서 무엇을 눌렀을 때 무슨 말이 떴는지**를 같이 알려 주시면 빨리 해결됩니다.

---

## 10. 정리

- **발행은 본인이** 하십니다. 계정을 지키기 위한 설계입니다
- AI 가 쓴 것은 **초안**입니다. 겪은 이야기를 더하셔야 검색에 잡힙니다
- 올리신 뒤 **[발행 완료]** 를 누르셔야 다음 글이 안 겹칩니다
- 이미지 키는 **셋 다** 넣으십시오. 하나가 막혀도 계속 나옵니다
- "접속 코드 관리"가 안 보이는 것은 **정상**입니다
