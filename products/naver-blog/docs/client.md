# 블로그 포스팅 — 사용 설명서

> 이 글은 **쓰시는 분**을 위한 것입니다.
> 설치·설정은 이미 끝나 있습니다. 주소와 접속키만 있으면 바로 쓰십니다.

---

## 1. 이 프로그램이 해 드리는 것

**네이버 블로그에 올릴 글과 대표 이미지 3장을 매일 아침 준비해 둡니다.**

아침에 주소를 열면 초안이 쌓여 있습니다. 마음에 드는 제목을 고르고, 복사해서
네이버에 붙여넣고, 발행하시면 됩니다. **5분이면 끝납니다.**

| 하는 것 | |
|---|---|
| 글 | 제목·본문·태그. 제목은 3가지로 뽑아 드립니다 |
| 이미지 | 무료 사진 3장. 글에 어울리는 것으로 골라 붙입니다 |
| 기록 | 언제 무엇을 올렸는지. 다음 글이 겹치지 않게 씁니다 |

---

## 2. 먼저 아셔야 할 것 둘

### ① 발행은 **직접** 하십니다

이 프로그램은 네이버에 **로그인하지 않습니다.** 네이버 비밀번호를 넣는 칸이
아예 없습니다.

```
프로그램이 글·이미지 준비  →  화면에 쌓임  →  복사  →  네이버에 붙여넣고 발행
                                                        ↑ 여기가 사람 자리
```

**왜 이렇게 만들었나** — 자동으로 올리는 기능을 넣었다가 네이버가 자동화를
잡아내 **계정 보호조치(비밀번호 강제 재설정)** 가 걸린 적이 있습니다. 그래서
그 기능을 통째로 걷어냈습니다.

**복사 한 번이 계정을 지킵니다.**

### ② AI 가 쓴 것은 **초안**입니다

그대로 올리셔도 글은 됩니다. 다만 **직접 겪은 이야기 한두 줄**을 더하시면
검색에서 훨씬 잘 잡힙니다.

> 예) "지난주에 상담 온 분도 이걸 물어보셨는데요"
> 예) "제가 3년 해 보니 이 부분이 제일 헷갈립니다"

AI 가 쓴 글은 AI 가 아는 것만 씁니다. **겪은 것은 쓰시는 분만 압니다.**

---

## 3. 들어가기

받으신 메일에 **주소**와 **인증키 네 개**가 들어 있습니다.

```
* 1차 인증키 : AAAA-BBBB-CCCC
* 2차 인증키
  - PC     : ...
  - 노트북  : ...
  - 휴대폰  : ...
```

주소를 열면 두 칸짜리 화면이 나옵니다.

1. **1차 인증키** — 하나뿐입니다. 어느 기기에서나 같은 것을 넣습니다
2. **2차 인증키** — **기기마다 다릅니다.** 지금 쓰시는 기기에 맞는 것을 넣으세요

> **PC 용을 휴대폰에 넣으면 PC 가 잠깁니다.**
> 같은 2차키로 다른 기기에서 들어오면 먼저 쓰던 기기가 끊깁니다. 기기 세 대
> (PC·노트북·휴대폰)까지 따로 쓰실 수 있게 하려는 것입니다.

한 번 들어가면 그 기기는 계속 기억합니다. 매번 넣지 않으셔도 됩니다.

---

## 4. 매일 하는 일 — 5분

### 4-1. 쌓인 초안 보기

왼쪽 **[포스팅]** 을 누르면 준비된 초안이 카드로 쌓여 있습니다.

급하시면 **[지금 생성]** 을 눌러 그 자리에서 만드실 수도 있습니다.
글쓰기와 이미지 찾기까지 **2~5분** 걸립니다.

### 4-2. 제목 고르기

제목이 **3가지**로 나옵니다.

| | 이런 글에 |
|---|---|
| **질문형** | "전세 계약할 때 이것 확인하셨나요?" — 궁금하게 |
| **숫자형** | "전세 사기 피하는 5가지" — 정리된 느낌 |
| **공감형** | "저도 전세 계약 때 밤새웠습니다" — 가깝게 |

하나를 누르면 그것이 제목이 됩니다.

### 4-3. 복사하기

| 버튼 | 무엇이 복사되나 |
|---|---|
| **[복사하기]** | 제목 + 본문 + 태그 |
| **[이미지 복사]** | **그림 자체.** 네이버 편집기에 바로 붙습니다 |

이미지 아래 파란 상자의 **대체텍스트**도 같이 복사해 두세요. 네이버 편집기의
「대체텍스트」 칸에 넣으면 검색에 도움이 됩니다.

### 4-4. 네이버에 붙여넣고 발행

네이버 블로그 글쓰기를 열고 **Ctrl+V**. 여기서 직접 겪은 이야기를 한두 줄
더하시고 발행하십시오.

### 4-5. 발행 완료로 표시

올리셨으면 카드의 **[발행 완료로 표시]** 를 누릅니다.

**이것을 눌러 주셔야 다음 글이 겹치지 않습니다.** 프로그램은 네이버를 들여다볼
수 없어서, 실제로 올리셨는지 알 길이 없습니다. 눌러 주신 것으로 압니다.

## 5. 이미지에 대해

### 만드는 게 아니라 **찾아 옵니다**

무료 사진 사이트 세 곳(Unsplash · Pexels · Pixabay)에서 글에 어울리는 것을
찾아 옵니다. **AI 가 그린 그림이 아닙니다.**

마음에 안 들면 **[이미지 재생성]** 으로 3장을 새로 받으실 수 있습니다.

### 출처가 기록됩니다

채택한 사진마다 **출처 · 원본 주소 · 라이선스 · 받은 시각**이 남습니다.
[이미지 출처 내려받기] 로 표로 받으실 수 있습니다.

나중에 "이 사진 어디서 났냐" 는 말이 나와도 **그때 그 기록을 보여 드리면**
됩니다.

### 이미지가 안 나올 때

글만 나오고 사진이 안 붙을 때가 있습니다. 사진 사이트의 **무료 사용 한도**를
넘긴 것입니다. 시간이 지나면 풀립니다.

급하시면 글만 먼저 올리고 사진은 직접 넣으셔도 됩니다.

## 6. 화면 여섯 개

| 메뉴 | 여기서 하는 일 |
|---|---|
| **홈** | 오늘 몇 개 준비됐나 한눈에 |
| **블로그 관리** | 어떤 주제로 쓸지 (카테고리) |
| **포스팅** | **매일 오시는 곳.** 초안을 보고 복사합니다 |
| **발행 이력** | 언제 무엇을 올렸나 |
| **관리자 설정** | 설치하신 분이 잡아 둔 곳입니다 |
| **사용법** | 이 설명서의 짧은 판 |

> **「관리자 설정」은 손대지 마세요.** AI 연결과 글의 톤이 들어 있습니다.
> 바꾸고 싶으시면 **설치해 주신 분께** 말씀하세요.

## 7. 자주 묻는 것

**"자동으로 올려 주면 안 되나요?"**
안 됩니다. 넣었다가 계정 보호조치가 걸린 적이 있어 그 기능을 없앴습니다.
복사 한 번이 계정을 지킵니다.

**"갑자기 로그아웃됐어요"**
**같은 2차키를 두 기기에서 쓰신 것입니다.** 받으신 메일에서 지금 기기에 맞는
2차키를 찾아 넣으세요. PC 용·노트북용·휴대폰용이 따로 있습니다.

**"접속키를 잃어버렸어요"**
받으신 메일을 다시 찾아보세요. 없으면 **주신 분께** 말씀하시면 새로 발급해
드립니다.

**"매일 몇 개나 나오나요?"**
설치하신 분이 정해 둔 만큼 나옵니다. 바꾸고 싶으시면 그분께 말씀하세요.

**"글이 마음에 안 들어요"**
[지금 생성] 으로 다시 만들어 보세요. 그래도 톤이 안 맞으면 설치하신 분께
말씀하시면 됩니다 — 톤은 설정에서 바뀝니다.

**"이미지가 하나도 안 나와요"**
사진 사이트 한도를 넘긴 것입니다. 시간이 지나면 풀립니다. 계속 그러면
설치하신 분께 말씀하세요.

**"제 돈이 나가나요?"**
쓰시는 분께는 **추가 비용이 없습니다.** AI 와 서버 비용은 설치하신 분 쪽에서
나갑니다.

## 8. 막히면

| 이럴 때 | 이렇게 |
|---|---|
| 화면이 안 열린다 | 주소를 다시 확인. 인터넷 연결 확인 |
| 로그인이 안 된다 | 기기에 맞는 2차키인지 확인 |
| 갑자기 로그아웃됐다 | 같은 2차키를 두 기기에서 쓰신 것 |
| 초안이 안 쌓인다 | 설치하신 분께 문의 |
| 이미지가 안 나온다 | 사진 사이트 한도. 기다리면 풀림 |
| 그 외 | **설치해 주신 분께** 문의 |

## 9. 정리

**매일 5분입니다.**

```
① 주소 열기          ② 마음에 드는 제목 고르기
③ [복사하기]        ④ 네이버에 붙여넣기
⑤ 내 이야기 한두 줄  ⑥ 발행
⑦ [발행 완료로 표시]
```

⑤번을 빼먹지 마세요. **그 한두 줄이 이 글을 검색에 올려 줍니다.**
