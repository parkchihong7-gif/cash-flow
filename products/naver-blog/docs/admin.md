# 네이버 블로그 초안 생성기 — 관리자 매뉴얼

## 1. 이 상품의 한 줄

**"글을 대신 써 주는 도구" 가 아니라 "빈칸만 채우면 되게 만들어 주는 도구"** 입니다.

이 구분이 가격과 신뢰를 정합니다. 대신 써 준다고 팔면 경쟁자가 널렸고 값이
바닥입니다. 빈칸을 남기는 쪽으로 팔면 **왜 남기는지**를 설명할 수 있고,
그 설명이 전문성이 됩니다.

---

## 2. 절대 넘으면 안 되는 선 — 자동 게시

### 사실관계

네이버는 **블로그 글쓰기 공개 API 를 제공하지 않습니다.** 개발자센터에서
받을 수 있는 것은 검색·데이터랩 같은 **읽는 API** 뿐입니다.

그러면 자동 게시는 브라우저를 흉내 내는 방법밖에 없습니다.

- 네이버 이용약관 위반 → 계정 정지
- CLAUDE.md §7 위반 → 비공식 자동화·비밀번호 저장형 금지

### 고객이 "자동으로 올려 달라" 고 하면

**안 됩니다.** 그리고 이렇게 설명하세요.

> 지금 그렇게 파는 곳이 있습니다. 그런데 그건 사장님 네이버 계정 비밀번호를
> 프로그램에 넣어야 하는 방식입니다. 계정이 정지되면 블로그가 통째로 날아갑니다.
> 저희는 그 방식을 쓰지 않습니다.

비밀번호 얘기를 꺼내면 대부분 납득합니다. **"약관 위반" 보다 "비밀번호를
넣어야 한다" 가 훨씬 잘 먹힙니다.**

### 그리고 이건 사실 강점입니다

네이버 검색은 원본성·체류시간·주제 일관성을 봅니다. 양산한 글은 어차피 안
올라갑니다. "자동으로 하루 10편" 을 산 고객들이 6개월 뒤에 방문자가 안 늘어서
환불을 요구하고 있습니다.

---

## 3. 대가성 문구 — 이건 법입니다

협찬·제휴·원고료 글은 경제적 이해관계를 공개해야 합니다(공정위 추천·보증 심사지침,
표시광고법 근거). **빠뜨리면 사업자가 제재를 받습니다.**

`naver_blog/policy.py` 의 `assert_disclosed()` 가 산출물을 내보내기 전에 막습니다.
**우회 경로를 두지 않았습니다.** 고객이 빼 달라고 해도 빼지 마세요.

### 실무에서 자주 틀리는 것

| 틀린 것 | 왜 |
|---|---|
| 맨 아래에 작게 | 표시한 것으로 보지 않습니다 |
| '더보기' 안에 | 같은 이유 |
| 해시태그 사이에 | 같은 이유 |
| "체험단입니다" 만 | 무엇을 받았는지가 없습니다 |
| 회색 작은 글씨 | 본문과 같은 크기·색이어야 합니다 |

이 목록을 상담에서 그대로 보여 주세요. 대부분 처음 듣습니다.

---

## 4. 수요 조회 — 무엇을 알 수 있고 없나

| 알 수 있는 것 | 알 수 없는 것 |
|---|---|
| 그 키워드로 이미 쓰인 글 수 | **월 검색 수** |
| 검색어 트렌드의 상대적 흐름 | 클릭률 |
| 오르는 중인지 내려가는 중인지 | 상위 노출 가능성 |

절대 검색량은 **네이버 검색광고 API** 에 있는데 광고주 가입이 따로 필요합니다.
고객이 "월 검색량 보여 주는 도구" 를 기대하고 온다면 **미리 정정하세요.**

### 숫자를 해석할 때

- **붐빈다고 피할 이유는 없습니다.** 각도가 다르면 자리가 있습니다
- **너무 한산하면 오히려 의심하세요.** 경쟁이 없는 게 아니라 찾는 사람이
  없는 것일 수 있습니다. 그래서 `too_quiet` 를 따로 표시합니다

---

## 5. 비용

| 항목 | 비용 |
|---|---|
| 네이버 검색 API | **무료**, 하루 25,000회 |
| 데이터랩 | **무료** |
| Claude 초안 | 한 편에 100~200원 |

키가 없어도 `--fixture`, `--dry-run` 으로 전체 흐름이 돕니다.

---

## 6. 파는 법

| 플랜 | 값 | 구성 |
|---|---|---|
| 기본 | 49,000원 | 프로그램 + 설명서 |
| 세팅 | 250,000원 | 위 + 키 발급 대행 + 키워드 20개 조사 |
| 월 관리 | 월 150,000원 | 월 8편 초안 + 수요 조사 + 검사 |

월 관리가 본체입니다. 다만 **"월 8편 초안" 이지 "월 8편 발행" 이 아닙니다.**
계약서에 이 구분을 꼭 쓰세요. 안 쓰면 분쟁이 납니다.

### 상세페이지에 반드시 넣을 것

- 자동 게시를 하지 않는다는 것과 **그 이유**(비밀번호 얘기까지)
- 네이버 API 는 무료라는 것
- 절대 검색량은 못 본다는 것
- 노출·방문자 수를 약속하지 않는다는 것

---

## 7. 자주 나오는 문의

**Q. 자동으로 올려 주는 곳도 있던데요**
사장님 계정 비밀번호를 넣는 방식입니다. 계정이 정지되면 블로그가 날아갑니다.

**Q. 월 검색량을 보여 주세요**
네이버 공개 API 로는 안 나옵니다. 검색광고 API 가 필요한데 광고주 가입이
따로 있어야 합니다. 필요하시면 별도로 연동해 드립니다.

**Q. 빈칸을 안 채우면 안 되나요**
채우지 않으면 검사기가 막습니다. 일반론만 남은 글은 어차피 노출이 안 됩니다.

**Q. 상위 노출 보장되나요**
안 됩니다. 검색 로직은 공개돼 있지 않고, 누구도 보장할 수 없습니다.

## 8. 내부 구조

```
naver_blog/
  policy.py   되는 것과 안 되는 것. 대가성 문구를 강제하는 곳
  demand.py   검색 API·데이터랩 (읽기만)
  draft.py    초안. 빈칸을 남기는 곳
  review.py   올리기 전 검사
cli.py        policy / disclosure / demand / draft / review
```

`policy.py` 를 먼저 읽으세요. 나머지가 왜 그렇게 생겼는지가 거기 있습니다.

---

## 9. 손볼 만한 곳

- `draft.DRAFT_SYSTEM` — 말투와 구성을 고객 블로그에 맞춥니다.
  이 상품에서 가장 값어치 있는 텍스트입니다
- `review.MIN_CHARS` / `MAX_CHARS` — 업종마다 적정 길이가 다릅니다
- `policy.DISCLOSURE` — 문구 자체. **법 해석이 바뀌면 여기를 고칩니다**

---

## 10. 관리 화면에서

통합 관리자 대시보드 3번입니다.

- **테스트** — 샘플 자료로 수요 조회와 초안을 만들어 봅니다. 비용 0원
- **수정** — 초안 프롬프트와 대가성 문구를 직접 고칩니다
- **권한·환경** — 네이버 앱 등록이 '즉시' 로 잡혀 있습니다. 심사가 없어서
  파시기 쉬운 상품입니다
- **규정 점검** — 대가성 문구 장치가 붙어 있는지 확인합니다

## 11. 이 상품을 팔면 안 되는 고객

- **"자동으로 하루 10편"** 을 원하는 분 — 팔아도 6개월 뒤 환불입니다
- **상위 노출을 보장받고 싶은 분** — 누구도 보장할 수 없습니다
- **블로그를 아직 안 만드신 분** — 먼저 10편을 직접 써 보시라고 권하세요.
  C-Rank 는 블로그의 누적 이력을 봅니다. 도구가 그걸 대신 만들어 주지 못합니다

## 12. 상담에서 쓰는 순서

### 1단계 — 지금 쓰는 방식을 물어보기

"블로그 한 편 쓰시는 데 얼마나 걸리세요?" 로 시작하세요.
대개 두세 시간이라고 답합니다. 그중 대부분이 **무엇을 쓸지 정하는 시간**입니다.

### 2단계 — 수요 조회를 그 자리에서

고객 업종 키워드 3개를 받아 `demand` 를 돌려 보여 주세요.
붐비는 것과 한산한 것이 갈리는 장면이 설득력이 있습니다.

### 3단계 — 빈칸을 설명하기

**여기가 이 상품이 팔리느냐 마느냐가 갈리는 지점입니다.**

> 저희는 글을 다 써 드리지 않습니다. 일부러 빈칸을 남깁니다.
> 네이버는 직접 쓴 글인지를 봅니다. 사장님만 쓸 수 있는 두세 문단이
> 있어야 검색에 올라갑니다. 그 두세 문단을 어디에 넣어야 하는지를
> 저희가 정해 드립니다.

"다 써 드립니다" 보다 이쪽이 오히려 비싸게 팔립니다.

### 4단계 — 대가성 문구 목록 보여 주기

4장의 '실무에서 자주 틀리는 것' 표를 그대로 보여 주세요.
협찬 글을 써 보신 분이면 대부분 한두 개는 틀리고 계십니다.

### 5단계 — 자동 게시 얘기는 물어볼 때만

먼저 꺼내지 마세요. 물어보시면 비밀번호 얘기를 하시면 됩니다.

## 13. 월 관리 플랜에서 실제로 하는 일

| 주기 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 월 1회 | 키워드 20개 수요 조사 → 8개 선정 | 40분 |
| 월 8회 | 초안 생성 + 빈칸 자리 지정 | 편당 15분 |
| 월 8회 | 고객이 채운 뒤 검사 | 편당 5분 |
| 분기 1회 | 어떤 글이 노출됐는지 돌아보기 | 1시간 |

마지막 줄을 빠뜨리지 마세요. **무엇이 먹혔는지 같이 보는 일**이
해지를 막습니다. 초안만 계속 보내면 "이거 내가 해도 되겠는데" 가 됩니다.

## 14. 계약서에 꼭 쓸 것

- **"월 8편 초안 제공" 이지 "월 8편 발행" 이 아닙니다.** 발행은 고객이 합니다
- 빈칸을 고객이 채워야 한다는 것
- 노출·방문자 수를 보장하지 않는다는 것
- 협찬 글의 대가성 문구 책임은 게시자(고객)에게 있다는 것

네 번째가 중요합니다. 문구를 넣어 드리지만, 실제로 그 문구를 지우고 올리는
것은 고객이 할 수 있는 일입니다. 책임 소재를 미리 갈라 두세요.

---

## 15. 앞으로 붙일 만한 것

- **네이버 검색광고 API 연동** — 절대 검색량이 나옵니다. 광고주 가입이 필요해서
  별도 옵션으로 파는 것이 낫습니다
- **발행 이력 관리** — 어떤 키워드로 언제 올렸는지. 주제 일관성을 보는 데 씁니다
- **경쟁 글 구조 분석** — 상위 글의 소제목 개수·길이 같은 것. 다만 **본문을
  긁어오면 안 됩니다.** 구조 통계만 봐야 합니다

마지막 줄을 조심하세요. 상위 글을 긁어 와서 "이렇게 쓰세요" 로 만들면
그건 다른 사람 글을 베끼게 만드는 도구가 됩니다 (CLAUDE.md §3-1).
