# 블로그 포스팅 — 사장님 매뉴얼 (설치·운영·판매)

> 이 글은 **이 상품을 사신 분**을 위한 것입니다.
> 쓰는 법만 필요하시면 `client.md` 를 보십시오.

---

## 1. 이 상품이 무엇인가

**네이버 블로그에 올릴 글과 대표 이미지를 매일 아침 준비해 두는 프로그램**입니다.
발행은 사람이 합니다.

### 그런데 왜 **사장님 서버에** 세우나

이것이 이 상품의 핵심입니다.

| | 남의 서버를 빌려 쓰면 | **사장님 서버에 세우면** |
|---|---|---|
| 글이 쌓이는 곳 | 파는 사람 서버 | **사장님 서버** |
| 서비스가 닫히면 | 글도 같이 사라짐 | 그대로 남음 |
| 값 | 매달 냄 | **한 번 사면 끝** |
| 고객에게 되팔기 | 못 함 | **하실 수 있음** |

그래서 설치 안내서를 함께 드립니다. **한 번만 세우시면 그 뒤로는 사장님
것입니다.** 저희가 들여다볼 수 없고, 저희가 문을 닫아도 계속 돕니다.

> 받으신 접속키는 **라이선스 확인용**입니다. 사장님 서버가 "정품인가" 를
> 물을 때만 쓰입니다. 글은 그 길로 오가지 않습니다.

---

## 2. 절대 되살리면 안 되는 것 — 자동 발행

**이 장을 맨 앞에 두는 이유가 있습니다. 한 번 데였습니다.**

### 무슨 일이 있었나

처음에는 Playwright 로 네이버 스마트에디터를 열어 **자동으로 발행**하는 구조였습니다.
실제 시험 중 **네이버가 자동화를 탐지해 계정 보호조치**(비밀번호 강제 재설정)가
걸렸습니다.

그 뒤 네이버 자동 로그인·발행 코드를 **전부 삭제**했습니다. 지금 이 프로그램에는
네이버 비밀번호를 넣는 칸이 **아예 없습니다.**

### 그래서 구조가 이렇습니다

```
Claude 가 글·이미지 준비  →  화면에 카드로 쌓임  →  사람이 복사  →  네이버에 붙여넣고 발행
                                                      ↑ 여기가 사람 자리
```

**마지막 한 단계만 사람이 합니다.** 복사 한 번이 계정을 지킵니다.

### 고객이 "자동으로 올려 주면 안 되나요" 라고 물으면

이렇게 답하십시오.

> "넣었다가 계정이 잠긴 적이 있습니다. 네이버는 블로그 글쓰기 공개 API 를 열어
> 두지 않았고, 남은 방법은 비밀번호를 프로그램에 넣어 브라우저를 조작하는 것뿐인데
> 그건 약관 위반입니다. 계정을 잃으면 그동안 쌓은 글이 다 묶입니다.
> 복사 한 번이 훨씬 쌉니다."

**돈을 더 주겠다고 해도 하지 마십시오.** 사고가 나면 고객 계정이지 사장님 계정이 아닙니다.

## 3. 설치 — 한 번만 하시면 됩니다

> **30~60분 걸립니다.** 어려운 것은 없고, 붙여넣기만 하시면 됩니다.
> 중간에 막히시면 **10번**을 보십시오.

### 3-0. 준비물 셋

| | 무엇 | 왜 |
|---|---|---|
| ① | **구글 계정** | 서버를 여기에 세웁니다 |
| ② | **Claude 구독** (Pro 이상) | 글을 씁니다. **이것 없이는 안 돕니다** |
| ③ | 카드 한 장 | 구글에 등록만 합니다. 무료 한도 안이라 실제로 빠져나가는 돈은 거의 없습니다 (4번 참고) |

**②가 없으면 여기서 멈추십시오.** 우회로가 없습니다.

### 3-1. 검은 창 열기 (Cloud Shell)

1. https://console.cloud.google.com 에 구글 계정으로 들어갑니다
2. 화면 **오른쪽 위**의 `>_` 모양 아이콘을 누릅니다
3. 화면 아래에 검은 창이 열립니다 (처음엔 10~30초 걸립니다)

| 화면에서 찾으실 것 | 어디에 |
|---|---|
| `>_` 모양 아이콘 | **오른쪽 위**, 물음표(?)와 톱니(⚙) 왼쪽 |
| 검은 창 | 누르면 **화면 아래쪽**에 열립니다 |
| `$` 와 깜빡이는 커서 | 검은 창 안. 여기에 붙여넣습니다 |


**화면 위쪽에 보이는 「프로젝트 ID」를 적어 두십시오.** 아래에서 계속 씁니다.
(`my-project-123456` 같은 모양입니다.)

### 3-2. 저장통 만들기

아래를 붙여넣고 Enter. **`YOUR_PROJECT_ID` 를 사장님 것으로 바꾸십시오.**

```bash
gcloud storage buckets create gs://maim-data-YOUR_PROJECT_ID --location=us-central1
```

> `Creating gs://...` 이 뜨면 된 것입니다.

**여기가 글이 쌓이는 곳입니다.** 사장님 계정 안에 있습니다.

### 3-3. 서버 세우기

먼저 프로그램을 받습니다.

```bash
git clone https://github.com/parkchihong7-gif/maim.git && cd maim
```

그리고 아래를 붙여넣습니다. **대문자 다섯 곳을 바꾸십시오.**

```bash
gcloud run deploy maim \
  --source . \
  --region=us-central1 \
  --allow-unauthenticated \
  --memory=2Gi \
  --min-instances=0 --max-instances=1 --concurrency=1 \
  --timeout=1800 \
  --set-env-vars=HOST=0.0.0.0,DATA_DIR=/tmp/maim-state,HOME=/tmp/maim-state/home,GCS_STATE_BUCKET=maim-data-YOUR_PROJECT_ID,TIMEZONE=Asia/Seoul,CLAUDE_BIN=claude,DASHBOARD_TOKEN=YOUR_PASSWORD,KEYSERVER_URL=YOUR_KEYSERVER_URL,KEYSERVER_PROGRAM=naver-blog
```

| 바꿀 곳 | 무엇을 넣나 |
|---|---|
| `YOUR_PROJECT_ID` | 3-1 에서 적어 두신 것 |
| `YOUR_PASSWORD` | **사장님이 정하시는 비밀번호.** 아무도 모르는 것으로 |
| `YOUR_KEYSERVER_URL` | 저희가 메일로 함께 보내 드린 주소 |

> **`--memory=2Gi` 를 줄이지 마십시오.** 512Mi 로 뒀다가 데이터가 깨진
> 적이 있습니다. 이 프로그램은 잠들어 있는 동안 요금이 0원이라, 메모리를
> 키워도 돈이 더 나가지 않습니다.

5~10분 걸립니다. 끝나면 이런 줄이 뜹니다.

```
Service URL: https://maim-xxxxx-uc.a.run.app
```

**이 주소가 사장님 프로그램 주소입니다. 적어 두십시오.**

### 3-4. Claude 로그인 — 빠뜨리면 글이 안 나옵니다

아래를 **한 줄씩** 붙여넣습니다.

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
gcloud storage buckets add-iam-policy-binding gs://maim-data-YOUR_PROJECT_ID \
  --member="user:$(gcloud config get-value account)" --role="roles/storage.objectAdmin"
```

```bash
mkdir -p /tmp/maim-home && export HOME=/tmp/maim-home
```

```bash
claude login
```

파란 링크가 뜹니다. 눌러서 **사장님 Claude 계정**으로 들어가고 `Authorize` 를
누르십시오. 검은 창에 `Logged in as ...` 가 뜨면 된 것입니다.

**그리고 이 마지막 줄을 꼭 하십시오.**

```bash
gcloud storage cp -r /tmp/maim-home/.claude gs://maim-data-YOUR_PROJECT_ID/home/.claude
```

> **이것을 빠뜨리면** 검은 창에서는 로그인이 됐는데 **서버는 여전히 로그인이
> 안 된 상태**로 남습니다. 제일 많이 놓치는 곳입니다.

### 3-5. 이미지 키 셋 — 셋 다 넣으십시오

무료 사진 사이트 세 곳입니다. 가입하면 바로 받습니다.

| 곳 | 받는 곳 | 시간당 한도 |
|---|---|---|
| Unsplash | unsplash.com/developers | 50회 |
| Pexels | pexels.com/api | 200회 |
| Pixabay | pixabay.com/api/docs | 5,000회 |

```bash
gcloud run services update maim --region us-central1 \
  --update-env-vars=UNSPLASH_ACCESS_KEY=키1,PEXELS_API_KEY=키2,PIXABAY_API_KEY=키3
```

> `--update-env-vars` 입니다. **`--set-env-vars` 를 쓰면 3-3 에서 넣은 설정이
> 전부 지워집니다.** 한 번 그렇게 날린 적이 있습니다.

**하나만 넣으면** 그것이 한도에 걸릴 때 글만 나오고 사진이 안 붙습니다.
셋을 넣으면 하나가 막혀도 나머지가 받습니다.

### 3-6. 자동 포스팅 켜기 — **이게 진짜 마지막이고, 제일 많이 빠뜨립니다**

**여기를 안 하시면 매일 아침 초안이 안 쌓입니다.** 프로그램은 멀쩡한데
아무 일도 안 일어납니다.

왜 그런가 — 이 서버는 **아무도 안 쓸 때 잠듭니다.** 그래서 요금이 0원입니다.
그런데 잠든 서버는 스스로 못 깨어납니다. **깨워 줄 자명종**이 따로 필요합니다.

| 시각 | 무슨 일이 | 이걸 안 걸면 |
|---|---|---|
| 06:00 | **Cloud Scheduler** 가 서버를 두드립니다 | 아무도 안 두드립니다 |
| 06:00 | 잠든 서버가 깨어납니다 | 계속 잠들어 있습니다 |
| ~06:10 | 글과 이미지를 준비합니다 | **아무 일도 안 일어납니다** |
| | 서버가 다시 잠듭니다 (요금 0원) | |


```bash
gcloud scheduler jobs create http maim-daily \
  --location=us-central1 \
  --schedule="0 6 * * *" \
  --time-zone="Asia/Seoul" \
  --uri="https://사장님-서비스-URL/api/run/daily" \
  --http-method=POST \
  --headers="x-dashboard-token=YOUR_PASSWORD"
```

`사장님-서비스-URL` 은 3-3 에서 적어 두신 것, `YOUR_PASSWORD` 도 3-3 에서
정하신 것입니다.

| 시각을 바꾸시려면 | `--schedule` |
|---|---|
| 매일 새벽 6시 | `"0 6 * * *"` |
| 매일 아침 8시 | `"0 8 * * *"` |
| 평일만 아침 7시 | `"0 7 * * 1-5"` |

> **컴퓨터를 켜 두실 필요는 없습니다.** 구글 쪽에서 깨웁니다. 사장님 컴퓨터가
> 꺼져 있어도, 주무시는 동안에도 초안은 쌓입니다. **다만 이 자명종을 걸었을
> 때만 그렇습니다.**

### 3-7. 접속키 넣고 확인

1. 3-3 에서 받으신 주소를 엽니다
2. 메일로 받으신 **1차 인증키**와, 지금 쓰시는 기기에 맞는 **2차 인증키**를 넣습니다
3. 들어가지면 **[블로그 관리]** 에서 카테고리를 만드십시오
4. **[지금 생성]** 을 눌러 글이 나오는지 보십시오 (2~5분)

글이 나오면 **설치 끝입니다.**

## 4. 비용

| 항목 | 비용 | 비고 |
|---|---|---|
| 글쓰기 (Claude) | **구독 한도 안에서** | `claude -p` 헤드리스. API 종량 과금 아님 |
| 이미지 | 0원 | 무료 스톡 3곳 |
| 서버 (Cloud Run) | 거의 0원 | 안 쓸 때 잠듭니다 |
| 저장 (Cloud Storage) | 0원 | 무료 한도 5GB 안 |
| 자동 실행 (Scheduler) | 0원 | 작업 3개까지 무료 |

**고객이 늘어도 월 고정비가 거의 안 붙습니다.**

### 이미지 API 한도

| 곳 | 한도 |
|---|---|
| Unsplash | 시간당 50회 |
| Pexels | 시간당 200회 |
| Pixabay | 시간당 5,000회 |

**셋 다 걸어 두십시오.** 하나가 막혀도 나머지가 살아서 이미지가 계속 나옵니다.
하나만 걸면 그것이 막힐 때 글만 나오고 이미지가 안 붙습니다.

### 돈이 나갈 수 있는 곳 하나

Cloud Run 의 **최소 인스턴스를 1 이상**으로 두면 안 잠들고 계속 켜져 있어
월 7달러 안팎이 붙습니다. **0 으로 두십시오.** 첫 접속이 2~10초 느려지는 대신
안 쓸 때 요금이 0원입니다.

## 5. 파는 법

### 값

사장님이 되파실 때 정하실 값입니다. 참고:

- 이 상품의 값어치는 **매일 아침 초안이 쌓여 있다**는 것입니다. "글 써 주는 AI" 로
  팔면 무료 도구와 비교당합니다. **"매일 열면 준비돼 있다"** 로 파십시오
- 후킹 제목 3종과 이미지 3장은 **고르는 재미**입니다. 이것도 값에 들어갑니다
- 블로그를 **이미 쓰고 계신 분**이 고객입니다. 처음 시작하는 분은 무엇을 쓸지부터
  모르셔서 만족도가 낮습니다

### 상세페이지에 반드시 넣을 것

- **발행은 사람이 한다**는 것. 미리 말하지 않으면 환불 사유가 됩니다
- **본인 Claude 구독**이 필요하다는 것
- **한 번은 설치를 해야 한다**는 것 (30~60분, 붙여넣기). 이걸 안 적으면
  "받아서 바로 쓰는 줄 알았다" 가 그대로 환불 요청으로 옵니다
- 무료 이미지 API 키를 본인이 발급해야 한다는 것 (가입 즉시, 무료)
- 기기 세 대까지라는 것

### 넣으면 안 되는 것

- **"자동으로 올려 드립니다"** — 사실이 아니고, 그렇게 팔면 계정 사고의 책임이 사장님께 옵니다
- **조회수·수익을 약속하는 말.** 글은 준비해 드리지만 결과는 아무도 모릅니다
- "AI 가 다 해 줍니다" — 직접 겪은 이야기를 더하지 않으면 네이버 검색에 안 잡힙니다

## 6. 이 상품을 팔면 안 되는 고객

| 이런 분 | 왜 |
|---|---|
| "자동으로 올려 주는 거죠?" 를 끝까지 고집하는 분 | 안 된다고 세 번 말해도 기대가 안 바뀌면 환불로 갑니다 |
| 블로그를 한 번도 안 써 보신 분 | 무엇을 쓸지부터 모르셔서 초안이 쌓여도 안 쓰십니다 |
| Claude 구독을 안 하실 분 | 글이 안 나옵니다. 이건 우회로가 없습니다 |
| 하루에 열 개씩 올리려는 분 | 네이버가 싫어합니다. 그 사용법 자체가 위험합니다 |

**안 파는 것도 영업입니다.** 위 넷은 반드시 환불 요청으로 돌아옵니다.

## 7. 자주 들어오는 문의

**"관리자 설정에 접속 코드 관리가 안 보여요"**
정상입니다. 고객 코드로 들어오시면 숨겨집니다. 마스터 토큰으로 들어가야 보입니다.

**"이미지가 하나도 안 나와요"**
무료 API 키가 없거나 전부 한도를 넘긴 것입니다. 홈 화면 **"AI 연결 상태"** 카드에
살아 있는 소스 개수가 나옵니다. 0 이면 관리자 설정 → AI 커넥트에서 넣으십시오.

**"지금 생성이 가끔 실패해요"**
Cloud Run 의 요청 제한 시간에 걸린 것입니다. 글쓰기 재시도와 이미지 파이프라인이
길어질 때 납니다. 제한 시간을 늘려 두면 해결됩니다.

**"코드를 잃어버렸어요"**
1차·2차 모두 한 번만 씁니다. 다시 발급해 드려야 합니다.

**"같은 주제가 또 나왔어요"**
최근 제목 20개와 안 겹치게 쓰고 있습니다. 그보다 더 거슬러 올라가면 겹칠 수
있습니다. 카테고리를 늘리시는 편이 낫습니다.

## 8. 환불 요청이 들어오면

**"자동 발행이 안 되는 줄 몰랐다"**
상세페이지에 적혀 있었는지 보십시오. **안 적혀 있었다면 사장님 책임입니다.**
환불하시고 상세페이지를 고치십시오.

**"Claude 구독이 필요한 줄 몰랐다"**
같습니다. 이건 우회로가 없는 조건이라 반드시 먼저 말씀하셔야 합니다.

**"설치가 이렇게 복잡한 줄 몰랐다"**
상세페이지에 적어 두셨는지 보십시오. 안 적혀 있었다면 환불해 드리는 것이
맞습니다. 적혀 있었다면, **한 번만 같이 해 드리겠다**고 제안해 보십시오 —
대개 여기서 풀립니다. 이 제안이 곧 월 관리 플랜의 입구이기도 합니다.

**"생각보다 글이 별로다"**
관리자 설정 → **포스팅 방향**에서 톤 프리셋을 바꿔 보시라고 안내하십시오.
그래도 안 맞으면 환불해 주십시오. 취향 문제는 설득이 안 됩니다.

## 9. 계약서에 꼭 쓸 것

- **발행은 고객이 직접 한다.** 자동 발행 기능은 제공하지 않는다
- 네이버 계정 정보를 수탁하지 않는다
- 조회수·수익·검색 노출을 보장하지 않는다
- 고객 본인의 Claude 구독이 필요하다
- AI 가 만든 초안이며, 최종 책임은 발행하는 고객에게 있다
- **프로그램은 고객 자신의 서버에 설치되며, 생성된 글·설정·이미지는 전량
  고객의 계정 안에 보관된다.** 공급자는 이를 열람·보관하지 않는다
- **설치는 고객이 수행한다.** 안내서를 제공하며, 설치 대행은 별도 계약으로 한다
- 서버·AI 이용료는 고객이 자신의 계정으로 직접 부담한다

> 마지막 세 줄이 이 상품의 무게 중심입니다. **데이터가 고객 것**이라는 점은
> 파실 때 가장 강한 말이 되고, 동시에 **글이 사라졌다는 책임**에서 사장님을
> 빼 줍니다. 빼지 마십시오.

## 10. 막혔을 때

| 이런 증상 | 십중팔구 이것입니다 |
|---|---|
| [지금 생성] 을 눌렀는데 오류 | **3-4 의 마지막 줄**을 빠뜨리셨습니다 |
| 아침에 초안이 안 쌓임 | **3-6 자명종**을 안 거셨습니다 |
| 글은 나오는데 사진이 없음 | 이미지 키 한도. 3-5 에서 셋 다 넣으셨는지 |
| 첫 접속이 느림 | 정상입니다. 잠든 서버가 깨는 데 2~10초 |
| 데이터가 깨졌다는 말 | 메모리가 2Gi 인지 확인 (3-3) |
| 접속키가 안 통함 | `KEYSERVER_URL` 이 들어갔는지 확인 |

설정을 다시 보시려면:

```bash
gcloud run services describe maim --region us-central1 --format="value(spec.template.spec.containers[0].env)"
```

그래도 안 되면 **사신 곳에 문의**하십시오. 위 명령의 결과를 함께 보내 주시면
빠릅니다. (비밀번호 줄은 지우고 보내십시오.)
