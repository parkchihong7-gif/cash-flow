# 블로그 포스팅 — 관리자 매뉴얼 (판매용)

> 이 글은 **판매용 키를 받으신 분**(이 상품을 사신 분)을 위한 것입니다.
> 사장님 서버에 **직접 세워** 쓰십니다. 세우는 절차는 **「설치 안내서」 메일로
> 따로** 보내 드렸습니다. 이 글은 그 밖의 것 — 무엇인지, 매일 쓰는 법, 비용,
> 막혔을 때 — 입니다.
> 체험용 키를 받으신 분께는 이 글이 아니라 **쓰는 법만 담은 짧은 안내서**가 갑니다.

> **글 쓸 AI 는 Gemini · Claude · Codex 중 하나면 됩니다.** Gemini 는 가입만으로
> 무료, Claude 는 Pro(월 $20) 이상, Codex 는 ChatGPT Plus(월 $20) 이상 유료
> 구독이 필요합니다. 자세한 것은 **설치 안내서 0단계**의 표를 보십시오.

---

## 1. 이 상품이 무엇인가

**네이버 블로그에 올릴 글과 대표 이미지를 매일 아침 준비해 두는 프로그램**입니다.
발행은 사람이 합니다.

### 왜 **사장님 서버에** 세우나

이것이 이 상품의 핵심입니다.

| | 남의 서버를 빌려 쓰면 | **사장님 서버에 세우면** |
|---|---|---|
| 글이 쌓이는 곳 | 빌려준 쪽 서버 | **사장님 서버** |
| 서비스가 닫히면 | 글도 같이 사라짐 | 그대로 남음 |
| 값 | 매달 냄 | **한 번 사면 끝** |
| 글 수·카테고리 수 | 요금제만큼 | **제한 없음** |

그래서 설치 안내서를 함께 드립니다. **한 번만 세우시면 그 뒤로는 사장님
것입니다.** 저희가 들여다볼 수 없고, 저희가 문을 닫아도 계속 돕니다.

> 받으신 접속키는 **라이선스 확인용**입니다. 사장님 서버가 "정품인가" 를
> 물을 때만 쓰입니다. 글은 그 길로 오가지 않습니다.

---

## 2. 절대 되살리면 안 되는 것 — 자동 발행

**이 장을 맨 앞에 두는 이유가 있습니다. 한 번 데였습니다.**

### 무슨 일이 있었나

처음에는 Playwright 로 네이버 스마트에디터를 열어 **자동으로 발행**하는 구조였습니다.
실제 시험 중 **네이버가 자동화를 탐지해 계정 보호조치**(비밀번호 강제 재설정)가
걸렸습니다.

그 뒤 네이버 자동 로그인·발행 코드를 **전부 삭제**했습니다. 지금 이 프로그램에는
네이버 비밀번호를 넣는 칸이 **아예 없습니다.**

### 그래서 구조가 이렇습니다

```
AI 가 글·이미지 준비      →  화면에 카드로 쌓임  →  사람이 복사  →  네이버에 붙여넣고 발행
                                                      ↑ 여기가 사람 자리
```

**마지막 한 단계만 사람이 합니다.** 복사 한 번이 계정을 지킵니다.

### "그래도 자동으로 올리고 싶은데" 하는 생각이 드시면

쓰시다 보면 마지막 복사 한 번도 귀찮아지는 날이 옵니다. 그때 이 글을
다시 보십시오.

네이버는 블로그 글쓰기 공개 API 를 **열어 두지 않았습니다.** 남은 방법은
비밀번호를 프로그램에 넣어 브라우저를 조작하는 것뿐인데, 그건 약관
위반이고 **실제로 잡혔습니다.**

**잃는 것은 그동안 쌓은 글 전부입니다.** 5분을 아끼려다 몇 년을 잃습니다.
복사 한 번이 훨씬 쌉니다.

---

## 3. 설치 — **「설치 안내서」 메일을 따로 보내 드렸습니다**

설치는 **한 번만** 하시면 되고 30~60분 걸립니다. 절차가 길어서 이 메일과
**따로 한 통** 더 보내 드렸습니다. 제목이 **「[블로그 포스팅] 설치 안내서」** 인
메일입니다. 안 보이시면 스팸함도 한번 봐 주십시오.

| 단계 | 할 일 |
|---|---|
| 0 | 준비물 — 구글 계정 · **글 쓸 AI 하나** · 카드 |
| 1~3 | 검은 창 열기 → 저장통 → 서버 세우기 |
| 4 | AI 연결 (Gemini 는 키 한 줄, Claude·Codex 는 네 줄) |
| 5 | 이미지 키 셋 |
| 6~7 | 자동 포스팅 켜기 · 하루 몇 편 |
| 8 | 체험 서버 (나중에) |
| 9 | 접속키 넣고 글 한 편 만들어 보기 |

> 설치 안내서는 통합 대시보드의 **매뉴얼 탭 → 설치 안내서**에도 있습니다.

---

## 4. 매일 쓰시는 법 — 5분

설치가 끝나면 하실 일은 이것뿐입니다.

```
① 아침에 주소 열기      ② 마음에 드는 제목 고르기
③ [복사하기]           ④ 네이버에 붙여넣기
⑤ 내 이야기 한두 줄     ⑥ 발행
⑦ [발행 완료로 표시]
```

### ⑤번을 빼먹지 마십시오

AI 가 쓴 글은 AI 가 아는 것만 씁니다. **겪은 것은 사장님만 아십니다.**
직접 겪은 이야기 한두 줄이 이 글을 검색에 올려 줍니다.

> 예) "지난주에 상담 온 분도 이걸 물어보셨는데요"
> 예) "제가 3년 해 보니 이 부분이 제일 헷갈립니다"

### ⑦번을 빼먹으면 글이 겹칩니다

프로그램은 네이버를 들여다볼 수 없습니다. 실제로 올리셨는지 알 길이
없어서, **눌러 주신 것으로 압니다.** 안 누르시면 다음 글이 같은 주제로
나올 수 있습니다.

### 화면 여섯 개

| 메뉴 | 여기서 하는 일 |
|---|---|
| **홈** | 오늘 몇 개 준비됐나 한눈에 |
| **블로그 관리** | 어떤 주제로 쓸지 (카테고리) |
| **포스팅** | **매일 오시는 곳.** 초안을 보고 복사합니다 |
| **발행 이력** | 언제 무엇을 올렸나 |
| **관리자 설정** | AI 연결·톤·**포스팅 예약**(차례와 하루 편수) |
| **사용법** | 짧은 판 |

## 5. 비용

| 항목 | 비용 | 비고 |
|---|---|---|
| 글쓰기 (AI) | **Gemini 는 무료 등급 안에서 0원** · Claude 는 Pro(월 $20) 이상 · Codex 는 ChatGPT Plus(월 $20) 이상 | 구독 한도 안에서 돌아 **건당 요금이 따로 안 나갑니다.** Gemini 는 무료 한도를 넘겨 결제를 등록하시면 그때부터 쓴 만큼 |
| 이미지 | 0원 | 무료 스톡 3곳 |
| 서버 (Cloud Run) | 거의 0원 | 안 쓸 때 잠듭니다 |
| 저장 (Cloud Storage) | 0원 | 무료 한도 5GB 안 |
| 자동 실행 (Scheduler) | 0원 | 작업 3개까지 무료 |

**고객이 늘어도 월 고정비가 거의 안 붙습니다.**

### 이미지 API 한도

| 곳 | 한도 |
|---|---|
| Unsplash | 시간당 50회 |
| Pexels | 시간당 200회 |
| Pixabay | 시간당 5,000회 |

**셋 다 걸어 두십시오.** 하나가 막혀도 나머지가 살아서 이미지가 계속 나옵니다.
하나만 걸면 그것이 막힐 때 글만 나오고 이미지가 안 붙습니다.

### 돈이 나갈 수 있는 곳 하나

Cloud Run 의 **최소 인스턴스를 1 이상**으로 두면 안 잠들고 계속 켜져 있어
월 7달러 안팎이 붙습니다. **0 으로 두십시오.** 첫 접속이 2~10초 느려지는 대신
안 쓸 때 요금이 0원입니다.

## 6. 이미지에 대해

### 만드는 게 아니라 **찾아 옵니다**

무료 사진 사이트 세 곳에서 글에 어울리는 것을 찾아 옵니다.
**AI 가 그린 그림이 아닙니다.** 마음에 안 드시면 [이미지 재생성] 으로
3장을 새로 받으실 수 있습니다.

### 출처가 기록됩니다

채택한 사진마다 **출처 · 원본 주소 · 라이선스 · 받은 시각**이 남습니다.
[이미지 출처 내려받기] 로 표로 받으실 수 있습니다.

나중에 "이 사진 어디서 났냐" 는 말이 나와도 **그때 그 기록을 보여
드리면** 됩니다.

## 7. 이럴 때는 이렇게

**"이미지가 하나도 안 나와요"**
무료 API 키가 없거나 전부 한도를 넘긴 것입니다. 홈 화면 **"AI 연결 상태"** 카드에
살아 있는 소스 개수가 나옵니다. 0 이면 **설치 안내서 5단계** 로 돌아가 키 셋을 다시 넣으십시오.

**"지금 생성이 가끔 실패해요"**
Cloud Run 의 요청 제한 시간에 걸린 것입니다. 설치 안내서 3단계의 `--timeout=1800` 이
들어갔는지 확인하십시오. 기본값(5분)이면 다 되어 가던 요청이 끊깁니다.

**"접속키를 잃어버렸어요"**
받으신 메일을 다시 찾아보십시오. 없으면 **사신 곳에 말씀하시면** 새로
발급해 드립니다.

**"다른 기기에서 열었더니 먼저 쓰던 게 끊겼어요"**
**같은 2차키를 두 기기에서 쓰신 것입니다.** 2차키는 PC·노트북·휴대폰용이
따로 있습니다. 지금 기기에 맞는 것을 넣으십시오.

**"같은 주제가 또 나왔어요"**
최근 제목 20개와 안 겹치게 쓰고 있습니다. 그보다 더 거슬러 올라가면 겹칠 수
있습니다. 카테고리를 늘리시는 편이 낫습니다.

## 8. 막혔을 때

| 이런 증상 | 십중팔구 이것입니다 |
|---|---|
| [지금 생성] 을 눌렀는데 오류 | **설치 안내서 4단계의 마지막 줄**을 빠뜨리셨습니다 |
| 아침에 초안이 안 쌓임 | **설치 안내서 6단계 자명종**을 안 거셨습니다. [관리자 설정 → 4) 포스팅 예약 설정] 맨 위에 경고가 떠 있는지 보십시오 |
| 아침에 너무 많이 쌓임 | **설치 안내서 7단계** 에서 하루 건수를 줄이십시오 |
| 아침에 아무것도 안 나옴 | 자명종(**설치 안내서 6단계**)을 안 거신 것입니다. 예약 화면에 「자동 준비가 꺼져 있습니다」가 떠 있으면 그 자리에 붙여넣을 명령이 함께 나옵니다 |
| Cloud Shell 명령이 자꾸 실패 | **설치 안내서 1단계의 [승인]** 을 [거부] 하셨을 수 있습니다. 검은 창 탭을 닫았다 다시 여시면 그 창이 다시 뜹니다 |
| 글은 나오는데 사진이 없음 | 이미지 키 한도. 설치 안내서 5단계에서 셋 다 넣으셨는지 |
| 첫 접속이 느림 | 정상입니다. 잠든 서버가 깨는 데 2~10초 |
| 데이터가 깨졌다는 말 | 메모리가 2Gi 인지 확인 (설치 안내서 3단계) |
| 접속키가 안 통함 | `KEYSERVER_URL` 이 들어갔는지 확인. 체험 서버도 **같은 값**이어야 합니다 |
| 체험 회원 화면이 비어 있다 | 처음 들어가실 때 카테고리 셋이 깔립니다. 안 깔렸다면 그분이 이미 다 지우신 것입니다 |

설정을 다시 보시려면:

```bash
gcloud run services describe maim --region us-central1 --format="value(spec.template.spec.containers[0].env)"
```

그래도 안 되면 **사신 곳에 문의**하십시오. 위 명령의 결과를 함께 보내 주시면
빠릅니다. (비밀번호 줄은 지우고 보내십시오.)

## 9. 알아 두시면 좋은 것

- **하루에 열 개씩 올리지 마십시오.** 네이버가 싫어합니다. 하루 1~3편이
  꾸준한 것이 가장 낫습니다
- **블로그를 이미 쓰고 계신 분**께 잘 맞습니다. 무엇을 쓸지 정해져 있어야
  초안이 쓸모 있습니다
- **조회수·수익은 아무도 모릅니다.** 이 프로그램이 해 드리는 것은
  "매일 아침 준비돼 있다" 까지입니다
- 고르신 AI 의 로그인이 풀리면 **글이 안 나옵니다.** [관리자 설정 → 1단계]의
  [연결 테스트]로 확인하시고, 설치 안내서 4단계의 ⓑ와 마지막 줄을 한 번 더 하시면 됩니다
- **Gemini 는 무료 등급에도 하루 한도가 있습니다.** 하루 1~2편 맛보기에는
  대개 되지만, 매일 여러 편이면 모자랄 수 있습니다 (설치 안내서 0단계 참고). 한도는 구글이
  수시로 바꿉니다 — https://ai.google.dev/gemini-api/docs/rate-limits
