# 15. 네이버 블로그 포스팅 초안 생성기 (naver-blog)

수요를 확인하고, 초안을 쓰고, 올리기 전에 검사합니다.

> **자동 게시는 하지 않습니다.**
> 네이버에는 블로그 글쓰기 공개 API 가 없고, 브라우저를 흉내 내는 방식은
> 약관 위반이라 계정이 정지됩니다. 이유는 §2 에 적었습니다.

---

## 1. 무엇을 하나

```
수요 보기  →  초안 쓰기  →  검사  →  (사람이) 복사해 붙이기
cli.py demand  cli.py draft  cli.py review        ← 여기만 사람
```

| 명령 | 하는 일 |
|---|---|
| `demand` | 키워드마다 이미 몇 건이 쓰였는지와 검색 흐름 |
| `draft` | 소제목 나눈 초안 + 태그 + 대가성 문구 |
| `review` | 올리면 탈이 나는 것만 골라서 |
| `disclosure` | 협찬·제휴 문구를 유형에 맞게 |
| `policy` | 네이버에서 되는 것과 안 되는 것 |

---

## 2. 왜 자동 게시를 안 만들었나

### 네이버에는 글쓰기 API 가 없습니다

네이버 개발자센터에서 받을 수 있는 것은 **읽는 API** 입니다.

| API | 되나 | 비고 |
|---|---|---|
| 검색 (블로그·뉴스·카페) | ○ | 하루 25,000회, 무료 |
| 데이터랩 검색어 트렌드 | ○ | **상대값만**. 절대 검색 수는 안 줍니다 |
| 네이버 로그인·지도 등 | ○ | 이 상품과 무관 |
| **블로그 글쓰기** | **✗** | 예전 오픈API 기능은 닫혔습니다 |

### 그러면 남는 방법은 하나뿐인데

브라우저를 흉내 내 로그인하고 글쓰기 화면을 조작하는 것입니다.
**두 가지 이유로 안 만듭니다.**

1. 네이버 이용약관이 금지합니다. 계정이 정지됩니다
2. 이 프로젝트 규칙이 금지합니다 — 비공식 자동화, 비밀번호 저장형 금지

"그래도 다들 하던데요" 라는 말을 듣습니다. **하는 사람이 있는 것과 팔아도 되는
것은 다릅니다.** 남의 계정이 정지되는 도구를 팔면 환불로 끝나지 않습니다.

### 역설적으로 이게 낫습니다

네이버 검색 노출 로직(C-Rank·D.I.A.+)이 보는 것은 대체로 이렇습니다.

- **원본성** — 남의 글과 얼마나 다른가
- **체류시간** — 들어와서 얼마나 머무는가
- **주제 일관성** — 한 분야를 꾸준히 쓰는가

셋 다 양산과 반대 방향입니다. **양산한 글은 어차피 안 올라갑니다.**
붙여넣기 전에 한 번 읽고 고치는 그 과정이 품질을 만듭니다.

---

## 3. 빈칸을 일부러 남깁니다

초안에는 이런 자리가 들어갑니다.

```
[직접 겪은 일을 여기에 쓰세요]
```

**이걸 채우지 않으면 검사기가 막습니다.** 그냥 지우기만 해도 막습니다.
일반론만 남은 글은 원본성이 없어서 안 올라가기 때문입니다.

이 상품이 파는 것은 "글을 대신 써 주는 것" 이 아니라 **"빈칸만 채우면 되게
만들어 주는 것"** 입니다.

---

## 4. 대가성 문구

협찬·제휴·원고료를 받은 글은 **경제적 이해관계를 공개**해야 합니다
(공정거래위원회 추천·보증 등에 관한 표시·광고 심사지침, 표시광고법 근거).

이 프로그램은 대가를 받은 글에 **문구 없이는 산출물을 내보내지 않습니다.**
우회 경로를 두지 않았습니다.

| 유형 | 문구 |
|---|---|
| `sponsored` | 이 글은 OO으로부터 원고료를 지급받아 작성한 광고 글입니다 |
| `affiliate` | 이 글에는 제휴 링크가 포함되어 있으며, 구매 시 수수료를 받습니다 |
| `paid` | 이 글은 OO으로부터 대가를 받아 작성하였습니다 |
| `gift` | 이 글은 OO으로부터 제품을 무상으로 제공받아 작성하였습니다 |

### 넣는 법이 더 중요합니다

- **본문 맨 위**에 둡니다. 맨 아래나 '더보기' 안에 숨기면 표시한 것으로 안 봅니다
- 본문과 **같은 크기·같은 색**으로 씁니다
- '체험단', '서포터즈' 같은 말만으로는 부족합니다. 무엇을 받았는지 적습니다
- 해시태그 사이에 끼워 넣지 않습니다

```bash
python cli.py disclosure --kind sponsored --name OO상사
```

## 5. 설치와 키

```bash
pip install -r requirements.txt
cp .env.example .env
```

| 키 | 필요한가 | 받는 데 |
|---|---|---|
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 수요 조회에만 | **즉시, 무료** |
| `ANTHROPIC_API_KEY` | 초안 문장에만 | 즉시 |

**둘 다 없어도 전체 흐름을 볼 수 있습니다.**

```bash
python cli.py demand --fixture      # 샘플 자료로
python cli.py draft --dry-run       # 뼈대만
```

### 네이버 키 받기 (5분, 무료)

1. developers.naver.com → 애플리케이션 등록
2. 사용 API 에 **검색**과 **데이터랩(검색어 트렌드)** 을 고릅니다
3. 나오는 Client ID / Secret 을 `.env` 에 넣습니다

### 절대 검색량이 필요하면

데이터랩은 **상대값만** 줍니다. 절대 검색 수는 **네이버 검색광고 API** 에
있는데, 그건 광고주 가입이 따로 필요합니다. 이 프로그램은 선택으로 두었습니다.

---

## 6. 한계

- 글 수는 경쟁의 **한 가지 신호**일 뿐입니다. 붐벼도 각도가 다르면 자리가 있습니다
- 너무 한산한 키워드는 경쟁이 없는 게 아니라 **찾는 사람이 없는 것**일 수 있습니다
- 데이터랩은 상대값이라 "월 몇 회 검색" 을 알 수 없습니다
- 검색 노출 로직은 공개돼 있지 않습니다. 여기 적은 것은 알려진 경향입니다
- **노출이나 방문자 수를 약속하지 않습니다**

---

## 7. 판매 문구 초안

> 네이버 블로그 글을 **빈칸만 채우면 되게** 만들어 드립니다.
>
> - 키워드마다 이미 몇 건이 쓰였는지와 검색 흐름을 봅니다 (네이버 공식 API)
> - 소제목을 나눈 초안과 태그를 만듭니다
> - 협찬·제휴 글이면 **대가성 문구를 자동으로** 넣습니다. 빠뜨리면 산출물이 안 나옵니다
> - 올리기 전에 과장 문구·길이·빈칸을 검사합니다
>
> **자동 게시는 하지 않습니다.** 네이버는 글쓰기 API 를 열어 두지 않았고,
> 브라우저를 흉내 내는 방식은 계정이 정지됩니다. 초안까지 만들어 드리면
> 복사해서 붙이시면 됩니다.
>
> 네이버 API 는 무료입니다. 노출이나 방문자 수를 약속하지 않습니다.
