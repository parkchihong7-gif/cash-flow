# 강의 슬라이드 생성기 (lecture-deck)

강의 주제와 시간을 넣으면 **커리큘럼 → 슬라이드 pptx → 발표자 노트 → 수강생 실습지**까지
만드는 CLI입니다.

> ## ⚠️ 이 도구는 초안 생성기입니다. 강의 전 강사 검수가 필수입니다.
>
> 발표자 노트는 강사가 **자기 말투로 고쳐야** 읽을 수 있습니다.
> 슬라이드에 남은 `[강사가 채울 곳]` 표시는 본인 경험으로 바꾸세요.
> 그 작업을 거쳐야 남의 자료가 아니라 내 강의가 됩니다.

## 설치

```bash
# 저장소 루트에서
pip install -r requirements.txt
cp .env.example .env      # ANTHROPIC_API_KEY 를 채웁니다
```

## 실행

```bash
cd products/lecture-deck

python cli.py build deck_input.yaml            # 커리큘럼을 보여 주고 진행 여부를 물어봅니다
python cli.py build deck_input.yaml --yes      # 묻지 않고 끝까지
python cli.py build deck_input.yaml --dry-run  # 비용 없이 형태만 확인
```

| 옵션 | 설명 |
|---|---|
| `--yes`, `-y` | 커리큘럼 확인 단계를 건너뜁니다 |
| `--model MODEL` | Claude 모델 ID |
| `--no-ai-label` | AI 생성물 표시를 끕니다 |
| `--out DIR` | 산출물 상위 폴더 (기본 `outputs/`) |
| `--dry-run` | Claude 를 부르지 않고 예시 콘텐츠로 (비용 없음) |

종료 코드: 0 정상 / 2 확인 필요(자동 분할·노트 보정 발생) / 1 오류.

### 커리큘럼 확인 단계 (휴먼 인 더 루프)

슬라이드를 만들기 전에 커리큘럼을 화면에 보여 주고 물어봅니다.

```
  ── 커리큘럼 ──────────────────────────────
  1. 왜 지금 정리가 필요한가  (25분)
     목표: 파일이 쌓이는 진짜 원인을 말할 수 있다
     개념: 기준 없는 저장, 이름의 무질서, 버리지 않는 습관
  ...
  ─────────────────────── 합계 180분

  이 커리큘럼으로 슬라이드를 만들까요? [Y/n]
```

**여기가 비용을 아끼는 지점입니다.** 커리큘럼 생성은 LLM 호출 1회지만,
슬라이드는 모듈 수만큼 호출합니다. 커리큘럼이 마음에 안 들면 여기서 중단하고
`deck_input.yaml` 의 모듈을 고쳐 다시 실행하세요.

`n` 을 누르면 슬라이드를 만들지 않고 종료합니다. `--yes` 를 쓰면 묻지 않습니다.

## 입력 — `deck_input.yaml`

| 키 | 설명 |
|---|---|
| `course_title` | 강의 제목 |
| `audience` | 누가 듣는 강의인지 한 줄. **좁을수록 좋습니다** |
| `total_minutes` | 전체 강의 시간(분). 30~960 |
| `instructor` | 표지·실습지에 들어갈 이름. 비우면 자리만 만듭니다 |
| `style` | `minimal` / `bold` / `corporate` |
| `modules` | 모듈 목록. **비우면 LLM 이 5~8개 제안** |

모듈을 직접 쓸 때는 제목만 적어도 되고, 목표·핵심 개념까지 적으면 그대로 씁니다.
핵심 개념을 적을 때는 3~5개여야 합니다.

## 산출물 — `outputs/<강의명>/`

| 파일 | 내용 |
|---|---|
| `curriculum.md` | 모듈별 학습 목표, 소요 시간, 실습 과제, 평가 기준 |
| `deck.pptx` | 슬라이드 + 발표자 노트 |
| `worksheet.docx` | 수강생용 실습지 (모듈별 빈칸 3개 + 체크리스트) |
| `deck_outline.json` | 슬라이드별 제목·본문·노트. 다른 도구에서 재활용 |

### 덱 구조

```
표지 → 강사 소개(자리) → 커리큘럼 개요
  → [모듈 표지][개념 3~5장][실습][요약]  × 모듈 수
  → 마무리/CTA → AI 고지
```

모듈 5개 × 개념 4개면 40장 내외가 됩니다.

### 슬라이드 규칙 (프로그램이 강제합니다)

| 항목 | 값 |
|---|---|
| 본문 줄 수 | 슬라이드당 **6줄 이하** |
| 한 줄 글자 수 | **20자 이하** |
| 발표자 노트 | **200~400자**, 빈 슬라이드 없음 |
| 캔버스 | 16:9 (13.333 × 7.5 in) |
| 글꼴 | 맑은 고딕 |

프롬프트로 부탁만 하지 않습니다. 생성 결과를 검사해서 **넘치면 의미 단위로 쪼개고
슬라이드를 나눕니다.** 나뉜 슬라이드는 제목이 `(1/2)` 로 바뀌고 실행 결과에 보고됩니다.
노트가 짧으면 채우고 `[강사가 채울 곳]` 표시를 남깁니다.

### 색상 팔레트

`templates/palettes.json` 에 스타일 3종이 있습니다. 대시보드 **수정** 탭에서 고칠 수 있습니다.

| 스타일 | 성격 |
|---|---|
| `minimal` | 차콜과 오프화이트. 내용에 시선이 가게 하는 기본값 |
| `bold` | 체리 레드와 네이비. 대비가 강해 큰 강의실에서 잘 보임 |
| `corporate` | 네이비와 아이스 블루. 사내 교육·B2B 강의용 |

제목·마무리 슬라이드는 진한 배경, 본문은 밝은 배경을 씁니다.
제목 밑줄이나 장식용 색 띠는 쓰지 않습니다. AI가 만든 티가 나는 대표적인 요소입니다.

**도형은 python-pptx 기본 도형만 씁니다.** 외부 이미지 파일에 의존하지 않아
어디서 열어도 깨지지 않습니다.

## 크몽 상세페이지 초안

### 강의 자료 만드는 시간을 줄입니다

강의 내용은 머리에 있는데 슬라이드를 만들다 밤을 새우는 경우가 많습니다.
특히 발표자 노트는 대부분 비워 둔 채 강의에 들어갑니다.

이 프로그램은 강의 주제와 시간을 넣으면 **커리큘럼·슬라이드·발표자 노트·실습지**를
한 번에 초안으로 만들어 드립니다.

**이런 분께 맞습니다**
- 가르칠 내용은 있는데 슬라이드 구성에서 막히는 분
- 강의는 해봤지만 매번 자료를 새로 만드는 분
- 수강생 실습지까지 챙기기 버거운 분

**이런 분께는 맞지 않습니다**
- AI가 만든 자료를 그대로 읽고 싶은 분 — 이 도구는 강사 검수를 전제로 만들었습니다
- 이미 쓰는 사내 템플릿이 정해져 있는 분 — 자체 디자인으로 만듭니다
- 터미널에서 명령어를 실행하기 어려우신 분

**드리는 것**
- 커리큘럼 (모듈별 목표·시간·실습 과제·평가 기준)
- 슬라이드 pptx 40장 내외 (16:9, 색상 스타일 3종)
- 슬라이드마다 200~400자 발표자 노트
- 수강생용 실습지 워드 파일
- 슬라이드 목록 JSON (다른 도구에서 재활용)

**차별점**
- 슬라이드가 넘치지 않습니다. 6줄·20자를 프로그램이 검사해서 넘으면 쪼갭니다.
- **발표자 노트가 비어 있는 슬라이드가 없습니다.** 짧으면 채우고 어디를 채워야 하는지 표시합니다.
- 슬라이드를 만들기 전에 커리큘럼을 보여 주고 물어봅니다. 마음에 안 들면 거기서 멈춥니다.
- 외부 이미지에 의존하지 않아 어느 PC에서 열어도 깨지지 않습니다.
- 인공지능기본법(2026.1.22 시행)에 맞춰 고지 슬라이드와 문서 메타데이터를 넣습니다.

**미리 알려드립니다**
- 산출물은 **초안**입니다. 발표자 노트를 본인 말투로 고쳐야 읽을 수 있습니다.
- Claude API 키가 필요하며 사용료는 별도입니다 (한 벌에 천 원 안팎).
- 수강 만족도는 강의 내용과 전달에 달려 있습니다. 이 도구는 자료 만드는 시간을
  줄일 뿐이며 결과는 검증이 필요합니다.
