# 강의 슬라이드 생성기 — 사용 설명서

> 구매해 주셔서 감사합니다.
> **컴퓨터를 잘 모르셔도 따라 하실 수 있게** 하나하나 적었습니다.
> 막히시면 7장을 보시고, 그래도 안 되면 판매자에게 문의해 주세요.

---

## 1장. 무엇을 받으셨나요

강의 주제와 시간을 적으면 **강의 자료 한 벌**을 만들어 드리는 프로그램입니다.

| 파일 | 무엇인가요 |
|---|---|
| `curriculum.md` | 커리큘럼. 모듈별 목표·시간·실습 과제·확인 방법 |
| `deck.pptx` | 슬라이드. **발표자 노트까지 채워져 있습니다** |
| `worksheet.docx` | 수강생에게 나눠 줄 실습지 |
| `deck_outline.json` | 슬라이드 목록. 다른 도구에서 쓰실 때 |

### 이 프로그램이 신경 쓴 두 가지

**1. 발표자 노트가 비어 있지 않습니다.**
슬라이드마다 200~400자로 "여기서 뭘 말할지"가 적혀 있습니다.
강의 직전에 노트가 비어 있으면 슬라이드를 읽게 되고, 그러면 수강생이 지루해합니다.

**2. 슬라이드가 넘치지 않습니다.**
한 줄 20자, 한 장 6줄을 프로그램이 검사합니다.
넘으면 자동으로 나눠서 글자가 화면 밖으로 나가지 않습니다.

### ⚠️ 먼저 알아두셔야 할 것

**나오는 자료는 완성본이 아니라 초안입니다.**

특히 **발표자 노트는 반드시 본인 말투로 고치셔야** 합니다.
남이 쓴 말을 그대로 읽으면 어색하고, 수강생도 금방 압니다.

슬라이드에 `[강사가 채울 곳]` 이라고 적힌 자리가 있습니다.
본인 경험이나 실제 사례로 바꾸세요. 그 작업을 거쳐야 내 강의가 됩니다.

## 2장. 처음 준비 (한 번만)

### 2-1. 파이썬이 있는지 확인

**Windows**: 시작 메뉴에서 `cmd` 검색 → 명령 프롬프트 실행
**Mac**: `터미널` 앱 실행

아래를 치고 엔터:

```
python --version
```

`Python 3.11.0` 처럼 숫자가 나오면 됩니다 (3.11 이상 필요).

**"찾을 수 없습니다"가 나오면** https://www.python.org 에서 내려받아 설치하세요.
Windows 는 설치 첫 화면에서 **"Add Python to PATH" 를 꼭 체크**하셔야 합니다.

### 2-2. 부품 설치

받으신 폴더 안에서:

```
pip install -r requirements.txt
```

### 2-3. AI 키 발급

이 프로그램은 Claude 라는 AI 를 씁니다. **키는 직접 발급받으셔야 합니다.**

1. https://console.anthropic.com 가입 (구글 계정 가능)
2. 왼쪽 **Settings → API Keys → Create Key**
3. `sk-ant-` 로 시작하는 긴 글자가 나옵니다.
   **창을 닫으면 다시 못 보니 메모장에 붙여두세요**
4. 왼쪽 **Billing** 에서 카드 등록 + **10달러 정도 충전**

> **💰 비용 안내**
>
> 강의 자료 한 벌에 **천 원 안팎**의 AI 사용료가 발생합니다.
> 10달러(약 1만 4천 원)면 열 번 넘게 만드실 수 있습니다.
>
> 이 돈은 **판매자가 아니라 AI 회사에 내는 것**입니다.
> 판매자는 이 금액을 받지 않습니다.

### 2-4. 키 넣기

1. 폴더에서 `.env.example` 파일을 찾습니다
2. 복사해서 이름을 **`.env`** 로 바꿉니다 (앞에 점이 있습니다)
3. 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 아까 키를 붙여넣습니다
4. 저장

> ⚠️ 이 파일은 비밀번호와 같습니다. 누구에게도 보내지 마세요.

### 2-5. 관리 화면 켜기

```
python -m dashboard
```

브라우저가 열립니다. 안 열리면 주소창에 `http://127.0.0.1:8000` 입력.
끄실 때는 검은 창에서 `Ctrl` + `C`.

## 3장. 강의 정보 적기

관리 화면에서 **강의 슬라이드 생성기 → 수정 → 입력 파일 편집**을 누릅니다.

```yaml
course_title: "혼자 일하는 사람의 파일 관리 실무"
audience: "혼자 일하며 파일을 직접 관리하는 프리랜서"
total_minutes: 180
instructor: ""
style: minimal
modules: []
```

### 하나씩 설명드리면

**`course_title`** — 실제 강의 제목 그대로 적으세요.

**`audience`** — **여기가 제일 중요합니다.** 좁게 쓸수록 좋은 커리큘럼이 나옵니다.
- 그냥 그런 예: `직장인`
- 좋은 예: `혼자 일하며 파일을 직접 관리하는 3년차 프리랜서 디자이너`

**`total_minutes`** — 강의 시간을 **분 단위 숫자**로. 3시간이면 `180` 입니다.
쉬는 시간은 빼고 순수 강의 시간으로 적으세요.

**`instructor`** — 표지와 실습지에 들어갈 이름. 비우면 자리만 만들어 둡니다.

**`style`** — 슬라이드 색 조합입니다.

| 적을 값 | 언제 쓰나 |
|---|---|
| `minimal` | 기본값. 온라인 강의, 작은 워크숍 |
| `bold` | **큰 강의실**이나 프로젝터 화질이 나쁜 곳. 대비가 강합니다 |
| `corporate` | 회사 사내 교육, 기업 대상 강의 |

**`modules`** — 강의 순서입니다.

비워 두면(`modules: []`) AI 가 5~8개를 제안합니다.
이미 순서가 정해져 있다면 **제목만 적어도 됩니다.** 나머지는 AI 가 채웁니다.

```yaml
modules:
  - title: "왜 지금 정리가 필요한가"
  - title: "자리 정하기"
  - title: "이름 규칙 만들기"
  - title: "버리는 기준"
  - title: "유지하는 법"
```

모듈은 **5개 이상 8개 이하**여야 합니다.

### 편집할 때 주의

- **들여쓰기에 탭 키를 쓰지 마세요.** 스페이스만 씁니다
- 목록 앞의 `- ` (하이픈 + 공백)를 지우지 마세요
- 저장할 때 인코딩을 **UTF-8** 로

## 4장. 만들기

검은 창에서 프로그램 폴더로 이동한 뒤:

```
python cli.py build deck_input.yaml
```

### 4-1. 커리큘럼을 먼저 보여 드립니다

슬라이드를 만들기 전에 커리큘럼이 화면에 나옵니다.

```
  ── 커리큘럼 ──────────────────────────────
  1. 왜 지금 정리가 필요한가  (25분)
     목표: 파일이 쌓이는 진짜 원인을 말할 수 있다
     개념: 기준 없는 저장, 이름의 무질서, 버리지 않는 습관
  ...
  ─────────────────────── 합계 180분

  이 커리큘럼으로 슬라이드를 만들까요? [Y/n]
```

**여기서 꼼꼼히 보세요.** 세 가지를 확인하시면 됩니다.

1. 모듈 제목만 읽어서 순서가 자연스러운가
2. 시간 배분이 맞는가 (합계가 어긋나면 ⚠ 가 뜹니다)
3. 실습 과제를 그 시간 안에 끝낼 수 있는가

마음에 들면 **엔터**(또는 `y`), 아니면 **`n`** 을 누르세요.
`n` 을 누르면 슬라이드를 만들지 않고 끝납니다. 돈도 더 들지 않습니다.

> 💡 **여기가 돈을 아끼는 지점입니다.**
> 커리큘럼은 AI 를 한 번만 부르지만 슬라이드는 모듈 수만큼 부릅니다.
> 커리큘럼이 마음에 안 들면 여기서 멈추고 `modules` 를 직접 적어 다시 실행하세요.

### 4-2. 슬라이드 만들기

`y` 를 누르면 모듈별로 슬라이드를 만듭니다. 2~4분 걸립니다.

```
[2/3] 슬라이드 집필 — 모듈 5개
      1번 모듈 슬라이드 6장 (1회 시도)
      2번 모듈 슬라이드 6장 (1회 시도)
```

### 4-3. 끝나면

```
✓ 본문 규칙 (6줄·20자): 전부 통과
✓ 발표자 노트: 빈 슬라이드 없음
```

⚠ 표시가 나오면 그 내용을 읽고 해당 슬라이드를 확인하세요.

| ⚠ 메시지 | 뜻 |
|---|---|
| `N장이 자동으로 나뉘었습니다` | 글자가 많아 프로그램이 두 장으로 쪼갰습니다. 제목에 `(1/2)` 가 붙습니다 |
| `N장을 자동으로 채웠습니다` | 발표자 노트가 짧아 보충했습니다. `[강사가 채울 곳]` 을 고치세요 |

## 5장. ⚠️ 강의 전에 반드시

### 5-1. 발표자 노트를 본인 말투로 고치기

**이 작업이 가장 중요하고 시간도 제일 많이 걸립니다.**

PowerPoint 에서 슬라이드 아래쪽에 노트가 보입니다.
안 보이면 메뉴에서 **보기 → 발표자 노트**를 켜세요.

한 장씩 읽어 보시고 어색한 문장을 고치세요.
남이 쓴 말을 그대로 읽으면 티가 납니다.

### 5-2. `[강사가 채울 곳]` 표시 처리하기

노트와 슬라이드에 이런 표시가 있습니다.

```
[강사가 채울 곳: 본인 경험이나 현장 사례 한 가지]
```

**본인 이야기로 바꾸세요.** AI 가 만든 일반적인 설명에 본인 사례가 들어가면
강의가 완전히 달라집니다.

### 5-3. 강사 소개 슬라이드 채우기

2번 슬라이드가 비어 있습니다.

```
[경력 한 줄]
[이 주제를 다루는 이유]
[연락처 또는 채널]
```

직접 채우세요. 길게 쓰지 마시고 한 줄씩이면 충분합니다.

### 5-4. 시간 확인

`curriculum.md` 의 시간 합계가 실제 강의 시간과 맞는지 보세요.
**쉬는 시간은 포함되어 있지 않습니다.** 3시간 강의라면 쉬는 시간 10분을 빼고
170분 정도로 잡으셔야 맞습니다.

### 5-5. 실습지 인쇄

`worksheet.docx` 를 열어 보시고 인원수만큼 인쇄하세요.
빈칸 힌트가 너무 쉽거나 어려우면 직접 고치셔도 됩니다.

PowerPoint 에서 그냥 고치시면 됩니다. 글자, 색, 순서 전부 바꿀 수 있습니다.
**외부 이미지 파일을 쓰지 않아서** 다른 컴퓨터로 옮겨도 깨지지 않습니다.

다음에 만들 때부터 적용됩니다. 이미 만든 파일은 PowerPoint 에서 직접 바꾸세요.

## 7장. 안 될 때

| 화면에 이렇게 나오면 | 이렇게 하세요 |
|---|---|
| `모듈은 5~8개여야 합니다` | 직접 적은 모듈 수를 5~8개로 |
| `핵심 개념은 3~5개여야 합니다` | 개념을 3~5개로 하거나 비우세요 |
| `total_minutes` 관련 오류 | 30~960 사이 숫자로 |
| `모르는 스타일입니다` | `minimal`, `bold`, `corporate` 중 하나 |
| `ANTHROPIC_API_KEY 가 없습니다` | 2-4 를 다시 |
| `credit balance` 가 보임 | 충전 잔액이 없습니다. 콘솔 Billing 에서 충전 |
| `쿼터 초과` | 너무 빨리 여러 번 눌렀습니다. **1분 기다렸다가** 다시 |
| `ModuleNotFoundError` | 부품이 안 깔렸습니다. 2-2 를 다시 |
| 한글이 □□□ 로 깨짐 | 저장할 때 인코딩을 **UTF-8** 로 |
| PowerPoint 에서 글꼴이 다르게 보임 | 맑은 고딕이 없는 PC 입니다. 다른 글꼴로 바꿔 쓰세요 |

**그래도 안 되면** 화면 글자를 **그대로 복사**해서 판매자에게 보내주세요.

## 8장. 자주 묻는 것

**Q. 커리큘럼이 마음에 안 듭니다.**
`n` 을 눌러 멈추고, `modules` 에 제목을 직접 적어 다시 실행하세요.
제목만 적어도 나머지는 AI 가 채웁니다. 이게 가장 확실한 방법입니다.

**Q. 슬라이드 몇 장이 나오나요?**
모듈 5개에 개념 4개씩이면 40장 정도입니다. 모듈과 개념 수에 따라 달라집니다.

**Q. 같은 강의로 여러 번 만들어도 되나요?**
네. 돌릴 때마다 조금씩 다르게 나옵니다. (매번 사용료가 듭니다)

**Q. 한 모듈만 다시 만들 수 있나요?**
지금은 전체를 다시 만드셔야 합니다. 대신 커리큘럼 확인 단계에서 멈출 수 있어
잘못된 방향으로 전부 만들어지는 일은 없습니다.

**Q. PDF 로 바꾸려면?**
PowerPoint 에서 "다른 이름으로 저장" → 형식을 PDF 로 고르세요.
발표자 노트까지 인쇄하시려면 인쇄 설정에서 "노트 페이지"를 고르시면 됩니다.

**Q. 구글 슬라이드에서 열리나요?**
열립니다. 다만 글꼴과 색이 조금 다르게 보일 수 있습니다.

**Q. 수강생이 늘어나나요?**
이 도구는 **자료 만드는 시간을 줄여주는 도구**입니다.
수강 만족도와 재수강은 강의 내용과 전달에 달려 있으며 이 도구가 보장하지 않습니다.

## 마지막으로

세 가지만 기억하시면 됩니다.

1. **`audience` 를 좁게 쓴다** — 커리큘럼 품질이 여기서 갈립니다
2. **커리큘럼 확인 단계에서 꼼꼼히 본다** — 여기서 멈추면 돈이 안 듭니다
3. **발표자 노트를 본인 말투로 고친다** — 이게 내 강의로 만드는 작업입니다
