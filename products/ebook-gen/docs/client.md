# 전자책 원고 생성기 — 사용 설명서

> 구매해 주셔서 감사합니다.
> **컴퓨터를 잘 모르셔도 따라 하실 수 있게** 하나하나 적었습니다.
> 막히시면 8장을 보시고, 그래도 안 되면 판매자에게 문의해 주세요.

---

## 1장. 어떻게 만들어지나

전자책 한 권을 **세 번에 나눠** 만듭니다. 한 번에 다 나오지 않습니다.

```
1단계  목차를 만듭니다        →  목차 파일이 생깁니다
       ✋ 여기서 목차를 고칩니다

2단계  각 장의 글을 씁니다    →  장별 파일이 생깁니다
       ✋ 여기서 글을 고칩니다

3단계  워드 파일로 합칩니다   →  ebook.docx 완성
```

**왜 나눠서 하나요?**

한 번에 다 나오면 고치기가 어렵습니다. 60쪽짜리 워드 파일을 받으면
어디를 손대야 할지 막막합니다. 나눠 놓으면 목차만 먼저 보고,
마음에 들 때 글을 쓰고, 한 장씩 고칠 수 있습니다.

### ⚠️ 먼저 알아두셔야 할 것

**나오는 글은 완성본이 아니라 초안입니다. 그대로 팔면 안 됩니다.**

AI가 쓴 문장에는 그럴듯하지만 사실과 다른 내용이 섞일 수 있습니다.
특히 숫자와 사례는 반드시 확인하셔야 합니다.

이 프로그램은 초안을 **고치기 쉽게** 내놓도록 만들어져 있습니다.
2단계에서 나온 파일을 읽고 본인 경험으로 바꾸는 것이 이 도구를 제대로 쓰는 방법입니다.
그 작업을 거쳐야 비로소 팔 수 있는 원고가 됩니다.

## 2장. 처음 준비 (한 번만)

### 2-1. 파이썬이 있는지 확인

**Windows**: 시작 메뉴에서 `cmd` 검색 → 명령 프롬프트 실행
**Mac**: `터미널` 앱 실행

아래를 치고 엔터:

```
python --version
```

`Python 3.11.0` 처럼 숫자가 나오면 됩니다 (3.11 이상 필요).

**"찾을 수 없습니다"가 나오면** https://www.python.org 에서 내려받아 설치하세요.
Windows 는 설치 첫 화면에서 **"Add Python to PATH" 를 꼭 체크**하셔야 합니다.

### 2-2. 부품 설치

받으신 폴더 안에서:

```
pip install -r requirements.txt
```

글자가 쭉 지나가다 멈추면 끝입니다.

### 2-3. AI 키 발급

이 프로그램은 Claude 라는 AI 를 씁니다. **키는 직접 발급받으셔야 합니다.**

1. https://console.anthropic.com 가입 (구글 계정 가능)
2. 왼쪽 **Settings → API Keys → Create Key**
3. `sk-ant-` 로 시작하는 긴 글자가 나옵니다.
   **창을 닫으면 다시 못 보니 메모장에 붙여두세요**
4. 왼쪽 **Billing** 에서 카드 등록 + **20달러 정도 충전**

> **💰 비용 안내 — 이 프로그램은 다른 것보다 비쌉니다**
>
> 전자책 한 권에 **수천 원** 정도의 AI 사용료가 발생합니다.
> 장이 열 개면 AI 를 열세 번쯤 부르고, 각각 2,000자 넘는 글을 쓰기 때문입니다.
>
> 20달러(약 3만 원)를 충전하시면 몇 권은 만드실 수 있습니다.
>
> 이 돈은 **판매자가 아니라 AI 회사에 내는 것**입니다.
> 판매자는 이 금액을 받지 않습니다.
>
> **아끼는 방법**: 1단계(목차)는 한 번만 부르기 때문에 쌉니다.
> 목차가 마음에 들 때까지 1단계를 여러 번 돌리고, 그다음 2단계로 넘어가세요.

### 2-4. 키 넣기

1. 폴더에서 `.env.example` 파일을 찾습니다
2. 복사해서 이름을 **`.env`** 로 바꿉니다 (앞에 점이 있습니다)
3. 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 아까 키를 붙여넣습니다
4. 저장

> ⚠️ 이 파일은 비밀번호와 같습니다. 누구에게도 보내지 마세요.

### 2-5. 관리 화면 켜기

```
python -m dashboard
```

브라우저가 열립니다. 안 열리면 주소창에 `http://127.0.0.1:8000` 입력.
끄실 때는 검은 창에서 `Ctrl` + `C`.

> 이 프로그램은 3단계로 나뉘어 있어서 **명령어를 쓰시는 편이 편합니다.**
> 관리 화면은 설정을 바꾸고 파일을 편집하는 데 쓰시고,
> 실행은 아래 3~5장의 명령어를 쓰세요.

## 3장. 1단계 — 목차 만들기

검은 창에서 프로그램 폴더로 이동한 뒤:

```
python cli.py outline "혼자 일하는 사람의 파일 관리" --audience "혼자 일하며 파일을 직접 관리하는 프리랜서" --pages 40 --author "홍길동"
```

### 각 부분 설명

| 부분 | 무엇을 적나 |
|---|---|
| `"..."` (맨 앞) | 책의 주제. 따옴표로 감싸세요 |
| `--audience "..."` | **누가 읽는 책인지.** 좁게 쓸수록 좋습니다 |
| `--pages 40` | 목표 쪽수. 16~40 사이를 권합니다 |
| `--author "..."` | 표지에 들어갈 이름 |

**`--audience` 를 좁게 쓰세요. 여기가 책의 품질을 가장 크게 좌우합니다.**

- 그냥 그런 예: `"직장인"`
- 좋은 예: `"혼자 일하며 파일을 직접 관리하는 3년차 프리랜서 디자이너"`

### 쪽수에 대해

챕터는 8~12개, 한 장은 1,500~2,500자로 정해져 있습니다.
그래서 만들 수 있는 범위는 **약 16~40쪽**입니다.
이 범위를 벗어나게 적으시면 만들 수 있는 분량을 알려드리고 그대로 진행합니다.

### 끝나면

`outputs/주제이름/outline.yaml` 이라는 파일이 생깁니다.
화면에 정확한 경로가 나오니 그대로 복사해두세요.

## 4장. ✋ 목차 고치기 (중요)

`outline.yaml` 을 메모장으로 엽니다. 이런 내용이 들어 있습니다.

```yaml
title_options:
- 파일이 쌓이지 않는 사람들의 규칙
- '최종2'가 없는 폴더 만들기
- 자리부터 정하는 파일 관리법
subtitle: 도구를 바꾸지 않고 파일 찾는 시간을 줄이는 열 가지 순서
preface: 이 책은 ...
chapters:
- number: 1
  title: 왜 파일이 계속 늘어나는가
  key_message: 문제는 정리 습관이 아니라 저장할 자리를 안 정한 것이다
  subheadings:
  - 저장할 자리를 먼저 정한다
  - ...
  target_chars: 2000
```

### 꼭 확인하실 세 가지

**1. 제목을 고르세요**
`title_options` 에 3안이 있습니다. **마음에 드는 것을 맨 위로 옮기세요.**
맨 위 제목이 표지에 들어갑니다. 직접 쓰셔도 됩니다.

**2. 목차 순서를 보세요**
챕터 제목만 쭉 읽어보세요. 순서가 자연스러운가요?
어색하면 통째로 잘라서 다른 위치에 붙여넣으세요.
(옮기신 뒤 `number:` 를 1부터 순서대로 다시 적어주세요)

**3. `key_message` 를 다듬으세요**
각 장에서 독자가 가져갈 문장 하나입니다.
여기가 흐릿하면 그 장의 글도 흐릿해집니다.

### 지켜야 하는 규칙

- 챕터는 8개 이상 12개 이하
- `number` 는 1부터 빠짐없이 (1, 2, 3...)
- `subheadings` 는 3~5개
- `target_chars` 는 1500~2500 사이

어기시면 2단계에서 어디가 문제인지 알려드립니다. 고치고 다시 실행하시면 됩니다.

### 편집할 때 주의

- **들여쓰기에 탭 키를 쓰지 마세요.** 스페이스만 씁니다
- 목록 앞의 `- ` (하이픈 + 공백)를 지우지 마세요
- 저장할 때 인코딩을 **UTF-8** 로

## 5장. 2단계 — 원고 쓰기

```
python cli.py write outputs/주제이름/outline.yaml
```

(경로는 1단계 끝에 화면이 알려준 것을 그대로 쓰세요)

**시간이 걸립니다.** 장마다 따로 만들기 때문에 열 장이면 5~10분 정도 걸립니다.
한 장씩 끝날 때마다 화면에 나옵니다.

```
 1장 완료 1,977자 (1회 시도)
 2장 완료 2,140자 (2회 시도)
```

`(2회 시도)` 는 처음 쓴 글에 문제가 있어 다시 썼다는 뜻입니다. 정상입니다.

### 한 장이 실패하면

```
 5장 실패 (3회 시도): ...
```

이렇게 나와도 나머지 장은 무사합니다. 그 장만 다시 만들면 됩니다.

```
python cli.py write outputs/주제이름/outline.yaml --only 5
```

여러 장이면 `--only 5 7 9` 처럼 띄어쓰기로 나열하세요.

### 끝나면

`chapters` 폴더에 `ch01.md` 부터 파일이 생깁니다.
마지막에 총 글자 수가 나옵니다.

```
✓ 총 19,764자 (목표 20,000자, 허용 16,000~24,000자)
```

## 6장. ✋ 원고 고치기 (가장 중요)

**여기가 이 프로그램을 제대로 쓰는 지점입니다.**

`chapters` 폴더의 파일을 하나씩 메모장으로 엽니다. 이런 구조입니다.

```markdown
# 1장. 왜 파일이 계속 늘어나는가

## 도입 사례
지난달에 한 분이 ...

## 핵심 설명
### 저장할 자리를 먼저 정한다
...

## 실행 체크리스트
- [ ] 지금 바탕화면에서 파일 다섯 개를 골라 ...

## 요약 3줄
1. ...
```

### 우선순위대로 고치세요

**1. `[저자가 채울 곳: ...]` 표시를 찾으세요**
이런 표시가 있으면 **반드시** 실제 내용으로 바꾸세요. 그대로 두고 팔면 안 됩니다.

**2. 도입 사례를 본인 경험으로**
AI가 만든 사례는 익명의 일반적인 이야기입니다.
**본인이 실제로 겪은 일로 바꾸면 책이 완전히 달라집니다.**
이것 하나만 해도 다른 AI 전자책과 구별됩니다.

**3. 숫자와 출처를 확인하세요**
참고 자료를 넣지 않으셨다면 숫자가 없어야 정상입니다.
혹시 숫자가 보이면 사실인지 꼭 확인하세요.

**4. 체크리스트를 구체적으로**
"꾸준히 관리한다" 같은 항목은 "매주 금요일에 지난주 항목을 지운다" 처럼 바꾸세요.

### ⚠️ 제목 구조는 건드리지 마세요

```
## 도입 사례
## 핵심 설명
## 실행 체크리스트
## 요약 3줄
```

이 네 줄은 3단계가 읽는 **표지판**입니다. 글자를 바꾸거나 지우면
워드 파일을 만들 때 멈춥니다. **안쪽 내용만** 고치세요.

(실수로 바꾸셔도 괜찮습니다. 어느 부분이 문제인지 알려드립니다.)

## 7장. 3단계 — 워드 파일 만들기

```
python cli.py build outputs/주제이름/
```

세 개 파일이 생깁니다.

| 파일 | 무엇인가요 |
|---|---|
| `ebook.docx` | 완성된 워드 파일 |
| `sales_copy.md` | 판매용 소개글, 추천 대상, 가격 제안 3안 |
| `cover_brief.md` | 표지 디자인 지시서 (이미지 만드는 프롬프트 포함) |

### ⚠️ 워드에서 꼭 하실 일

`ebook.docx` 를 열면 목차 자리에 이렇게 보입니다.

```
목차를 업데이트하세요 (F9)
```

**전체 선택(Ctrl+A) 후 F9 를 누르세요.** 목차와 쪽 번호가 채워집니다.
워드가 쪽 번호를 계산하는 방식이라 프로그램이 미리 넣을 수 없습니다.

Mac 의 Pages 나 한글(HWP)에서는 목차가 안 채워질 수 있습니다.
가능하면 **Word 나 LibreOffice** 에서 여세요.

### 원고를 더 고치고 싶으면

`chapters` 폴더의 파일을 고치고 3단계를 다시 실행하시면 됩니다.
몇 번을 돌려도 됩니다. **이때는 AI 를 부르지 않는 부분이 많아 비용이 적게 듭니다.**

다만 `sales_copy.md` 와 `cover_brief.md` 는 다시 만들어집니다.
그 파일을 손보셨다면 다른 이름으로 복사해두세요.

## 8장. 안 될 때

| 화면에 이렇게 나오면 | 이렇게 하세요 |
|---|---|
| `목차 파일이 없습니다` | 경로가 틀렸습니다. 1단계가 알려준 경로를 그대로 복사하세요 |
| `챕터 번호는 1부터 빠짐없이` | 목차를 고치다 번호가 꼬였습니다. 1, 2, 3... 순서로 |
| `target_chars` 관련 오류 | 1500~2500 사이 숫자로 |
| `'실행 체크리스트' 를 찾지 못했습니다` | 6장의 제목 구조를 바꾸셨습니다. 원래대로 |
| `원고가 없습니다` | 2단계를 먼저 실행하세요 |
| `ANTHROPIC_API_KEY 가 없습니다` | 2-4 를 다시 |
| `credit balance` 가 보임 | 충전 잔액이 없습니다. 콘솔 Billing 에서 충전 |
| `쿼터 초과` | 너무 빨리 여러 장을 불렀습니다. **1분 기다렸다가** `--only` 로 남은 장만 |
| 워드에서 목차가 비어 있음 | Ctrl+A 후 F9 |
| 한글이 □□□ 로 깨짐 | 저장할 때 인코딩을 **UTF-8** 로 |

**그래도 안 되면** 화면 글자를 **그대로 복사**해서 판매자에게 보내주세요.

## 9장. 자주 묻는 것

**Q. 목차가 마음에 안 듭니다.**
1단계를 다시 실행하세요. 돌릴 때마다 조금씩 다르게 나옵니다.
1단계는 AI 를 한 번만 부르기 때문에 비용이 적습니다. 여러 번 돌려보세요.

**Q. 한 장만 다시 쓰고 싶습니다.**
`python cli.py write outputs/주제이름/outline.yaml --only 3` (3장만 다시)

**Q. 전부 다시 쓰고 싶습니다.**
`--overwrite` 를 붙이세요. 다만 비용이 다시 전부 듭니다.

**Q. PDF 로 바꾸려면?**
워드에서 "다른 이름으로 저장" → 형식을 PDF 로 고르시면 됩니다.

**Q. EPUB(전자책 형식)으로 만들려면?**
이 프로그램은 워드까지만 만듭니다. EPUB 변환은 별도 도구를 쓰셔야 합니다.

**Q. 표지는 어떻게 만드나요?**
`cover_brief.md` 에 디자인 지시서가 있습니다.
맨 아래 영문 프롬프트를 이미지 생성 도구에 그대로 넣으면 배경 이미지가 나옵니다.
글자는 나중에 따로 얹으세요.

**Q. 참고 자료를 넣을 수 있나요?**
1단계에 `--evidence "자료1" "자료2"` 로 넣으실 수 있습니다.
넣지 않으시면 책에 숫자를 만들어 넣지 않습니다. **안 넣는 편이 안전합니다.**

**Q. 이 책이 팔리나요?**
