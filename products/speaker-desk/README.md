# 16. 해외 연사 초청 관리 (speaker-desk)

국제 컨퍼런스에 해외 연사를 부를 때 **돈과 일정이 어긋나는 세 지점**을 잡습니다.

> **법률·세무 자문이 아닙니다.**
> 체류자격은 출입국·주한공관에, 원천징수는 세무대리인에게 확인하세요.
> 이 프로그램은 **무엇을 확인해야 하는지**를 좁혀 줍니다.

---

## 1. 실무에서 터지는 세 가지

### ① "무비자 나라니까 그냥 오시면 됩니다"

**강연료를 받으면 그렇지 않습니다.** 대가를 받는 강연은 취업활동으로 봅니다.
사증면제(K-ETA)로 들어와 돈을 받고 강연하면 체류자격 외 활동이 됩니다.

이게 가장 많이 틀리는 지점이고, 틀리면 **연사가 공항에서 돌아갑니다.**

```bash
python cli.py visa --paid --days 5 --waiver
```

### ② "강연료 500만 원" 이라고만 쓴 계약서

비거주자에게 국내 인적용역 대가를 지급하면 **지급하는 쪽이 원천징수**를 합니다
(소득세법 제156조). 소득세 20% + 지방소득세 2% = **합계 22%**.

계약서에 "500만 원" 이라고만 써 놓으면 연사는 500만 원을 기대하고 실제로는
390만 원을 받습니다. **그 자리에서 분쟁이 납니다.**

정할 것은 하나입니다.

| 방식 | 뜻 | 주최 측 부담 |
|---|---|---|
| **gross** | 500만 원에서 떼고 390만 원 송금 | 500만 원 |
| **net** | 연사 손에 500만 원이 가도록 | **641만 원** |

```bash
python cli.py tax 5000000 --basis net
```

### ③ 거주자증명서를 늦게 요청

조세조약이 있으면 면제되거나 제한세율이 적용될 수 있습니다. **자동이 아닙니다.**
연사가 거주국 세무당국에서 **거주자증명서**를 받아 와야 하고,
**지급일 전에** 손에 있어야 합니다.

늦으면 기본 세율로 떼고 나중에 경정청구를 해야 하는데 훨씬 번거롭습니다.
나라에 따라 발급에 몇 주가 걸립니다. 그래서 체크리스트에서 **D-80** 에 세웠습니다.

## 2. 무엇을 만들어 주나

```bash
python cli.py brief --demo          # 연사별 브리프 (한 장짜리)
python cli.py checklist --demo      # D-120 역산 일정
python cli.py budget --demo         # 결재용 예산 (xlsx)
python cli.py letter --demo         # 영문 초청장 + 계약서 초안 (docx)
```

| 산출물 | 무엇 |
|---|---|
| **브리프** | 연사 한 명의 비자·돈·일정·예산을 한 장에 |
| **체크리스트** | D-120 에서 역산. 놓치면 못 되돌리는 일에 **(필수)** 표시 |
| **예산 xlsx** | 결재 올릴 때 그대로 씁니다 |
| **초청장** | 영문. 비자 신청에 그대로 냅니다 |
| **계약서 초안** | 영문. **세금 조항을 흐리지 않습니다** |

---

## 3. 체크리스트가 D-120 부터인 이유

일정이 터지는 이유는 대개 하나입니다. **비자를 늦게 시작해서.**
초청장은 하루면 쓰지만 비자 심사는 못 당깁니다.

| D-day | 할 일 | 필수 |
|---|---|---|
| D-120 | 연사 확정과 구두 합의 | |
| D-110 | **체류자격 확인** | ✓ |
| D-100 | 초청장 발급 | ✓ |
| D-95 | 계약서 (세전/세후를 여기서 정합니다) | ✓ |
| D-90 | 비자 신청 시작 | ✓ |
| D-80 | **거주자증명서 요청** | ✓ |
| D-30 | 비자 발급 확인 (대안을 찾을 마지막 시점) | ✓ |
| D-7 | 원천징수 서류 최종 확인 | ✓ |
| D+7 | 사례비 지급과 원천징수 신고 | ✓ |

`(필수)` 는 **놓치면 되돌릴 수 없는 일**입니다. 날짜가 지났는데 안 끝났으면
브리프가 빨갛게 표시합니다.

## 4. 시차도 봅니다

리허설을 도착 다음 날 오전에 잡아 놓고 연사가 못 일어나는 일이 실제로 있습니다.

```
시차 14시간. 도착 다음 날 오전 일정은 피하세요.
리허설은 도착 이틀째 오후가 무난합니다.
```

명부에 `utc_offset` 만 적으면 자동으로 나옵니다.

## 6. 명부 쓰는 법

`event.yaml` 에 행사와 연사를 적습니다.

```yaml
speakers:
  - name: Jane Doe
    country: United States
    fee_krw: 5000000
    fee_basis: net          # gross 면 이 금액에서 세금을 뗍니다
    treaty_rate:            # 비우면 기본 22%
    visa_waiver: true
    arrival: 2026-11-18
    departure: 2026-11-22
    utc_offset: -5
```

- `fee_krw: 0` + `expenses_only: true` → 대가 없이 실비만. **비자 판단이 달라집니다**
- 강연료가 있는데 `expenses_only` 를 켜면 프로그램이 거절합니다. 둘 다일 수 없습니다

## 7. 한계

- **판정하지 않습니다.** 확인할 방향을 좁혀 줄 뿐입니다
- 조세조약 적용 여부와 세율은 사안마다 다릅니다. 기본 세율로 계산합니다
- 비자 심사 기간은 나라마다 다르고 예고 없이 바뀝니다
- 통역비·항공비는 입력한 값을 그대로 씁니다. 시세 조회 기능이 없습니다

---

## 8. 판매 문구 초안

> 해외 연사 초청에서 **돈과 일정이 어긋나는 지점**을 미리 잡아 드립니다.
>
> - 강연료를 주는지·며칠 머무는지로 **어느 체류자격을 확인해야 하는지** 좁힙니다
> - 원천징수 22%를 **세전으로 적을지 세후로 적을지** 계약 전에 계산해 드립니다
> - 거주자증명서처럼 **늦으면 못 되돌리는 서류**를 D-120 역산 일정에 세웁니다
> - 영문 초청장과 계약서 초안, 결재용 예산 엑셀까지
>
> **법률·세무 자문이 아닙니다.** 체류자격은 출입국·주한공관에, 원천징수는
> 세무대리인에게 확인하셔야 합니다. 이 프로그램은 확인할 것을 빠뜨리지 않게
> 해 드립니다.
