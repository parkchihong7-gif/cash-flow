# 해외 연사 초청 관리 — 사용 설명서

---

## 1. 이 프로그램이 해 드리는 것

해외 연사를 부를 때 **빠뜨리기 쉬운 것**을 짚어 드립니다.

1. 어떤 **체류자격(비자)** 을 확인해야 하는지
2. 사례비에서 **세금이 얼마나 빠지는지**, 계약서에 어떻게 적어야 하는지
3. **언제까지 무엇을 해야 하는지** (D-120 부터 역산)
4. 영문 **초청장**과 **계약서 초안**, 결재용 **예산 엑셀**

---

## 2. 먼저 아셔야 할 것

### 이 프로그램은 정해 드리지 않습니다

비자 종류를 정하는 것은 출입국이고, 세금을 확정하는 것은 세무대리인입니다.
이 프로그램은 **무엇을 물어봐야 하는지**를 정리해 드립니다.

실무에서 사고는 대부분 "물어봐야 하는 줄 몰라서" 납니다. 거기를 메웁니다.

### 인터넷도 계정도 필요 없습니다

바깥으로 나가는 통신이 없습니다. 연사 개인정보가 컴퓨터 밖으로 안 나갑니다.

---

## 3. 실무에서 가장 많이 터지는 세 가지

### ① "무비자 나라니까 그냥 오시면 됩니다"

**강연료를 드리면 그렇지 않습니다.**

대가를 받는 강연은 '일' 로 봅니다. 무비자나 K-ETA 로 들어와서 돈을 받고
강연하시면 체류자격에 안 맞는 활동이 됩니다.

**여기서 틀리면 연사분이 공항에서 돌아가십니다.**

```
python cli.py visa --paid --days 5 --waiver
```

### ② "강연료 500만 원" 이라고만 쓴 계약서

외국에 사시는 분께 국내에서 강연료를 드리면 **주최 측이 세금을 떼고** 드려야
합니다. 소득세 20% + 지방소득세 2% = **합계 22%** 입니다.

계약서에 "500만 원" 이라고만 쓰면

- 연사분은 **500만 원**을 받으실 줄 아시고
- 실제로는 **390만 원**이 송금됩니다

그 자리에서 얼굴 붉히는 일이 생깁니다.

**정하실 것은 하나입니다.**

| 어떻게 적나 | 연사가 받는 돈 | 주최 측이 쓰는 돈 |
|---|---|---|
| 세전 500만 원 (gross) | 390만 원 | 500만 원 |
| **세후 500만 원 (net)** | 500만 원 | **641만 원** |

```
python cli.py tax 5000000 --basis net
```

**이 141만 원이 예산에서 빠져 있는 경우가 아주 많습니다.**

### ③ 거주자증명서를 늦게 요청

나라에 따라 세금을 **면제받거나 덜 낼 수** 있습니다(조세조약).
다만 자동이 아닙니다. 연사분이 **본국 세무당국에서 서류를 받아 오셔야** 합니다.

그리고 **돈을 드리기 전에** 그 서류가 손에 있어야 합니다.
늦으면 일단 다 떼고 나중에 돌려받는 절차를 밟아야 하는데 훨씬 번거롭습니다.

나라에 따라 발급에 **몇 주**가 걸립니다. 그래서 체크리스트에서 D-80 에 있습니다.

## 4. 준비

### 컴퓨터

집이나 사무실 컴퓨터면 됩니다.

### 비용

**0원입니다.** 계정도 API 키도 필요 없고, 외부 서비스를 부르지 않습니다.

### 설치

```
pip install -r requirements.txt
```

## 5. 쓰는 순서

### 5-1. 명부 만들기

`event.yaml` 을 메모장으로 열어 고치시면 됩니다.

```yaml
title: 국제 AI 컨퍼런스 2026
event_date: 2026-11-20
venue: 서울 코엑스
host: 한국인공지능학회

speakers:
  - name: Jane Doe
    country: United States
    fee_krw: 5000000
    fee_basis: net          gross 면 이 금액에서 세금을 뗍니다
    visa_waiver: true
    arrival: 2026-11-18
    departure: 2026-11-22
    utc_offset: -5          연사 현지 시차
```

**사례비가 없고 항공·숙박만 대 드리는 경우**는 이렇게 적습니다.

```yaml
    fee_krw: 0
    expenses_only: true
```

이 값에 따라 **비자 판단이 달라집니다.** 정확히 적어 주세요.

### 5-2. 브리프 만들기

```
python cli.py brief --input event.yaml
```

연사 한 분당 한 장짜리 문서가 나옵니다. 담당자가 들고 다니는 문서입니다.

### 5-3. 체크리스트 보기

```
python cli.py checklist --input event.yaml
```

기본은 **지난 것과 곧 닥칠 것**만 보여 드립니다.
전부 보시려면 `--all` 을 붙이세요.

`(필수)` 표시는 **놓치면 되돌릴 수 없는 일**입니다.

### 5-4. 예산 엑셀

```
python cli.py budget --input event.yaml
```

결재 올리실 때 그대로 쓰시면 됩니다.

### 5-5. 초청장과 계약서

```
python cli.py letter --input event.yaml --speaker "Jane Doe"
```

`.txt` 와 `.docx` 두 가지로 나옵니다.

- **초청장** — 비자 신청에 그대로 내시면 됩니다
- **계약서** — **초안**입니다. 서명 전에 검토를 받으세요

## 6. 시차도 봅니다

리허설을 도착 다음 날 오전에 잡아 놓고 연사분이 못 일어나시는 일이
실제로 있습니다.

명부에 `utc_offset` 만 적으시면 브리프에 이렇게 나옵니다.

> 시차 14시간. 도착 다음 날 오전 일정은 피하세요.
> 리허설은 도착 이틀째 오후가 무난합니다.

## 8. 문서는 초안입니다

계약서는 **초안**입니다. 문서 안에도 영문·국문으로 적혀 있습니다.
법률 자문이 아니니 서명 전에 꼭 검토를 받으세요.

특히 이 두 조항은 **비워 두었습니다.** 직접 정하셔야 합니다.

- **녹화물 사용 범위와 기간** — 가장 흔한 분쟁 거리입니다
- **취소 조항** — 특히 **비자가 안 나왔을 때** 어떻게 할지

## 9. 자주 묻는 것

**Q. 비자 대행도 해 주나요**
아니요. 행정사 업무입니다. 무엇이 필요한지만 정리해 드립니다.

**Q. 세금 신고도 해 주나요**
아니요. 세무대리인 업무입니다. 계산해 보고 서류 목록을 드립니다.

**Q. 조세조약 세율을 알려 주나요**
자동으로는 안 됩니다. 조약마다 다릅니다. 세무대리인께 확인하신 뒤
`treaty_rate` 에 넣으시면 계산에 반영됩니다.

**Q. 연사 개인정보가 밖으로 나가나요**
안 나갑니다. 인터넷을 쓰지 않습니다. 다만 `event.yaml` 파일 자체에
이름·소속·이메일이 들어 있으니 파일 관리는 조심하세요.

**Q. 90일 넘게 머무시면요**
단기 체류자격으로는 안 됩니다. 프로그램이 그렇게 알려 드리고,
준비 기간이 훨씬 길어집니다.
