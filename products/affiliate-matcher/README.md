# 10. 제휴 상품 매칭 로직 (affiliate-matcher)

원고(대본·블로그 글·릴스 캡션)를 읽고 **어느 문단에 어떤 상품을 어떤 문장으로
붙이면 되는지**를 표로 만들어 줍니다. 쿠팡파트너스 링크 후보까지 모읍니다.

상품을 골라 주는 도구가 아닙니다. **자리를 찾아 주는 도구**입니다.
무엇을 붙일지는 쓰는 사람이 정합니다. 프로그램이 상품까지 정하면 본문과 무관한
물건이 섞이고, 그게 이 바닥에서 신뢰를 잃는 가장 빠른 길이라서요.

---

## 1. 무엇이 나오나

`outputs/<원고 이름>/` 아래 세 개입니다.

| 파일 | 무엇 |
|---|---|
| `insert_plan.md` | **사람이 보는 표.** 어느 문단 뒤에 무엇을, 어떤 문장으로 |
| `matches.json` | 전체 결과. 다른 도구로 넘길 때 |
| `disclosure.txt` | 대가성 문구와 채널별로 넣는 자리 |

세 파일 **전부 맨 위에 대가성 문구가 붙습니다.** 지우는 옵션은 없습니다.

---

## 2. 설치

```bash
pip install -r requirements.txt     # 루트 requirements.txt 로도 됩니다
cp .env.example .env                # ANTHROPIC_API_KEY 를 넣으세요
```

쿠팡 API 키는 **없어도 됩니다.**

```
COUPANG_ACCESS_KEY=...    # 있으면 실제 상품 후보 5개 + 추적 링크
COUPANG_SECRET_KEY=...    # 없으면 검색 주소만. 오류가 아닙니다
```

파트너스 오픈 API 는 실적 요건이 있어 가입 직후에는 안 열릴 수 있습니다.
키가 없어도 "3번 문단 뒤에 '캠핑 의자' 로 찾은 상품을 붙이면 된다" 까지는 나옵니다.

---

## 3. 사용법

```bash
# 원고 한 편 읽기
python cli.py run data/samples/캠핑_유튜브_대본.md

# 비용 없이 형태만 보기
python cli.py run 원고.md --dry-run

# 수수료율 표와 근거 보기
python cli.py rates --sources

# 결과 파일만 다시 검사
python cli.py check outputs/<폴더>/matches.json
```

종료 코드: `0` 문제없음 / `2` 만들었지만 사람이 볼 곳이 있음 / `1` 오류.

---

## 4. 어떻게 도나

```
원고
 └ extract  Claude 1회 — 상품 이야기가 나온 자리를 뽑습니다
     ├ 문단 번호 · 문맥 문장
     ├ 쿠팡 카테고리 · 검색 키워드 3개
     ├ 구매 의도 강도 1~5          ← 여기가 핵심입니다
     └ 자연스러운 삽입 문장
 └ score    수수료율 × 객단가 × 의도 가중치 = 우선순위
 └ links    키가 있으면 API, 없으면 검색 주소
 └ output   파일 3개 (대가성 문구 강제)
```

### 구매 의도 강도

| 강도 | 뜻 | 계획에 |
|---|---|---|
| 5 | 지금 사려 한다 | ✅ |
| 4 | 무엇을 살지 고르는 중 | ✅ |
| 3 | 관심은 있으나 살 때가 아니다 | ✅ |
| 2 | 맥락만 겹친다 | ❌ 뺍니다 |
| 1 | 스쳐 지나간다 | ❌ 뺍니다 |

**2 이하는 점수가 낮은 게 아니라 가중치가 0 입니다.** 본문과 무관한 상품을
끼워 넣지 않기 위해서입니다. 뺀 것도 "왜 뺐는지" 와 함께 표 아래에 남겨 둡니다.

### 우선순위 점수

```
1건 수수료 = 객단가 추정 × 카테고리 수수료율
우선순위   = 1건 수수료 × 구매 의도 가중치
```

일부러 단순하게 두었습니다. **더 정교하게 만들 근거가 없어서**입니다.
전환율을 알려면 본인 파트너스 화면의 실측이 있어야 하는데, 그건 이 프로그램이
가질 수 없는 값입니다. 없는 정밀도를 흉내 내면 그 숫자를 믿게 됩니다.

## 5. 수수료율 표

`data/commission_rates.yaml` 한 장이 원본입니다. 코드에는 숫자가 없습니다.

- **모든 줄에 근거(`source`)가 있어야 합니다.** 비면 프로그램이 표를 읽지 않습니다.
- 기본 3%, 뷰티·패션·스포츠·출산육아는 상향 구간입니다(CLAUDE.md §2-1).
- 상향/하향 구간은 **추정값**이라고 줄마다 적어 두었습니다. 쿠팡은 요율을 예고
  없이 바꿉니다. 파트너스 화면에서 확인하고 이 파일을 고쳐 쓰세요.
- 객단가는 실거래 통계가 아니라 **카테고리 감각치**입니다.

```bash
python cli.py rates --sources    # 근거 문장까지 봅니다
```

## 6. 쿠팡 API 서명

공식 문서에 적힌 규칙 그대로 구현했습니다.

```
message   = signed-date + METHOD + path + query     (물음표는 빼고 잇습니다)
signature = HMAC-SHA256(secret, message) 16진수 소문자
header    = CEA algorithm=HmacSHA256, access-key=..., signed-date=..., signature=...
```

`signed-date` 는 **GMT 기준** `yymmddTHHMMSSZ` 입니다.

⚠️ 이 저장소를 만든 환경에서는 `api-gateway.coupang.com` 에 닿지 못해
**실제 응답으로 검증하지 못했습니다.** 조립 규칙은 테스트로 고정해 두었습니다.
처음 쓰실 때 401 이 나면 이 순서로 보세요.

1. ACCESS 와 SECRET 을 바꿔 넣지 않았는지
2. **컴퓨터 시계가 맞는지** — 5분 이상 틀어지면 거절합니다
3. 키 앞뒤에 공백이나 따옴표가 붙지 않았는지

---

## 7. 이것만은 지켜 주세요

### 대가성 문구는 옵션이 아닙니다

쿠팡파트너스는 문구가 없으면 **경고 없이** 자격을 정지합니다.
유튜브는 유료 프로모션을 알리지 않으면 영상을 내립니다.

그래서 이 프로그램은 문구 없이는 파일을 저장하지 않습니다. 끄는 옵션도 없습니다.
옵션으로 두면 언젠가 꺼지기 때문입니다.

### 자가 구매 유도는 규격에서 막습니다

"제 링크로 사시면", "페이백", "캐시백", "수수료 나눠" 같은 표현이 삽입 문장에
들어가면 파일을 만들지 않습니다. 파트너스는 본인 구매를 금지하고, 걸리면 계정이
끊깁니다.

### 안 써 본 물건을 써 본 것처럼 쓰지 마세요

프로그램이 막을 수 없는 유일한 것입니다. 한 번 어긴 채널은 댓글로 먼저 알려집니다.

### 비공식 자동화는 하지 않습니다

로그인 매크로도, 비밀번호 저장도 없습니다. 공식 API 와 검색 주소뿐입니다
(CLAUDE.md §3-7).

## 8. 한계

- **전환율을 모릅니다.** 우선순위는 순서를 정하는 눈금이지 수익 예측이 아닙니다.
- **유튜브 쇼핑은 API 로 못 붙입니다.** 스튜디오에서 손으로 태그하셔야 합니다.
  2026년 3월부터 구독자 500명 + YPP 면 쓸 수 있고 플랫폼 수수료는 없습니다.
- **쿠팡 쿠키는 24시간**이고 정산은 다다음 달 15일입니다. 오늘 클릭이 이번 달
  수입이 아닙니다.
- 원고가 너무 길면(2만 자 초과) 앞부분만 봅니다. 나눠서 돌리세요.

---

## 9. 판매 문구 초안

> 원고를 읽고 **어디에 무엇을 붙일지** 표로 만들어 드립니다.
>
> - 문단 단위로 자리를 찍어 줍니다. "이 글 어딘가" 가 아니라 "3번 문단 뒤" 로요.
> - 구매 의도가 약한 대목은 **일부러 뺍니다.** 본문과 겉도는 링크가 채널을 깎습니다.
> - 대가성 문구가 산출물마다 자동으로 붙습니다. 빠뜨려서 자격 정지되는 일을 막습니다.
> - 쿠팡 API 키가 있으면 상품 후보와 추적 링크까지, 없으면 검색 주소까지.
>
> 수익을 약속하지 않습니다. 원고를 읽고 자리를 찾는 시간을 줄여 드리는 도구입니다.
> 무엇을 붙일지, 그 물건을 실제로 써 봤는지는 쓰는 분이 정하십니다.
