# 고객용 매뉴얼 — 제휴 상품 매칭 도구

글이나 대본을 쓰시고, 거기에 제휴 링크를 붙이시는 분을 위한 도구입니다.

원고를 넣으면 **어느 문단 뒤에 어떤 상품을 어떤 문장으로 넣을지** 표로 나옵니다.

---

## 1장. 먼저 아셔야 할 것

이 도구는 **자리를 찾아 줍니다. 상품을 골라 주지 않습니다.**

```
원고를 읽는다 → 상품 이야기가 나온 자리를 찾는다 → 표로 정리한다
                                                    ↓
                                          무엇을 붙일지는 사장님이 정하십니다
```

왜 이렇게 만들었냐면, 프로그램이 상품까지 정하면 **본문과 상관없는 물건**이
섞여 들어가기 때문입니다. 그런 글은 읽는 사람이 바로 압니다. 그리고 한 번
그렇게 느낀 독자는 다시 오지 않습니다.

그래서 이 도구는 **일부러 덜 합니다.**

### 수익을 약속하지 않습니다

이 도구가 줄이는 것은 시간입니다. 글 하나에 링크 붙일 자리를 찾고 키워드를
정하는 데 드는 30~40분을요. 팔리고 안 팔리고는 글의 힘이지 도구의 힘이 아닙니다.

---

## 2장. 관리 화면 쓰는 법

브라우저에서 관리 화면을 열고 왼쪽에서 **10번 제휴 상품 매칭**을 고릅니다.

| 탭 | 여기서 하는 일 |
|---|---|
| **열람** | 이용 순서·FAQ·이 매뉴얼 |
| **수정** | 수수료율 표, 추출 규칙, 샘플 원고 |
| **테스트** | 모의 실행 / 실제 실행 |
| **회원관리** | 이 프로그램을 사 간 고객 |
| **설정** | AI 모델, 쿠팡 키 |

### 순서

1. **테스트** 탭에서 **모의 실행**을 먼저 누르세요. 비용이 0원입니다.
   샘플 원고로 산출물이 어떤 모양인지 봅니다.
2. 형태가 마음에 들면 본인 원고로 돌립니다.
3. 나온 `insert_plan.md` 를 **읽고 고치세요.** 그대로 쓰지 마시고요.

---

## 3장. 터미널로 쓰기

```
python cli.py run 내원고.md --medium "블로그"
```

한 편에 30초쯤 걸리고 비용은 수십 원 수준입니다.

### 원고 준비

- 마크다운이든 텍스트든 됩니다.
- **문단을 빈 줄로 나눠 주세요.** 이게 "어디에" 를 정하는 기준입니다.
- 빈 줄이 하나도 없으면 줄 단위로 자릅니다. 대본은 이래도 됩니다.
- 2만 자가 넘으면 앞부분만 봅니다. 긴 글은 나눠 돌리세요.

### 그 밖의 명령

```
python cli.py run 원고.md --dry-run     # 비용 없이 형태만
python cli.py rates --sources           # 수수료율과 그 근거 보기
python cli.py check outputs/<폴더>/matches.json
```

## 4장. 나오는 파일 3개

| 파일 | 누가 봅니까 |
|---|---|
| `insert_plan.md` | **사장님이 보는 표.** 이것만 보셔도 됩니다 |
| `matches.json` | 다른 도구로 넘길 때 |
| `disclosure.txt` | 대가성 문구. **반드시 쓰셔야 합니다** |

### insert_plan.md 읽는 법

**넣을 자리** 표가 먼저 나옵니다.

| 자리 | 카테고리 | 의도 | 검색 키워드 | 1건 수수료 추정 | 우선순위 |
|---|---|---|---|---|---|
| 3 뒤 | 스포츠레저 | 5 | 캠핑 의자 / 경량 폴딩 체어 / … | 3,600원 | 3,600 |

- **자리** — "3번 문단 뒤" 라는 뜻입니다. 문단은 0번부터 셉니다.
- **의도** — 그 대목에서 독자가 얼마나 사고 싶어 하는지 1~5.
- **1건 수수료** — 하나 팔렸을 때 받는 돈 추정입니다. **추정입니다.**
- **우선순위** — 어디부터 붙일지 정하는 순서입니다.

그 아래에 자리마다 **넣을 문장**과 **링크 후보**가 붙습니다.

---

## 5장. 반드시 고치셔야 하는 것

나온 것은 **초안**입니다. 그대로 올리면 티가 납니다.

### 삽입 문장은 말투를 바꾸세요

프로그램이 만든 문장은 평범합니다. 사장님 글에서 그 문장만 튀면 독자가
"여기서 광고 시작이구나" 하고 압니다.

```
프로그램:  제가 쓰는 건 1kg 아래 접이식인데, 이 기준만 지켜도 됩니다.
고쳐서:    저는 지금 세 번째 의자 쓰는데요, 1kg 넘어가면 진짜 안 들고 다니게 돼요.
```

### 써 보지 않은 물건은 써 본 것처럼 쓰지 마세요

**이 도구가 막을 수 없는 유일한 것입니다.** 그리고 한 번 어기면 댓글로 먼저
알려집니다. 안 써 봤으면 "저는 아직 안 써 봤는데 평이 좋더라고요" 라고
쓰시면 됩니다. 그 편이 오래갑니다.

### 링크한 상품을 꼭 열어 보세요

품절됐거나, 가격이 두 배가 됐거나, 판매자가 바뀐 경우가 생각보다 잦습니다.
품절 링크를 누른 독자는 그 글 전체를 안 믿게 됩니다.

---

## 6장. 대가성 문구 — 이건 선택이 아닙니다

`disclosure.txt` 에 있는 문구를 **반드시** 넣으셔야 합니다.

| 채널 | 어디에 | 안 넣으면 |
|---|---|---|
| 블로그 | 본문 **맨 위** | 쿠팡파트너스 자격 정지 |
| 유튜브 | '유료 프로모션 포함' 체크 + 설명란 첫 줄 | 영상이 내려갑니다 |
| 인스타 | 캡션 **첫 줄** | 게시물 제재 |

### 맨 아래에만 두면 안 한 것과 같습니다

공정위 지침이 "본문 첫머리에, 소비자가 쉽게 알아볼 수 있게" 를 요구합니다.
글 맨 끝에 회색 작은 글씨로 넣는 것은 안 넣은 것으로 봅니다.

### 쿠팡은 경고를 주지 않습니다

다른 플랫폼처럼 "고치세요" 하고 알려 주지 않습니다. 어느 날 정지됩니다.
그래서 이 프로그램은 **문구 없이는 파일을 만들지 않습니다.** 끄는 옵션도
넣지 않았습니다.

### 자가 구매는 하지 마세요

본인 링크로 본인이 사는 것은 파트너스 규정 위반입니다. 가족 명의도 위험합니다.
"제 링크로 사시면 페이백 드려요" 같은 안내도 마찬가지입니다. 이런 문장이
들어가면 프로그램이 파일 만들기를 거부합니다.

## 7장. 쿠팡 API 키 (선택)

**없어도 됩니다.** 없으면 검색 주소만 만들고 정상으로 끝납니다.

| | 키 있을 때 | 키 없을 때 |
|---|---|---|
| 자리 찾기 | ✅ | ✅ |
| 키워드 | ✅ | ✅ |
| 삽입 문장 | ✅ | ✅ |
| 상품 후보 5개 | ✅ | ❌ 검색 화면 주소만 |
| 추적 링크 | ✅ | ❌ 직접 만드셔야 합니다 |

키는 쿠팡파트너스 사이트에서 발급합니다. **실적 요건이 있어 가입 직후에는
안 열릴 수 있습니다.** 안 열려도 이 도구를 쓰시는 데 큰 지장은 없습니다.

키를 넣으셨는데 오류가 나면 이 순서로 보세요.

1. ACCESS 와 SECRET 을 바꿔 넣지 않았는지
2. **컴퓨터 시계가 맞는지** — 5분만 틀어져도 거절합니다. 이게 제일 흔합니다
3. 키 앞뒤에 공백이나 따옴표가 붙지 않았는지

---

## 8장. 숫자를 어디까지 믿을까

**전부 추정입니다.** 다음 세 가지는 특히 그렇습니다.

1. **수수료율** — 기본 3% 만 조사값이고, 상향·하향 구간은 추정입니다.
   쿠팡은 요율을 예고 없이 바꿉니다.
2. **객단가** — 카테고리 감각치입니다. 실거래 통계가 아닙니다.
3. **의도 가중치** — 전환율을 아는 숫자가 아닙니다.

그래서 **우선순위 점수는 수익 예측이 아니라 순서**입니다.
"이걸 붙이면 3,600원 번다" 가 아니라 "이쪽부터 붙이는 게 낫다" 입니다.

### 본인 숫자로 바꾸시면 달라집니다

`data/commission_rates.yaml` 의 객단가를 사장님 채널에서 실제로 팔리는 가격대로
바꾸시면 우선순위가 크게 달라집니다. 파트너스 화면에서 실제 요율도 확인해서
같이 고치세요.

---

## 9장. 돈이 언제 들어오나

이걸 모르고 시작하시면 한 달 뒤에 실망하십니다.

- **쿠키는 24시간**입니다. 오늘 클릭한 사람이 내일모레 사면 안 잡힙니다.
- **정산은 다다음 달 15일**입니다. 9월에 발생한 것이 11월 15일에 들어옵니다.
- 기본 수수료는 3% 입니다. 3만 원짜리를 팔면 900원입니다.

그래서 이건 한 달 해 보고 판단할 일이 아닙니다. 석 달은 지나야 흐름이 보입니다.

## 10장. 자주 묻는 질문

**Q. 넣을 자리가 없다고 나옵니다.**
상품 이야기가 없는 글일 수 있습니다. 그러면 그게 맞는 답입니다.
억지로 넣으면 본문과 겉돌고, 그런 글은 한 번 읽히고 끝납니다.

**Q. 의도 2 이하는 왜 빼나요?**
맥락만 겹치는 언급이라 링크를 붙이면 끼워 넣은 티가 납니다.
뺀 것도 표 아래에 "왜 뺐는지" 와 함께 남겨 두니, 보시고 필요하면 직접 넣으세요.

**Q. 키워드가 마음에 안 듭니다.**
그대로 쿠팡에서 검색해 보시고 바꾸세요. 너무 넓으면 엉뚱한 게 나오고,
너무 좁으면 하나도 안 나옵니다.

**Q. 유튜브 쇼핑도 되나요?**
자동으로는 안 됩니다. 공개 API 로 상품을 붙일 수 없어서,
유튜브 스튜디오 → 수익 창출 → 쇼핑에서 손으로 태그하셔야 합니다.
2026년 3월부터 구독자 500명 + YPP 면 쓸 수 있고 플랫폼 수수료는 없습니다.

**Q. 비용이 얼마나 드나요?**
원고 한 편에 Claude 호출 1회로 수십 원 수준입니다. 쿠팡 API 는 무료입니다.
모의 실행은 0원입니다.

**Q. AI 가 만든 글이라는 표시가 붙나요?**
붙습니다. 인공지능기본법에 따라 기본으로 켜 두었습니다.
다만 이 표시는 **산출물 파일**에 붙는 것이고, 사장님이 고쳐 쓰신 본문에는
직접 판단해 넣으시면 됩니다.

**Q. 하나의 글에 링크를 몇 개나 넣을까요?**
2~4개가 적당합니다. 우선순위 위에서부터 고르세요. 많이 넣는다고 많이
팔리지 않고, 오히려 글이 광고처럼 보입니다.

**Q. 안 써 본 물건을 추천해도 되나요?**
권하지 않습니다. 굳이 쓰신다면 "안 써 봤지만 평이 좋다" 고 밝히세요.
써 본 척하는 글은 결국 들킵니다.
