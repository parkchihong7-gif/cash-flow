# 관리자 매뉴얼 — 10. 제휴 상품 매칭 로직

이 프로그램을 팔고 운영하는 사람을 위한 문서입니다.

---

## 1장. 이 상품이 무엇을 파는가

원고를 읽고 **어디에 무엇을 붙일지 찾아 주는 도구**입니다.

파는 것은 "제휴 수익" 이 아니라 **시간**입니다. 글 하나에 링크 붙일 자리를 찾고,
키워드 정하고, 상품 찾고, 대가성 문구 챙기는 데 30~40분이 듭니다. 이 도구는
그 앞부분을 5분으로 줄입니다. 고를 사람은 여전히 사람입니다.

### 이 상품이 안 하는 것 — 상담할 때 분명히 말하세요

- **상품을 골라 주지 않습니다.** 후보만 모읍니다.
- **수익을 예측하지 않습니다.** 우선순위 점수는 순서를 정하는 눈금입니다.
- **글을 대신 써 주지 않습니다.** 삽입 문장은 초안이고 말투를 맞춰야 합니다.
- **자동으로 올려 주지 않습니다.** 사람 검수 없는 발행은 만들지 않습니다(CLAUDE.md §3-3).

여기서 기대를 낮춰 두지 않으면 환불 문의가 옵니다. "이거 돌리면 돈 벌리나요" 라는
질문에는 "자리를 찾아 주는 도구지 수익을 만드는 도구가 아닙니다" 로 답하세요.

## 2장. 준비

```bash
pip install -r requirements.txt
cp .env.example .env
```

| 키 | 필요한가 | 없으면 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 실제 실행에 필요 | `--dry-run` 만 됩니다 |
| `COUPANG_ACCESS_KEY` | **없어도 됩니다** | 검색 주소만 만듭니다 |
| `COUPANG_SECRET_KEY` | **없어도 됩니다** | 〃 |
| `COUPANG_SUB_ID` | 선택 | 채널별 구분만 못 합니다 |

쿠팡 오픈 API 는 실적 요건이 있어 **가입 직후에는 안 열릴 수 있습니다**
(CLAUDE.md §9 의 미확정 항목). 그래서 키가 없는 쪽을 기본 경로로 만들었습니다.
키 없이 돌려도 종료 코드가 0 이고, 화면에 "오류가 아닙니다" 라고 적힙니다.

## 3장. 파이프라인 — 네 조각

```
extract.py   Claude 1회. 상품 이야기가 나온 자리를 뽑습니다
score.py     수수료율 × 객단가 × 의도 가중치
links.py     키가 있으면 쿠팡 API, 없으면 검색 주소
output.py    파일 3개. 대가성 문구를 강제합니다
```

### extract — 왜 문단 번호를 미리 매겨 넘기나

Claude 에게 원고를 통째로 주고 "어디에 넣을까" 를 물으면 "중반부쯤" 같은 답이
옵니다. 그건 쓸 수 없는 답입니다. 그래서 문단을 먼저 자르고 `[0] [1] [2]` 로
번호를 붙여 넘깁니다. 번호가 있어야 "어디에" 를 말할 수 있습니다.

본문에 없는 번호를 가리켜 오면 그 언급은 버리고 경고로 남깁니다.

### score — 왜 이렇게 단순한가

```
1건 수수료 = 객단가 추정 × 수수료율
우선순위   = 1건 수수료 × 의도 가중치
```

더 정교하게 만들 **근거가 없어서**입니다. 전환율을 알려면 본인 파트너스 화면의
실측이 필요한데, 그건 이 프로그램이 가질 수 없는 값입니다.

없는 정밀도를 흉내 내면 쓰는 사람이 그 숫자를 믿습니다. 그래서 숫자마다 근거
문장을 붙이고, 근거가 비면 표를 아예 읽지 않게 했습니다.

### links — 서명(HMAC)

공식 문서 규칙 그대로입니다.

```
message   = signed-date + METHOD + path + query   (물음표는 빼고 잇습니다)
signature = HMAC-SHA256(secret, message) 16진수 소문자
header    = CEA algorithm=HmacSHA256, access-key=..., signed-date=..., signature=...
```

`signed-date` 는 **GMT** `yymmddTHHMMSSZ` 입니다. 한국 시각으로 서명하면 9시간이
어긋나 전부 401 이 납니다.

⚠️ **이 저장소를 만든 환경에서는 api-gateway.coupang.com 에 닿지 못했습니다.**
그래서 실제 응답으로 검증하지 못했습니다. 조립 규칙만 테스트로 고정해 두었고,
문서에는 그 사실을 적어 두었습니다. 고객에게도 "첫 호출은 함께 확인해 드립니다"
로 안내하시는 편이 정직하고, 실제로 그게 상담 거리가 됩니다.

### output — 이 상품의 마지막 방어선

산출물 세 개 모두 맨 위에 대가성 문구가 붙고, **파일을 쓰기 직전에 문구가 살아
있는지 한 번 더 확인**합니다. 없으면 저장하지 않습니다.

끄는 옵션은 만들지 않았습니다. 옵션으로 두면 언젠가 꺼지기 때문입니다.

## 4장. 수수료율 표 관리 — 가장 손이 가는 곳

`data/commission_rates.yaml` 한 장이 원본입니다. 코드에는 숫자가 없습니다.

### 반드시 알아 두실 것

**쿠팡은 요율을 예고 없이 바꿉니다.** 이 표는 2026-09-16 기준이고, 상향/하향
구간은 공개 안내를 근거로 한 **추정값**입니다. 줄마다 그렇게 적어 두었습니다.

고객에게 넘기실 때 이 말을 꼭 하세요. "표는 출발점이고, 파트너스 화면에서
확인해 이 파일을 고쳐 쓰셔야 합니다." 이 말을 안 하면 나중에
"숫자가 다르다" 는 문의가 옵니다.

### 고치는 법

```yaml
  - name: 뷰티
    rate: 0.07          # 0~1 사이 비율
    avg_price: 35000    # 원 단위 정수
    source: >-          # 8자 이상. 비면 프로그램이 멈춥니다
      어디서 온 숫자인지 적습니다
    note: 알아 두면 좋은 것 (선택)
```

`source` 를 비우면 표를 읽지 않습니다. 부탁이 아니라 규칙으로 막았습니다.

### 객단가는 무엇인가

카테고리 감각치입니다. 실거래 통계가 아닙니다. **고객 채널의 실제 후기 단가로
바꾸면 우선순위가 크게 달라집니다.** 이게 대행 상담에서 값을 받을 수 있는
지점이기도 합니다. 채널 성격에 맞게 표를 손봐 드리는 것이요.

## 5장. 대시보드에서 쓰기

'테스트' 탭에서 **모의 실행**을 먼저 누르세요. Claude 를 부르지 않아 0원입니다.
샘플 원고 세 편(`data/samples/`)으로 산출물이 어떤 모양인지 봅니다.

'수정' 탭에서 고칠 수 있는 것

| 파일 | 무엇 |
|---|---|
| `data/commission_rates.yaml` | 수수료율·객단가·의도 가중치·제외 기준 |
| `prompts/extract.md` | 추출 규칙. 의도 강도 기준이 여기 있습니다 |
| `data/samples/*.md` | 샘플 원고 |

`prompts/extract.md` 를 고치실 때 **"2 이하는 올려 적지 마라" 는 문단을 지우지
마세요.** 그 문장이 없으면 Claude 가 전부 4~5로 적어 옵니다. 그러면 거르는
장치가 있으나 마나 해집니다.

## 6장. 법·정책에서 걸리는 것

### 대가성 표시 (가장 중요)

| 채널 | 무엇을 | 안 하면 |
|---|---|---|
| 쿠팡파트너스 | 링크와 같은 화면에 문구 | **경고 없이 자격 정지** |
| 유튜브 | '유료 프로모션 포함' 체크 + 설명란 | 영상이 내려갑니다 |
| 인스타 | 캡션 **첫 줄** | 게시물 제재 |

표시광고법상 경제적 이해관계 공개는 사업자 의무입니다. 공정위 심사지침이
"본문 첫머리에, 소비자가 쉽게 인식할 수 있게" 를 요구합니다. 맨 아래에만 두면
안 한 것과 같게 봅니다.

### 자가 구매 금지

쿠팡파트너스는 본인 구매를 금지합니다. "제 링크로 사시면", "페이백", "캐시백",
"수수료 나눠" 같은 표현이 삽입 문장에 들어가면 **규격 단계에서 막힙니다.**

### 효능·안전 단정 금지

헬스건강식품·출산유아동 카테고리가 특히 위험합니다. "이거 먹고 나았다",
"아이에게 안전합니다" 같은 문장은 표시광고법 문제가 됩니다. 프롬프트에
"단정하지 않는다" 를 넣어 두었지만, **사람이 한 번 더 봐야 합니다.**

### AI 생성물 표시

산출물에 자동으로 붙습니다(인공지능기본법 제31조, CLAUDE.md §3-5).
`--no-ai-label` 로 끌 수 있지만 끄는 선택은 쓰는 사람 책임입니다.

## 7장. 값 매기기

| 플랜 | 값 | 무엇 |
|---|---|---|
| 단품 | 9만 원 | 프로그램 일체, 수수료율 표, 매뉴얼 |
| 세팅 묶음 | 25만 원 | + 고객 채널에 맞춘 수수료율·객단가 조정, 원고 3편 대행 |

세팅 묶음을 권합니다. 이 상품은 **표를 고객 채널에 맞추는 순간 쓸모가 달라지는데**,
그걸 혼자 하기는 어렵기 때문입니다. 객단가 하나만 바꿔도 우선순위가 뒤집힙니다.

리테이너로 넘기기는 어렵습니다. 한 번 세팅하면 고객이 혼자 돌릴 수 있어서요.
대신 요율이 바뀔 때 표를 갱신해 드리는 월 3만 원 정도는 이야기가 됩니다.

## 8장. 문제가 생겼을 때

**401 이 납니다**
1. ACCESS 와 SECRET 을 바꿔 넣지 않았는지
2. **컴퓨터 시계** — 5분 이상 틀어지면 거절합니다. 이게 제일 흔합니다
3. 키 앞뒤 공백·따옴표

**403 이 납니다**
파트너스 계정이 API 승인을 못 받은 상태입니다. 실적 요건 때문일 수 있습니다.
키 없이 쓰는 경로로 안내하세요.

**429 가 납니다**
호출이 너무 잦습니다. **재시도하지 말고 기다립니다**(CLAUDE.md §7).
키워드를 줄이거나 다음 날 돌리세요.

**"넣을 자리가 없습니다" 만 나옵니다**
정상일 수 있습니다. 상품 이야기가 없는 글이면 그게 맞는 답입니다.
자꾸 그러면 원고를 보세요. 제품 이야기가 정말 없는 글입니다.

**의도 강도가 전부 5 로 옵니다**
`prompts/extract.md` 의 강도 표와 "올려 적지 마라" 문단이 지워졌는지 보세요.

**카테고리가 자꾸 '표에 없음' 으로 떨어집니다**
Claude 가 표에 없는 이름을 쓰고 있습니다. `commission_rates.yaml` 에 그 이름을
추가하거나, 프롬프트의 카테고리 목록을 고치세요.

## 9장. 새 원고를 넣는 법

특별한 것이 없습니다. 마크다운이든 텍스트든 됩니다.

```bash
python cli.py run 내원고.md --medium "블로그" --title "제목"
```

문단은 **빈 줄**로 나눕니다. 빈 줄이 하나도 없으면 줄 단위로 자릅니다.
대본을 줄바꿈 한 번으로 이어 쓰는 분들이 많아서 넣어 둔 장치입니다.

2만 자를 넘으면 앞부분만 봅니다. 긴 원고는 나눠 돌리세요.

## 10장. 정직하게 말해야 하는 것

이 상품을 팔 때 감추면 나중에 더 크게 돌아오는 것들입니다.

1. **쿠팡 API 를 실제 응답으로 검증하지 못했습니다.** 서명 규칙은 문서대로
   구현하고 테스트로 고정했지만, 첫 호출은 함께 확인하는 편이 안전합니다.
2. **수수료율 표의 상향/하향 구간은 추정값입니다.** 기본 3% 만 조사값입니다.
3. **객단가와 의도 가중치는 전부 가정값입니다.** 실측이 아닙니다.
4. **전환율은 모릅니다.** 우선순위는 순서일 뿐입니다.
5. **쿠팡 정산은 다다음 달 15일**이고 쿠키는 24시간입니다. 오늘 클릭이 이번 달
   수입이 아닙니다. 이걸 모르고 시작한 분들이 한 달 뒤에 실망합니다.
