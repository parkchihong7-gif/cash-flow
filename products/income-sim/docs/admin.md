# 관리자 매뉴얼 — 수익 시뮬레이터

이 문서는 프로그램을 **파는 쪽**(관리자)이 봅니다.
고객에게 그대로 주는 문서는 `docs/client.md` 입니다.

---

## 1장. 이 상품이 다른 일곱 개와 다른 점

1~7번은 **뭔가를 만들어 주는** 도구입니다. 랜딩 페이지, 대본, 원고, 엑셀.
8번은 **판단을 돕는** 도구입니다. 아무것도 만들어 내지 않습니다.

그래서 팔 때 기대치를 다르게 잡아야 합니다.

| | 1~7번 | 8번 |
|---|---|---|
| 산출물 | 파일이 나옵니다 | 숫자와 그래프뿐입니다 |
| 값어치 | 시간을 줄여 줍니다 | 잘못된 선택을 줄여 줍니다 |
| 증명 | 결과물을 보여 주면 됩니다 | 어렵습니다 |
| API 비용 | 듭니다 | **0원** — Claude 를 안 부릅니다 |

**단독으로 팔기보다 묶음의 앞단으로 쓰는 편이 자연스럽습니다.**
"어느 부업이 나에게 맞나" 를 먼저 보여 주고, 고른 모델에 맞는 프로그램
(6번 n8n, 7번 공구 장부 등)으로 이어 주는 흐름입니다.

---

## 2장. 기본값을 어떻게 잡았는가 — 이 상품의 핵심

숫자를 다루는 도구에서 가장 위험한 것은 **근거 없는 기본값**입니다.
그럴듯한 숫자가 화면에 떠 있으면 사람은 그걸 기준으로 판단합니다.
어디서 온 숫자인지 모르면서요.

그래서 이 상품은 **`source` 가 비면 모델을 아예 읽지 않습니다.**
부탁이 아니라 규칙으로 막아 둔 것입니다. (`income_sim/schema.py` 의 `ParamSpec`)

### 세 종류를 구분해 적었습니다

| 종류 | 예 | 근거 문장에 쓴 표현 |
|---|---|---|
| **조사 수치** | 롱폼 RPM 1,000~4,500원 | "CLAUDE.md §2-1 조사 —" |
| **목표치** | SaaS 전환율 5% | "우리가 세운 목표치입니다" |
| **가정값** | 이탈률 5% / 8% | "확인된 수치가 아닌 가정값입니다" |

**이 구분이 중요한 이유**: 목표치를 조사 수치처럼 보여 주면 거짓말이 됩니다.
8번 SaaS 모델의 전환율 5%는 CLAUDE.md §5 에 적힌 **목표**이지 달성한 값이 아닙니다.
근거 문장에 그렇게 적어 두었고, 화면에서도 그대로 보입니다.

### 역산으로 얻은 값도 밝혀 두었습니다

5번 공구의 참여율 1.5%는 조사 수치가 아닙니다.
"팔로워 3,000명 계정도 1회 공구 135~270만 원" 이라는 문장에서
마진 20%·객단가 45,000원을 가정해 거꾸로 계산한 값입니다.
근거 문장에 "역산이라 확인된 수치가 아닙니다" 라고 적어 두었습니다.

### 고칠 때

`models/*.yaml` 의 `source` 를 고치면 됩니다. 파일 맨 위 주석에도
같은 내용을 적어 두어, 파일만 열어도 보이게 했습니다.
새 조사 결과가 나오면 **숫자와 근거를 같이** 고치세요. 한쪽만 고치면 거짓말이 됩니다.

## 3장. 계산이 어디서 도는가

```
models/*.yaml  ← 값과 계산식이 글자로 적혀 있다
      │
      ├─ expr.py     파이썬이 그 글자를 해석해 계산 (터미널)
      └─ formula.js  자바스크립트가 같은 글자를 해석해 계산 (대시보드)
```

### 왜 이렇게 했는가

계산식을 파이썬에 한 번, 자바스크립트에 한 번 적으면 **언젠가 어긋납니다.**
그러면 터미널에서 본 숫자와 대시보드에서 본 숫자가 다른데,
어느 쪽이 맞는지 알 수 없습니다. 그 순간 도구를 못 쓰게 됩니다.

식을 한 군데만 두면 그 일이 원리적으로 없습니다.

### 두 해석기를 맞춰 둔 것

| | 파이썬 기본 | 자바스크립트 기본 | 맞춘 값 |
|---|---|---|---|
| 0 으로 나누기 | 오류 | `Infinity` | **0** |
| 무한대·NaN | — | 그대로 | **0** |
| `-2**2` | `-4` | `4` (Math.pow 순서) | **-4** |

`tests/test_income_sim.py` 가 **node 를 실제로 돌려** 8개 모델의 12개월 값을
전부 맞춰 봅니다. 모델을 추가하면 그 검사가 자동으로 따라붙습니다.

### eval 을 쓰지 않은 이유

`eval(식)` 한 줄이면 끝나지만, 그러면 `models/*.yaml` 을 고칠 수 있는 사람이
**무엇이든 실행할 수 있게** 됩니다. 이 파일들은 고객이 고치라고 열어 둔 파일입니다.

그래서 식을 해석해서 사칙연산·거듭제곱·`min`·`max` 만 통과시킵니다.
자바스크립트 쪽도 `new Function` 을 쓰지 않고 직접 해석합니다
(브라우저 보안 정책이 그걸 막는 곳에서도 돌아가야 하기 때문입니다).

## 4장. 손익분기를 왜 둘로 나눴는가

가장 흔한 오해가 여기 있습니다.

```
매달 60원씩 남는다. 초기 투자는 300원이었다.
```

- **월 손익분기**: 1개월차 — 그달 매출이 그달 비용을 넘겼습니다
- **누적 손익분기**: 6개월차 — 300원을 60원씩 갚는 데 다섯 달 더 걸립니다

하나로 합쳐 "손익분기 1개월" 이라고 하면 **틀린 말은 아닌데 오해를 삽니다.**
초기 투자를 아직 못 갚았는데 흑자라고 생각하게 됩니다.

그래서 따로 계산하고 화면에도 두 줄로 보여 줍니다.
테스트가 이 구분을 고정합니다 (`test_monthly_and_cumulative_breakeven_are_not_the_same_thing`).

### 딱 0 은 아직 갚은 게 아닙니다

누적이 정확히 0 인 달은 손익분기로 치지 않습니다. `> 0` 이어야 합니다.
0 은 본전이지 이익이 아니기 때문입니다.

## 5장. 이탈률이 쌓이는 계산

7번(대행 리테이너)과 8번(구독 SaaS)만 **달마다 이어지는 값**이 있습니다.

```
1개월차 고객 = initial
n개월차 고객 = 지난달 고객 × (1 - 이탈률) + 그달 신규
```

### 천장이 있습니다

매달 같은 수가 들어오면 고객 수는 무한히 늘지 않습니다.

```
천장 = 월 신규 ÷ 이탈률
```

8번 기본값(월 신규 유료 5명, 이탈률 8%)이면 **62.5명**에서 멈춥니다.
12개월차에 39.5명이고, 아직 오르는 중입니다.

**이게 구독 사업의 핵심입니다.** 유입을 늘리거나 이탈을 줄이는 것 말고는
천장을 올릴 방법이 없습니다. 고객에게 설명할 때 이 지점을 짚어 주세요.

### 7번과 8번의 시작이 다릅니다

| | 1개월차 |
|---|---|
| 7번 대행 | **지금 있는 고객만**. 이번 달 납품한 고객은 다음 달부터 냅니다 |
| 8번 SaaS | 그달 가입자 × 전환율. 무료 체험 후 바로 결제하는 구조라 |

일부러 다르게 했습니다. 대행은 납품하고 한 달 뒤부터 유지비를 받는 것이
실제에 가깝기 때문입니다. 테스트가 둘 다 고정합니다.

## 6장. 몬테카를로

### 왜 필요한가

기본값 하나로 나온 숫자는 "이대로 되면" 이라는 가정 위에 있습니다.
조회수나 전환율은 원래 크게 흔들립니다. 그 흔들림을 같이 보여 주는 편이
판단에 도움이 됩니다.

특히 **손해로 끝날 확률**이 쓸모 있습니다.
8번 SaaS 를 기본값으로 돌리면 97% 가 넘게 나옵니다. 이 한 줄이
"목표치대로 되어도 첫해는 적자" 라는 사실을 분명하게 보여 줍니다.

### 삼각분포를 쓴 이유

정규분포보다 **설명하기 쉽습니다.** "가장 그럴듯한 값이 가운데이고
양쪽으로 갈수록 덜 그럴듯하다" 는 사람의 어림과 모양이 같습니다.
고객에게 설명할 때 이 말 한 줄이면 됩니다.

### 흔드는 값 고르기

모델 파일의 `uncertain` 이 정합니다. 0 이면 안 흔듭니다.

**흔들 값을 고르는 기준**: 내가 정하는 값은 안 흔들고, 시장이 정하는 값만 흔듭니다.
판매가·수수료율·투입 시간은 내가 정합니다. 조회수·전환율·참여율은 그렇지 않습니다.

### 재현성

`--seed` 를 같게 주면 결과가 항상 같습니다. 고객에게 결과를 보여 준 뒤
"다시 돌려 보니 다르게 나오는데요" 하는 일을 막습니다.
견적서에 seed 값을 적어 두세요.

## 7장. 비교표를 어떻게 읽히는가

정렬 기준이 **12개월 손익이 아니라 시간당 수익**입니다.
손익이 커도 시간을 네 배 쓰고 있으면 더 나은 선택이 아니기 때문입니다.

### '환산' 칸의 한계를 꼭 말해 주세요

`월 40h 환산` 은 시간당 수익 × 시간인 **단순 비례값**입니다. 화면에도 적혀 있지만
고객은 이 숫자를 제일 먼저 봅니다. 상담 때 직접 짚어 주세요.

- 고정비는 시간을 줄여도 줄지 않습니다
- 시간을 두 배 넣는다고 조회수가 두 배가 되지 않습니다
- 혼자 할 수 있는 양에는 한계가 있습니다 (7번 대행이 특히 그렇습니다)

## 8장. 대시보드

```bash
python cli.py html
```

파일 하나(약 60KB)로 나옵니다. 메일로 보내도 되고 USB 에 담아도 됩니다.

### 그래프 색

dataviz 검증기를 통과한 조합만 씁니다. 색맹인 분도 세 계열을 구분할 수 있는지를
기계로 확인한 값입니다.

```
밝은 화면  #2a78d6(매출) #eb6834(비용) #1baf7a(손익)
어두운 화면 #3987e5       #d95926       #199e70
```

밝은 화면에서 초록의 대비가 3:1 아래라 **숫자 표를 같이 싣는 것**으로
그 조건을 채웠습니다. 표를 빼면 안 됩니다.

### 인터넷이 없을 때

그래프만 인터넷이 필요합니다(Chart.js 를 cdnjs 에서 받습니다).
못 받아오면 **왜 안 보이는지 화면에 적어 주고** 표에 같은 숫자가 다 남습니다.
빈칸만 남겨 두면 고장 난 줄 알기 때문입니다.

## 9장. 모델 추가하기

`models/새이름.yaml` 한 장이면 됩니다. 코드는 건드리지 않습니다.
README 7장에 서식이 있습니다. 확인할 것 네 가지.

1. `source` 를 채웠는가 — 비면 프로그램이 모델을 읽지 않습니다
2. 비율을 0~1 로 적었는가 — 20% 는 `0.2`
3. `initial_cost` 를 넣었는가 — 없으면 누적 손익분기가 늘 1개월차가 됩니다
4. `uncertain` 을 시장이 정하는 값에만 붙였는가

그리고 테스트를 돌리세요. node 파이썬 대조 검사가 새 모델에도 자동으로 붙습니다.

```bash
python3 -m pytest ../../tests/test_income_sim.py -q
```

## 11장. 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 모델이 목록에 안 나옴 | `source` 가 비었거나 8자 미만 | 근거를 한 문장으로 적으세요 |
| `모르는 이름` 오류 | 계산식에 없는 값 이름 | `params` 의 `key` 와 철자를 맞추세요 |
| `밖입니다` 오류 | 기본값이 min~max 밖 | 범위를 넓히거나 기본값을 고치세요 |
| 비율이 100배 이상해짐 | 20% 를 `20` 으로 적음 | `0.2` 로 적습니다. 프로그램이 막아 줍니다 |
| 누적 손익분기가 늘 1개월차 | `initial_cost` 가 0 | 초기 투자를 넣으면 뜻이 생깁니다 |
| 몬테카를로가 거부됨 | 흔들 값이 없음 | `uncertain` 을 하나 이상 붙이세요 |
| 대시보드 그래프가 빈칸 | 인터넷이 안 됨 | 화면에 이유가 적힙니다. 표를 보세요 |
| 터미널과 대시보드 숫자가 다름 | 있으면 안 되는 일 | 테스트를 돌려 보고 결과를 알려 주세요 |

## 12장. 규정 관련

- **고정 문구** — 모든 출력 맨 위에 "이 계산은 추정치이며 실제 수익을 보장하지
  않습니다" 가 붙습니다. `engine.DISCLAIMER` 한 곳에서 나오고 테스트가 지킵니다.
  **지우지 마세요.** 고액 부업 강의 피해가 2025년 42건이고 소비자원 주의보가
  나온 분야입니다(CLAUDE.md §3).
- **성과를 단정하지 않습니다** — 이 도구는 어느 모델이 좋다고 말하지 않습니다.
  숫자를 나란히 놓을 뿐이고, 상담에서도 같은 태도를 지키세요.
  "이거 하면 얼마 번다" 가 아니라 "이 가정이면 이 숫자가 나온다" 입니다.
- **AI 생성물 표시** — 이 상품에는 붙이지 않습니다. 계산 결과는 AI 가 만든 것이
  아니라 입력한 값에서 나온 것이기 때문입니다. 표시를 붙이면 오히려 오해를 삽니다.
- **개인정보** — 다루지 않습니다. 이 상품은 어디로도 데이터를 보내지 않습니다.
