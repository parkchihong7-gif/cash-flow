# 고객용 매뉴얼 — 수익 시뮬레이터

부업 여덟 가지의 손익을 같은 기준으로 견주어 보는 도구입니다.

> **먼저 말씀드립니다.** 이 계산은 추정치이며 실제 수익을 보장하지 않습니다.
> 화면에 뜨는 숫자는 "이런 가정이면 이렇게 된다" 이지 "이렇게 된다" 가 아닙니다.

---

## 1장. 이 도구가 답하는 질문

부업을 고를 때 대개 이렇게 묻습니다.

> "그거 하면 얼마 벌어요?"

이 질문에는 빠진 게 있습니다. **시간**입니다.
월 100만 원을 20시간 써서 버는 것과 100시간 써서 버는 것은 다릅니다.

그래서 이 도구는 **시간당 수익**으로 견줍니다.
비교표의 순서도 총액이 아니라 시간당 기준입니다.

### 답해 주지 않는 것

| 답해 줍니다 | 답해 주지 않습니다 |
|---|---|
| 이 가정이면 12개월 뒤 얼마 | 실제로 얼마를 벌지 |
| 초기 투자를 몇 달 만에 갚는지 | 그 일이 나에게 맞는지 |
| 시간당으로 어느 쪽이 나은지 | 배우는 데 걸리는 시간 |
| 잘 풀렸을 때와 안 풀렸을 때의 폭 | 운 |

**특히 "배우는 기간" 이 계산에 없습니다.** 전자책 모델의 1개월차 매출은
원고가 이미 있다고 가정한 숫자입니다. 실제로는 원고 쓰는 두세 달 동안 매출이 0 입니다.

## 2장. 직접 써 보실 분께 — 관리 화면

브라우저에서 관리 화면을 열고 왼쪽에서 **8번 수익 시뮬레이터**를 고릅니다.

| 탭 | 하는 일 |
|---|---|
| **열람** | 이 매뉴얼과 이용 순서 |
| **수정** | 모델 파일 — 기본값을 본인 수치로 바꿉니다 |
| **테스트** | 실행하면 대시보드 HTML 이 나옵니다 |
| **회원관리** | 납품하실 때 쓰는 목록 |

**이 프로그램은 AI 를 쓰지 않아 실행 비용이 0원입니다.**
마음껏 여러 번 돌리셔도 됩니다. 8개 프로그램 중 유일합니다.

### API 키가 필요 없습니다

다른 프로그램은 글을 쓰기 위해 AI 를 부르고, 그때 **API 키**(AI 서비스를 쓸 때
요금을 매기는 긴 비밀번호)가 필요합니다. 이 프로그램은 계산만 하기 때문에
그 키가 없어도 됩니다.

| | 다른 프로그램 | 수익 시뮬레이터 |
|---|---|---|
| API 키 | 필요합니다 | **필요 없습니다** |
| 실행 비용 | 건당 수십~수백 원 | **0원** |
| 인터넷 | 필요합니다 | 없어도 됩니다 (그래프만 예외) |

'기타 설정' 화면에 "API 키가 설정되지 않았습니다" 경고가 떠 있어도
**이 프로그램은 그대로 돌아갑니다.**

## 3장. 대시보드 — 가장 쉬운 길

터미널이 어려우시면 이것만 쓰셔도 됩니다.

실행하면 `dashboard.html` 파일 하나가 나옵니다. 더블클릭하면 브라우저에서 열립니다.

### 화면 구성

```
맨 위      경고 문구 (추정치입니다)
그 아래    모델 8개 탭 — 눌러서 오갑니다
왼쪽       슬라이더 — 값을 움직입니다
오른쪽     결과 4칸 → 그래프 2개 → 월별 표 → 주의사항
```

### 쓰는 순서

1. **위쪽 탭에서 궁금한 모델을 고릅니다.**
2. **왼쪽 슬라이더를 본인 수치로 바꿉니다.** 움직이는 즉시 오른쪽이 다시 계산됩니다.
3. **오른쪽 위 네 칸을 봅니다.**
   - 12개월 손익
   - 최종 잔액 (초기 투자까지 뺀 값)
   - **시간당 수익** ← 가장 중요합니다
   - 누적 손익분기
4. **기본값으로** 버튼을 누르면 처음으로 돌아갑니다.

### 근거 보기

슬라이더 아래 **근거 보기**를 누르면 그 숫자가 어디서 왔는지 나옵니다.

**반드시 한 번은 열어 보세요.** 기본값 중에는 조사해서 나온 숫자도 있고,
그냥 가정해서 넣은 숫자도 있습니다. 근거 문장에 구분해 적혀 있습니다.

| 근거에 이렇게 적혀 있으면 | 뜻 |
|---|---|
| "CLAUDE.md §2-1 조사 —" | 실제로 조사해서 나온 구간의 중간값 |
| "우리가 세운 목표치입니다" | 달성한 값이 아니라 목표 |
| "확인된 수치가 아닌 가정값입니다" | **그냥 넣어 본 숫자입니다** |
| "역산이라 확인된 수치가 아닙니다" | 다른 숫자에서 거꾸로 계산한 값 |

아래 두 가지는 **본인 수치로 바꾸지 않으면 뜻이 없습니다.**

## 4장. 결과를 읽는 법

### 손익분기가 두 개인 이유

```
누적 손익분기   초기 투자까지 다 갚은 달   ← 진짜 본전 찾는 시점
월 손익분기     그달은 남기 시작한 달
```

**이 둘이 다른 게 정상입니다.** 매달 남고 있어도 처음에 쓴 돈을 아직
못 갚았을 수 있습니다. 장비를 80만 원어치 샀으면 매달 남더라도
그 80만 원을 갚기 전까지는 본전이 아닙니다.

### 시간당 수익

```
12개월 손익 ÷ 12개월 투입 시간
```

이 값이 **2026년 최저임금(시급 10,320원)보다 낮으면** 화면이 알려 줍니다.
마이너스면 "시간을 쓸수록 돈이 나갑니다" 라고 나옵니다.

낮다고 해서 하지 말라는 뜻은 아닙니다. 다만 **알고 시작하는 것과
모르고 시작하는 것은 다릅니다.**

### 그래프 둘

| | 보는 법 |
|---|---|
| **월별 매출·비용·손익** | 파란선(매출)이 주황선(비용) 위로 올라간 달부터 그달은 남습니다 |
| **누적 잔액** | 점선(0) 위로 올라간 달이 본전 찾는 달입니다 |

그래프가 안 보이면 인터넷 연결을 확인하세요. 그래프만 인터넷이 필요하고,
**아래 표에 같은 숫자가 다 들어 있습니다.**

## 5장. 터미널로 쓰기

### 목록 보기

```
python cli.py models
```

여덟 모델의 시간당 수익이 한눈에 나옵니다.

### 하나 자세히 보기

```
python cli.py run 7
python cli.py run agency_retainer     ← 이름으로도 됩니다
```

12개월 표가 나옵니다.

### 값 바꾸기

```
python cli.py run youtube_long --monthly_views=500000 --rpm=3000
```

**비율은 0~1 로 적습니다.** 20% 는 `0.2` 입니다.
`20` 이라고 적으면 프로그램이 막고 알려 줍니다. `30%` 처럼 적어도 됩니다.

### 근거 보기

```
python cli.py sources 1
```

그 모델의 모든 기본값과 근거가 나옵니다.

### 견주기

```
python cli.py compare 7 6 5
```

시간당 수익이 높은 순으로 줄을 세웁니다.

⚠️ **'월 40h 환산' 칸을 조심하세요.** 시간당 수익에 시간을 곱한 단순 계산입니다.
실제로는 시간을 두 배 넣는다고 조회수가 두 배가 되지 않고,
고정비는 시간을 줄여도 줄지 않습니다. 참고로만 보세요.

### 잘 풀렸을 때와 안 풀렸을 때

```
python cli.py montecarlo 5 --n 1000 --seed 42
```

조회수·전환율처럼 원래 흔들리는 값을 1,000번 흔들어 봅니다.

| | 뜻 |
|---|---|
| **P10** | 열 번 중 한 번은 이보다 나쁩니다 |
| **P50** | 한가운데 |
| **P90** | 열 번 중 한 번은 이보다 좋습니다 |
| **손해로 끝날 확률** | 12개월 뒤 마이너스일 확률 |

`--seed` 를 같게 주면 **결과가 항상 같습니다.** 다르게 주면 다르게 나옵니다.

이 폭은 프로그램에 적어 둔 가정에서 나온 것이지, 시장을 실제로 관측한 결과가
아닙니다. "이 정도 흔들릴 수 있다" 는 감각을 잡는 용도입니다.

## 6장. 여덟 모델

| # | 모델 | 이 모델을 볼 때 |
|--:|---|---|
| 1 | 유튜브 롱폼 | 광고 수익만 계산합니다. 강의·전자책은 안 들어 있습니다 |
| 2 | 유튜브 쇼츠 | 단가가 롱폼의 3% 수준입니다. 숫자로 확인해 보세요 |
| 3 | 유튜브 쇼핑 제휴 | 조회 → 클릭 → 구매로 세 번 걸러집니다 |
| 4 | 쿠팡파트너스 | 조사 결론이 "수익성 낮음" 이었습니다 |
| 5 | 인스타 공동구매 | 매출이 아니라 **마진**을 계산합니다 |
| 6 | 전자책·강의 | 원고 쓰는 기간이 계산에 없습니다 |
| 7 | 자동화 대행 | 리테이너가 쌓입니다. 고객 수 칸을 보세요 |
| 8 | 구독 SaaS | 이탈률이 천장을 정합니다 |

각 모델 아래 **같이 봐야 할 것**에 숫자가 말해 주지 않는 부분을 적어 두었습니다.
결과를 보기 전에 읽으세요.

### 쌓이는 모델(7, 8)의 천장

7번과 8번은 고객이 쌓입니다. 대신 이탈률만큼 빠집니다.
그래서 무한히 늘지 않고 **한 지점에서 멈춥니다.**

```
천장 = 월 신규 고객 ÷ 이탈률
```

8번 기본값이면 62명 근처입니다. 표에서 고객 수 칸이 눕는 것을 보세요.
**천장을 올리는 방법은 둘뿐입니다.** 유입을 늘리거나, 이탈을 줄이거나.

## 7장. 자주 묻는 질문

**Q. 기본값 그대로 봐도 되나요?**
참고만 하세요. 기본값은 "일반적으로 이 정도" 라는 출발점이지 사장님 상황이 아닙니다.
특히 조회수·전환율·참여율은 반드시 본인 수치로 바꾸세요.

**Q. 내 수치를 모르는데요.**
그러면 아직 이 도구를 쓸 때가 아닙니다. 한 달만 해 보고 실제 숫자를 얻은 뒤
돌아오세요. 그게 어떤 계산기보다 정확합니다.

**Q. 왜 유튜브 모델이 마이너스로 나오나요?**
편집비를 외주 기준으로 잡았기 때문입니다. 직접 편집하시면 편집비를 0 으로 두고
대신 투입 시간을 늘리세요. 그러면 손익은 올라가고 시간당 수익은 내려갑니다.
**그게 실제로 일어나는 일입니다.**

**Q. 어느 부업이 제일 낫나요?**
이 도구는 답하지 않습니다. 숫자를 나란히 놓을 뿐입니다.
시간당 수익이 높은 쪽이 대개 신뢰나 경험이 필요한 일입니다.
그건 계산에 안 들어갑니다.

**Q. 값을 바꿨는데 결과가 안 변해요.**
그 값이 계산식에 안 들어가는 경우입니다. 예를 들어 4번 쿠팡파트너스의
투입 시간은 매출에 영향을 주지 않고 **시간당 수익만** 바꿉니다.

**Q. 12개월 말고 더 길게 볼 수 있나요?**
화면에서는 12개월 고정입니다. 그보다 먼 예측은 가정이 너무 쌓여서
숫자가 뜻을 잃습니다.

**Q. 이 숫자를 사업계획서에 써도 되나요?**
추정이라는 것을 함께 밝히시면 됩니다. 근거 문장도 같이 옮기세요.
숫자만 떼어 내면 그 숫자가 어디서 왔는지 아무도 모르게 됩니다.

## 8장. 이 숫자는 판단의 초안입니다

이 도구가 내놓는 것은 **결론이 아니라 초안**입니다.

```
계산기가 초안을 낸다 → 사람이 따져 보고 고친다 → 그때 판단이 된다
```

초안인 이유가 셋 있습니다.

1. **입력이 가정입니다.** 조회수 20만, 전환율 1.5% 는 사장님이 확인한 숫자가
   아니라 출발점입니다. 바꾸는 순간 결과가 크게 달라집니다.
2. **계산에 없는 것이 있습니다.** 배우는 기간, 신뢰를 쌓는 시간, 세금,
   건강보험료, 그리고 하다가 그만두게 되는 경우입니다.
3. **숫자가 못 보는 것이 있습니다.** 그 일이 나에게 맞는지, 오래 할 수 있는지는
   계산으로 나오지 않습니다.

그래서 이 초안을 **그대로 사업계획서나 대출 서류에 옮겨 적으시면 안 됩니다.**
추정이라는 것과 어떤 가정 위에 있는지를 함께 밝히세요.

한 가지만 기억하시면 됩니다. **이 도구는 답을 주지 않습니다.
같은 기준으로 견주어 볼 수 있게 숫자를 나란히 놓아 줄 뿐입니다.**

## 9장. 이 도구를 쓸 때 조심할 것

- **숫자가 크게 나왔다고 그 일을 잘하게 되는 건 아닙니다.** 계산은 "이렇게만 되면" 을
  전제합니다. 그렇게 되도록 만드는 일이 실제 부업입니다.
- **기본값으로 판단하지 마세요.** 특히 "가정값" 이라고 적힌 값은 그냥 넣어 본 숫자입니다.
- **한 모델만 보지 마세요.** 견주기를 돌려 보면 생각과 순서가 다를 때가 많습니다.
- **손해로 끝날 확률을 꼭 보세요.** 한가운데 값만 보면 위험이 안 보입니다.
- **계산에 없는 것들이 있습니다.** 배우는 기간, 신뢰를 쌓는 시간, 세금, 건강보험료,
  그리고 하다가 그만두게 되는 경우입니다.
