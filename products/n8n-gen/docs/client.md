# 고객용 매뉴얼 — n8n 워크플로 JSON 생성기

자동화 워크플로를 받으신 분, 또는 이 프로그램을 직접 쓰시는 분을 위한 문서입니다.
컴퓨터를 특별히 잘 다루지 않아도 따라올 수 있게 썼습니다.

---

## 1장. n8n 이 뭔가요

**정해 둔 순서대로 컴퓨터가 일을 대신 해 주는 프로그램**입니다.

예를 들어 지금 이런 일을 매일 손으로 하신다면,

> 아침에 출근해서 → 구글시트를 열고 → 어제 매출을 확인하고 → 요약해서 → 슬랙에 올린다

이 순서를 n8n 에 한 번 적어 두면, 매일 아침 9시에 컴퓨터가 알아서 합니다.

n8n 화면에서는 이 순서가 **상자와 화살표**로 보입니다.

```
[매일 9시] → [구글시트 읽기] → [Claude 요약] → [슬랙 전송]
```

상자 하나를 **노드**라고 부릅니다. 화살표는 "이 상자가 끝나면 다음 상자로" 라는 뜻입니다.
전체 그림 하나를 **워크플로**라고 합니다.

### 자동화되는 일 / 안 되는 일

| 되는 일 | 안 되는 일 |
|---|---|
| 정해진 시간에 반복하는 일 | 그때그때 판단이 필요한 일 |
| 어디서 가져와 어디로 보내는 일 | 공식 연동 창구(API)가 없는 서비스 |
| 조건이 분명한 분기 ("10만원 넘으면") | 사람이 읽고 결정해야 하는 일 |
| 형식이 일정한 문서 만들기 | 고객과의 관계·신뢰 |

**자동화는 원래 하던 일의 순서를 옮기는 것이지, 없던 성과를 만들지 않습니다.**
효과는 그 일에 원래 쓰시던 시간에 달려 있습니다. 하루 10분 걸리던 일이면 하루 10분이 줄어듭니다.

## 2장. 직접 만들어 보실 분께 — 관리 화면 쓰는 법

워크플로 파일을 **받기만** 하신 분은 이 장을 건너뛰고 3장으로 가세요.
프로그램을 구매해 **직접 만들어 쓰시는 분**만 보시면 됩니다.

브라우저에서 관리 화면을 열고 왼쪽 목록에서 **6번 n8n 워크플로 JSON 생성기**를 고릅니다.
화면 위쪽에 탭이 다섯 개 있습니다.

| 탭 | 여기서 하는 일 |
|---|---|
| **열람** | 이용 순서·FAQ·이 매뉴얼을 봅니다. 처음이면 여기부터 |
| **수정** | `request.txt` 에 만들고 싶은 자동화를 한 줄로 적습니다 |
| **테스트** | 모의 실행 / 실제 실행 버튼이 있습니다 |
| **회원관리** | 고객에게 납품하실 때 쓰는 목록입니다 |
| **설정** | 쓰는 AI 모델, AI 표시 켜고 끄기, n8n 주소 |

### 순서

1. **수정** 탭에서 `request.txt` 를 엽니다. 안내 줄 아래에 이렇게 한 줄로 적습니다.

   > 매일 아침 9시에 구글시트 매출 탭을 읽어 Claude로 세 줄 요약해 슬랙 #report 채널에 보내줘

   **언제 시작하고 → 어디서 가져와 → 무엇을 하고 → 어디로 보내는지** 네 가지를 넣으세요.
   막연하게 적으면 막연한 워크플로가 나옵니다. 저장을 누릅니다.

2. **테스트** 탭에서 **모의 실행**을 먼저 누릅니다. AI 를 부르지 않아 **비용이 들지 않고**,
   결과 파일이 어떤 모양인지 그대로 볼 수 있습니다.

3. 형태가 마음에 들면 **실제 실행**을 누릅니다. 1분쯤 걸리고 비용은 한 번에 수십 원 수준입니다.

4. 결과 줄의 색을 봅니다.

   - **초록(성공)** — 검사를 모두 통과했습니다
   - **노랑(경고)** — 파일은 만들어졌지만 손볼 곳이 있습니다. `plan.md` 를 열어 확인하세요
   - **빨강(실패)** — 만들지 못했습니다. 요구를 더 구체적으로 적어 다시 해 보세요

5. 만들어진 파일을 내려받아 3장부터 이어갑니다.

## 3장. 받으신 파일

| 파일 | 무엇 |
|---|---|
| `workflow.json` | n8n 에 넣는 파일. 이 안에 순서가 들어 있습니다 |
| `setup_guide.md` | 설치 순서. **이 파일을 보면서 따라 하시면 됩니다** |
| `plan.md` | 각 상자가 무슨 일을 하는지 설명. 나중에 고치실 때 보세요 |
| `test_payload.json` | (있을 때만) 테스트로 보내 볼 예시 자료 |

`workflow.json` 을 메모장으로 열어 보면 알 수 없는 글자가 잔뜩 있습니다. **고치지 마세요.**
한 글자만 틀려도 n8n 이 못 읽습니다. 고칠 일은 n8n 화면 안에서 합니다.

**이 파일에는 비밀번호나 API 키가 들어 있지 않습니다.** 메일로 주고받아도 괜찮습니다.

## 4장. n8n 준비하기

이미 설치가 되어 있다면 5장으로 넘어가세요.

### 방법 1. 클라우드 (가장 쉬움)

[n8n.io](https://n8n.io) 에서 가입하면 설치 없이 바로 씁니다. 월 이용료가 있습니다.
컴퓨터를 계속 켜 둘 필요가 없고, 밤에도 자동으로 돕니다. 처음이라면 이쪽을 권합니다.

### 방법 2. 내 컴퓨터에 설치 (Docker)

Docker Desktop 을 먼저 설치하고, 터미널(명령 프롬프트)에 아래를 붙여넣습니다.

```bash
docker run -it --rm -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

브라우저에서 `http://localhost:5678` 을 엽니다.

⚠️ **이 창을 닫으면 자동화가 멈춥니다.** 컴퓨터를 끄면 그동안은 돌지 않습니다.
매일 아침 돌아야 하는 일이라면 클라우드나 항상 켜 두는 서버가 낫습니다.

### 처음 접속하면

이메일과 비밀번호를 정해 계정을 만듭니다. 내 컴퓨터에 설치한 경우 이 계정은
이 컴퓨터에만 있습니다. **비밀번호를 적어 두세요.** 잊으면 되찾기가 번거롭습니다.

## 5장. 워크플로 넣기 (5분)

1. n8n 화면 왼쪽 위 **Workflows** 를 누릅니다.
2. 오른쪽 위 **⋯**(점 세 개) → **Import from File**.
3. 받으신 `workflow.json` 을 고릅니다.
4. 상자와 화살표가 화면에 나타납니다. 오른쪽 위 **Save** 를 누릅니다.

상자에 ⚠️ 표시가 보여도 정상입니다. **"계정을 아직 연결하지 않았다"** 는 뜻이고, 다음 장에서 합니다.

---

## 6장. 계정 연결하기 (가장 오래 걸립니다)

워크플로가 구글시트나 슬랙을 쓰려면, **"이 계정을 써도 좋다"** 고 한 번 허락해 줘야 합니다.
이것을 **credential(자격 증명)** 이라고 합니다.

### 하는 법

1. ⚠️ 가 붙은 상자를 **두 번 클릭**합니다.
2. 맨 위 **Credential to connect with** 칸에서 **Create New** 를 고릅니다.
3. 화면 안내대로 로그인하거나 키를 넣습니다.
4. 저장하면 ⚠️ 가 사라집니다.

받으신 `setup_guide.md` 에 **그 워크플로에 실제로 필요한 것만** 골라 적혀 있습니다.
거기 적힌 순서대로 하시면 됩니다.

### 서비스별 요령

| 서비스 | 요령 |
|---|---|
| **구글시트 / Gmail** | 구글 계정으로 로그인하는 창이 뜹니다. "안전하지 않은 앱" 경고가 나와도 본인이 만든 연결이면 계속 진행합니다 |
| **슬랙** | 토큰(`xoxb-` 로 시작)을 붙여넣습니다. **그리고 채널에서 `/invite @봇이름` 으로 봇을 초대해야 합니다.** 이걸 빼먹는 경우가 가장 많습니다 |
| **텔레그램** | 텔레그램에서 `@BotFather` 에게 `/newbot` 을 보내 봇을 만들고 토큰을 받습니다. **봇에게 아무 메시지나 한 번 보내야** 봇이 나에게 말을 걸 수 있습니다 |
| **노션** | notion.so/my-integrations 에서 만들고, **대상 데이터베이스 페이지 오른쪽 위 ⋯ → 연결 추가**로 붙여야 보입니다 |
| **Claude** | Header Auth 를 만들고 Name 칸에 정확히 `x-api-key`, Value 칸에 콘솔에서 받은 키를 넣습니다 |

### 여기 넣는 비밀번호는 어디 저장되나요

**n8n 안에만 저장됩니다.** 워크플로를 만들어 드린 쪽에도, 이 파일에도 남지 않습니다.
그래서 **직접 넣으셔야 합니다.** 비밀번호나 키를 메일·카톡으로 보내 달라는 요청은 받아들이지 마세요.

## 7장. 값 채우기

계정을 연결했으면 이제 "어느 시트", "어느 채널" 인지 정합니다.
`[ ]` 대괄호로 표시된 칸이 **직접 채우셔야 하는 곳**입니다.

| 표시 | 어디서 찾나요 |
|---|---|
| `[스프레드시트 ID를 넣으세요]` | 구글시트 주소창 `.../spreadsheets/d/` **뒤부터 다음 `/` 앞까지** 긴 글자 |
| `[채팅 ID]` | 텔레그램 `@userinfobot` 에게 말을 걸면 알려 줍니다 |
| `[데이터베이스 ID]` | 노션 데이터베이스 주소의 긴 글자 부분 |
| `[API 주소]` | 연동할 서비스가 알려 준 주소 |

`={{ ... }}` 로 시작하는 칸은 **앞 상자에서 넘어온 값을 가져오는 자리**입니다. 손대지 마세요.
예를 들어 `={{ $json.summary }}` 는 "앞에서 만든 요약을 여기 넣어라" 라는 뜻입니다.

## 8장. 테스트 — 켜기 전에 꼭

**바로 켜지 마세요.** 한 번 돌려 보고 결과를 확인한 뒤 켭니다.

1. 오른쪽 아래 **Test workflow** 를 누릅니다.
2. 상자가 하나씩 초록색으로 바뀝니다.
3. 상자를 클릭하면 **그 단계에서 무슨 자료가 나왔는지** 볼 수 있습니다.

### 빨간 상자가 나오면

빨간 상자를 클릭하면 아래에 이유가 나옵니다. 흔한 것들:

| 메시지 | 뜻 | 조치 |
|---|---|---|
| `401` / `Unauthorized` | 계정 연결이 안 됐거나 키가 틀림 | 6장을 다시 |
| `404` / `Not Found` | 시트 ID·채널 이름이 틀림 | 7장의 값을 확인 |
| `403` / `Forbidden` | 권한이 없음 | 그 계정에 편집 권한이 있는지, 봇을 채널에 초대했는지 |
| `not_in_channel` | 슬랙 봇이 채널에 없음 | 채널에서 `/invite @봇이름` |
| 아무 일도 안 일어남 | 가져온 자료가 0건 | 시트에 자료가 있는지, 탭 이름이 맞는지 |

**빨간 상자가 하나도 없고, 슬랙이나 메일에 실제로 도착한 것을 확인한 뒤**에 다음으로 갑니다.

### 웹훅으로 시작하는 워크플로라면

시작 상자를 열면 **Test URL** 이 있습니다. 그 주소로 자료를 보내면 워크플로가 돕니다.
`test_payload.json` 이 그 예시 자료입니다. 연동하실 서비스(결제·폼 등)의 설정 화면에
이 주소를 넣으시면 됩니다.

⚠️ 테스트를 마치고 **Production URL** 로 바꿔야 실제로 계속 돕니다. Test URL 은 한 번만 받습니다.

## 9장. 켜기

오른쪽 위 **Inactive** 스위치를 눌러 **Active** 로 바꿉니다. 이제 정해진 때에 알아서 돕니다.

### 잘 돌고 있는지 확인

왼쪽 **Executions** 에 실행 기록이 쌓입니다.

- **초록** 정상
- **빨강** 실패 — 클릭해서 어느 상자에서 멈췄는지 봅니다
- **기록이 없음** 아직 시작 조건이 안 됐거나, 워크플로가 꺼져 있습니다

**처음 일주일은 하루 한 번 들어와서 확인하세요.** 자동화는 조용히 실패할 수 있습니다.
"어제부터 슬랙에 안 왔는데 몰랐다" 가 가장 흔한 사고입니다.

## 10장. 자주 묻는 질문

**Q. 시간을 바꾸고 싶어요.**
첫 상자(시계 모양)를 두 번 클릭하고 시간을 고친 뒤 Save 를 누릅니다.

**Q. 슬랙 채널을 바꾸고 싶어요.**
슬랙 상자를 열고 채널 이름을 고칩니다. **새 채널에도 봇을 초대**해야 합니다.

**Q. 중간에 한 단계를 빼고 싶어요.**
그 상자를 클릭하고 **D** 키를 누르면 "사용 안 함"이 됩니다. 지우는 것보다 안전합니다.
앞뒤 화살표가 자동으로 이어집니다.

**Q. 실수로 망가뜨렸어요.**
받으신 `workflow.json` 을 5장대로 다시 넣으면 처음 상태로 돌아옵니다.
**이 파일을 지우지 말고 보관하세요.**

**Q. 컴퓨터를 꺼도 도나요?**
클라우드면 돕니다. 내 컴퓨터에 설치했으면 컴퓨터가 켜져 있고 n8n 창이 떠 있어야 합니다.

**Q. 비용이 드나요?**
n8n 자체는 내 컴퓨터에 설치하면 무료입니다. 클라우드는 월 이용료가 있습니다.
Claude 를 쓰는 상자가 있으면 호출한 만큼 Anthropic 에 요금이 붙습니다(보통 건당 수십~수백 원).

**Q. 슬랙 대신 카카오톡으로 받고 싶어요.**
카카오톡은 개인 메시지를 자동으로 보내는 공식 창구가 없습니다.
카카오톡 채널(비즈니스)이 있으면 알림톡으로 가능하지만 별도 신청이 필요합니다. 만들어 주신 분께 문의하세요.

**Q. 다른 자동화도 추가할 수 있나요?**
같은 n8n 안에 워크플로를 여러 개 둘 수 있습니다. 새 `workflow.json` 을 받아 5장대로 넣으면 됩니다.

**Q. 이 자동화는 AI 가 만들었나요?**
워크플로 **설계 초안**을 생성형 AI 로 만들고, 사람이 확인해 고친 것입니다.
함께 받으신 문서에 그 사실이 표시되어 있습니다.

## 11장. 안전하게 쓰기

- **비밀번호·키를 누구에게도 보내지 마세요.** n8n 화면에 직접 넣습니다.
  대신 넣어 드리겠다는 제안은 정중히 거절하셔도 됩니다.
- **자동으로 보내는 메시지는 켜기 전에 꼭 테스트하세요.** 고객에게 잘못된 메일이 100통 나가면
  되돌릴 수 없습니다.
- **사람이 읽고 결정해야 하는 일은 자동화하지 마세요.** 환불 승인, 계약 조건, 민감한 응대는
