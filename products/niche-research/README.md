# 12. 니치 리서치 (niche-research)

유튜브에서 **공급이 비어 있는 자리**를 찾는 수집·분석기입니다.

> **이 도구는 "터진 영상 따라 만들기" 를 하지 않습니다.**
> 개별 영상이나 채널을 추천하지 않고, 키워드와 포맷 단위의 지표만 봅니다.
> 아래 '노아AI 전례와 설계 차이' 를 꼭 읽어 주세요.

---

## 1. 무엇을 하나

```
매일 1회 수집  →  쌓인 자료로 분석  →  공백 큰 키워드에 포맷 아이디어
collector.py       analyzer.py          suggest.py
```

| 파일 | 하는 일 |
|---|---|
| `collector.py` | 키워드마다 최근 30일 영상·채널 지표를 모아 SQLite 에 쌓습니다 |
| `analyzer.py` | 다섯 지표를 계산해 보고서(md + html)를 만듭니다 |
| `suggest.py` | 공백 큰 키워드에 포맷 아이디어 3개씩 |

---

## 2. 왜 매일 돌려야 하나 — 시계열은 직접 쌓아야 합니다

**유튜브 API 는 "어제 조회수가 몇이었는지" 를 알려 주지 않습니다.** 지금 값만
줍니다. 그래서 "이 키워드가 뜨고 있는지" 를 알려면 매일 한 번씩 찍어 두는 수밖에
없습니다.

- 하루 이틀은 아무것도 안 보입니다 (정상입니다)
- **3일치**부터 지표가 계산되고
- **2주쯤** 지나야 추이가 보입니다

이게 이 상품에서 가장 정직하게 말해야 하는 부분이고, 동시에 **경쟁 도구와 다른
지점**이기도 합니다. 뷰트랩(월 20만 원)·블링($999)이 비싼 이유의 상당 부분이
이 축적입니다. 여기서는 본인 키워드만 본인 컴퓨터에 쌓습니다.

### 매일 돌리는 법

```bash
# cron
0 6 * * *  cd /path/to/niche-research && /usr/bin/python3 collector.py run >> collect.log 2>&1
```

n8n 이면 Schedule Trigger(매일 06:00) → Execute Command 두 노드입니다.

## 3. 설치

```bash
pip install -r requirements.txt     # 루트 requirements.txt 로도 됩니다
cp .env.example .env
```

| 키 | 필요한가 |
|---|---|
| `YOUTUBE_API_KEY` | 실제 수집에 필요. **무료**입니다 |
| `ANTHROPIC_API_KEY` | 해설 5줄에만. 없으면 규칙으로 씁니다 |

키가 없어도 **샘플 자료로 전체 흐름을 볼 수 있습니다.**

```bash
python collector.py run --fixture      # 유튜브를 부르지 않고
python analyzer.py run --demo --dry-run
python suggest.py run --demo --dry-run
```

### 유튜브 키 받기 (10분, 무료)

1. console.cloud.google.com → 새 프로젝트
2. API 및 서비스 → 라이브러리 → **YouTube Data API v3** 사용 설정
3. 사용자 인증 정보 → API 키 만들기
4. `.env` 의 `YOUTUBE_API_KEY` 에 넣습니다

## 5. 다섯 지표

| 지표 | 계산 | 어떻게 읽나 |
|---|---|---|
| **공백 지수** | 중앙값 조회수 ÷ 신규 영상 수 | 높을수록 보는 사람 대비 만드는 사람이 적다 |
| **소형 채널 성과율** | 구독자 1만 이하 채널 영상 중 조회수가 구독자의 5배 이상인 비율 | **가장 중요합니다.** 작은 채널이 뚫고 있으면 지금 들어갈 만하다 |
| **공급 증가율** | 최근 주 ÷ 직전 주 신규 영상 수 | 남들도 들어오고 있는지 |
| **쇼츠 vs 롱폼** | 3분 이하 비중과 각각의 중앙값 조회수 | 어떤 포맷이 도는 시장인지 |
| **채널 성장률** | 7일 구독자 증가율 중앙값 | 시장 전체가 커지는 중인지 |

### 왜 평균이 아니라 중앙값인가

영상 하나가 크게 터지면 평균이 통째로 끌려갑니다. 그 하나는 **시장의 모양이
아니라 예외**입니다. 중앙값은 그런 것에 흔들리지 않습니다.

### 소형 채널 성과율을 제일 먼저 보세요

공백 지수가 높아도 큰 채널만 잘되는 곳이면 이미 자리가 굳은 곳입니다.
**구독자 1천 명짜리가 5천 회를 찍고 있다면** 거기는 아직 열려 있습니다.

## 7. 노아AI 전례와 설계 차이

### 무슨 일이 있었나

노아AI(주언규)는 "터진 영상을 찾아 따라 만들라" 는 방향의 도구였습니다.
**표절 논란이 일었고 2023년 2월에 서비스를 닫고 전액 환불했습니다.**

문제는 기능이 아니라 **방향**이었습니다. "이 영상이 잘됐으니 비슷하게 만드세요"
라는 제안 자체가, 쓰는 사람을 표절 쪽으로 밀어붙입니다.

### 이 도구가 하지 않는 것

- ❌ **특정 영상을 집어 "이걸 따라 만드세요"**
- ❌ 조회수 높은 영상 목록 보여 주기
- ❌ 채널 이름·영상 제목을 보고서에 싣기
- ❌ "이 채널의 포맷을 복제하세요"
- ❌ 조회수 예측

### 어떻게 막았나 — 부탁이 아니라 구조로

| 막는 곳 | 어떻게 |
|---|---|
| **입력** | Claude 에게 영상 제목·채널명을 **주지 않습니다.** 키워드와 숫자뿐입니다 |
| 프롬프트 | "따라 만들라는 제안을 하지 마라" 를 명시 |
| **출력 검사** | 나온 글에 '따라 만드', '베끼', '이 채널처럼' 같은 말이 있으면 **그 줄을 버리고** 규칙 문장으로 바꿉니다 |
| 보고서 | 영상 목록 자체를 만들지 않습니다 |

프롬프트로만 막으면 언젠가 새어 나갑니다. **없는 것은 따라 만들 수 없습니다.**
그래서 입력에서부터 뺐습니다.

### 그럼 무엇을 주나

**시장의 모양**입니다. "이 키워드는 보는 사람 대비 만드는 사람이 적고, 작은
채널도 뚫리고 있고, 쇼츠 쪽이 도는 시장이다" 까지입니다.

무엇을 만들지는 사람이 정합니다. 그게 이 도구가 팔 수 있는 최대치이고,
그 이상을 파는 도구는 오래가지 못합니다(CLAUDE.md §3-1).

## 8. 한계

- **API 가 주는 것만 봅니다.** 검색량·클릭률·시청 지속 시간은 API 로 못 받습니다
- `search.list` 는 유튜브의 검색 결과라, 같은 키워드라도 날마다 조금씩 다릅니다
- 조회수는 영상이 올라온 지 얼마나 됐는지에 크게 좌우됩니다.
  최근 30일로 자른 이유이지만 그래도 완전히 공평하지는 않습니다
- **키워드를 잘 고르는 것이 지표보다 중요합니다.** 내가 만들 수 없는 주제의
  공백은 내 공백이 아닙니다
- 지표가 좋아도 안 될 수 있고, 나빠도 될 수 있습니다. 이 도구는 **어디를 볼지**
  좁혀 줄 뿐입니다

---

## 9. 판매 문구 초안

> 유튜브에서 **공급이 비어 있는 자리**를 찾아 드립니다.
>
> - 키워드마다 최근 30일 영상·채널 지표를 매일 쌓아 **시계열**로 봅니다
> - 공백 지수와 **소형 채널 성과율**로 "지금 들어갈 만한 자리" 를 좁힙니다
> - 쇼츠·롱폼 어느 쪽이 도는 시장인지 나눠 봅니다
>
> **특정 영상을 따라 만들라고 하지 않습니다.** 영상 제목도 채널 이름도 보고서에
> 싣지 않습니다. 시장의 모양만 보여 드리고, 무엇을 만들지는 사장님이 정하십니다.
>
> 유튜브 API 는 무료입니다. 조회수나 구독자 증가를 약속하지 않습니다.
