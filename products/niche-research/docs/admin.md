# 관리자 매뉴얼 — 12. 니치 리서치

이 상품을 팔고 운영하는 사람을 위한 문서입니다.

---

## 1장. 이 상품이 파는 것

**시간이 쌓인 자료**입니다. 코드가 아니라요.

유튜브 API 는 지금 값만 줍니다. "지난주에 이 키워드가 어땠는지" 를 물을 방법이
없습니다. 그래서 매일 찍어 두는 것 말고는 방법이 없고, **그 축적이 이 상품의
값어치**입니다.

뷰트랩이 월 20만 원, 블링이 $999 를 받는 이유의 상당 부분이 여기 있습니다.
그들은 몇 년 치를 쌓아 두었습니다.

### 그래서 가격을 이렇게 잡습니다

| 플랜 | 값 | 무엇 |
|---|---|---|
| 프로그램 | 90,000원 | 파일 일체, 본인 컴퓨터에서 본인 키워드만 |
| 월 구독 | 9,900원 | 내가 쌓은 자료를 보는 권한 (CLAUDE.md §5) |

**월 구독이 본체입니다.** 프로그램만 팔면 한 번으로 끝나고, 고객은 2주를 기다려야
쓸 만해집니다. 그 2주 동안 이탈합니다.

구독으로 팔면 첫날부터 쌓인 자료를 보여 줄 수 있습니다. 대신 **내가 매일 수집을
돌려야 하고**, 그게 이 사업의 실제 일거리입니다.

## 2장. 세 조각

```
collector.py   매일 1회. 유튜브에서 긁어 SQLite 에 쌓는다
analyzer.py    쌓인 것을 다섯 지표로 바꾼다
suggest.py     공백 큰 키워드에 포맷 아이디어
```

### collector — 쿼터가 전부입니다

하루 10,000 유닛인데 `search.list` 한 번이 **100 유닛**입니다.
키워드 하나에 102 유닛이라 하루 80개가 상한입니다.

`niche/quota.py` 가 코드로 막습니다. 넘치면 버리지 않고 다음 날로 넘기고,
**밀린 것이 다음 날 맨 앞에 섭니다.**

넘기면 그날 남은 호출이 전부 거절됩니다. 수집이 하루 빠지면 시계열에 구멍이
나고, 이 상품은 시계열이 전부입니다. 그래서 강제입니다.

### analyzer — 왜 중앙값인가

영상 하나가 터지면 평균이 통째로 끌려갑니다. 그 하나는 시장의 모양이 아니라
예외입니다. 고객이 "왜 평균이 아니냐" 물으면 이렇게 답하세요.

### suggest — 표절을 입력에서 막습니다

Claude 에게 **키워드와 숫자만** 줍니다. 영상 제목도 채널 이름도 주지 않습니다.
줄 수 있는데 안 줍니다. 없는 것은 따라 만들 수 없기 때문입니다.

나온 글도 한 번 더 검사합니다. '따라 만드', '베끼', '이 채널처럼' 같은 말이
있으면 그 줄을 버리고 규칙 문장으로 갈아 끼웁니다.

## 3장. 노아AI 전례 — 상담에서 꼭 하세요

노아AI(주언규)는 "터진 영상 찾아 따라 만들기" 로 표절 논란을 겪고 2023년 2월에
서비스를 닫고 전액 환불했습니다.

**기능이 문제가 아니라 방향이 문제였습니다.** "이 영상이 잘됐으니 비슷하게
만드세요" 는 쓰는 사람을 표절 쪽으로 밉니다.

상담에서 이 이야기를 먼저 꺼내세요. 세 가지가 따라옵니다.

1. **차별점이 분명해집니다** — "우리는 영상 목록을 안 보여 줍니다"
2. **기대를 맞출 수 있습니다** — "터질 영상을 찍어 주는 도구가 아닙니다"
3. **신뢰가 생깁니다** — 남의 실패를 알고 만든 물건이라는 게 보입니다

"터진 영상 목록 보여 주는 기능 넣어 주세요" 라는 요청이 옵니다. **거절하세요.**
그게 이 상품의 정체성이고, 넣는 순간 노아AI 와 같은 물건이 됩니다.

## 4장. 운영 — 매일 돌리기

```bash
0 6 * * *  cd /path/to/niche-research && /usr/bin/python3 collector.py run >> collect.log 2>&1
```

### 매주 확인할 것

```bash
python collector.py status
```

- **빠진 날이 있는지** — 있으면 추이가 왜곡됩니다. 화면이 알려 줍니다
- 밀린 키워드가 쌓이고 있는지 — 키워드를 줄이거나 쿼터 증설을 신청하세요
- DB 크기 — 키워드 80개면 하루 4천 줄쯤, 1년에 150만 줄쯤 됩니다.
  SQLite 가 감당하지만 1년쯤 지나면 오래된 스냅샷을 주 단위로 줄이세요

### 키워드 고르기 — 고객과 같이 하세요

이 상품의 실제 값어치는 여기서 나옵니다.

- 고객이 **실제로 만들 수 있는** 주제만 (남의 공백은 내 공백이 아닙니다)
- 너무 넓은 말은 빼세요: '요리' 말고 '자취 요리 10분'
- 10~20개로 시작하세요. 80개를 채우면 보기만 힘듭니다

## 6장. 문제가 생겼을 때

**403 이 납니다**
쿼터를 다 썼거나 API 를 안 켰습니다. `collector.py status` 로 쓴 유닛을 보세요.

**지표가 이상합니다**
며칠치가 쌓였는지 보세요. 3일 미만이면 추이 지표는 뜻이 없습니다.
보고서에도 그렇게 적힙니다.

**같은 키워드인데 날마다 영상이 다릅니다**
`search.list` 는 유튜브의 검색 결과입니다. 날마다 조금씩 다릅니다.
그래서 하루치가 아니라 추이를 봅니다.

**소형 채널 성과율이 0% 입니다**
구독자 1만 이하 채널의 영상이 없었다는 뜻입니다. 큰 채널만 도는 자리입니다.
보고서에 그렇게 적힙니다.

**DB 가 커집니다**
1년쯤 지나면 오래된 스냅샷을 주 단위로 줄이세요. 일 단위가 필요한 것은
최근 3개월이면 충분합니다.

## 7장. 정직하게 말해야 하는 것

1. **2주는 기다려야 합니다.** 설치 당일에는 볼 것이 없습니다
2. **조회수를 예측하지 않습니다.** 어디를 볼지 좁혀 줄 뿐입니다
3. **API 가 주는 것만 봅니다.** 검색량·클릭률·시청 지속 시간은 못 받습니다
4. **지표가 좋아도 안 될 수 있습니다.** 만드는 사람이 그 주제를 아는지가
   지표보다 중요합니다
5. **영상 목록은 앞으로도 안 넣습니다.** 이건 기능 부족이 아니라 설계입니다

## 8장. 파는 법

### 이 상품을 사는 사람

- 유튜브를 시작하려는데 **어느 주제로 할지 못 정한** 사람
- 이미 하고 있는데 **다음 주제를 찾는** 사람
- 뷰트랩(월 20만 원)·블링($999)이 비싸다고 느끼는 사람

세 번째가 핵심입니다. CLAUDE.md §4-5 가 가리키는 가격 공백입니다.
**월 9,900원**이면 API 가 무료라 원가가 거의 없습니다.

### 상담에서 먼저 말할 것

1. **"2주는 기다리셔야 합니다"** — 이걸 먼저 말하면 환불이 줄어듭니다.
   나중에 알게 되면 "왜 안 알려 줬냐" 가 됩니다
2. **"터진 영상을 찍어 주는 도구가 아닙니다"** — 노아AI 이야기를 하세요
3. **"조회수를 약속하지 않습니다"**

### 시연 순서

```
python analyzer.py run --demo --dry-run      # 30초. 0원
```

샘플 자료로 보고서를 만들어 화면을 같이 봅니다. "이런 게 2주 뒤에 사장님
키워드로 나옵니다" 라고 하시면 됩니다.

### 무료 베타로 시작하세요

CLAUDE.md §5 의 3순위 계획대로, 무료 베타 100명을 먼저 받으세요.
그동안 내가 자료를 쌓고, 쌓인 자료가 곧 상품이 됩니다.

베타에서 얻을 것은 후기가 아니라 **키워드 목록**입니다. 사람들이 어떤 주제를
궁금해하는지 알게 됩니다.

## 9장. 앞으로 손볼 만한 곳

지금 없지만 있으면 좋을 것들입니다. **다만 5명에게 팔아 본 뒤에 만드세요.**

- ❌ 영상 목록·순위표
- ❌ 조회수 예측
- ❌ 경쟁 채널 추적

세 번째는 요청이 자주 옵니다. 거절하세요. 특정 채널을 따라가는 순간
이 도구의 방향이 바뀝니다.
