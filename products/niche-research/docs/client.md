# 고객용 매뉴얼 — 니치 리서치

유튜브에서 **공급이 비어 있는 자리**를 찾는 도구입니다.

---

## 1장. 먼저 알아 두실 것 — 2주가 필요합니다

유튜브는 "지난주에 이 키워드가 어땠는지" 를 알려 주지 않습니다. **지금 값만**
줍니다. 그래서 이 도구는 매일 한 번씩 찍어서 직접 쌓습니다.

```
설치 당일     볼 것이 거의 없습니다 (정상입니다)
3일차         지표가 계산되기 시작합니다
2주차         "이 키워드가 뜨고 있구나" 가 보이기 시작합니다
```

**하루 이틀 보고 판단하지 마세요.** 그건 이 도구가 할 수 있는 일이 아닙니다.

먼저 어떤 모양인지 보고 싶으시면 샘플 자료로 돌려 보세요.

```
python analyzer.py run --demo --dry-run
```

숫자는 지어낸 것이지만 화면은 실제와 같습니다.

---

## 2장. 매일 한 번 돌리기

```
python collector.py run
```

컴퓨터가 켜져 있어야 합니다. 자동으로 돌리시려면 담당자에게 말씀하세요
(cron 이나 n8n 으로 걸어 드립니다).

**하루 빠지면 그날 자료가 비고, 추이가 조금 흔들립니다.** 며칠 빠져도 망가지지는
않지만 매일 도는 편이 낫습니다.

```
python collector.py status
```

지금까지 며칠치가 쌓였는지, 빠진 날이 있는지 알려 줍니다.

---

## 3장. 키워드 고르기 — 여기가 제일 중요합니다

`keywords.txt` 에 한 줄에 하나씩 적습니다.

### 세 가지만 지키세요

1. **내가 만들 수 있는 주제만** — 남의 공백은 내 공백이 아닙니다.
   전기차 이야기를 못 하는데 전기차 공백을 찾아 봐야 소용없습니다
2. **너무 넓은 말은 빼세요** — '요리' 말고 '자취 요리 10분'.
   넓은 말은 온갖 영상이 섞여 지표가 흐려집니다
3. **10~20개로 시작하세요** — 하루 80개까지 되지만, 많이 넣는다고 더 알게
   되지 않습니다. 보기만 힘들어집니다

넘치면 다음 날로 넘어갑니다. 버려지지 않습니다.

---

## 4장. 보고서 읽는 법

```
python analyzer.py run
```

`outputs/` 에 `.md` 와 `.html` 이 생깁니다. HTML 을 브라우저로 열면 차트가 있습니다.

### 다섯 지표

| 지표 | 무슨 뜻 |
|---|---|
| **공백 지수** | 높을수록 보는 사람 대비 만드는 사람이 적다 |
| **소형 채널 성과율** | 작은 채널이 뚫고 있는 비율. **제일 먼저 보세요** |
| 공급 증가율 | 남들도 들어오고 있는지 |
| 쇼츠 비중 | 어떤 포맷이 도는 시장인지 |
| 채널 성장률 | 시장 전체가 커지는 중인지 |

### 소형 채널 성과율을 제일 먼저 보세요

공백 지수가 높아도 **큰 채널만 잘되는 곳**이면 이미 자리가 굳은 곳입니다.

구독자 1천 명짜리가 5천 회를 찍고 있다면 거기는 아직 열려 있습니다.
표에서 🟢 가 붙은 키워드가 그런 곳입니다.

### 며칠치인지 항상 확인하세요

보고서 맨 위에 "모은 날수" 가 적혀 있습니다. 3일 미만이면 추이 지표는
아직 뜻이 없고, 보고서도 그렇게 알려 줍니다.

---

## 5장. 포맷 아이디어

```
python suggest.py run --top 5
```

공백이 큰 키워드 5개에 대해 **포맷 아이디어 3개씩**을 냅니다.

포맷 아이디어란 무엇을 찍을지가 아니라 **어떤 틀로 만들지**입니다.
"하나를 끝까지 따라가는 기록", "실패한 것만 모아 보기" 같은 식입니다.

### 이 아이디어는 어떻게 나온 건가요

**키워드 이름과 숫자만 보고** 나온 것입니다. AI 에게 영상 제목도 채널 이름도
주지 않습니다. 남의 영상을 보고 만든 것이 아닙니다.

### 쓰는 법

- **틀만 가져가시고 내용은 본인 것으로 채우세요**
- 세 개 중 하나만 골라 4주만 해 보세요. 동시에 하면 다 어중간해집니다
- 마음에 안 들면 지표를 다시 보세요. 아이디어보다 지표가 중요합니다

---

## 6장. 이 도구가 하지 않는 것

- ❌ **"이 영상을 따라 만드세요"** — 하지 않습니다
- ❌ 조회수 높은 영상 목록 — 보여 주지 않습니다
- ❌ 채널 이름·영상 제목 — 보고서에 싣지 않습니다
- ❌ 조회수 예측 — 하지 않습니다

왜 안 하는지는 담당자에게 물어보세요. 짧게 말하면, 그 방향으로 만든 도구가
표절 논란으로 문을 닫은 전례가 있습니다. 같은 길을 가지 않으려고 **입력에서부터**
빼 두었습니다.

이 도구가 주는 것은 **시장의 모양**입니다. 무엇을 만들지는 사장님이 정하십니다.

---

## 7장. 관리 화면에서 보기

담당자가 **관리 화면**(통합 관리자 대시보드)을 열어 드렸다면, 브라우저에서
이용 순서·매뉴얼·설정값을 한 번에 보실 수 있습니다.

| 탭 | 보시는 것 |
|---|---|
| **열람** | 이용 순서, 자주 묻는 질문, 이 매뉴얼 |
| **수정** | `keywords.txt` — 여기서 키워드를 고치셔도 됩니다 |
| **테스트** | **모의 실행** — 샘플 자료로 보고서를 만들어 봅니다 (0원) |
| **설정** | 어떤 키가 들어 있는지 (값은 보이지 않습니다) |

관리 화면이 없어도 터미널로 다 되십니다. 화면은 보기 편하라고 있는 것입니다.

## 9장. 자주 묻는 질문

**Q. 설치했는데 보고서가 안 나옵니다.**
아직 자료가 없어서입니다. `collector.py run` 을 한 번 돌리고 다시 해 보세요.

**Q. 3일치인데 지표가 이상합니다.**
정상입니다. 추이 지표(공급 증가율·채널 성장률)는 며칠 더 모아야 뜻이 생깁니다.
보고서 맨 위에도 그렇게 적힙니다.

**Q. 같은 키워드인데 날마다 영상 목록이 다릅니다.**
유튜브 검색 결과가 날마다 조금씩 다릅니다. 그래서 하루치가 아니라 추이를 봅니다.

**Q. 공백 지수가 높은데 해 보니 안 됩니다.**
지표는 **어디를 볼지** 좁혀 줄 뿐입니다. 그 주제를 얼마나 아는지, 어떻게
말하는지가 지표보다 큽니다. 이 도구는 그걸 대신해 주지 못합니다.

**Q. 조회수를 예측해 주나요?**
안 합니다. 할 수 있다고 말하는 도구가 있다면 의심하세요.

**Q. 영상 목록을 보여 주는 기능을 넣어 주실 수 있나요?**
넣지 않습니다. 그 방향으로 만든 도구가 표절 논란으로 문을 닫은 전례가 있어서,
처음부터 빼고 설계했습니다.

## 10장. 나오는 것은 모두 초안입니다

보고서의 **해설 5줄**과 **포맷 아이디어**는 AI 가 쓴 **초안**입니다.
숫자는 프로그램이 계산한 값이지만, 그 숫자를 읽어 주는 문장은 초안입니다.

| 무엇 | 누가 만들었나 | 어떻게 쓰나 |
|---|---|---|
| 다섯 지표 숫자 | 프로그램이 계산 | 그대로 믿으셔도 됩니다 |
| 해설 5줄 | AI 초안 | 참고만 하세요 |
| 포맷 아이디어 | AI 초안 | **틀만 가져가시고 내용은 본인 것으로** |

초안을 그대로 쓰면 티가 납니다. 그리고 이 도구가 아는 것은 숫자뿐이라,
사장님이 그 분야에 대해 아시는 것이 훨씬 많습니다.

AI 가 쓴 부분에는 문서 끝에 그렇다는 표시가 붙습니다(인공지능기본법).
지우지 마세요.

## 11장. 언제 그만두어야 하나

이 도구를 계속 쓸지 판단하는 기준입니다.

- **한 달을 모았는데 볼 만한 키워드가 없다** → 키워드 목록을 바꾸세요.
  도구 문제가 아니라 고른 키워드 문제일 가능성이 큽니다
- **지표는 좋은데 만들 수가 없다** → 만들 수 있는 주제로 목록을 다시 짜세요
- **보고서를 안 열게 된다** → 키워드가 너무 많은 경우가 많습니다. 10개로 줄이세요

지표를 보는 것 자체가 목적이 되면 안 됩니다. **만들기 시작하는 것**이 목적입니다.
